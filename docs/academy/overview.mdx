# Netuno Overview

## Introduction

Welcome to **Netuno**!

We know that adopting new technologies can be a challenge due to the large number of options available on the market. Netuno was created to solve this problem, simplifying development by bringing together the best tools and solutions in one place.

We are a platform focused on productivity. One of the biggest accelerators in Netuno is the absence of time-consuming compilation or build processes.

We offer a fluid and flexible development experience to use various programming languages integrated with the main databases.

Netuno's **low-code** environment is polyglot, allowing you to choose the language that best suits the specific need of each service.

> Our motto is simple: **with fewer lines of code, you do more.**

## Productivity at Work

Netuno eliminates development bottlenecks through its pillars:

-  **Safe Choice of Tools:** We reduce your research and initial setup time. Netuno already comes structured with today's most efficient solutions.

- **Polyglot Flexibility:** Work with the programming language of your preference within the same ecosystem, using a wide variety of ready-made resources for each specific Web Service.

- **Rapid Web Service Creation:** The low-code approach allows you to develop complex REST APIs with agility.

- **Uncomplicated Integration:** Develop the backend quickly and connect it easily to any frontend, mobile applications, corporate portals, or online stores.

- **Real-Time Updates (Hot Reload):** The speed of development is also due to not needing to restart the server. In the Netuno ecosystem, there are no compilations and restarts. Code changes are immediate and in real time.

* **Development Agility:** Test your APIs simultaneously while you develop. Save the code in Netuno and make the request in your frontend at the same moment.

* **Focus on Business Logic:** Let Netuno handle the basic infrastructure and connections. Focus on how your system can deliver more value to the end user.

## Backoffice

The platform simplifies the development journey by unifying the creation of form interfaces with the automatic structuring of the database.

This approach drastically reduces the learning curve, allowing developers to focus on business logic while the platform manages the infrastructure.

This eliminates the need to write manual SQL scripts or create repetitive CRUD (Create, Read, Update, Delete) screens.


When you design a form, you are simultaneously modeling your database and generating a complete administrative interface.

Netuno delivers a ready-to-use administrative ecosystem, which includes:

| Feature | Description |
| :--- | :--- |
| **Relationships** | Automatic management of diagrams, foreign keys, and links between tables. |
| **Advanced Search** | Refined filters for quick location of records. |
| **File Management** | Native components for uploading images and documents. |
| **Export** | Data extraction in formats compatible with reports. |
| **Security** | Access profile control and integrated authentication. |

Netuno is **open-source** and allows you to explore the full potential of the tool for free and collaboratively to carry out complex work with high productivity. [Get started now](/docs/get-started/installation).

## Database

Netuno simplifies data management by unifying the creation of the Backoffice with the database structure. This construction does not require manually writing complex SQL scripts to create tables.

Through the visual interface, you can define fields and relationships, and the platform synchronizes these definitions with the database, automatically generating the administration interface and the data diagram.

## Query

Netuno provides a robust and intuitive database console, allowing developers to interact directly with data in an agile and organized way.

You can save complex or recurring commands for quick access in the future.
The system keeps a history of executed commands, facilitating auditing and retrieval of previous query logic.

The console allows the execution of several commands simultaneously. To separate the instructions and ensure that Netuno interprets each one correctly, use the double semicolon delimiter `;;`.

## Low-code and Polyglot Development


Netuno stands out for its flexible architecture, allowing each project to use multiple programming languages simultaneously.

You can create several independent applications (projects) and, within each one, write services using the most popular market languages supported by Netuno.

The platform automatically identifies which execution engine to use based on the extension of the file created in the server's services folder, for example:

- `.js` - JavaScript
- `.py` - Python
- `.rb` - Ruby
- `.kts` - Kotlin Script
- `.groovy` - Groovy
