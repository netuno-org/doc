## Introduction

Netuno generates CSV files through the [CSV](/docs/library/resources/csv) feature, which provides a low-code abstraction of [Apache Commons CSV](https://commons.apache.org/proper/commons-csv/) for the various programming languages supported by Netuno.

The application that comes with Netuno called **demo** (demonstration application) contains many examples of possible code implementations in various languages, including the demonstration of export to CSV through the `csv` service located at:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/csv`
]} />

## Create a CSV file

To create a CSV file, first you need to initialize a `CSVPrinter` from `Apache Commons CSV`.
To do this, we need to pass the folder name and the file name, as well as the CSV format.
In the example, we will generate the file inside the application's `storage`:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const csvPrinter = _csv.printer(
                  _storage.filesystem("server", "data.csv"),
                  _csv.format("EXCEL")
                )
            `
        },
        {
            lang: 'python',
            code: `
                csv_printer = _csv.printer(
                    _storage.filesystem("server", "data.csv"),
                    _csv.format("EXCEL")
                )
            `
        },
        {
            lang: 'ruby',
            code: `
                csv_printer = _csv.printer(
                    _storage.filesystem("server", "data.csv"),
                    _csv.format("EXCEL")
                )
            `
        },
        {
            lang: 'kotlin',
            code: `
                val csvPrinter = _csv.printer(
                    _storage.filesystem("server", "data.csv"),
                    _csv.format("EXCEL")
                )
            `
        },
        {
            lang: 'groovy',
            code: `
                def csvPrinter = _csv.printer(
                    _storage.filesystem("server", "data.csv"),
                    _csv.format("EXCEL")
                )
            `
        }
    ]}
/>

The supported formats are described [here](https://doc.netuno.org/pt/docs/library/resources/csv/#format).

### Writing

To write rows to the CSV file:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                csvPrinter.printRecord("id", "userName", "firstName", "lastName", "birthday")
                csvPrinter.printRecord(1, "john73", "John", "Doe", 123)
            `
        }
    ]}
/>

### Closing

At the end, you need to close the `CSVPrinter`:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                csvPrinter.close()
            `
        }
    ]}
/>


## Read a CSV file

To read a CSV file, first you need to initialize a `CSVParser` from `Apache Commons CSV`.
To do this, we need to pass the folder name and the file name.
In the example, we will read the file inside the application's `storage`:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const csvParser = _csv.parser(_storage.filesystem("server", "data.csv"))
            `
        }
    ]}
/>

### Rows 

Now it is possible to iterate over the `CSVRecord` from `Apache Commons CSV`, which represent each row of the CSV file:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                for (const record of csvParser) {
                    const columnOne = record.get(0)
                    const columnTwo = record.get(1)
                }
            `
        },
        {
            lang: 'python',
            code: `
                for record in csvParser:
                    columnOne = record.get(0)
                    columnTwo = record.get(1)
            `
        },
        {
            lang: 'ruby',
            code: `
                csvParser.each do |record|
                    columnOne = record.get(0)
                    columnTwo = record.get(1)
                end
            `
        },
        {
            lang: 'kotlin',
            code: `
                for (record in csvParser) {
                    val columnOne = record.get(0)
                    val columnTwo = record.get(1)
                }
            `
        },
        {
            lang: 'groovy',
            code: `
                for (record in csvParser) {
                    def columnOne = record.get(0)
                    def columnTwo = record.get(1)
                }
            `
        },
    ]}
/>

Or get each row with the `getRecord` method from `Apache Commons CSV`.
In this example, the first `get` gets the first row. The second `get` gets the first field/value of that row:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                csvParser.getRecords().get(0).get(0)
            `
        }
    ]}
/>

### Closing

At the end, you need to close the `CSVParser`:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                csvParser.close()
            `
        }
    ]}
/>
