Process custom PDF files.

## Introduction

Netuno generates PDF files with support for images, tables, fonts, and much more, through the [PDF](/docs/library/resources/pdf) feature, which provides a low-code abstraction of [iTextPDF](https://itextpdf.com/) for the various programming languages supported by Netuno.

The application that comes with Netuno called **demo** (demonstration application) contains many examples of possible code implementations in various languages, including the demonstration of PDF export through the `export-pdf` service located at:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-pdf`
]} />

## Initialization

If nothing is defined, it will be generated in the service's data output, for example:

## HTTP Header

To create a service in the REST API that returns a PDF file as data output, you need to add the HTTP protocol's `Content-Type` parameter to the header.

Example of how to set the content as PDF:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("pdf")
            `
        },
    ]}
/>

The `pdf` code is shorthand for:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("application/pdf")
            `
        },
    ]}
/>

## Paragraph

Adds a new paragraph to the document:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    _pdf.paragraph("My text here...")
                        .setFontSize(15)
                )
            `
        },
    ]}
/>

To add a paragraph at a fixed position:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    pdfDocument.add(
                        _pdf.paragraph("My fixed text...")
                            .setFixedPosition(100, 500, 200)
                            .setFontSize(15)
                    )
                )
            `
        },
    ]}
/>

In the code above, in the `setFixedPosition` method, the first parameter is the X position (`100`), the second parameter is the Y position (`500`), and the third parameter is the width (`200`).

**Attention:** if Y is set to the value `0`, it means it stays at the bottom of the page, so to move it up you need to increase the Y value; the higher the Y value, the closer to the top it will appear, but if it is too high beyond the page length, it will not be visible.

> Documentation with all methods of the [iText Paragraph](https://api.itextpdf.com/iText/java/8.0.3/com/itextpdf/layout/element/Paragraph.html) object.

## Table

It is possible to create tables, which allows presenting a data set in a more readable way.

The number of table columns is defined with the parameter: `_pdf.table(numberColumns)`

In the example below, `numberColumns` is the number `1`, that is, one column.

Since we add two cells to the table, the second cell goes to the next row.

Note:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    _pdf.table(1)
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Person")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBorder(_pdf.border("solid", 2))
                                .setBackgroundColor(_pdf.colorRGB(1, 0, 0))
                        )
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Nicole")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBackgroundColor(_pdf.colorGray(0.5))
                        )
                )
            `
        },
    ]}
/>

The `addCell` method allows inserting the cell definitions with their respective content.

> Documentation with all methods of the [iText Cell](https://api.itextpdf.com/iText/java//8.0.3/com/itextpdf/layout/element/Cell.html) object.

## Closing and Saving the Document

The document is only fully saved or generated when the `close` method is called, as follows:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.close()
            `
        },
    ]}
/>

Where the document is generated is defined at initialization, so it is when initializing the document that we define where the final document will be generated, whether in the service's data output (`output`) or in a file.

## Reading a File

To read a PDF document, extracting the text information.

We use the `extract` method, which gets all the PDF file data into a JSON object.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'python',
            code: `
                pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'ruby',
            code: `
                pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'kotlin',
            code: `
                val pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'groovy',
            code: `
                def pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
    ]}
/>

The returned JSON has the `content` key with all the text content of the PDF file, and has the `metadata` key with the various properties of the PDF file.

Here is an example of the JSON returned by `extract`:

```json
{
  "content": "All the text content of the PDF file goes here...",
  "metadata":{
    "Content-Type":"application/pdf",
    "dc:format":"application/pdf; version=1.4",
    "dc:title":"Linux 1",
    "pdf:PDFVersion":"1.4",
    "pdf:charsPerPage":"580",
    "pdf:containsDamagedFont":"false",
    "pdf:containsNonEmbeddedFont":"false",
    "pdf:docinfo:producer":"Skia/PDF m125 Google Docs Renderer",
    "pdf:docinfo:title":"File 1",
    "pdf:encrypted":"false",
    "xmpTPg:NPages":"3",
    ...
  }
}
```

There are many other data items obtained in `metadata` but omitted in `...` so the example does not become too long.

## Converting

It is possible to programmatically convert the PDF to text or even to HTML.

### PDF to Text

We can extract all the PDF file content as plain text using the method:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _pdf.toText(...)
            `
        },
    ]}
/>

Example of how to use it to read a file at the root of the application:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _out.print(_pdf.toText(_app.file("my-document.pdf")))
            `
        },
    ]}
/>

Or even using a file in the application's `storage`:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _out.print(_pdf.toText(_storage.filesystem("server", "my-document.pdf")))
            `
        },
    ]}
/>
