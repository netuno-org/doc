Process custom Excel files.

## Introduction

Netuno generates EXCEL files compatible with LibreOffice, OpenOffice, Microsoft Office, Google Drive, etc., through the [XLS](/docs/library/resources/xls) resource, which provides a low-code abstraction of [Apache POI](https://poi.apache.org/) for the various programming languages supported by Netuno.

We can generate XLSX, XLS, or ODS files.

The application that comes with Netuno called **demo** (the demonstration application) contains many examples of possible code implementations in various languages, including a demonstration of spreadsheet export through the `export-excel` service located at:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-excel`
]} />

## Formatting

The definition of visual formatting styles—that is, date, time, currency formats, and others—must be done before defining cell values, because when defining cell values it is possible to associate their formatting style along with them.

Thus, as demonstrated in the example included in the `demo` application, the formats are defined at the beginning of the code.

To format dates:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `

            `
        },
    ]}
/>

To format times:

<PolyglotCode
    codes={[

    ]}
/>

To format dates with times:

<PolyglotCode

        },
    ]}
/>

To format currency values in **euros**:

## Appearance

The definition of visual appearance styles—that is, the appearance of cells such as colors, font, borders, alignment, and others—must be done before defining cell values, because when defining cell values it is possible to associate their appearance style along with them.

Thus, as demonstrated in the example included in the `demo` application, the appearances are defined at the beginning of the code.

Example of defining colors and alignment:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const styleHeader = excel.cellStyle()
                styleHeader.setFillPattern(_xls.fillPattern("solid-foreground"))
                styleHeader.setFillBackgroundColor(excel.color("black"))
                styleHeader.setAlignment(_xls.horizontalAlignment("center"))
            `
        },
    ]}
/>

> Documentation with all methods of the <a href="https://poi.apache.org/apidocs/dev/org/apache/poi/hssf/usermodel/HSSFCellStyle.html" target="_blank">Styles object in Apache POI</a>.

Defining the border style:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const styleData = excel.cellStyle()
                styleData.setBorderBottom(_xls.borderStyle("thin"))
                styleData.setBorderTop(_xls.borderStyle("thin"))
                styleData.setBorderLeft(_xls.borderStyle("thin"))
                styleData.setBorderRight(_xls.borderStyle("thin"))
            `
        },
    ]}
/>

> Documentation with all methods of the <a href="https://poi.apache.org/apidocs/dev/org/apache/poi/hssf/usermodel/HSSFCellStyle.html" target="_blank">Styles object in Apache POI</a>.

Creates a new font style for the text and associates the font definitions with a specific existing cell style:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const fontTitle = excel.font()
                fontTitle.setBold(true)
                fontTitle.setFontHeightInPoints(14)
                fontTitle.setColor(excel.color("yellow"))
                // Set the font of styleHeader
                styleHeader.setFont(fontTitle)
            `
        },
    ]}
/>

> Documentation with all methods of the <a href="https://poi.apache.org/apidocs/dev/org/apache/poi/hssf/usermodel/HSSFFont.html" target="_blank">Font object in Apache POI</a>.

## Merging Cells

To merge cells in a region, we use the `mergedRegion` method.

The parameter order is:

1. Starting Row
2. Starting Column
3. Ending Row
4. Ending Column

> Numeric positioning references always start at **zero**.

In the example below, all cells from column 10 through column 15 that are on row 3 will be merged:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.mergedRegion(2, 9, 2, 14)
            `
        },
    ]}
/>

## Inserting Tabular Data

We can insert a data table using the `addDataTable` method.

Since the first two parameters define the position where the data table should be inserted, they are the row and column numbers.

> Note that positioning in the code for rows and columns always starts from **zero**.
>
> That is, Row 1 is position `0`, and Column A is also position `0`.

Next, we pass a list of rows, where each row contains another list for the columns, and only then do we add a map with the cell value.

Complete example:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, 1,
                    _val.list() // Rows
                        .add(
                            _val.list() // Column
                                .add(
                                    _val.map() // Cell
                                        .set("value", "Name")
                                )
                                .add(
                                    _val.map()
                                        .set("value", "Age")
                                )
                        )
                        .add( // Another Row
                            _val.list()
                                .add( // First Column
                                    _val.map()
                                        .set("value", "Maria")
                                )
                                .add( // Second Column
                                    _val.map()
                                        .set("value", 26)
                                )
                        )
                )
            `
        },
    ]}
/>

### Appearance

In the cell map, we can associate the styles already created, for example using the styles defined in the appearance and formatting section we saw earlier.

The following is an example of how to associate styles with cells:

/>

### Formulas

To insert formulas, we use the `formula` key in the cell definition map.

In this example, the sum of all values from the other cells will be performed in the last cell:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, 1,
                    _val.list()
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 45))
                                .add(_val.map().set("value", 26))
                        )
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 51))
                                .add(_val.map().set("value", 30))
                        )
                        .add(
                            _val.list()
                                .add(
                                    _val.map().set("value", "Total")
                                )
                                .add(
                                    _val.map().set("formula", "SUM(B7:C8)")
                                )
                        )
                )
            `
        },
    ]}
/>

To get the column letter from the column number, you can use the `columnReference` method, which can help when defining formulas. The same method can also be used to get the column number from the reference letter, for example:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, _xls.columnReference('B'),
                    _val.list()
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 45))
                                .add(_val.map().set("value", 26))
                        )
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 51))
                                .add(_val.map().set("value", 30))
                        )
                        .add(
                            _val.list()
                                .add(
                                    _val.map().set("value", "Total")
                                )
                                .add(
                                    _val.map().set(
                                        "formula",
                                        "SUM("+ _xls.columnReference(1) +"7:"+ _xls.columnReference(2) +"8)"
                                )
                            )
                        )
                )
            `
        },
    ]}
/>

### Activate

So, to avoid having to constantly indicate in the methods which sheet should be processed, as in the examples above, as an alternative you can indicate which sheet is active.

> All methods for manipulating cells, images, and data use the sheet that is activated when a specific sheet is **not** indicated.

See two ways to activate a specific sheet, first with the object reference and then with the sheet index:

<PolyglotCode

To directly change the same file, you can do so using `inputStream`.

The following is an example of how to change a cell value:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const fileInput = _app.file("file.xlsx").inputStream()
                const excel = _xls.open(fileInput)

                excel.setCellData(
                    10, 1,
                    _val.map()
                        .set(
                            "value",
                            excel.getCellData(10, 1).getInt("value") + 10
                        )
                )

                fileInput.close() // Closes the opened file.
                excel.save(_app.file("file.xlsx")) // Saves the new version.
                `
        },
    ]}
/>

The cell type is obtained through the code:

- `column.getString("type")`

And the supported types are:

- `string` - Text content.
- `numeric` - Numeric content or date and/or time content.
- `boolean` - True or false.
- `blank` - Blank cell.
- `formula` - Cell that contains a formula.
- `error` - Error in cell processing.

### Additional Parameters

For each cell type, we have some additional parameters.

`string` - Cell type with textual content.

- `value` - Cell text.
- `richValue` - Cell formatting.

`numeric` - Cell type with numeric content, or dates and also times.

- `value` - Value of the cell's numeric content.
  
In the case of dates and times, we have these additional parameters:

- `localDateTime` - Java Time LocalDateTime object that represents the cell's date and time value.
- `localDate` - Java Time LocalDate object that represents the cell's date value.
- `localTime` - Java Time LocalTime object that represents the cell's time value.
- `instant` - Java Time Instant object that represents the cell's date and/or time value.
- `date` - Java Date object that represents the cell's date and/or time value.

`boolean` - Cell type with boolean content, that is, true or false.

- `value` - Value of type _boolean_, `true` or `false`.

`blank` - Cell type without content, therefore it does not contain additional parameters.

`formula` - Cell type that contains calculation formulas.

- `value` - Final value resulting from the calculation.
- `formula` - Contains the formula expression used for the calculation.

`error` - Cell type that contains an error.

- `value` - Byte value of the generated error.
- `code` - If there are errors in the formula calculation, provides the code of the error that occurred here.
