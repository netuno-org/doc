Keep in mind what is needed to continue evolving with Netuno.

The documentation as a whole undergoes constant improvements and strives to be as simple and introductory as possible.

But it is assumed that you have some foundational knowledge and some experience in certain areas, such as:

* Databases, such as queries in general, insert, update, and delete;
* Web services, using GET and POST;
* <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a> and <a href="https://reactjs.org/" target="_blank">ReactJS</a>;

If you do not have any of these skills, we will try to help you develop them.

Always seek help on GitHub or Discord; see the information in the site footer.

## Database

With Netuno, you can work with various types of databases and deepen your knowledge.

Only with good database knowledge is it possible to create applications with complex structures to collect and manage a large volume of data.

This way, you will have the autonomy to robustly create the most important part, which is the database.

Building a well-organized and optimized database makes all the difference in the experience of end users as well as in performance from development to execution.

## Services

If you already have some knowledge of any of the following programming languages, such as <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a>, or <a href="https://groovy-lang.org/" target="_blank">Groovy</a>, you can quickly create complex and robust web services using the various resources that Netuno provides for **low code** programming.

Inside the applications folder, especially in the **server** folder, you can program in these various languages.

Just use the corresponding extension:

* **.js** &nbsp; <a href="https://developer.mozilla.org/pt-PT/docs/Web/JavaScript" target="_blank">JavaScript</a>
* **.ts** &nbsp; <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>
* **.py** &nbsp; <a href="https://www.jython.org/" target="_blank">Python</a>
* **.rb** &nbsp; <a href="https://www.jruby.org/" target="_blank">Ruby</a>
* **.kts** &nbsp; <a href="https://kotlinlang.org/" target="_blank">Kotlin</a>
* **.groovy** &nbsp; <a href="https://groovy-lang.org/" target="_blank">Groovy</a>

Explore the web service examples that come with the **demo**_nstration_ application, in:

- `/apps/demo/server/services/samples`

And also explore our **library** documentation to learn about the available resources in detail.


## User Interface

Frontend web development has undergone many changes in recent years, and using <a href="https://vite.dev/" target="_blank">Vite</a> has become standard.

Our technology choices, such as <a href="https://reactjs.org/" target="_blank">ReactJS</a>, <a href="https://bun.sh/" target="_blank">Bun</a>, <a href="https://ant.design/" target="_blank">Ant.Design</a>, and <a href="http://lesscss.org/" target="_blank">Less</a>, are technologies that increase productivity and have been widely adopted.

To deepen your knowledge of these technologies, explore the various text and video documentation available on the internet.

Since these are technologies with large communities, it is not difficult to find good material to start learning.

We remind you that with Netuno, even with a little knowledge, it is already possible to achieve great results, which empowers frontend developers to develop the entire backend and vice versa, and you can even choose to develop everything with just a single programming language such as <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>.

## Conclusion

Netuno facilitates web application development, where a single person with little knowledge of databases, web services, and frontend can develop complex applications autonomously.

It also brings a significant overall productivity increase for large teams, where there are people with greater expertise in each area.

Netuno can also be used as a backoffice for databases or as a REST API server for decoupled frontends and mobile applications.

Save time and develop with more focus on business rule logic, and with the knowledge you already have, you will go further.
