With Netuno, you can create **_Web Services_** and build any type of complex **<a href="https://pt.wikipedia.org/wiki/REST" target="_blank">REST</a> APIs** for data integration between systems.

:::info What is a Web Service?
A Web Service allows systems to exchange information online in a standardized way. In Netuno, each file inside `server/services/` automatically becomes an endpoint accessible via HTTP.
:::

## Why use Web Services?

Using asynchronous services brings clear benefits to the user experience:

- **Faster loading:** the server delivers the page's visual structure immediately, without waiting for all data to be processed.
- **Dynamic data on demand:** the frontend requests only the necessary data, when needed.
- **Integration between systems:** a service created in Netuno can be consumed by any external application (mobile, another web system, etc.).
- **Better user experience:** the user does not need to wait for the page to fully process before seeing something on the screen.

## Prerequisites

Before you begin, make sure that:

- Netuno is installed and running locally.
- The `demo` application was created as described in [Create Application](../app-create).
- There is data registered in **Tasks** and related to **Records** (required so the return is not empty).

## Configure the Code Editor

To create and edit services in Netuno, use a code editor of your choice. We recommend **[Visual Studio Code](https://code.visualstudio.com/download)** because it is free, lightweight, and highly intuitive, but any editor compatible with JavaScript/Python/Groovy will work normally.

## Open the Demo Application {#abrir-a-aplicacao-demo}

1. Open **Visual Studio Code**.
2. Click the **Files** icon in the left sidebar.
3. Select **Open Folder** (File > Open Folder).
4. Navigate to the Netuno installation folder.
5. Select the directory: **`apps/demo`**
6. Click **Open**.

The `demo` application's folder structure will be loaded in the left panel.

## Create the Service

Services are processed on the **server** side. To create a new service:

1. In the file panel, expand the structure until you find the `server/services/` folder.
2. **Right-click** the `services` folder.
3. Select **New File** `New File`.
4. Name the file according to the language you want to use:

Implement the service by adding the code below to the file you created. This service queries the database and returns a list of workers with the total number of recorded hours in **JSON** format.

### Understanding the Code

| Object/Method | Description |
|---|---|
| `_db.query()` | Executes an SQL query and returns a list of key-value objects (column → data). |
| `_val.list()` | Creates a mutable list to accumulate the results. |
| `_val.map()` | Creates a mapping object (key-value) for each result row. |
| `_out.json()` | Serializes the object to JSON and sends the response to HTTP requests. |

:::warning Required data
Make sure there is data registered in **Tasks** and linked to **Records**. Otherwise, the endpoint will return an empty list `[]`.
:::

## Run and Test the Service

With Netuno running, open the endpoint in your browser:

:::tip Tip for viewing the JSON
We recommend **[Firefox](https://www.mozilla.org/)** for testing endpoints directly in the browser, as it formats and displays the JSON response legibly with syntax highlighting. Alternatively, use extensions such as **JSON Viewer** in Chrome or tools such as **[Postman](https://www.postman.com/)** for more advanced testing.
:::

The expected return will be a JSON similar to:

```json
[
  { "name": "Anna Smith", "total": 12 },
  { "name": "Charles Miller", "total": 28 },
  { "name": "John Costa", "total": 45 }
]
```
