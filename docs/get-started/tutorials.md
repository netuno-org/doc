# Tutorials

Explore the Netuno platform tutorials and learn, in practice, how to configure resources, model data, create interfaces, and develop business logic in the backend.

This page gathers the main content for those who are just getting started and also for those who want to deepen their use of the platform.

## Before you begin

Before starting any tutorial, check that your environment is ready:

- **Netuno installed** and running in the local or development environment.
- **Access to the administrative panel** with the appropriate permissions.
- **Recommended basic knowledge** of data modeling, HTTP, and REST APIs to make the most of the technical content.

See the [Installation](./installation) guide before proceeding.

## Recommended order

If this is your first experience with Netuno, follow this sequence:

1. Get to know the graphical interface.
2. Learn how to create forms and fields.
3. Configure relationships between forms.
4. Move on to permissions and user groups.
5. Explore queries and backend resources as the project requires.

## Backend

Netuno lets you combine low-code with backend development in different languages and scenarios. The tutorials below help you create integrations, manipulate data, and implement business rules.

### Prerequisites

Before moving on to this section, it is recommended that you be familiar with:

- Client-server architecture and the HTTP protocol.
- JSON data structures.
- Programming logic in JavaScript, Python, or another language compatible with your development flow.

:::tip How to choose a tutorial

Use the **graphical interface** tutorials when the goal is to configure the application visually, structure data, and administer resources through the interface.  
Use the **backend** tutorials when you need to create business logic, integrations, authentication, automations, or programmatic access to data.
:::
