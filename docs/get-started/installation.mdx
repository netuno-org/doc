# Introduction

Welcome to the **Netuno** installation guide, the *low-code*, polyglot, and *open source* platform developed to accelerate the creation of your projects and simplify the configuration of the development environment.

Here you build robust full-stack applications agilely, combining the speed of low-code with the power of traditional coding.

## Quick Installation 

The easiest way to install Netuno is through the installation script provided by the platform. Just run the commands in the terminal according to your operating system.

<Tabs groupId="os">
    <TabItem value="linux-mac" label="Linux or macOS" default>

```bash
bash <(curl -fsSL https://netu.no/install.sh)
```

    </TabItem>
    <TabItem value="windows" label="Windows">

```powershell
powershell -c "irm https://netu.no/install.ps1|iex"
```

    </TabItem>
</Tabs>

## Start the DEMO App

After completing the installation, run the command below inside the `netuno` folder to start the server with the demo application:

```bash
./netuno server
```

### Open the Application in the Browser

After startup, the browser will open automatically with the local server address. If this does not happen, manually access one of the addresses below:

- [http://demo.local.netu.no:9000](http://demo.local.netu.no:9000)
- [http://localhost:9000](http://localhost:9000)

## Stop the Server

To stop the server, press the following keys in the terminal:

**CTRL + C**

To start it again, use the same `./netuno server` command.
