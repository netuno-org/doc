Public files directly accessible via URL.

## Public Folder

The `📂 public` folder gathers the client-side UI (User Interface) content after compilation, among other public
files such as logos and the icon.

It can contain any file that needs to be accessed publicly.

## Folder Structure

When you enter the `📂 public` folder, by default you will find the following structure:

## Images

The `📂 images` folder initially contains the application logos and the icon.

This folder is where you can place all the public images of your application.

### icon.png

Application icon, it appears in the browser tab (favicon).

### logo.png

It is the logo image that is displayed on the backoffice login page and on the error pages.

### logo-main.png

It is the logo image that is displayed in the header after logging in and entering the backoffice.

## Scripts

In the `📂 scripts` folder is the final JavaScript code generated by the UI compilation, it is where other public
JavaScript files can be placed.

### ui.js

The `ui.js` file is the final code compilation of the UI.

Typically the UI is developed in React and LESS, and [Vite](https://vite.dev/) is used to perform the compilation
of the final JavaScript bundle, which is the `ui.js` file.

The compilation instructions are in `ui/vite.config.js`, this file contains the details of how `ui.js`
is processed and generated.

### ui.js.map

The `ui.js.map` file is the source maps of the UI, this file is important to indicate what the original code is
when debugging errors in the browser _console_.

## Styles
  
The `📂 styles` folder should contain the CSS files that are used for styling the application.

### main.css

The `main.css` is typically used for global CSS or to change Netuno's default styles.

### ui.css

The `ui.css` is the CSS generated from the UI compilation.

Typically the UI is developed in React and LESS, and [Vite](https://vite.dev/) is used to perform the compilation
of the final CSS bundle which is `ui.css`.

The compilation instructions are in `ui/vite.config.js`, this file contains the details of how `ui.css`
is generated.
