Netuno is a low-code platform for rapidly creating web services that simplifies data management with an integrated visual interface, ensuring the creation of high-performance web-based applications.

It reduces development effort and time, as well as production costs in administration, management, and industrial areas.

> The Netuno platform is free, [get started now](/docs/get-started/installation).

## Forms and fields

Data model creation is made easier through the forms engine in a web environment. Defining forms creates database tables, and their fields define the columns. You can configure data types, field properties, and their relationships. The web construction _suite_ provides several features such as database queries, Entity-Relationship Model visualization, among others.

## Access and permissions management

User management and permissions are configurable in a web environment and are accessible through backend services in Netuno. You can also control access by user and by group to forms and reports.

## Resource library

The resource library offers a wide range of ready-to-use features. These include everything from integrations with PDF, Excel, Email, Firebase to task scheduling or report generation with Jasper.

## REST API

The server communication layer is provided through a REST API. Providing services via JSON allows Netuno to communicate with multiple applications of different kinds, for example serving web clients and mobile applications simultaneously through the same interface.

## Polyglot services layer

Write services in <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://groovy-lang.org/" target="_blank">Groovy</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a>, or <a href="https://pt.wikipedia.org/wiki/Java_(linguagem_de_programa%C3%A7%C3%A3o)" target="_blank">Java</a>; all of them are valid. Netuno removes the isolation between programming languages; the same application supports services running simultaneously in multiple languages without increasing processing overhead.

## Multiple databases

Configure several different databases and use them simultaneously. Natively, Netuno supports several relational database engines such as <a href="https://www.h2database.com/html/main.html" target="_blank">H2DataBase</a>, <a href="https://www.postgresql.org/" target="_blank">PostgreSQL</a> and CockroachDB, <a href="https://mariadb.org/" target="_blank">MariaDB (_MySQL_)</a>, Microsoft SQL Server, and Oracle. You can create your application using, for example, PostgreSQL as the main database and integrate with other databases in MariaDB, and in the middle of a project switch to Microsoft SQL Server or Oracle without having to make any code changes.

> It offers native support for integration with MongoDB.

## Serverless

Netuno is also your application server. With a single command, run your application without having to waste time on licensing, configurations, and additional development.

## Performance in development and execution

You don't need to learn to work with a new drag-and-drop development software or memorize the interface of a new framework. With the ability to program in 6 different languages, have an auto-generated data layer, and have libraries available to use on the fly, Netuno's low-code is the best solution for your tight deadlines.

Using code generators optimized for high performance and the recent <a href="https://www.graalvm.org/" target="_blank">GraalVM</a>, the application server becomes incredibly fast, regardless of the language you use.
