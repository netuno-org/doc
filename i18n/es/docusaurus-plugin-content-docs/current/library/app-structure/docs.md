Documentación y documentos en general.

## Carpeta de los Documentos

En la carpeta `📂 docs` es donde organizamos los documentos generales de la aplicación.

Sirve para organizar los archivos útiles como documentación, diseño, arquitectura, integraciones, etc.

Cualquier cosa que sea útil para las otras personas que también trabajan en el desarrollo de la aplicación, o que
sea útil en el desarrollo de mantenimiento o evolución.

Debe tener en consideración que los archivos binarios demasiado grandes pueden contaminar y ensuciar definitivamente el
repositorio de código, es decir, el GIT. Porque cualquier archivo demasiado grande que va al GIT aumenta
considerablemente el historial de cambios, así que los archivos de vídeo, zips, o cualquier otro documento muy
extenso, deben evitarse para no sobrecargar el GIT y crear complicaciones futuras.
