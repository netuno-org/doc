Documentación y documentos en general.

## Carpeta de Documentos

En la carpeta `📂 docs` es donde organizamos los documentos generales de la aplicación.

Sirve para organizar los archivos útiles como documentación, diseño, arquitectura, integraciones, etc.

Cualquier cosa que sea útil para las otras personas que también trabajan en el desarrollo de la aplicación, o que sea útil en el desarrollo de mantenimiento o evolución.

Debe tener en cuenta que los archivos binarios demasiado grandes pueden contaminar y ensuciar definitivamente el repositorio de código, es decir, GIT. Porque cualquier archivo demasiado grande que va a GIT aumenta considerablemente el historial de cambios, así que los archivos de vídeo, zips, o cualquier otro documento muy extenso, deben evitarse para no sobrecargar GIT y crear inconvenientes futuros.
