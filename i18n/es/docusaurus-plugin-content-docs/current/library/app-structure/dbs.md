Organización de los archivos de base de datos.

## Carpeta para Base de Datos

La carpeta `📂 dbs` está destinada a guardar los archivos de base de datos de su aplicación.

En el caso de las bases de datos del tipo H2 Database todos los archivos se generan automáticamente en esta carpeta.

Esta carpeta es útil para guardar cualquier cosa relacionada con la base de datos, por ejemplo copias de seguridad, scripts,
dumps, diagramas, etc.

Toda la documentación relacionada con la base de datos y que debe acompañar al proyecto de la aplicación se recomienda
organizarla en esta carpeta.
