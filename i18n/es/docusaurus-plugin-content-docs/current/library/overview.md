Netuno es una plataforma low-code de creación rápida de servicios web que facilita la gestión de datos con una interfaz visual integrada, garantizando la creación de aplicaciones basadas en web con alto rendimiento.

Reduce el esfuerzo y tiempo de desarrollo, así como los costes de producción en el área de administración, gestión e industrial.

![Estructura Netuno](/docs/assets/introducao1.png)

Descubra cómo Netuno favorece su experiencia de programación para que tenga una programación creativa y no repetitiva, manteniendo los niveles de rendimiento desde el desarrollo hasta la ejecución:

> La plataforma Netuno es gratuita, [empiece ya](/docs/get-started/installation).

## Formularios y campos

La creación del modelo de datos se facilita a través del motor de formularios en entorno WEB. La definición de formularios da origen a tablas en la base de datos, y sus campos definen las columnas. Es posible parametrizar el tipo de datos, las propiedades de los campos, así como sus relaciones. La _suite_ de construcción WEB ofrece varias funcionalidades como consultas a la base de datos, visualización del Modelo Entidad-Asociación, entre otras.

## Gestión de accesos y permisos

La gestión de usuarios y sus permisos son configurables en entorno WEB y están accesibles a través de servicios de backend en Netuno. También es posible controlar el acceso por usuario y por grupo a formularios e informes.

## Biblioteca de recursos

La biblioteca de recursos presenta una amplia gama de funcionalidades listas para usar. Entre estas es posible encontrar desde integradores con PDF, Excel, Email, Firebase y hasta programación de tareas o generador de informes con Jasper.

## API REST

La capa de comunicación del servidor se pone a disposición mediante API REST. La disponibilización de servicios por JSON permite a Netuno comunicar con múltiples aplicaciones de distinta naturaleza, pudiendo por ejemplo servir simultáneamente a clientes WEB y aplicaciones móviles sobre la misma interfaz.

## Capa de servicios políglota

Escriba servicios en <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://groovy-lang.org/" target="_blank">Groovy</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a> o en <a href="https://pt.wikipedia.org/wiki/Java_(linguagem_de_programa%C3%A7%C3%A3o)" target="_blank">Java</a>, todas ellas son válidas. Netuno elimina el aislamiento entre lenguajes de programación, la misma aplicación soporta servicios ejecutándose simultáneamente en múltiples lenguajes sin que ello aumente la carga de procesamiento.

## Multi base de datos

Configure varias bases de datos diferentes y úselas simultáneamente. De forma nativa Netuno soporta diversos motores de bases de datos relacionales como <a href="https://www.h2database.com/html/main.html" target="_blank">H2DataBase</a>, <a href="https://www.postgresql.org/" target="_blank">PostgreSQL</a> y CockroachDB, <a href="https://mariadb.org/" target="_blank">MariaDB (_MySQL_)</a>, Microsoft SQL Server y Oracle. Podrá crear su aplicación usando, por ejemplo, PostgreSQL con una base de datos principal e integrarla con otras bases de datos en MariaDB, y a mitad de un proyecto poder cambiar a Microsoft SQL Server u Oracle sin tener que realizar ningún cambio de código.

> Ofrece soporte nativo a la integración con MongoDB.

## Serverless

Netuno es también su servidor de aplicaciones. Con un comando ejecute su aplicación sin que para ello tenga que perder tiempo en licencias, configuraciones y desarrollos adicionales.

## Rendimiento en el desarrollo y en la ejecución

No necesita aprender a trabajar con un nuevo software de desarrollo mediante arrastrar y soltar, ni memorizar la interfaz de un nuevo framework. Con la posibilidad de programar en 6 lenguajes diferentes, disponer de una capa de datos autogenerada y de bibliotecas disponibles para usar on-the-fly, el low-code de Netuno es la mejor solución para sus plazos ajustados.

Utilizando generadores de código optimizados para un alto rendimiento y usando la reciente <a href="https://www.graalvm.org/" target="_blank">GraalVM</a>, el servidor de aplicaciones se vuelve increíblemente rápido, independientemente del lenguaje que utilice.
