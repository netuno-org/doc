Ten en cuenta lo que se necesita para continuar evolucionando en Netuno.

La documentación en general sufre constantes mejoras y trata de ser lo más simple e introductoria posible.

Pero se asume que tiene algunas bases de conocimiento y algo de experiencia en ciertas áreas, tales como:

* Bases de datos, como consultas en general, insertar, actualizar y eliminar;
* Servicios web, con GET y POST;
* <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a> y <a href="https://reactjs.org/" target="_blank">ReactJS</a>;

En caso de que no tenga alguna de estas competencias, vamos a intentar ayudarle a desarrollarlas.

Busque siempre ayuda en GitHub o en Discord, vea las indicaciones en el pie de página del sitio.

## Base de Datos

Con Netuno podrá trabajar con diversos tipos de bases de datos y profundizar sus conocimientos.

Solo con un buen conocimiento de bases de datos es posible crear aplicaciones con estructuras complejas para recopilar y gestionar un gran volumen de datos.

Así tendrá autonomía para crear de forma robusta la parte más importante, que es la base de datos.

La construcción de una base de datos bien organizada y optimizada marca la diferencia en la experiencia de los usuarios finales, así como en el rendimiento desde el desarrollo hasta la ejecución.

## Servicios

Si ya tiene algún conocimiento en alguno de los siguientes lenguajes de programación como <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a> o <a href="https://groovy-lang.org/" target="_blank">Groovy</a>, podrá crear rápidamente servicios web complejos y robustos utilizando los diversos recursos que Netuno ofrece para la programación **low code**.

Dentro de la carpeta de las aplicaciones, especialmente en la carpeta **server**, podrá programar en estos diversos lenguajes.

Basta con utilizar la extensión correspondiente:

* **.js** &nbsp; <a href="https://developer.mozilla.org/pt-PT/docs/Web/JavaScript" target="_blank">JavaScript</a>
* **.ts** &nbsp; <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>
* **.py** &nbsp; <a href="https://www.jython.org/" target="_blank">Python</a>
* **.rb** &nbsp; <a href="https://www.jruby.org/" target="_blank">Ruby</a>
* **.kts** &nbsp; <a href="https://kotlinlang.org/" target="_blank">Kotlin</a>
* **.groovy** &nbsp; <a href="https://groovy-lang.org/" target="_blank">Groovy</a>

Explore los ejemplos de servicios web que vienen en la aplicación **demo**_stración_, en:

- `/apps/demo/server/services/samples`

Y explore también la documentación de nuestra **biblioteca** para conocer en detalle los recursos disponibles.


## Interfaz de Usuario

El desarrollo del frontend en la web ha sufrido muchos cambios en los últimos años y el uso de <a href="https://vite.dev/" target="_blank">Vite</a> se ha convertido en un estándar.

Nuestras elecciones de tecnologías como <a href="https://reactjs.org/" target="_blank">ReactJS</a>, <a href="https://bun.sh/" target="_blank">Bun</a>, <a href="https://ant.design/" target="_blank">Ant.Design</a> y <a href="http://lesscss.org/" target="_blank">Less</a>, son tecnologías que aportan un aumento de productividad con gran acogida.

Para profundizar en el conocimiento de estas tecnologías, explore las diversas documentaciones en formato texto y vídeo disponibles en internet.

Como son tecnologías con grandes comunidades, no es difícil encontrar buen material para empezar a aprender.

Recordamos que con Netuno, incluso con un poco de conocimiento, ya es posible obtener grandes resultados, lo que da el poder al programador de frontend de desarrollar todo el backend y viceversa, pudiendo además optarse por desarrollar todo con un único lenguaje de programación como <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>.

## Conclusión

Netuno facilita el desarrollo de las aplicaciones web donde una única persona con pocos conocimientos de bases de datos, servicios web y frontend, podrá desarrollar aplicaciones complejas de forma autónoma.

También para equipos grandes, donde hay personas con mayor competencia en cada una de las áreas, trae, en general, un gran aumento de productividad.

Netuno también puede utilizarse como backoffice para bases de datos o como servidor de APIs REST para frontends desacoplados y aplicaciones móviles.

Ahorre tiempo y desarrolle más centrado en la lógica de las reglas de negocio y, con el conocimiento que ya tiene, llegará más lejos.
