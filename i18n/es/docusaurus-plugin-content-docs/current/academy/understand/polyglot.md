Netuno es políglota tanto a nivel de base de datos como a nivel de código de programación, pero también a nivel de sistema operativo.

Con toda esta diversidad aumentan las opciones de dónde puede utilizarse.

Al soportar diversas bases de datos, lenguajes de programación y sistemas operativos, facilita el desarrollo consiguiendo adaptarse a cada una de las situaciones pero garantizando un entorno cohesionado para los desarrollos.

## Base de datos

Puede utilizarse para integrar varios tipos de bases de datos diferentes e incluso desarrollarse con lenguajes de programación diferentes en el mismo proyecto.

Integrar bases de datos diferentes es bastante común para realizar la integración de datos al consultar o modificar datos en bases de datos de otro sistema.

![Logos de las bases de datos](/docs/assets/business/databases.jpg "Múltiples bases de datos")

Netuno soporta las siguientes bases de datos:

- H2 Database
- PostgreSQL
- MariaDB
- MySQL
- Microsoft SQL Server
- Oracle

## Lenguajes de programación

Soportar lenguajes de programación diferentes puede no parecer muy interesante en el sentido de mezclar lenguajes de programación, pero es posible y no significa que deba hacerse así.

En la práctica, muchas veces es complicado realizar proyectos donde hay una tecnología dominante limitada a un lenguaje de programación, así que es necesario conseguir personas exclusivamente competentes para ese lenguaje de programación.

Con Netuno terminamos teniendo una oferta mayor, donde todo el trabajo no se desperdicia si es necesario utilizar un nuevo lenguaje de programación derivado de un cambio de estrategia, o de la falta de técnicos competentes, o de ganar mayor agilidad al desarrollar algo en específico, entre otras situaciones que puedan tener sentido.

Por norma, esto sería impensable porque el mantenimiento de un sistema con diversos lenguajes de programación empieza a preocupar, pero al ser esta low-code esa preocupación deja de ser muy relevante, porque:

* Los lenguajes de programación acaban siendo similares a nivel de lógica y algoritmo.
* El lenguaje de programación puede ser diferente, pero los recursos de Netuno son los mismos y se utilizan de la misma forma independientemente del lenguaje.

Así, aunque un técnico esté muy habituado a trabajar con un lenguaje de programación, nada le impedirá realizar el mantenimiento en otro; si necesita extender mucho más su intervención o incluso rehacerlo, entonces podrá optar por desarrollar en su lenguaje preferido e integrar su desarrollo en el lenguaje ya existente en uso.

![Logos de los lenguajes de programación](/docs/assets/business/languages.jpg "Lenguajes de programación")

Netuno soporta el desarrollo en los siguientes lenguajes de programación:

- Groovy
- Java
- JavaScript
- Kotlin
- Python
- Ruby

## Sistemas operativos

Netuno, al trabajar con múltiples sistemas operativos y con soporte para configuraciones de entorno, permite garantizar el correcto funcionamiento de los desarrollos de forma transversal y organizar en entornos de desarrollo, prueba, calidad, producción, entre otros.

El cambio del sistema operativo o del entorno es indiferente para el correcto funcionamiento de Netuno y de las aplicaciones.

![Logos de los sistemas operativos](/docs/assets/business/operationsystems.jpg "Múltiples sistemas operativos")

Los sistemas operativos soportados por Netuno son:

* Linux
* Mac OS X
* Windows
