La interfaz de Netuno se divide en dos áreas de trabajo, con finalidades específicas y diferentes. El modo de *visualización* para interactuar y mostrar el resultado de la aplicación final (Frontend), y el modo de *construcción* para desarrollar su aplicación.

### Visualizar

Este es el entorno frontend donde los usuarios interactúan con la parte visual de la aplicación.

#### 1 - Construir

Este botón le permite acceder al modo de desarrollo de la aplicación.

#### 2 - Menú desplegable

 Permite seleccionar opciones para gestionar su sesión, tales como cerrar sesión, cambiar la contraseña de su cuenta y consultar datos de su usuario y grupos.

#### 3 - Mi área de trabajo

Esta es el área central, donde se muestra su aplicación web frontend, programada en la carpeta `public`.

#### 4 - Tablas formularios

En esta área, usted encuentra el acceso a todas las tablas de datos. Haga clic para visualizar, añadir, editar o eliminar datos directamente a través de formularios.

![view-pt.png](/docs/assets/academy/ui/get-to-know/view-pt.png)

### Construir

Es el entorno low-code donde usted configura y gestiona todos los aspectos de su aplicación sin la necesidad de escribir un código extensivo.

#### 1 - Visualizar

Permite el retorno inmediato al modo "Visualizar", para verificar el impacto de sus cambios en tiempo real.

#### 2 - Menú desplegable

Permite salir de la aplicación.

#### 3 -  Mi área de trabajo

Esta es el área central, donde se muestra su aplicación web frontend, programada en la carpeta `public`. 

#### 4 - Gestión

Esta sección permite gestionar formularios, informes, query y diagramas.

#### 5 - Depurar

Esta sección posibilita la monitorización y la inspección del comportamiento de los scripts en tiempo de ejecución. Así, es posible identificar problemas, rastrear valores de variables y comprender el flujo de ejecución del código.

#### 6 - Gestión de campos

Esta sección permite la gestión de la estructura de sus tablas de datos. Puede añadir, editar o eliminar campos y definir el tipo de dato (texto, número, fecha, etc.) para cada uno.
