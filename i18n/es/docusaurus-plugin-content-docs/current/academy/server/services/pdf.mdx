Procesar archivos PDF personalizados.

## Introducción

Netuno genera archivos PDF con soporte para imágenes, tablas, fuentes y mucho más, a través del recurso [PDF](/docs/library/resources/pdf), que permite una abstracción low-code de [iTextPDF](https://itextpdf.com/) para los distintos lenguajes de programación soportados por Netuno.

La aplicación que viene con Netuno denominada **demo** (aplicación de demostración) contiene bastantes ejemplos de las posibles implementaciones de código en varios lenguajes, incluida la demostración de la exportación a PDF mediante el servicio `export-pdf`, que se encuentra en:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-pdf`
]} />

## Inicialización

En primer lugar es necesario crear el objeto que va a contener el contexto del nuevo documento que se está creando; por defecto, el tamaño de las páginas es A4.

## Cabecera HTTP

Para crear un servicio en la API REST que devuelva un archivo PDF como salida de datos, es necesario añadir en la cabecera el parámetro `Content-Type` del protocolo HTTP.

Ejemplo de cómo definir el contenido como PDF:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("pdf")
            `
        },
    ]}
/>

El código `pdf` es una abreviatura de:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("application/pdf")
            `
        },
    ]}
/>

## Párrafo

Añade un nuevo párrafo al documento:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentoPdf.add(
                    _pdf.paragraph("Mi texto aquí...")
                        .setFontSize(15)
                )
            `
        },
    ]}
/>

Para añadir un párrafo en una posición fija:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentoPdf.add(
                    documentoPdf.add(
                        _pdf.paragraph("Mi texto fijo...")
                            .setFixedPosition(100, 500, 200)
                            .setFontSize(15)
                    )
                )
            `
        },
    ]}
/>

En el código anterior, en el método `setFixedPosition`, el primer parámetro es la posición X (`100`), el segundo parámetro es la posición Y (`500`) y el tercer parámetro es la anchura (`200`).

**Atención:** si el valor de Y se define como `0`, significa que queda en el fondo de la página; por tanto, para subirlo hay que aumentar el valor de Y. Cuanto mayor sea el valor de Y, más arriba aparecerá, pero si es demasiado alto y supera la longitud de la página, no será visible.

> Documentación con todos los métodos del objeto de [Párrafo de iText](https://api.itextpdf.com/iText/java/8.0.3/com/itextpdf/layout/element/Paragraph.html).

## Tabla

Es posible crear tablas, lo que permite presentar un conjunto de datos de forma más legible.

El número de columnas de la tabla se define con el parámetro: `_pdf.table(numeroColumnas)`

En el ejemplo siguiente, `numeroColumnas` es el número `1`, es decir, una columna.

Como añadimos dos celdas a la tabla, la segunda celda pasa a la línea siguiente.

Observe:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentoPdf.add(
                    _pdf.table(1)
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Persona")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBorder(_pdf.border("solid", 2))
                                .setBackgroundColor(_pdf.colorRGB(1, 0, 0))
                        )
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Nicole")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBackgroundColor(_pdf.colorGray(0.5))
                        )
                )
            `
        },
    ]}
/>

Con el método `addCell` se permite insertar la definición de las celdas con su respectivo contenido.

> Documentación con todos los métodos del objeto de [Celda de iText](https://api.itextpdf.com/iText/java//8.0.3/com/itextpdf/layout/element/Cell.html).

## Cerrar y guardar el documento

El documento solo se guarda o genera por completo cuando se llama al método `close`, de la siguiente forma:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentoPdf.close()
            `
        },
    ]}
/>

El lugar donde se genera el documento se define en la inicialización; por tanto, es en la inicialización del documento donde definimos dónde se generará el documento final, si será en la salida de datos del servicio (`output`) o en un archivo.

## Leer archivo

Para leer un documento PDF, extrayendo la información de texto.

Utilizamos el método `extract`, que obtiene todos los datos del archivo PDF en un objeto JSON.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const datosPdf = _pdf.extract(_app.file("archivo-1.pdf"))

                _out.json(datosPdf)
            `
        },
        {
            lang: 'python',
            code: `
                datosPdf = _pdf.extract(_app.file("archivo-1.pdf"))

                _out.json(datosPdf)
            `
        },
        {
            lang: 'ruby',
            code: `
                datosPdf = _pdf.extract(_app.file("archivo-1.pdf"))

                _out.json(datosPdf)
            `
        },
        {
            lang: 'kotlin',
            code: `
                val datosPdf = _pdf.extract(_app.file("archivo-1.pdf"))

                _out.json(datosPdf)
            `
        },
        {
            lang: 'groovy',
            code: `
                def datosPdf = _pdf.extract(_app.file("archivo-1.pdf"))

                _out.json(datosPdf)
            `
        },
    ]}
/>

El JSON devuelto tiene la clave `content` con todo el contenido de texto del archivo PDF, y tiene la clave `metadata` con las distintas propiedades del archivo PDF.

Aquí tiene un ejemplo del JSON devuelto por `extract`:

```json
{
  "content": "Todo el contenido en texto del archivo PDF viene aquí...",
  "metadata":{
    "Content-Type":"application/pdf",
    "dc:format":"application/pdf; version=1.4",
    "dc:title":"Linux 1",
    "pdf:PDFVersion":"1.4",
    "pdf:charsPerPage":"580",
    "pdf:containsDamagedFont":"false",
    "pdf:containsNonEmbeddedFont":"false",
    "pdf:docinfo:producer":"Skia/PDF m125 Google Docs Renderer",
    "pdf:docinfo:title":"Archivo 1",
    "pdf:encrypted":"false",
    "xmpTPg:NPages":"3",
    ...
  }
}
```

Existen muchos otros datos que se obtienen en `metadata`, pero que se han omitido en los `...` para que el ejemplo no sea demasiado largo.

## Convertir

Es posible convertir programáticamente el PDF a texto o incluso a HTML.

### PDF a texto

Podemos extraer todo el contenido del archivo PDF en texto corrido utilizando el método:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _pdf.toText(...)
            `
        },
    ]}
/>

Ejemplo de cómo utilizarlo para leer un archivo en la raíz de la aplicación:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _out.print(_pdf.toText(_app.file("mi-documento.pdf")))
            `
        },
    ]}
/>

O incluso utilizando un archivo en el `storage` de la aplicación:

<PolyglotCode
    codes={[
