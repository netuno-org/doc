Subir y descargar archivos, gestionar carpetas remotas.

## Introducción

Netuno tiene integrado en su framework low-code un cliente FTP, que permite conectar con servidores, enviar y
recibir archivos, modificar carpetas, entre otras operaciones remotas.

Soporta múltiples conexiones simultáneas, e incluso FTPS.

Esto gracias a la implementación Java y de código abierto [Apache Commons Net](https://github.com/apache/commons-net), que
permite a Netuno proporcionar estas funcionalidades en todos los lenguajes de _script_ a través del recurso `_ftp`.

> Más sobre el recurso [FTP](/docs/library/resources/ftp) de Netuno.

## Configuración

El primer paso será configurar los datos de acceso al FTP que Netuno utilizará para realizar la conexión.

Navegue dentro de la aplicación que está desarrollando hasta el archivo de configuración de entorno. En este ejemplo,
utilizaremos el archivo de entorno de desarrollo ubicado en:

- `config/_development.json`

Verifique que no contenga ya las configuraciones para el FTP; si aún no existe, entonces al final del archivo de
configuración (en formato JSON) añada los parámetros de configuración del FTP:

```json title="config/_development.json"
{
  ...
  "ftp": {
    "default": {
      "enabled": true,
      "host": "mi.servidor.net",
      "port": 21,
      "username": "temp",
      "password": "$eCr37"
    }
  },
  ...
}
```

Después de guardar los cambios, basta con reiniciar Netuno para asumir los cambios de la configuración. Siendo estas las
configuraciones predeterminadas para la conexión, como indica el nombre `default`.

Puede añadir más configuraciones de conexión FTP, pero solo una podrá ser definida como predeterminada.

Para añadir más configuraciones de conexión FTP basta con repetir el bloque de configuración predeterminado y cambiar el nombre
`default` por otro nombre a su elección, vea el ejemplo:

```json title="config/_development.json"
{
  ...
  "ftp": {
    "default": {
      "enabled": true,
      "host": "mi.servidor.net",
      "port": 22,
      "username": "temp",
      "password": "$eCr37"
    },
    "otro": {
      "enabled": true,
      "host": "mi.otro-servidor.net",
      "port": 22,
      "username": "temp",
      "password": "$eCr37"
    }
  },
  ...
}
```

Una configuración similar al ejemplo anterior permitirá utilizar la cuenta predeterminada cuando se llame de la siguiente
forma en el código:

<PolyglotCode
    codes={[
        {

            code: `
                ftp.connect()
            `
        },
    ]}
/>

## Carpeta de Trabajo

Al realizar operaciones en el FTP es necesario definir qué carpeta se utilizará.

A través de la definición de la carpeta de trabajo podremos realizar las diversas manipulaciones a partir de esta carpeta base.

Para cambiar la carpeta de trabajo:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                ftp.changeWorkingDirectory("mi/carpeta/base")
            `
        },
    ]}
/>

Ahora cualquier operación se realizará en esta carpeta o a partir de esta carpeta.

## Crear y Eliminar Carpetas

Al crear una carpeta basta con indicar la ruta de esta carpeta:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                ftp.createDirectory("carpeta-temporal")
                ftp.createDirectory("carpeta-temporal/sub-carpeta")
            `
        },
    ]}
/>

Para eliminar o borrar carpetas:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                ftp.deleteDirectory("carpeta-temporal/sub-carpeta")
                ftp.deleteDirectory("carpeta-temporal")
            `
        },
    ]}
/>

## Renombrar

Es posible renombrar archivos o carpetas; se pasa la ruta antigua y a continuación la nueva ruta:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                ftp.rename("nombre-antiguo", "nombre-nuevo")
            `
        },
    ]}
/>

## Enviar Archivos

Para subir un archivo de texto:

<PolyglotCode

                        _out.print("Archivo: ")
                    } else {
                        _out.print("Otro: ")

                    _out.println("<br/>")
