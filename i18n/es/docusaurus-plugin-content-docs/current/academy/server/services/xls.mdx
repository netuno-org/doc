Procesar archivos Excel personalizados.

## Introducción

Netuno genera archivos EXCEL compatibles con LibreOffice, OpenOffice, Microsoft Office, Google Drive, etc., a través del recurso [XLS](/docs/library/resources/xls) que permite una abstracción low-code de [Apache POI](https://poi.apache.org/) para los diversos lenguajes de programación soportados por Netuno.

Podemos tanto generar archivos XLSX, XLS u ODS.

La aplicación que viene con Netuno denominada **demo** (aplicación de demostración) contiene bastantes ejemplos de las posibles implementaciones de código en varios lenguajes, incluyendo la demostración de la exportación de hojas de cálculo a través del servicio `export-excel` que se localiza en:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-excel`
]} />

## Inicialización

Para iniciar el recurso XLS:

<PolyglotCode
    codes={[

            lang: 'javascript',
            code: `

            `
        },
    ]}
/>

Crea el objeto que contiene el contexto del nuevo archivo que será construido, con una hoja de cálculo vacía.

## Formato

La definición de estilos de formato visual, es decir, formato de fechas, horas, dinero, entre otros, debe realizarse antes de la definición de valores de las celdas, porque al definir los valores de las celdas es posible asociar junto su estilo de formato.

Entonces, como se muestra en el ejemplo que viene en la aplicación `demo`, los formatos se definen al principio del código.

Para formatear fechas:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const estiloFecha = excel.cellStyleFormat("dd/mm/yy")
            `
        },
    ]}
/>

Para formatear horas:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const estiloHora = excel.cellStyleFormat("hh:mm:ss")
            `
        },
    ]}
/>

Para formatear fechas con horas:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const estiloFechaHora = excel.cellStyleFormat("dd/mm/yyyy hh:mm:ss")
            `
        },
    ]}
/>

Para formatear valores de dinero en **euros**:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const estiloMonedaEuro = excel.cellStyleFormat("€#,##0.00;\\-€#,##0.00")

        },
    ]}
/>

Para formatear valores de dinero en **reales**:

<PolyglotCode
    codes={[

            code: `
                const estiloMonedaReal = excel.cellStyleFormat("R$#,##0.00;\\-R$#,##0.00")

Para formatear valores en **porcentaje**:

<PolyglotCode
    codes={[

        },
    ]}

## Apariencia

La definición de estilos de apariencia visual, es decir, la apariencia de las celdas como colores, fuente, bordes, alineación, entre otros, debe realizarse antes de la definición de valores de las celdas, porque al definir los valores de las celdas es posible asociar junto su estilo de apariencia.

Entonces, como se muestra en el ejemplo que viene en la aplicación `demo`, las apariencias se definen al principio del código.

Ejemplo para la definición de colores y alineación:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const estiloCabecera = excel.cellStyle()
                estiloCabecera.setFillPattern(_xls.fillPattern("solid-foreground"))
                estiloCabecera.setFillBackgroundColor(excel.color("black"))
                estiloCabecera.setAlignment(_xls.horizontalAlignment("center"))
            `
        },
    ]}
/>

> Documentación con todos los métodos del objeto de <a href="https://poi.apache.org/apidocs/dev/org/apache/poi/hssf/usermodel/HSSFCellStyle.html" target="_blank">Estilos en Apache POI</a>.

Definición del estilo de bordes:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const estiloDatos = excel.cellStyle()
                estiloDatos.setBorderBottom(_xls.borderStyle("thin"))
                estiloDatos.setBorderTop(_xls.borderStyle("thin"))
                estiloDatos.setBorderLeft(_xls.borderStyle("thin"))
                estiloDatos.setBorderRight(_xls.borderStyle("thin"))
            `
        },
    ]}
/>

> Documentación con todos los métodos del objeto de <a href="https://poi.apache.org/apidocs/dev/org/apache/poi/hssf/usermodel/HSSFCellStyle.html" target="_blank">Estilos en Apache POI</a>.

Crea un nuevo estilo de fuente para el texto y asocia las definiciones de la fuente a un estilo de celda ya existente:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const fuenteTitulo = excel.font()
                fuenteTitulo.setBold(true)
                fuenteTitulo.setFontHeightInPoints(14)
                fuenteTitulo.setColor(excel.color("yellow"))
                // Define la fuente de estiloCabecera
                estiloCabecera.setFont(fuenteTitulo)
            `
        },
    ]}
/>

> Documentación con todos los métodos del objeto de <a href="https://poi.apache.org/apidocs/dev/org/apache/poi/hssf/usermodel/HSSFFont.html" target="_blank">Fuente en Apache POI</a>.

## Combinar celdas

Para unir celdas en una región utilizamos el método `mergedRegion`.

Siendo que el orden de los parámetros es:

1. Fila inicial
2. Columna inicial
3. Fila final
4. Columna final

> Las referencias numéricas de posicionamiento empiezan siempre en **cero**.

En este ejemplo a continuación se combinarán todas las celdas desde la columna 10 hasta la columna 15 que están en la fila 3:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.mergedRegion(2, 9, 2, 14)
            `
        },
    ]}
/>

## Insertar datos tabulados

Podemos insertar una tabla de datos utilizando el método `addDataTable`.

Como los dos primeros parámetros definen la posición donde se debe insertar la tabla de datos, ellos son los números de las filas y de las columnas.

> Atención: el posicionamiento en el código de filas y columnas empieza siempre a partir de **cero**.
>
> Es decir, la Fila 1 es la posición `0` y la Columna A también es la posición `0`.

A continuación pasamos una lista de filas, donde cada fila contiene otra lista para las columnas; solo entonces añadimos un mapa con el valor de la celda.

Ejemplo completo:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, 1,
                    _val.list() // Filas
                        .add(
                            _val.list() // Columna
                                .add(
                                    _val.map() // Celda
                                        .set("value", "Nombre")
                                )
                                .add(
                                    _val.map()
                                        .set("value", "Edad")
                                )
                        )
                        .add( // Otra fila
                            _val.list()
                                .add( // Primera columna
                                    _val.map()
                                        .set("value", "María")
                                )
                                .add( // Segunda columna
                                    _val.map()
                                        .set("value", 26)
                                )
                        )
                )
            `
        },
    ]}
/>

### Apariencia

En el mapa de las celdas podemos asociar los estilos ya creados, utilizando por ejemplo los estilos definidos en la sección de apariencia y formato que vimos anteriormente.

A continuación, el ejemplo de cómo asociar los estilos en las celdas:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, 1,
                    _val.list()
                        .add(
                            _val.list()
                                .add(
                                    _val.map()
                                        .set("value", "Nombre")
                                        .set("style", estiloCabecera)
                                )
                                .add(
                                    _val.map()
                                        .set("value", "Edad")
                                        .set("style", estiloCabecera)
                                )
                        )
                )
            `
        },
    ]}
/>

### Fórmulas

Para insertar fórmulas utilizamos la clave `formula` en el mapa de definiciones de la celda.

En este ejemplo se realizará la suma en la última celda de todos los valores de las otras celdas:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, 1,
                    _val.list()
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 45))
                                .add(_val.map().set("value", 26))
                        )
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 51))
                                .add(_val.map().set("value", 30))
                        )
                        .add(
                            _val.list()
                                .add(
                                    _val.map().set("value", "Total")
                                )
                                .add(
                                    _val.map().set("formula", "SUM(B7:C8)")
                                )
                        )
                )
            `
        },
    ]}
/>

Para obtener la letra de la columna a partir del número de la columna se puede utilizar el método `columnReference`, lo que puede ayudar en la definición de las fórmulas. El mismo método también se puede utilizar para obtener el número de la columna a partir de la letra de referencia, por ejemplo:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, _xls.columnReference('B'),
                    _val.list()
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 45))
                                .add(_val.map().set("value", 26))
                        )
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 51))
                                .add(_val.map().set("value", 30))
                        )
                        .add(
                            _val.list()
                                .add(
                                    _val.map().set("value", "Total")
                                )
                                .add(
                                    _val.map().set(
                                        "formula",
                                        "SUM("+ _xls.columnReference(1) +"7:"+ _xls.columnReference(2) +"8)"
                                )
                            )
                        )
                )
            `
        },
    ]}
/>

### Activar

Así, para evitar tener que indicar constantemente en los métodos cuál es la hoja de cálculo que debe procesarse, como en los ejemplos anteriores, como alternativa es posible indicar cuál es la hoja de cálculo activa.

> Todos los métodos de manipulación de celdas, imágenes y datos utilizan la hoja de cálculo que está activada cuando **no** se indica una hoja de cálculo específica.

Vea dos formas de activar una hoja de cálculo específica, primero con la referencia del objeto y después con el índice de la hoja de cálculo:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.activeSheet(miHoja) // Objeto de referencia de la hoja de cálculo.
                excel.activeSheet(1) // Índice de la hoja de cálculo que se activará.

        },
    ]}
/>

## Editar archivo

Podemos editar archivos abriéndolos, realizando los cambios necesarios y después guardar el nuevo archivo editado.

A continuación se muestran algunos ejemplos de cómo es posible abrir archivos.

Abrir un archivo en la raíz de la aplicación:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const excel = _xls.open(_app.file("file.xlsx"))
            `
        },
    ]}
/>

Para abrir el archivo generado en la carpeta `storage/filesystem` de la aplicación:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const excel = _xls.open(_storage.filesystem("server", "file.xlsx"))
            `
        },
    ]}
/>

Y además para abrir el archivo en la carpeta `/tmp` desde el sistema de archivos del disco duro:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const excel = _xls.open(_os.file("/tmp/file.xlsx"))
            `
        },
    ]}
/>

En los ejemplos anteriores, la constante `excel` contendrá el objeto de edición con el contexto del archivo correspondiente; así es posible hacer cualquier tipo de manipulación.

Cuando concluya los cambios, realice la generación del nuevo archivo.

> No es posible modificar directamente el mismo archivo abierto; es necesario generar un nuevo archivo con una ruta diferente.

Para modificar directamente el mismo archivo, entonces puede hacerse utilizando el `inputStream`.

A continuación, un ejemplo de cómo modificar el valor de una celda:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const archivoEntrada = _app.file("file.xlsx").inputStream()
                const excel = _xls.open(archivoEntrada)

                excel.setCellData(
                    10, 1,
                    _val.map()
                        .set(
                            "value",
                            excel.getCellData(10, 1).getInt("value") + 10
                        )
                )

                archivoEntrada.close() // Cierra el archivo abierto.
                excel.save(_app.file("file.xlsx")) // Guarda la nueva versión.
                `
        },
    ]}
/>

## Leer archivo

La extracción de datos de archivos en Excel se hace con el método `read`.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const datos = _xls.read(_app.file("file.xlsx"))
            `
        },
    ]}
/>

Los datos se obtienen en una estructura de objetos del tipo Values que contiene Listas, para las hojas de cálculo, filas y columnas, y Mapas (clave y valor) para las celdas.

Para visualizar todos los datos podemos colocarlos como salida de datos del servicio:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _out.json(datos)
            `
        },
    ]}
/>

Para realizar la interacción tenemos que tener en cuenta que la estructura de los datos está organizada en el siguiente orden:

1. `sheets` - Hojas de cálculo
2. `rows` - Filas
3. `columns` - Columnas

Ejemplo de una interacción completa:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                for (const hoja of datos.getValues("sheets")) {
                    _out.println(\`<h4>Hoja: \${hoja.getInt("index")} - \${hoja.getString("name")}</h4>\`)
                    for (const fila of hoja.getValues("rows")) {
                        _out.println(\`<h4>Fila: \${fila.getInt("row")}</h4>\`)
                        _out.println("<p>")
                        for (const columna of fila.getValues("columns")) {
                            _out.print(\`\${columna.getInt("row")}:\${columna.getInt("column")}\`)
                            _out.print(\` # \${columna.getString("address")}\`)
                            _out.print(\` # \${columna.getString("type")}\`)
                            _out.print(\` # \${columna.getString("value")}\`)
                            _out.println("<br>")
                        }
                        _out.println("</p>")
                    }
                }
            `
        },
        {
            lang: 'python',
            code: `
                for hoja in datos.getValues("sheets"):
                    _out.println(f"<h4>Hoja: {hoja.getInt('index')} - {hoja.getString('name')}</h4>")
                    for fila in hoja.getValues("rows"):

El tipo de la celda se obtiene mediante el código:

- `columna.getString("type")`

Y los tipos soportados son:

- `string` - Contenido de texto.
- `numeric` - Contenido numérico o de fecha y/o hora.
- `boolean` - Verdadero o falso.
- `blank` - Celda en blanco.
- `formula` - Celda que contiene una fórmula.
- `error` - Error en el procesamiento de la celda.

### Parámetros adicionales

Para cada tipo de celda tenemos algunos parámetros adicionales.

`string` - Tipo de celda con contenido textual.

- `value` - Texto de la celda.
- `richValue` - Formatos de la celda.

`numeric` - Tipo de celda con contenido numérico, o fechas y también horas.

- `value` - Valor del contenido numérico de la celda.
  
En el caso de fechas y horas tenemos además estos parámetros adicionales:

- `localDateTime` - Objeto de Java Time LocalDateTime que representa el valor de fecha y hora de la celda.
- `localDate` - Objeto de Java Time LocalDate que representa el valor de fecha de la celda.
- `localTime` - Objeto de Java Time LocalTime que representa el valor de hora de la celda.
- `instant` - Objeto de Java Time Instant que representa el valor de fecha y/o hora de la celda.
- `date` - Objeto Date de Java que representa el valor de fecha y/o hora de la celda.

`boolean` - Tipo de celda con contenido booleano, es decir, verdadero o falso.

- `value` - Valor de tipo _boolean_, `true` o `false`.

`blank` - Tipo de celda sin contenido, por lo tanto no contiene parámetros adicionales.

`formula` - Tipo de celda que contiene fórmulas de cálculo.

- `value` - Valor final resultante del cálculo.
- `formula` - Contiene la expresión de la fórmula utilizada para el cálculo.

`error` - Tipo de celda que contiene error.

- `value` - Valor en byte del error generado.
- `code` - En caso de que haya errores en el cálculo de la fórmula, aquí se proporciona el código del error ocurrido.
