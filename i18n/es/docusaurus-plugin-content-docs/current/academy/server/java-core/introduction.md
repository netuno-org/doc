Netuno está desarrollado en Java, así que a partir de Java podemos crear nuevas funcionalidades.

Por ejemplo, podemos crear nuevos servicios nativos, o incluso nuevos recursos de programación low-code que están disponibles en todos los lenguajes de programación políglota, como JavaScript, Python, Ruby, Groovy y Kotlin.

En Java también podemos crear servicios web multi-aplicación que están disponibles en todas las aplicaciones de Netuno.

Cualquier técnica o biblioteca del ecosistema de Java puede utilizarse para crear cualquier tipo de funcionalidad.

> Aconsejamos que antes de iniciar este tutorial tengas algunas nociones básicas de _Java_.
