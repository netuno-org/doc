Con Netuno es posible crear **_Servicios Web_** y construir cualquier tipo de **APIs <a href="https://pt.wikipedia.org/wiki/REST" target="_blank">REST</a>** complejas para la integración de datos entre sistemas.

:::info ¿Qué es un Servicio Web?
Un Servicio Web permite que los sistemas intercambien información en línea de forma estandarizada. En Netuno, cada archivo dentro de `server/services/` se convierte automáticamente en un endpoint accesible vía HTTP.
:::

## ¿Por qué usar Servicios Web?

El uso de servicios asíncronos aporta beneficios claros para la experiencia del usuario:

- **Carga más rápida:** el servidor entrega la estructura visual de la página inmediatamente, sin esperar el procesamiento de todos los datos.
- **Datos dinámicos bajo demanda:** el frontend solicita solo los datos necesarios, cuando es necesario.
- **Integración entre sistemas:** un servicio creado en Netuno puede ser consumido por cualquier aplicación externa (móvil, otro sistema web, etc.).
- **Mejor experiencia de usuario:** el usuario no necesita esperar el procesamiento completo de la página antes de ver algo en la pantalla.

## Requisitos previos

Antes de comenzar, asegúrese de que:

- Netuno está instalado y en ejecución local.
- La aplicación `demo` fue creada como se describe en [Crear Aplicación](../app-create).
- Hay datos registrados en **Tareas** y relacionados con **Registros** (necesario para que el retorno no esté vacío).

## Configurar el Editor de Código

Para crear y editar servicios en Netuno, utilice un editor de código de su preferencia. Recomendamos **[Visual Studio Code](https://code.visualstudio.com/download)** por ser gratuito, ligero y altamente intuitivo, pero cualquier editor compatible con JavaScript/Python/Groovy funcionará normalmente.

## Abrir la Aplicación Demo {#abrir-a-aplicacao-demo}

1. Abra **Visual Studio Code**.
2. Haga clic en el icono de **Archivos** en el panel lateral izquierdo.
3. Seleccione **Abrir Carpeta** (Archivo > Abrir carpeta).
4. Navegue hasta la carpeta de instalación de Netuno.
5. Seleccione el directorio: **`apps/demo`**
6. Haga clic en **Abrir**.

La estructura de carpetas de la aplicación `demo` se cargará en el panel izquierdo.

## Crear el Servicio

Los servicios se procesan en el lado del **servidor**. Para crear un nuevo servicio:

1. En el panel de archivos, expanda la estructura hasta encontrar la carpeta `server/services/`.
2. Haga clic con el **botón derecho** sobre la carpeta `services`.
3. Seleccione **Nuevo Archivo** `New File`.
4. Nombre el archivo de acuerdo con el lenguaje que desee usar:

Implemente el servicio añadiendo el código a continuación al archivo creado. Este servicio consulta la base de datos y devuelve una lista de trabajadores con el total de horas registradas, en formato **JSON**.

### Entendiendo el Código

| Objeto/Método | Descripción |
|---|---|
| `_db.query()` | Ejecuta una consulta SQL y devuelve una lista de objetos en formato clave-valor (columna → dato). |
| `_val.list()` | Crea una lista mutable para acumular los resultados. |
| `_val.map()` | Crea un objeto de mapeo (clave-valor) para cada fila de resultado. |
| `_out.json()` | Serializa el objeto a JSON y envía la respuesta a las solicitudes HTTP. |

:::warning Datos necesarios
Asegúrese de que hay datos registrados en **Tareas** y vinculados a **Registros**. De lo contrario, el endpoint devolverá una lista vacía `[]`.
:::

## Ejecutar y Probar el Servicio

Con Netuno en ejecución, acceda al endpoint en el navegador:

:::tip Consejo para visualizar el JSON
Recomendamos **[Firefox](https://www.mozilla.org/)** para probar endpoints directamente en el navegador, ya que formatea y muestra la respuesta JSON de forma legible con resaltado de sintaxis. Alternativamente, use extensiones como **JSON Viewer** en Chrome o herramientas como **[Postman](https://www.postman.com/)** para pruebas más avanzadas.
:::

El retorno esperado será un JSON similar a:

```json
[
  { "nombre": "Ana García", "total": 12 },
  { "nombre": "Carlos Méndez", "total": 28 },
  { "nombre": "Juan Costa", "total": 45 }
]
```
