# Visión general de Netuno

## Introducción

¡Bienvenidos a **Netuno**!

Sabemos que adoptar nuevas tecnologías puede ser un desafío debido a la gran cantidad de opciones disponibles en el mercado. Netuno se creó para resolver este problema, simplificando el desarrollo al reunir las mejores herramientas y soluciones en un solo lugar.

Somos una plataforma centrada en la productividad. Uno de los mayores aceleradores de Netuno es la ausencia de procesos lentos de compilación o build.

Ofrecemos una experiencia de desarrollo fluida y flexible para usar diversos lenguajes de programación integrados con las principales bases de datos.

El entorno **low-code** de Netuno es políglota, lo que te permite elegir el lenguaje que mejor se adapte a la necesidad específica de cada servicio.

> Nuestro lema es simple: **con menos líneas de código, haces más.**

## Lenguajes compatibles

* <a href="https://groovy-lang.org/" target="_blank">Groovy</a>

## Productividad en el trabajo

Netuno elimina los cuellos de botella del desarrollo a través de los siguientes pilares:

-  **Elección segura de herramientas:** Reducimos tu tiempo de investigación y configuración inicial. Netuno ya viene estructurado con las soluciones más eficientes de la actualidad.

- **Flexibilidad políglota:** Trabaja con el lenguaje de programación de tu preferencia dentro del mismo ecosistema, utilizando una amplia variedad de recursos listos para cada servicio web específico.

- **Creación rápida de servicios web:** El enfoque low-code permite desarrollar API REST complejas con agilidad.

- **Integración sencilla:** Desarrolla el backend de forma rápida y conéctalo fácilmente a cualquier frontend, aplicaciones móviles, portales corporativos o tiendas virtuales.

- **Actualización en tiempo real (Hot Reload):** La rapidez en el desarrollo se debe también a que no es necesario reiniciar el servidor. En el ecosistema de Netuno, no hay compilaciones ni reinicios. La modificación del código es inmediata y en tiempo real.

* **Agilidad en el desarrollo:** Prueba tus API simultáneamente mientras desarrollas. Guarda el código en Netuno y haz la petición en tu frontend al instante.

* **Enfoque en la regla de negocio:** Deja que Netuno se encargue de la infraestructura básica y las conexiones. Céntrate en cómo tu sistema puede aportar más valor al usuario final.

## Backoffice

La plataforma simplifica el proceso de desarrollo al unificar la creación de interfaces de formulario con la estructuración automática de la base de datos.

Este enfoque reduce drásticamente la curva de aprendizaje, permitiendo que los desarrolladores se centren en la lógica de negocio mientras la plataforma gestiona la infraestructura.

Esto elimina la necesidad de escribir scripts SQL manuales o crear pantallas CRUD (Crear, Leer, Actualizar, Eliminar) repetitivas.


Al diseñar un formulario, estás modelando simultáneamente tu base de datos y generando una interfaz administrativa completa.

Netuno entrega un ecosistema administrativo listo para usar, que incluye:

| Funcionalidad | Descripción |
| :--- | :--- |
| **Relaciones** | Gestión automática de diagramas, claves foráneas y vínculos entre tablas. |
| **Búsqueda avanzada** | Filtros refinados para localizar registros rápidamente. |
| **Gestión de archivos** | Componentes nativos para la subida de imágenes y documentos. |
| **Exportación** | Extracción de datos en formatos compatibles para informes. |
| **Seguridad** | Control de perfiles de acceso y autenticación integrada. |

Netuno es **código abierto** y te permite explorar todo el potencial de la herramienta de forma gratuita y colaborativa para realizar trabajos complejos con alta productividad. [Empieza ahora](/docs/get-started/installation).

## Base de datos

Netuno simplifica la gestión de datos al unificar la creación del Backoffice con la estructura de la base de datos. Esta construcción no exige escribir manualmente scripts SQL complejos para crear tablas.

A través de la interfaz visual, es posible definir los campos y relaciones, y la plataforma sincroniza estas definiciones con la base de datos, generando automáticamente la interfaz de administración y el diagrama de datos.

## Diagrama de datos

Netuno genera automáticamente un diagrama dinámico que representa el modelo de datos de tu aplicación. Este recurso es esencial para visualizar la arquitectura de la información y los vínculos entre las tablas.

## Consulta

Netuno proporciona una consola de base de datos robusta e intuitiva, que permite a los desarrolladores interactuar directamente con los datos de forma ágil y organizada.

Es posible guardar comandos complejos o recurrentes para acceder a ellos rápidamente en el futuro. 
El sistema mantiene un historial de los comandos ejecutados, lo que facilita la auditoría y la recuperación de lógicas de consulta anteriores.

La consola permite ejecutar varios comandos simultáneamente. Para separar las instrucciones y garantizar que Netuno interprete cada una correctamente, utiliza el delimitador de punto y coma doble `;;`.

## Desarrollo low-code y políglota


Netuno destaca por su arquitectura flexible, que permite que cada proyecto utilice múltiples lenguajes de programación simultáneamente. 

Es posible crear varias aplicaciones (proyectos) independientes y, dentro de cada una, escribir servicios utilizando los lenguajes de mercado más populares y compatibles con Netuno.

La plataforma identifica automáticamente qué motor de ejecución utilizar según la extensión del archivo creado en la carpeta de servicios del servidor, por ejemplo:

- `.js` - JavaScript
- `.py` - Python
- `.rb` - Ruby
- `.kts` - Kotlin Script
- `.groovy` - Groovy
