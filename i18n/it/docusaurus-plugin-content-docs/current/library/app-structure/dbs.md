Organizzazione dei file di database.

## Cartella per il Database

La cartella `📂 dbs` è destinata a contenere i file di database della tua applicazione.

Nel caso dei database di tipo H2 Database tutti i file vengono generati automaticamente in questa cartella.

Questa cartella è utile per conservare qualsiasi cosa correlata al database, ad esempio backup, script,
dump, diagrammi, ecc.

Tutta la documentazione relativa al database che deve accompagnare il progetto dell'applicazione è consigliato
organizzarla in questa cartella.
