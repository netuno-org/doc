Documentazione e documenti in generale.

## Cartella dei documenti

Nella cartella `📂 docs` è dove organizziamo i documenti generali dell'applicazione.

Serve per organizzare i file utili come documentazione, design, architettura, integrazioni, ecc.

Qualsiasi cosa che sia utile alle altre persone che lavorano anch'esse allo sviluppo dell'applicazione, o che sia utile nello sviluppo della manutenzione o dell'evoluzione.

Bisogna tenere in considerazione che file binari troppo grandi possono inquinare e sporcare definitivamente il repository del codice, ovvero GIT. Poiché qualsiasi file troppo grande che va in GIT aumenta considerevolmente la cronologia delle modifiche, quindi i file video, gli zip, o qualsiasi altro documento molto esteso, devono essere evitati per non sovraccaricare GIT e creare complicazioni future.
