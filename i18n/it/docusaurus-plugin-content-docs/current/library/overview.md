Netuno è una piattaforma low-code per la creazione rapida di servizi web che facilita la gestione dei dati con un'interfaccia visuale integrata, garantendo la creazione di applicazioni web-based ad alte prestazioni.

Riduce lo sforzo e il tempo di sviluppo, così come i costi di produzione in ambito amministrativo, gestionale e industriale.

![Struttura Netuno](/docs/assets/introducao1.png)

Scopri come Netuno favorisce la tua esperienza di programmazione affinché tu abbia una programmazione creativa e non ripetitiva, mantenendo i livelli di prestazioni dallo sviluppo all'esecuzione:

> La piattaforma Netuno è gratuita, [inizia subito](/docs/get-started/installation).

## Moduli e campi

La creazione del modello dati è facilitata tramite il motore di moduli in ambiente WEB. La definizione dei moduli dà origine a tabelle nel database, e i loro campi definiscono le colonne. È possibile parametrizzare il tipo di dati, le proprietà dei campi, così come le loro relazioni. La _suite_ di costruzione WEB mette a disposizione diverse funzionalità come query al database, visualizzazione del Modello Entità-Associazione, tra le altre.

## Gestione di accessi e permessi

La gestione degli utenti e dei loro permessi è configurabile in ambiente WEB ed è accessibile tramite servizi di backend in Netuno. È anche possibile controllare l'accesso per utente e per gruppo a moduli e report.

## Libreria di risorse

La libreria di risorse presenta un'ampia gamma di funzionalità pronte all'uso. Tra queste è possibile trovare dai connettori con PDF, Excel, Email, Firebase fino alla pianificazione delle attività o al generatore di report con Jasper.

## API REST

Il livello di comunicazione del server è reso disponibile tramite API REST. La disponibilità di servizi tramite JSON consente a Netuno di comunicare con molteplici applicazioni di diversa natura, potendo ad esempio servire contemporaneamente client WEB e applicazioni mobile sulla stessa interfaccia.

## Livello di servizi poliglotta

Scrivi servizi in <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://groovy-lang.org/" target="_blank">Groovy</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a> o in <a href="https://pt.wikipedia.org/wiki/Java_(linguagem_de_programa%C3%A7%C3%A3o)" target="_blank">Java</a>, tutte sono valide. Netuno rimuove l'isolamento tra linguaggi di programmazione, la stessa applicazione supporta servizi in esecuzione contemporanea in più linguaggi senza che ciò aumenti il carico di elaborazione.

## Multi database

Configura diversi database differenti e usali contemporaneamente. Nativamente Netuno supporta diversi motori di database relazionali come <a href="https://www.h2database.com/html/main.html" target="_blank">H2DataBase</a>, <a href="https://www.postgresql.org/" target="_blank">PostgreSQL</a> e CockroachDB, <a href="https://mariadb.org/" target="_blank">MariaDB (_MySQL_)</a>, Microsoft SQL Server e Oracle. Potrai creare la tua applicazione usando, ad esempio, PostgreSQL con un database principale e integrarti con altri database in MariaDB, e a metà di un progetto potrai passare a Microsoft SQL Server o Oracle senza dover apportare alcuna modifica al codice.

> Offre supporto nativo all'integrazione con MongoDB.

## Serverless

Netuno è anche il tuo server applicativo. Con un comando esegui la tua applicazione senza dover perdere tempo in licenze, configurazioni e sviluppi aggiuntivi.

## Prestazioni nello sviluppo e nell'esecuzione

Non devi imparare a lavorare con un nuovo software di sviluppo tramite drag and drop, né memorizzare l'interfaccia di un nuovo framework. Con la possibilità di programmare in 6 linguaggi diversi, avere un livello dati generato automaticamente e librerie disponibili da usare on-the-fly, il low-code di Netuno è la migliore soluzione per le tue scadenze strette.

Utilizzando generatori di codice ottimizzati per alte prestazioni e usando la recente <a href="https://www.graalvm.org/" target="_blank">GraalVM</a>, il server applicativo diventa incredibilmente veloce, indipendentemente dal linguaggio utilizzato.
