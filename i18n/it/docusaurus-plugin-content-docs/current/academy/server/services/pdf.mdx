Elaborare file PDF personalizzati.

## Introduzione

Netuno genera file PDF con supporto per immagini, tabelle, font e molto altro, tramite la risorsa [PDF](/docs/library/resources/pdf) che consente un'astrazione low-code di [iTextPDF](https://itextpdf.com/) per i vari linguaggi di programmazione supportati da Netuno.

L'applicazione fornita con Netuno denominata **demo** (applicazione di dimostrazione) contiene molti esempi delle possibili implementazioni di codice in varie lingue, inclusa la dimostrazione dell'esportazione in PDF tramite il servizio `export-pdf` che si trova in:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-pdf`
]} />

## Inizializzazione

Innanzitutto è necessario creare l'oggetto che conterrà il contesto del nuovo documento in fase di creazione; per impostazione predefinita, la dimensione delle pagine è A4.

## Intestazione HTTP

Per creare un servizio nell'API REST che restituisce un file PDF come output, è necessario aggiungere nell'header il parametro `Content-Type` del protocollo HTTP.

Esempio di come definire il contenuto come PDF:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("pdf")
            `
        },
    ]}
/>

Il codice `pdf` è un'abbreviazione per:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("application/pdf")
            `
        },
    ]}
/>

## Paragrafo

Aggiunge un nuovo paragrafo al documento:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentoPdf.add(
                    _pdf.paragraph("Il mio testo qui...")
                        .setFontSize(15)
                )
            `
        },
    ]}
/>

Per aggiungere un paragrafo in una posizione fissa:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentoPdf.add(
                    documentoPdf.add(
                        _pdf.paragraph("Il mio testo fisso...")
                            .setFixedPosition(100, 500, 200)
                            .setFontSize(15)
                    )
                )
            `
        },
    ]}
/>

Nel codice sopra, nel metodo `setFixedPosition`, il primo parametro è la posizione X (`100`), il secondo parametro è la posizione Y (`500`) e il terzo parametro è la larghezza (`200`).

**Attenzione:** se Y è impostato al valore `0` significa che si trova in fondo alla pagina, quindi per salire è necessario aumentare il valore di Y; maggiore è il valore di Y, più in alto apparirà, ma se è troppo alto oltre la lunghezza della pagina non sarà visibile.

> Documentazione con tutti i metodi dell'oggetto [Paragrafo di iText](https://api.itextpdf.com/iText/java/8.0.3/com/itextpdf/layout/element/Paragraph.html).

## Tabella

È possibile creare tabelle, il che permette di presentare un insieme di dati in modo più leggibile.

Il numero di colonne della tabella è definito con il parametro: `_pdf.table(numeroColonne)`

Nell'esempio sotto `numeroColonne` è il numero `1`, ovvero una colonna.

Poiché abbiamo aggiunto due celle alla tabella, la seconda cella passa alla riga successiva.

Nota:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentoPdf.add(
                    _pdf.table(1)
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Persona")
                                        .setFont(elvetica)
                                        .setFontSize(10)
                                )
                                .setBorder(_pdf.border("solid", 2))
                                .setBackgroundColor(_pdf.colorRGB(1, 0, 0))
                        )
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Nicole")
                                        .setFont(elvetica)
                                        .setFontSize(10)
                                )
                                .setBackgroundColor(_pdf.colorGray(0.5))
                        )
                )
            `
        },
    ]}
/>

Con il metodo `addCell` è possibile inserire la definizione delle celle con il loro rispettivo contenuto.

> Documentazione con tutti i metodi dell'oggetto [Cella di iText](https://api.itextpdf.com/iText/java//8.0.3/com/itextpdf/layout/element/Cell.html).

## Chiudere e salvare il documento

Il documento viene completamente salvato o generato solo quando viene chiamato il metodo `close`, nel modo seguente:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentoPdf.close()
            `
        },
    ]}
/>

Il luogo in cui viene generato il documento è definito all'inizializzazione; quindi è all'inizializzazione del documento che definiamo dove verrà generato il documento finale, se nell'output del servizio (`output`) o in un file.

## Leggere il file

Per leggere un documento PDF, estraendo le informazioni di testo.

Utilizziamo il metodo `extract`, che ottiene tutti i dati del file PDF in un oggetto JSON.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const datiPdf = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(datiPdf)
            `
        },
        {
            lang: 'python',
            code: `
                datiPdf = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(datiPdf)
            `
        },
        {
            lang: 'ruby',
            code: `
                datiPdf = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(datiPdf)
            `
        },
        {
            lang: 'kotlin',
            code: `
                val datiPdf = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(datiPdf)
            `
        },
        {
            lang: 'groovy',
            code: `
                def datiPdf = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(datiPdf)
            `
        },
    ]}
/>

Il JSON restituito ha la chiave `content` con tutto il contenuto testuale del file PDF e la chiave `metadata` con le varie proprietà del file PDF.

Qui c'è un esempio del JSON restituito da `extract`:

```json
{
  "content": "Tutto il contenuto testuale del file PDF viene qui...",
  "metadata":{
    "Content-Type":"application/pdf",
    "dc:format":"application/pdf; version=1.4",
    "dc:title":"Linux 1",
    "pdf:PDFVersion":"1.4",
    "pdf:charsPerPage":"580",
    "pdf:containsDamagedFont":"false",
    "pdf:containsNonEmbeddedFont":"false",
    "pdf:docinfo:producer":"Skia/PDF m125 Google Docs Renderer",
    "pdf:docinfo:title":"File 1",
    "pdf:encrypted":"false",
    "xmpTPg:NPages":"3",
    ...
  }
}
```

Esistono molti altri dati ottenuti in `metadata` che sono stati omessi nei `...` per non rendere l'esempio troppo lungo.

## Convertire

È possibile convertire programmaticamente il PDF in testo o persino in HTML.

### PDF in testo

Possiamo estrarre tutto il contenuto del file PDF in testo continuo utilizzando il metodo:

    codes={[

            lang: 'javascript',
            code: `

            `
        },
