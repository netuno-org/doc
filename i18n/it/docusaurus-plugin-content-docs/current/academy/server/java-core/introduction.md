Netuno è sviluppato in Java, quindi a partire da Java possiamo creare nuove funzionalità.

Ad esempio, possiamo creare nuovi servizi nativi, o anche nuove risorse di programmazione low-code che sono
disponibili in tutti i linguaggi di programmazione poliglotti, come JavaScript, Python, Ruby, Groovy e Kotlin.

In Java possiamo anche creare servizi web multi-applicazione che sono disponibili in tutte le applicazioni Netuno.

Qualsiasi tecnica o libreria dell'ecosistema Java può essere utilizzata per creare qualsiasi tipo di funzionalità.

> Consigliamo che prima di iniziare questo tutorial tu abbia alcune nozioni di base di _Java_.
