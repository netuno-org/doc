Tieni presente cosa serve per continuare a crescere con Netuno.

La documentazione nel suo complesso è in costante miglioramento e cerca di essere il più semplice e introduttiva possibile.

Ma si presuppone che tu abbia alcune basi di conoscenza e una certa esperienza in aree specifiche, come:

* Database, come query in generale, insert, update e delete;
* Web service, con GET e POST;
* <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a> e <a href="https://reactjs.org/" target="_blank">ReactJS</a>;

Se non possiedi alcune di queste competenze, proveremo ad aiutarti a svilupparle.

Cerca sempre aiuto su GitHub o Discord, consulta le indicazioni nel piè di pagina del sito.

## Database

Con Netuno potrai lavorare con diversi tipi di database e approfondire le tue conoscenze.

Solo con una buona conoscenza dei database è possibile creare applicazioni con strutture complesse per raccogliere e gestire un grande volume di dati.

In questo modo avrai l'autonomia per creare in modo robusto la parte più importante, cioè il database.

La costruzione di un database ben organizzato e ottimizzato fa tutta la differenza nell'esperienza degli utenti finali, così come nelle prestazioni, dallo sviluppo all'esecuzione.

## Servizi

Se hai già una certa conoscenza di uno dei seguenti linguaggi di programmazione come <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a> o <a href="https://groovy-lang.org/" target="_blank">Groovy</a>, potrai creare rapidamente web service complessi e robusti utilizzando le diverse risorse che Netuno mette a disposizione per la programmazione **low code**.

All'interno della cartella delle applicazioni, in particolare nella cartella **server**, potrai programmare in questi diversi linguaggi.

Basta utilizzare l'estensione corrispondente:

* **.js** &nbsp; <a href="https://developer.mozilla.org/pt-PT/docs/Web/JavaScript" target="_blank">JavaScript</a>
* **.ts** &nbsp; <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>
* **.py** &nbsp; <a href="https://www.jython.org/" target="_blank">Python</a>
* **.rb** &nbsp; <a href="https://www.jruby.org/" target="_blank">Ruby</a>
* **.kts** &nbsp; <a href="https://kotlinlang.org/" target="_blank">Kotlin</a>
* **.groovy** &nbsp; <a href="https://groovy-lang.org/" target="_blank">Groovy</a>

Esplora gli esempi di web service inclusi nell'applicazione **demo** (_dimostrativa_), in:

- `/apps/demo/server/services/samples`

Ed esplora anche la documentazione della nostra **libreria** per conoscere in dettaglio le risorse disponibili.


## Interfaccia utente

Lo sviluppo del frontend sul web ha subito molti cambiamenti negli ultimi anni e l'utilizzo di <a href="https://vite.dev/" target="_blank">Vite</a> è diventato uno standard.

Le nostre scelte tecnologiche come <a href="https://reactjs.org/" target="_blank">ReactJS</a>, <a href="https://bun.sh/" target="_blank">Bun</a>, <a href="https://ant.design/" target="_blank">Ant.Design</a> e <a href="http://lesscss.org/" target="_blank">Less</a>, sono tecnologie che apportano un aumento della produttività con un'ampia adozione.

Per approfondire le conoscenze su queste tecnologie, esplora le diverse documentazioni in formato testo e video disponibili su internet.

Poiché sono tecnologie con grandi community, non è difficile trovare buon materiale per iniziare a imparare.

Ricordiamo che con Netuno, anche con un po' di conoscenza, è già possibile ottenere ottimi risultati, il che dà al programmatore frontend il potere di sviluppare tutto il backend e viceversa, potendo anche scegliere di sviluppare tutto con un unico linguaggio di programmazione come <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>.

## Conclusione

Netuno facilita lo sviluppo delle applicazioni web, dove anche una sola persona con poche conoscenze di database, web service e frontend può sviluppare applicazioni complesse in modo autonomo.

Anche per team di grandi dimensioni, dove ci sono persone con maggiore competenza in ciascuna area, apporta in generale un grande aumento di produttività.

Netuno può anche essere utilizzato come backoffice per database o come server di API REST per frontend disaccoppiati e applicazioni mobile.

Risparmia tempo e sviluppa concentrandoti maggiormente sulla logica delle regole di business e, con le conoscenze che già possiedi, arriverai più lontano.
