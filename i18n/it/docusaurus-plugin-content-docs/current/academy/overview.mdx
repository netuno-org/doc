# Panoramica di Netuno

## Introduzione

Benvenuti in **Netuno**!

Sappiamo che adottare nuove tecnologie può essere una sfida a causa della grande quantità di opzioni disponibili sul mercato. Netuno è stato creato per risolvere questo problema, semplificando lo sviluppo e riunendo le migliori strumenti e soluzioni in un unico posto.

Siamo una piattaforma focalizzata sulla produttività. Uno dei maggiori acceleratori in Netuno è l'assenza di processi dispendiosi di compilazione o build.

Offriamo un'esperienza di sviluppo fluida e flessibile per utilizzare diversi linguaggi di programmazione integrati con i principali database.

L'ambiente **low-code** di Netuno è poliglotta, permettendoti di scegliere il linguaggio che meglio si adatta alle esigenze specifiche di ciascun servizio.

> Il nostro motto è semplice: **con meno righe di codice, fai di più.**

## Produttività sul lavoro

Netuno elimina i colli di bottiglia dello sviluppo attraverso i pilastri:

-  **Scelta sicura degli strumenti:** Riduciamo il tuo tempo di ricerca e configurazione iniziale. Netuno è già strutturato con le soluzioni più efficienti attuali.

- **Flessibilità poliglotta:** Lavora con il linguaggio di programmazione che preferisci all'interno dello stesso ecosistema, utilizzando un'ampia varietà di risorse pronte per ogni servizio Web specifico.

- **Creazione rapida di servizi Web:** L'approccio low-code permette di sviluppare API REST complesse con agilità.

- **Integrazione senza complicazioni:** Sviluppa il backend rapidamente e collegalo facilmente a qualsiasi frontend, applicazione mobile, portale aziendale o negozio online.

- **Aggiornamento in tempo reale (Hot Reload):** La rapidità nello sviluppo è dovuta anche al fatto di non dover riavviare il server. Nell'ecosistema di Netuno non ci sono compilazioni e riavvii. La modifica del codice è immediata e in tempo reale.

* **Agilità nello sviluppo:** Testa le tue API contemporaneamente mentre sviluppi. Salva il codice in Netuno ed effettua la richiesta nel tuo frontend nello stesso momento.

* **Focus sulla regola di business:** Lascia che Netuno si occupi dell'infrastruttura di base e delle connessioni. Concentrati su come il tuo sistema può offrire più valore all'utente finale.

## Backoffice

La piattaforma semplifica il percorso di sviluppo unificando la creazione di interfacce di formulario con la strutturazione automatica del database.

Questo approccio riduce drasticamente la curva di apprendimento, permettendo agli sviluppatori di concentrarsi sulla logica di business mentre la piattaforma gestisce l'infrastruttura.

Ciò elimina la necessità di scrivere script SQL manuali o creare schermate CRUD (Create, Read, Update, Delete) ripetitive.


Disegnando un formulario, stai contemporaneamente modellando il tuo database e generando un'interfaccia amministrativa completa.

Netuno offre un ecosistema amministrativo pronto all'uso, che include:

| Funzionalità | Descrizione |
| :--- | :--- |
| **Relazioni** | Gestione automatica di diagrammi, chiavi esterne e collegamenti tra tabelle. |
| **Ricerca avanzata** | Filtri raffinati per la localizzazione rapida dei record. |
| **Gestione file** | Componenti nativi per l'upload di immagini e documenti. |
| **Esportazione** | Estrazione di dati in formati compatibili per report. |
| **Sicurezza** | Controllo dei profili di accesso e autenticazione integrata. |

Netuno è **open-source** e ti permette di esplorare tutto il potenziale dello strumento in modo gratuito e collaborativo per realizzare lavori complessi con alta produttività. [Inizia ora](/docs/get-started/installation).

## Database

Netuno semplifica la gestione dei dati unificando la creazione del Backoffice con la struttura del database. Questa costruzione non richiede la scrittura manuale di script SQL complessi per la creazione di tabelle.

Attraverso l'interfaccia visuale, è possibile definire i campi e le relazioni, e la piattaforma sincronizza queste definizioni con il database, generando automaticamente l'interfaccia di amministrazione e il diagramma dei dati.

## Diagramma dei dati

Netuno genera automaticamente un diagramma dinamico che rappresenta il modello dei dati della tua applicazione. Questa risorsa è essenziale per visualizzare l'architettura dell'informazione e i collegamenti tra le tabelle.

## Query

Netuno fornisce una console di database robusta e intuitiva, che permette agli sviluppatori di interagire direttamente con i dati in modo agile e organizzato.

È possibile salvare comandi complessi o ricorrenti per un accesso rapido in futuro.
Il sistema mantiene una cronologia dei comandi eseguiti, facilitando l'audit e il recupero di logiche di consultazione precedenti.

La console permette l'esecuzione di diversi comandi contemporaneamente. Per separare le istruzioni e garantire che Netuno interpreti correttamente ciascuna di esse, utilizza il delimitatore di punto e virgola doppio `;;`.

## Sviluppo low-code e poliglotta


Netuno si distingue per la sua architettura flessibile, che permette a ogni progetto di utilizzare più linguaggi di programmazione contemporaneamente.

È possibile creare diverse applicazioni (progetti) indipendenti e, all'interno di ciascuna, scrivere servizi utilizzando i linguaggi di mercato più popolari e supportati da Netuno.

La piattaforma identifica automaticamente quale motore di esecuzione utilizzare in base all'estensione del file creato nella cartella dei servizi del server, ad esempio:

- `.js` - JavaScript
- `.py` - Python
- `.rb` - Ruby
- `.kts` - Kotlin Script
- `.groovy` - Groovy
