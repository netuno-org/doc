Netuno è poliglotta sia a livello di database che di codice di programmazione, ma anche a livello di sistema operativo.

Con tutta questa diversità aumentano le opzioni su dove può essere utilizzato.

Supportando diversi database, linguaggi di programmazione e sistemi operativi, facilita lo sviluppo riuscendo ad adattarsi a ciascuna situazione ma garantendo un ambiente coeso per gli sviluppi.

## Database

Può essere utilizzato per integrare vari tipi di database diversi e persino essere sviluppato con linguaggi di programmazione diversi nello stesso progetto.

Integrare database diversi è abbastanza comune per realizzare l'integrazione dei dati quando si consultano o modificano dati in database di un altro sistema.

![Loghi dei Database](/docs/assets/business/databases.jpg "Database multipli")

Netuno supporta i seguenti database:

- H2 Database
- PostgreSQL
- MariaDB
- MySQL
- Microsoft SQL Server
- Oracle

## Linguaggi di Programmazione

Supportare linguaggi di programmazione diversi può non sembrare molto interessante nel senso di mescolare linguaggi di programmazione, ma è possibile e non significa che debba essere fatto così.

In pratica, spesso è complicato realizzare progetti in cui c'è una tecnologia dominante limitata a un linguaggio di programmazione, quindi bisogna trovare persone esclusivamente competenti in quel determinato linguaggio di programmazione.

Con Netuno finiamo per avere un'offerta maggiore, in cui tutto il lavoro non va sprecato nel caso sia necessario utilizzare un nuovo linguaggio di programmazione derivante da un cambio di strategia, o dalla mancanza di tecnici competenti, o dal voler ottenere maggiore agilità nello sviluppo di qualcosa di specifico, tra le altre situazioni che possono avere senso.

Di norma questo sarebbe impensabile perché la manutenzione di un sistema con diversi linguaggi di programmazione inizia a destare preoccupazione, ma essendo questa low-code tale preoccupazione smette di essere molto rilevante, perché:

* I linguaggi di programmazione finiscono per essere simili a livello di logica e algoritmo.
* Il linguaggio di programmazione può essere diverso ma le risorse di Netuno sono le stesse e vengono utilizzate allo stesso modo indipendentemente dal linguaggio.

Così, anche se un tecnico è molto abituato a lavorare con un linguaggio di programmazione, nulla gli impedirà di effettuare la manutenzione in un altro; nel caso debba estendere molto di più il suo intervento o addirittura rifare, potrà scegliere di sviluppare nel suo linguaggio preferito e integrare il suo sviluppo nel linguaggio già esistente in uso.

![Loghi dei Linguaggi di Programmazione](/docs/assets/business/languages.jpg "Linguaggi di programmazione")

Netuno supporta lo sviluppo nei seguenti linguaggi di programmazione:

- Groovy
- Java
- JavaScript
- Kotlin
- Python
- Ruby

## Sistemi Operativi

Netuno, lavorando con molteplici sistemi operativi e con il supporto a configurazioni di ambiente, consente di garantire il corretto funzionamento degli sviluppi in modo trasversale e di organizzarli in ambienti di sviluppo, test, qualità, produzione, tra gli altri.

La modifica del sistema operativo o dell'ambiente è indifferente per il corretto funzionamento di Netuno e delle applicazioni.

![Loghi dei Sistemi Operativi](/docs/assets/business/operationsystems.jpg "Molteplici Sistemi Operativi")

I sistemi operativi supportati da Netuno sono:

* Linux
* Mac OS X
* Windows
