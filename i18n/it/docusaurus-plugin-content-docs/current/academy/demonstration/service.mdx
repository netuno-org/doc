Con Netuno è possibile creare **_Web Service_** e realizzare qualsiasi tipo di **API <a href="https://pt.wikipedia.org/wiki/REST" target="_blank">REST</a>** complesse per l'integrazione dei dati tra sistemi.

:::info Cos'è un Web Service?
Un Web Service consente ai sistemi di scambiare informazioni online in modo standardizzato. In Netuno, ogni file all'interno di `server/services/` diventa automaticamente un endpoint accessibile via HTTP.
:::

## Perché usare i Web Service?

L'uso di servizi asincroni offre chiari benefici per l'esperienza utente:

- **Caricamento più rapido:** il server fornisce immediatamente la struttura visiva della pagina, senza attendere l'elaborazione di tutti i dati.
- **Dati dinamici su richiesta:** il frontend richiede solo i dati necessari, quando serve.
- **Integrazione tra sistemi:** un servizio creato in Netuno può essere consumato da qualsiasi applicazione esterna (mobile, altro sistema web, ecc.).
- **Migliore esperienza utente:** l'utente non deve attendere l'elaborazione completa della pagina prima di vedere qualcosa sullo schermo.

## Prerequisiti

Prima di iniziare, assicurati che:

- Netuno sia installato e in esecuzione in locale.
- L'applicazione `demo` sia stata creata come descritto in [Creare Applicazione](../app-create).
- Ci siano dati registrati in **Attività** e collegati a **Registrazioni** (necessario affinché il risultato non sia vuoto).

## Configurare l'Editor di Codice

Per creare e modificare i servizi in Netuno, utilizza un editor di codice di tua preferenza. Consigliamo **[Visual Studio Code](https://code.visualstudio.com/download)** perché è gratuito, leggero e altamente intuitivo, ma qualsiasi editor compatibile con JavaScript/Python/Groovy funzionerà normalmente.

## Aprire l'Applicazione Demo {#abrir-a-aplicacao-demo}

1. Apri **Visual Studio Code**.
2. Fai clic sull'icona **File** nel pannello laterale sinistro.
3. Seleziona **Apri Cartella** (File > Open Folder).
4. Vai alla cartella di installazione di Netuno.
5. Seleziona la directory: **`apps/demo`**
6. Fai clic su **Apri**.

La struttura delle cartelle dell'applicazione `demo` verrà caricata nel pannello sinistro.

## Creare il Servizio

I servizi vengono elaborati sul lato **server**. Per creare un nuovo servizio:

1. Nel pannello dei file, espandi la struttura fino a trovare la cartella `server/services/`.
2. Fai clic con il **tasto destro** sulla cartella `services`.
3. Seleziona **Nuovo File** `New File`.
4. Assegna un nome al file in base al linguaggio che desideri usare:

Implementa il servizio aggiungendo il codice sotto al file creato. Questo servizio interroga il database e restituisce un elenco di lavoratori con il totale delle ore registrate, in formato **JSON**.

### Comprendere il Codice

| Oggetto/Metodo | Descrizione |
|---|---|
| `_db.query()` | Esegue una query SQL e restituisce un elenco di oggetti in formato chiave-valore (colonna → dato). |
| `_val.list()` | Crea un elenco mutabile per accumulare i risultati. |
| `_val.map()` | Crea un oggetto di mappatura (chiave-valore) per ogni riga di risultato. |
| `_out.json()` | Serializza l'oggetto in JSON e invia la risposta alle richieste HTTP. |

:::warning Dati necessari
Assicurati che ci siano dati registrati in **Attività** e collegati a **Registrazioni**. In caso contrario, l'endpoint restituirà una lista vuota `[]`.
:::

## Eseguire e Testare il Servizio

Con Netuno in esecuzione, accedi all'endpoint nel browser:

:::tip Suggerimento per visualizzare il JSON
Consigliamo **[Firefox](https://www.mozilla.org/)** per testare gli endpoint direttamente nel browser, poiché formatta e visualizza la risposta JSON in modo leggibile con evidenziazione della sintassi. In alternativa, usa estensioni come **JSON Viewer** in Chrome o strumenti come **[Postman](https://www.postman.com/)** per test più avanzati.
:::

Il risultato restituito sarà un JSON simile a:

```json
[
  { "nome": "Anna Rossi", "totale": 12 },
  { "nome": "Carlo Bianchi", "totale": 28 },
  { "nome": "Giovanni Costa", "totale": 45 }
]
```

- 🔗 Aggiungere **autenticazione** e **controllo degli accessi** al tuo servizio.
