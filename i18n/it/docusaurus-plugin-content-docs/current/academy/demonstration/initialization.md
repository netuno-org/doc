# Inizializzazione 

Inizializzazione dell'applicazione Demo

Per dare inizio a questo tutorial, il primo passo è avviare il server dell'applicazione **Demo** e preparare l'ambiente di sviluppo.


### Avvia il server 

Apri il terminale del tuo sistema operativo e spostati nella cartella radice in cui è installata la piattaforma Netuno (ad esempio, `📁 /netuno`).

Esegui il comando seguente per avviare il server:

```bash
./netuno server
```

:::info Alternativa di avvio
Se il comando principale non funziona o l'applicazione Demo non viene caricata per impostazione predefinita, forza l'avvio specificando il parametro dell'applicazione:
:::

```bash
./netuno server app=demo
```

### Scegli l'editor di codice
Puoi utilizzare l'editor di codice che preferisci per sviluppare sia il backend sia il frontend della tua applicazione.

Se non ne hai ancora uno, ti consigliamo le seguenti opzioni gratuite e open source:

- VS Code: <a href="https://code.visualstudio.com/" target="_blank">code.visualstudio.com</a>
- VS Codium: <a href="https://vscodium.com/" target="_blank">vscodium.com</a>
- WebStorm: <a href="https://www.jetbrains.com/webstorm/" target="_blank">jetbrains.com/webstorm</a>


#### Apri la cartella del progetto
Con l'editor di codice aperto, individua e apri la directory dell'applicazione Demo: `📁 apps/demo`.

Questa cartella contiene tutti i file e le configurazioni della nuova applicazione. È esclusivamente all'interno di questa directory che verrà svolto tutto lo sviluppo.

### Prossimi passi

Con il server in esecuzione e i file aperti nell'editor di codice, l'ambiente è pronto. Passa alla fase successiva del tutorial per iniziare a esplorare e modificare l'applicazione.
