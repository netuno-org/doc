# 소개

**Netuno** 설치 가이드에 오신 것을 환영합니다. **Netuno**는 프로젝트 생성을 가속화하고 개발 환경 설정을 간소화하기 위해 개발된 *로우코드*, 다중 언어 지원, *오픈 소스* 플랫폼입니다.

여기에서 로우코드의 속도와 전통적인 코딩의 강력함을 결합하여 견고한 풀스택 애플리케이션을 민첩하게 구축할 수 있습니다.

## 빠른 설치

Netuno를 설치하는 가장 쉬운 방법은 플랫폼에서 제공하는 설치 스크립트를 사용하는 것입니다. 운영체제에 맞는 명령을 터미널에서 실행하기만 하면 됩니다.

<Tabs groupId="os">
    <TabItem value="linux-mac" label="Linux 또는 macOS" default>

```bash
bash <(curl -fsSL https://netu.no/install.sh)
```

    </TabItem>
    <TabItem value="windows" label="Windows">

```powershell
powershell -c "irm https://netu.no/install.ps1|iex"
```

    </TabItem>
</Tabs>

## 데모 앱 시작

설치를 완료한 후 `netuno` 폴더 안에서 아래 명령을 실행하여 데모 애플리케이션과 함께 서버를 시작하세요:

```bash
./netuno server
```

### 브라우저에서 애플리케이션 열기

초기화가 완료되면 로컬 서버 주소로 브라우저가 자동으로 열립니다. 자동으로 열리지 않으면 아래 주소 중 하나에 수동으로 접속하세요:

- [http://demo.local.netu.no:9000](http://demo.local.netu.no:9000)
- [http://localhost:9000](http://localhost:9000)

## 서버 중지

서버를 종료하려면 터미널에서 다음 키를 누르세요:

**CTRL + C**

다시 시작하려면 동일한 명령 `./netuno server`를 사용하세요.
