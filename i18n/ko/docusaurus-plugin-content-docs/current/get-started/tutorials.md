# 튜토리얼

Netuno 플랫폼의 튜토리얼을 탐색하며 리소스 구성, 데이터 모델링, 인터페이스 생성, 백엔드 비즈니스 로직 개발 방법을 실습으로 배워보세요.

이 페이지는 이제 막 시작하는 분들과 플랫폼 활용을 더 깊이 있게 하고자 하는 분들을 위한 주요 콘텐츠를 모아 놓았습니다.

## 시작하기 전에

어떤 튜토리얼을 시작하기 전에 환경이 준비되어 있는지 확인하세요:

- **Netuno가 설치**되어 로컬 또는 개발 환경에서 실행 중이어야 합니다.
- 적절한 권한으로 **관리자 패널에 접근**할 수 있어야 합니다.
- 기술 콘텐츠를 더 잘 활용하기 위해 데이터 모델링, HTTP, REST API에 대한 **기본 지식을 갖추는 것을 권장**합니다.

진행하기 전에 [설치](./installation) 가이드를 참고하세요.

## 권장 순서

Netuno를 처음 경험한다면 다음 순서를 따르세요:

1. 그래픽 인터페이스를 알아보세요.
2. 폼과 필드 생성 방법을 배우세요.
3. 폼 간의 관계를 구성하세요.
4. 권한과 사용자 그룹으로 넘어가세요.
5. 프로젝트 필요에 따라 쿼리와 백엔드 리소스를 탐색하세요.

## 그래픽 인터페이스 - 프론트엔드

이 섹션의 튜토리얼은 플랫폼의 관리자 인터페이스를 활용하여 애플리케이션을 생성하고 구성하고자 하는 분들을 대상으로 합니다.

| 튜토리얼 | 목표 | 수준 |
|---|---|---|
| [그래픽 인터페이스 알아보기](/docs/academy/ui/graphical-interface) | 패널의 구조, 메뉴, 주요 리소스를 이해합니다. | 초급 |
| [폼](/docs/academy/ui/forms) | 폼을 시각적으로 생성하고 구성합니다. | 초급 |
| [필드](/docs/academy/ui/fields) | 데이터 유형, 유효성 검사, 필드 동작을 구성합니다. | 초급 |
| [폼 간의 관계](/docs/academy/ui/relationships-between-forms) | 데이터 간의 연결과 폼 간의 관계를 정의합니다. | 중급 |
| [그룹과 사용자](/docs/academy/ui/groups-users) | 권한, 접근 프로필, 사용자 구성을 관리합니다. | 중급 |
| [쿼리 인터페이스](/docs/academy/ui/queries-interface) | 데이터 분석 및 추출을 위한 시각적 쿼리를 생성합니다. | 중급 |
| [모달 폼](/docs/academy/explore/modal-form) | 모달 창을 사용한 고급 상호작용을 구축합니다. | 고급 |

## 백엔드

Netuno는 다양한 언어와 시나리오에서 로우코드와 백엔드 개발을 결합할 수 있도록 합니다. 아래 튜토리얼은 통합 생성, 데이터 조작, 비즈니스 규칙 구현에 도움을 줍니다.

### 사전 요구 사항

이 섹션으로 넘어가기 전에 다음에 익숙해지는 것을 권장합니다:

- 클라이언트-서버 아키텍처와 HTTP 프로토콜.
- JSON 데이터 구조.
- JavaScript, Python 또는 개발 흐름과 호환되는 다른 언어의 프로그래밍 로직.

### API 및 통합

| 튜토리얼 | 목표 | 수준 |
|---|---|---|
| [REST 웹 서비스](/docs/academy/server/services/rest) | 외부 애플리케이션과 시스템에서 사용할 수 있도록 엔드포인트를 생성하고 노출합니다. | 중급 |
| [이메일 전송](/docs/academy/server/services/sending-emails) | SMTP를 통한 트랜잭션 이메일 전송을 구성합니다. | 중급 |

:::tip 튜토리얼 선택 방법

애플리케이션을 시각적으로 구성하고, 데이터를 구조화하며, 인터페이스를 통해 리소스를 관리하는 것이 목표라면 **그래픽 인터페이스** 튜토리얼을 사용하세요.
비즈니스 로직, 통합, 인증, 자동화 또는 데이터에 대한 프로그래밍 방식 접근이 필요한 경우 **백엔드** 튜토리얼을 사용하세요.
:::
