Netuno는 통합 비주얼 인터페이스를 통해 데이터 관리를 용이하게 하는 빠른 웹 서비스 구축용 로우코드 플랫폼이며, 고성능 웹 기반 애플리케이션 생성을 보장합니다.

개발 노력과 시간, 그리고 행정, 경영 및 산업 분야의 생산 비용을 줄여줍니다.

![Netuno 구조](/docs/assets/introducao1.png)

Netuno가 어떻게 창의적이고 반복적이지 않은 프로그래밍 경험을 제공하여 개발부터 실행까지 성능 수준을 유지하는지 알아보세요:

> Netuno 플랫폼은 무료입니다. [지금 시작하세요](/docs/get-started/installation).

## 양식과 필드

데이터 모델 생성은 웹 환경의 양식 엔진을 통해 용이해집니다. 양식을 정의하면 데이터베이스에 테이블이 생성되며, 해당 필드가 열을 정의합니다. 데이터 유형, 필드 속성 및 관계를 매개변수화할 수 있습니다. 웹 구축 _제품군_은 데이터베이스 쿼리, 엔터티-관계 모델 시각화 등 여러 기능을 제공합니다.

## 접근 및 권한 관리

사용자 관리 및 사용자 권한은 웹 환경에서 구성할 수 있으며 Netuno의 백엔드 서비스를 통해 액세스할 수 있습니다. 또한 사용자 및 그룹별로 양식과 보고서에 대한 액세스를 제어할 수 있습니다.

## 리소스 라이브러리

리소스 라이브러리는 바로 사용할 수 있는 다양한 기능을 제공합니다. 여기에는 PDF, Excel, 이메일, Firebase와의 통합부터 작업 예약이나 Jasper를 사용한 보고서 생성기까지 포함됩니다.

## REST API

서버 통신 계층은 REST API로 제공됩니다. JSON을 통한 서비스 제공을 통해 Netuno는 서로 다른 성격의 여러 애플리케이션과 통신할 수 있으며, 예를 들어 동일한 인터페이스에서 웹 클라이언트와 모바일 애플리케이션을 동시에 지원할 수 있습니다.

## 다국어 서비스 계층

<a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://groovy-lang.org/" target="_blank">Groovy</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a> 또는 <a href="https://pt.wikipedia.org/wiki/Java_(linguagem_de_programa%C3%A7%C3%A3o)" target="_blank">Java</a>로 서비스를 작성하세요. 이들 모두 유효합니다. Netuno는 프로그래밍 언어 간의 격리를 없애므로, 동일한 애플리케이션이 처리 부담을 늘리지 않으면서 여러 언어로 실행되는 서비스를 동시에 지원할 수 있습니다.

## 다중 데이터베이스

여러 가지 데이터베이스를 구성하고 동시에 사용하세요. Netuno는 기본적으로 <a href="https://www.h2database.com/html/main.html" target="_blank">H2DataBase</a>, <a href="https://www.postgresql.org/" target="_blank">PostgreSQL</a> 및 CockroachDB, <a href="https://mariadb.org/" target="_blank">MariaDB (_MySQL_)</a>, Microsoft SQL Server, Oracle과 같은 다양한 관계형 데이터베이스 엔진을 지원합니다. 예를 들어 PostgreSQL을 기본 데이터베이스로 사용하여 애플리케이션을 만들고 MariaDB의 다른 데이터베이스와 통합할 수 있으며, 프로젝트 중간에 코드를 전혀 변경할 필요 없이 Microsoft SQL Server 또는 Oracle로 전환할 수 있습니다.

> MongoDB와의 통합을 기본적으로 지원합니다.

## 서버리스

Netuno는 애플리케이션 서버이기도 합니다. 명령 하나로 라이선스, 구성 및 추가 개발에 시간을 낭비하지 않고 애플리케이션을 실행할 수 있습니다.

## 개발 및 실행 성능

드래그 앤 드롭 방식의 새로운 개발 소프트웨어 사용법을 배우거나 새로운 프레임워크의 인터페이스를 외울 필요가 없습니다. 6가지 언어로 프로그래밍할 수 있고, 자동 생성된 데이터 계층과 즉시 사용 가능한 라이브러리를 갖춘 Netuno의 로우코드는 촉박한 일정을 위한 최고의 솔루션입니다.

고성능에 최적화된 코드 생성기와 최신 <a href="https://www.graalvm.org/" target="_blank">GraalVM</a>을 사용하여 애플리케이션 서버는 어떤 언어를 사용하든 놀라울 정도로 빨라집니다.
