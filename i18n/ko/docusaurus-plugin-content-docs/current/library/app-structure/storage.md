코드 또는 데이터베이스에 통합된 파일.

## 일반 저장소

`📂 storage` 폴더는 애플리케이션 처리에 유용한 일반 파일들을 안전하게 보관하는 목적을 가집니다.

## 폴더 구조

`📂 storage` 폴더에는 다음과 같은 구조가 있습니다:

<pre class="doc-structure__tree">
<span>./<b>storage</b>/</span>
&nbsp;<span>├─ ./<b>database</b>/</span>
&nbsp;<span>└─ ./<b>filesystem</b>/</span>
&nbsp;    <span>├─ ./<b>private</b>/</span>
&nbsp;    <span>├─ ./<b>public</b>/</span>
&nbsp;    <span>└─ ./<b>server</b>/</span>
</pre>

## 데이터베이스

`📂 database` 폴더는 데이터베이스와 관련된 파일이나 이미지를 저장하는 데 사용됩니다.

파일을 데이터베이스에 직접 저장하는 것은 실용적이지 않습니다. 왜냐하면 백업과 데이터 동기화를 저해하고, 일반적으로 많은 파일이 차지하는 공간 때문에 데이터베이스 크기가 상당히 커지기 때문입니다.

따라서 파일 또는 이미지 업로드 필드가 있는 모든 데이터 양식에서 최종 파일은 이곳에 정리되어 보관되며, 데이터베이스 필드에는 최종 파일 이름만 저장됩니다.

데이터 구조에 파일이 포함되어 있다면, 애플리케이션의 전체 백업을 수행하기 위해 데이터베이스 백업 외에도 이 폴더의 백업이 필요합니다.

## 일반 파일 시스템

`📂 filesystem` 폴더에서는 애플리케이션에 유용한 일반 파일들에 대한 접근 제한과 함께 정리할 수 있습니다.

애플리케이션 코드에서 직접적으로 유용한 모든 파일은 이곳에 보관해야 합니다.

제한은 다음과 같이 구분됩니다:

### 비공개

`📂 private` 폴더는 애플리케이션에 인증된 사용자만 읽기 또는 쓰기로 접근해야 합니다.

### 공개

`📂 public` 폴더는 외부 접근에 유용합니다.

### 서버

`📂 server` 폴더는 애플리케이션 내부 코드에서만 읽기와 쓰기가 허용됩니다.

따라서 내부 또는 외부의 어떤 사용자도 그 내용에 접근할 수 없습니다.

그 내용은 오직 코드를 통해서만 접근할 수 있습니다.
