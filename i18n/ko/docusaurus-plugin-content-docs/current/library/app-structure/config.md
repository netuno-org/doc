애플리케이션의 일반 설정입니다.

## 설정 폴더

애플리케이션 설정은 `📂 config` 폴더에서 사용할 수 있으며, 이곳에서 애플리케이션 및 외부 통합의 일반 매개변수 설정을 수행합니다.

Netuno는 다양한 유형의 환경을 지원하며, 기본적으로 `development`(개발) 및 `production`(운영)을 사용합니다.

활성 환경은 Netuno 설치 루트에 있는 `config.js`에서 정의됩니다:

```javascript title="netuno/config.js"
...
config.env = 'development'
...
```

환경을 정의하는 데 어떤 이름이든 사용할 수 있지만, 애플리케이션은 환경 이름과 동일한 이름의 파일(`📂 config` 폴더의 `.json` 및 `.js` 파일)을 가져야 합니다.

기본적으로 이 폴더에는 다음 파일이 있습니다:

## _development.js

`_development.json` 파일에 정의된 매개변수 설정에 대해 프로그래밍 로직을 통해 동적 구성을 수행할 수 있게 해주는 JavaScript 코드 주입입니다. 예를 들어 데이터베이스에 있는 정보를 기반으로 설정을 정의하거나, 코드 실행 동작의 매개변수 설정을 정의하는 등이 있습니다.

이 파일은 환경 정의에 따라 사용되며, `development`(개발) 환경인 경우 사용됩니다.

## _development.json

언어, 리소스 및 통합의 일반 설정 등 애플리케이션의 매개변수 설정을 정의합니다. 예를 들어 데이터베이스 설정, Cron Jobs, SMTP 또는 원격 API와의 통합, 인증 등이 있습니다.

이 파일은 환경 정의에 따라 사용되며, `development`(개발) 환경인 경우 사용됩니다.

## _production.js

JavaScript 코드 주입은 `_production.js`에 정의된 매개변수 설정에 대해 프로그래밍 로직을 통해 동적 구성을 수행할 수 있습니다. 예를 들어 데이터베이스에 있는 정보로 설정을 정의하거나, 코드 실행 동작의 매개변수 설정을 정의하는 등이 있습니다.

이 파일은 환경 정의에 따라 사용되며, `production`(운영) 환경인 경우 사용됩니다.

## _production.json

언어, 리소스 및 통합의 일반 설정 등 애플리케이션의 매개변수 설정을 정의합니다. 예를 들어 데이터베이스 설정, Cron Jobs, SMTP 또는 원격 API와의 통합, 인증 등이 있습니다.

이 파일은 환경 정의에 따라 사용되며, `production`(운영) 환경인 경우 사용됩니다.
