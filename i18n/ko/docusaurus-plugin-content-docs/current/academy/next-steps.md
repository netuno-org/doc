Netuno에서 계속 발전해 나가기 위해 필요한 점을 염두에 두세요.

전반적인 문서는 지속적으로 개선되고 있으며, 최대한 간단하고 입문자 친화적으로 작성되도록 노력하고 있습니다.

하지만 몇 가지 기본 지식과 특정 분야의 경험이 있다고 가정합니다. 예를 들면:

* 데이터베이스, 일반적인 쿼리, insert, update, delete 등;
* 웹 서비스, GET 및 POST;
* <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a> 및 <a href="https://reactjs.org/" target="_blank">ReactJS</a>;

이러한 역량 중 일부가 없더라도 저희가 개발할 수 있도록 도와드리겠습니다.

항상 GitHub 또는 Discord에서 도움을 구하고, 사이트 하단의 안내를 확인하세요.

## 데이터베이스

Netuno를 사용하면 다양한 유형의 데이터베이스로 작업하며 지식을 심화할 수 있습니다.

데이터베이스에 대한 충분한 지식만 있으면 대량의 데이터를 수집하고 관리하는 복잡한 구조의 애플리케이션을 만들 수 있습니다.

이렇게 하면 가장 중요한 부분인 데이터베이스를 견고하게 구축할 수 있는 자율성을 갖게 됩니다.

잘 정리되고 최적화된 데이터베이스 구축은 최종 사용자 경험은 물론 개발부터 실행까지의 성능에 큰 차이를 만듭니다.

## 서비스

<a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a> 또는 <a href="https://groovy-lang.org/" target="_blank">Groovy</a>와 같은 프로그래밍 언어 중 하나에 이미 지식이 있다면, Netuno가 **로우 코드** 프로그래밍을 위해 제공하는 다양한 리소스를 활용하여 복잡하고 견고한 웹 서비스를 빠르게 만들 수 있습니다.

애플리케이션 폴더, 특히 **server** 폴더 안에서 이러한 다양한 언어로 프로그래밍할 수 있습니다.

해당 확장자를 사용하기만 하면 됩니다:

* **.js** &nbsp; <a href="https://developer.mozilla.org/pt-PT/docs/Web/JavaScript" target="_blank">JavaScript</a>
* **.ts** &nbsp; <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>
* **.py** &nbsp; <a href="https://www.jython.org/" target="_blank">Python</a>
* **.rb** &nbsp; <a href="https://www.jruby.org/" target="_blank">Ruby</a>
* **.kts** &nbsp; <a href="https://kotlinlang.org/" target="_blank">Kotlin</a>
* **.groovy** &nbsp; <a href="https://groovy-lang.org/" target="_blank">Groovy</a>

**demo** 애플리케이션에 포함된 웹 서비스 예제를 살펴보세요:

- `/apps/demo/server/services/samples`

그리고 사용 가능한 리소스를 자세히 알아보려면 저희 **라이브러리** 문서도 살펴보세요.

## 사용자 인터페이스

웹 프런트엔드 개발은 최근 몇 년 동안 많은 변화를 겪었으며 <a href="https://vite.dev/" target="_blank">Vite</a> 사용이 표준이 되었습니다.

<a href="https://reactjs.org/" target="_blank">ReactJS</a>, <a href="https://bun.sh/" target="_blank">Bun</a>, <a href="https://ant.design/" target="_blank">Ant.Design</a>, <a href="http://lesscss.org/" target="_blank">Less</a>와 같은 저희의 기술 선택은 높은 채택률과 함께 생산성 향상을 가져오는 기술입니다.

이러한 기술에 대한 지식을 심화하려면 인터넷에서 제공되는 다양한 텍스트 및 비디오 형식의 문서를 살펴보세요.

큰 커뮤니티를 가진 기술이므로 학습을 시작하기에 좋은 자료를 찾기 어렵지 않습니다.

Netuno를 사용하면 약간의 지식만으로도 이미 큰 성과를 얻을 수 있어 프런트엔드 개발자가 전체 백엔드를 개발하거나 그 반대로 할 수 있는 힘을 주며, <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>와 같은 단일 프로그래밍 언어만으로 모든 것을 개발하는 것을 선택할 수도 있습니다.

## 결론

Netuno는 데이터베이스, 웹 서비스, 프런트엔드에 대한 기초 지식이 많지 않은 한 사람만으로도 복잡한 애플리케이션을 자율적으로 개발할 수 있도록 웹 애플리케이션 개발을 용이하게 합니다.

또한 각 분야에서 더 높은 역량을 가진 사람들이 있는 대규모 팀에게도 전반적으로 큰 생산성 향상을 가져옵니다.

Netuno는 데이터베이스용 백오피스로 사용하거나, 분리된 프런트엔드 및 모바일 애플리케이션을 위한 REST API 서버로도 사용할 수 있습니다.

시간을 절약하고 비즈니스 규칙의 로직에 더 집중하여 개발하세요. 이미 가진 지식으로 더 멀리 나아갈 수 있습니다.
