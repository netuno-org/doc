## 소개

Netuno에서는 기본 주소를 변경할 수 있습니다. 예를 들어:

- 관리 인터페이스의 주소, `admin`.
- 이미지, CSS, JS와 같은 공개 파일의 주소, `public`.
- REST API 서비스의 주소, `services`.

## 설정

개발 중인 애플리케이션 내에서 환경 설정 파일을 찾아 이동하십시오. 이 예제에서는 다음 위치에 있는 로컬 개발 환경 파일을 사용합니다:

- 📂 `config/_development.json`

URL 설정이 이미 존재하지 않는지 확인하고, 존재하지 않으면 설정 파일 끝에 URL 설정 매개변수를 (JSON 형식으로) 추가하십시오. 예를 들면 다음과 같습니다:

```json
{
    ...
    "url": {
        "admin": "/admin/",
        "public": "/public/",
        "services": "/api/"
    },
    ...
}
```

### admin

관리 인터페이스의 URL 주소 접두사를 정의하며, 기본값은 `/`입니다.

### public

이미지, CSS 스타일, JavaScript 코드와 같은 공개 정적 파일의 URL 주소 접두사를 정의하며, 기본값은 `/public`입니다.

### services

REST API 웹 서비스의 초기 URL 주소를 정의하며, 기본값은 `/services`입니다.

## 결론

URL 사용자 지정은 더 직관적으로 만들 뿐만 아니라 더 복잡하게 만들어 보안을 강화할 수 있기 때문에 중요합니다.

예를 들어 관리 주소에 무작위 문자 시퀀스로 된 접두사를 붙일 수 있으며, 이렇게 하면 해당 주소를 외워서 아는 사람만 접근 주소에 접근할 수 있어 접근이 어려워지고 공격을 방지할 수 있습니다.
