Netuno는 Java로 개발되었기 때문에 Java를 기반으로 새로운 기능을 만들 수 있습니다.

예를 들어, 새로운 네이티브 서비스를 만들거나, JavaScript, Python, Ruby, Groovy, Kotlin과 같은 모든 다중 언어 프로그래밍 언어에서 사용할 수 있는 새로운 로우코드 프로그래밍 기능을 만들 수 있습니다.

Java에서는 Netuno의 모든 애플리케이션에서 사용할 수 있는 다중 애플리케이션 웹 서비스도 만들 수 있습니다.

Java 생태계의 어떤 기술이나 라이브러리든 사용하여 모든 유형의 기능을 만들 수 있습니다.

> 이 튜토리얼을 시작하기 전에 _Java_에 대한 기본적인 개념을 어느 정도 알고 계시기를 권장합니다.
