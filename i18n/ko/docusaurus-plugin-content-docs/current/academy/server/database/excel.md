일반적으로 어떤 종류의 비즈니스에서든 엑셀 파일이나 Google 스프레드시트, LibreOffice, OpenOffice 등과 같은 스프레드시트가 널리 사용됩니다. 이는 정보를 조직화하고 분석하며 다른 스프레드시트와 통합하는 요구를 간단하게 해결해 주기 때문입니다.

따라서 정보 구조가 비교적 작고 복잡성이 크지 않을 때는 엑셀과 같은 도구들이 문제를 잘 해결해 줍니다.

시간이 지나면서 정보가 흩어진 파일이 점점 더 많이 생겨나는 경향이 있습니다.

![엑셀 파일 이미지](/docs/assets/business/excel-danger.jpg "엑셀 파일.")

문제는 해당 엑셀 파일이 다른 여러 파일과 함께 거대한 괴물이 될 때 발생합니다. 관리가 어려워지고, 특히 여러 사람이 관여하게 되면 여러 문제가 생기기 시작하며 정보가 취약해져 결국 감당할 수 없게 됩니다.

바로 그때 사용자 프로필과 그룹을 관리하고, 검증되고 더 나은 구조로 데이터를 관리하며, 그래프와 표가 포함된 복잡한 보고서로 데이터를 내보내고, 더 복잡한 검색을 수행하고, 다른 시스템과 통합하는 등 더 견고한 애플리케이션을 만들어야 할 필요성이 생깁니다.

> 가장 큰 딜레마는 엑셀이 상대적으로 저렴한 반면, 관리 애플리케이션을 개발하는 것은 너무 비싸다는 점입니다.

Netuno를 사용하면 **적은 노력**으로 모든 정보를 관리하는 애플리케이션을 빠르게 만들어 흩어져 있고 관리가 복잡한 엑셀 파일을 완전히 대체할 수 있습니다.

## 데이터베이스 테이블의 스프레드시트

데이터베이스가 매우 복잡하다고 생각하지 마세요. 그렇지 않으며 오히려 엑셀 스프레드시트와 매우 비슷하다는 것을 알게 될 것입니다.

> 데이터베이스 테이블은 스프레드시트와 같은 것입니다.

예를 들어 엑셀의 스프레드시트를 살펴보세요:

|   	|    A    	|      B     	|       C       	|      D      	|
|:-:	|:-------:	|:----------:	|:-------------:	|:-----------:	|
| **1** 	| 제품 	| 수량 	| 단가 	| 총 가격 	|
| **2** 	|  포크  	|     10     	|      3,00     	|    30,00    	|
| **3** 	|   컵  	|      5     	|      4,00     	|    20,00    	|
| **4** 	|   칼  	|      8     	|      2,00     	|    16,00    	|
| **5** 	|         	|            	|  **총 가격**  	|    **66,00**    	|

이 정보를 데이터베이스에 저장하려면 **제품** 정보를 저장할 테이블을 만들어야 합니다.

테이블은 아래 예시처럼 구조화되며 다음 데이터를 포함합니다:

<table>
    <thead>
        <tr>
            <th colspan="3">제품</th>
        </tr>
        <tr>
            <th>ID</th>
            <th>이름</th>
            <th>가격</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>1</td>
            <td>포크</td>
            <td>3,00</td>
        </tr>
        <tr>
            <td>2</td>
            <td>컵</td>
            <td>4,00</td>
        </tr>
        <tr>
            <td>3</td>
            <td>칼</td>
            <td>2,00</td>
        </tr>
    </tbody>
</table>

따라서 어떤 제품의 데이터를 사용할 때마다 반드시 이 테이블에서 가져와야 합니다.

즉, 제품 정보를 저장하는 스프레드시트가 있는 것과 같습니다.

각 행에는 ID, 즉 고유 식별자(예: 순차 번호)가 포함됩니다.

원하는 정보를 다시 표시하려면 제품에 대한 데이터를 다음과 같이 제품 테이블에서 제공받습니다:

![엑셀 파일 이미지](/docs/assets/business/excel-table.jpg "엑셀 파일.")
