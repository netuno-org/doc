사용자 정의 PDF 파일을 처리합니다.

## 소개

Netuno는 이미지, 표, 글꼴 등을 지원하는 PDF 파일을 [PDF](/docs/library/resources/pdf) 리소스를 통해 생성하며, 이는 Netuno가 지원하는 다양한 프로그래밍 언어에 대해 [iTextPDF](https://itextpdf.com/)의 로우 코드 추상화를 제공합니다.

Netuno와 함께 제공되는 **demo**(데모 애플리케이션)에는 다양한 언어의 가능한 코드 구현 예제가 많이 포함되어 있으며, 다음 위치에 있는 `export-pdf` 서비스를 통한 PDF 내보내기 데모도 포함되어 있습니다:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-pdf`
]} />

## 초기화

먼저 새로 생성되는 문서의 컨텍스트를 담을 객체를 생성해야 하며, 기본 페이지 크기는 A4입니다.

문서를 생성할 때 생성 위치가 정의됩니다.

아무것도 정의하지 않으면 서비스의 데이터 출력으로 생성됩니다. 예:

## HTTP 헤더

데이터 출력으로 PDF 파일을 반환하는 REST API 서비스를 만들려면 HTTP 프로토콜의 `Content-Type` 매개변수를 헤더에 추가해야 합니다.

콘텐츠를 PDF로 정의하는 예:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("pdf")
            `
        },
    ]}
/>

`pdf` 코드는 다음의 축약형입니다:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("application/pdf")
            `
        },
    ]}
/>

## 단락

문서에 새 단락을 추가합니다:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    _pdf.paragraph("여기에 텍스트가 들어갑니다...")
                        .setFontSize(15)
                )
            `
        },
    ]}
/>

고정 위치에 단락을 추가하려면:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    pdfDocument.add(
                        _pdf.paragraph("고정 텍스트...")
                            .setFixedPosition(100, 500, 200)
                            .setFontSize(15)
                    )
                )
            `
        },
    ]}
/>

위 코드에서 `setFixedPosition` 메서드의 첫 번째 매개변수는 X 위치(`100`)이고, 두 번째 매개변수는 Y 위치(`500`)이며, 세 번째 매개변수는 너비(`200`)입니다.

**주의:** Y가 `0` 값으로 정의되면 페이지 맨 아래에 위치한다는 뜻이므로, 위로 올리려면 Y 값을 늘려야 합니다. Y 값이 클수록 더 위쪽에 나타나지만, 페이지 길이를 넘을 만큼 너무 크면 보이지 않습니다.

> [iText 단락](https://api.itextpdf.com/iText/java/8.0.3/com/itextpdf/layout/element/Paragraph.html) 객체의 모든 메서드에 대한 문서입니다.

## 표

표를 만들 수 있으며, 이를 통해 데이터 집합을 더 읽기 쉽게 표시할 수 있습니다.

표의 열 수는 `_pdf.table(열_수)` 매개변수로 정의됩니다.

아래 예에서 `열_수`는 숫자 `1`, 즉 하나의 열입니다.

표에 두 개의 셀을 추가하면 두 번째 셀은 다음 행으로 이동합니다.

확인하세요:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    _pdf.table(1)
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("사람")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBorder(_pdf.border("solid", 2))
                                .setBackgroundColor(_pdf.colorRGB(1, 0, 0))
                        )
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("니콜")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBackgroundColor(_pdf.colorGray(0.5))
                        )
                )
            `
        },
    ]}
/>

`addCell` 메서드를 사용하면 각 셀의 정의와 해당 콘텐츠를 삽입할 수 있습니다.

> [iText 셀](https://api.itextpdf.com/iText/java//8.0.3/com/itextpdf/layout/element/Cell.html) 객체의 모든 메서드에 대한 문서입니다.

## 파일 읽기

PDF 문서를 읽고 텍스트 정보를 추출하려면.

`extract` 메서드를 사용하면 PDF 파일의 모든 데이터를 JSON 객체로 가져옵니다.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'python',
            code: `
                pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'ruby',
            code: `
                pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'kotlin',
            code: `
                val pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'groovy',
            code: `
                def pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
    ]}
/>

반환된 JSON에는 PDF 파일의 모든 텍스트 콘텐츠가 담긴 `content` 키와 PDF 파일의 다양한 속성이 담긴 `metadata` 키가 있습니다.

다음은 `extract`에서 반환된 JSON의 예입니다:

```json
{
  "content": "PDF 파일의 모든 텍스트 콘텐츠가 여기에 표시됩니다...",
  "metadata":{
    "Content-Type":"application/pdf",
    "dc:format":"application/pdf; version=1.4",
    "dc:title":"Linux 1",
    "pdf:PDFVersion":"1.4",
    "pdf:charsPerPage":"580",
    "pdf:containsDamagedFont":"false",
    "pdf:containsNonEmbeddedFont":"false",
    "pdf:docinfo:producer":"Skia/PDF m125 Google Docs Renderer",
    "pdf:docinfo:title":"파일 1",
    "pdf:encrypted":"false",
    "xmpTPg:NPages":"3",
    ...
  }
}
```

`metadata`에서 얻을 수 있는 다른 데이터도 많지만 예제가 너무 길어지지 않도록 `...`로 생략했습니다.
