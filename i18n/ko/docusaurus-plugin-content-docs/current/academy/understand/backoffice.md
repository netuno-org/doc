웹 및/또는 모바일 애플리케이션 개발에서는 데이터 관리 계층인 백오피스 개념이 흔히 존재합니다.

즉, 일반적으로 웹에 있는 계층으로, 비즈니스 관리 사용자가 데이터를 조작할 수 있는 인터페이스에 접속하게 되는 계층입니다.

다음과 같은 요구 사항은 매우 흔합니다.

- 사용자 관리;
- 사용자 그룹 관리;
- 비즈니스 규칙에 맞게 조정된 데이터베이스 레코드 조작;
- 사용자가 무엇을 언제 했는지 기록하는 로그;
- 액세스 제한: 그룹 또는 사용자에 따라 특정 데이터를 변경하거나 볼 수 없도록 함;
- 브라우저 및 모바일 기기를 통한 액세스 허용;
- 관리 보고서 생성;
- 관련 정보를 담은 비즈니스 맞춤형 대시보드로, 차트와 표를 표시할 수 있음;

이러한 이유와 여러 다른 이유로 백오피스 개발은 최종 애플리케이션 개발보다 더 많거나 비슷한 작업량을 요구하는 경우가 많습니다.

또한 백오피스가 최종 애플리케이션 또는 프런트엔드와 비즈니스 데이터 통신을 가능하게 하는 웹 서비스가 포함된 REST API를 제공하는 것도 흔합니다.

![백오피스.](/docs/assets/business/business-backoffice.svg "백오피스.")

Netuno는 강력한 백오피스 엔진을 제공하며, 코드 없이 데이터 구조를 생성하고 데이터베이스와 통합된 양식을 생성하여 생성, 검색, 편집, 삭제 같은 가장 일반적인 조작을 수행할 수 있습니다.

사용자 및 그룹 관리와 로그 기록이 포함된 액세스 제어도 제공합니다.

로우코드로 대시보드, 보고서, 그리고 JWT(JSON Web Token)와 통합된 REST API(웹 서비스)를 만들 수 있습니다.

> Netuno는 가장 일반적인 기능을 비즈니스 모델에 맞게 조정할 수 있도록 미리 제공하므로 맞춤형 백오피스 개발에 드는 노력이 크게 줄어듭니다.

## 새 프로젝트를 위한 백오피스

새 프로젝트를 개발할 때, 특히 외부 고객을 위한 애플리케이션인 경우 백오피스 예산을 줄이는 일이 흔합니다. 즉, 백오피스 개발과 인터페이스 구상에 투자하는 시간이 줄어듭니다.

대상 고객에게 보이지 않기 때문에 우선순위에서 뒤로 미룰 수 있기 때문입니다.

또한 의사 결정권자의 목표는 내부 관리 계층보다 최종 결과를 달성하는 데 더 가까우며, 특히 상당한 비용이 수반될 때는 더욱 그렇습니다.

하지만 개발 중, 특히 테스트 단계에서 백오피스 인터페이스가 있으면 데이터 일관성을 더 잘 검증할 수 있습니다.

Netuno는 **데이터 모델 구축을 용이하게 하고 데이터 관리를 위한 반응형 양식을 웹 인터페이스에서 자동으로 제공**하므로, 데이터 구조 모델링 단계에서 Netuno를 사용하기만 하면 자동으로 백오피스 인터페이스를 얻을 수 있습니다. 아주 간단합니다!

그런 다음 대시보드, 보고서, 웹 서비스를 모두 Netuno에서 개발하는 수준까지 더 발전시킬지 선택할 수 있습니다.

또는 어떤 제약이나 의무 사항으로 인해 다른 기술로 웹 서비스와 전체 REST API를 개발할 수도 있으며, 이를 위해서는 Netuno가 생성한 데이터베이스를 사용하기만 하면 됩니다.

어느 경우든 백오피스 요구 사항을 충족할 수 있는 옵션으로 Netuno를 활용할 수 있습니다.

## 기존 애플리케이션을 위한 백오피스

이미 존재하는 애플리케이션에서 백오피스가 개발되지 않았거나, 백오피스가 있더라도 제한 사항이 있는 경우입니다.

Netuno는 기존 백오피스를 확장하거나 부재한 백오피스를 구축하는 데 모두 사용할 수 있습니다.

Netuno로 백오피스를 만드는 노력이 상당히 적으므로, Netuno로 전체 백오피스를 만들 수도 있고 일부 모듈만 만들 수도 있습니다.

사용할 기술 옵션의 방향과 자신의 상상력에 따라 결정하는 것은 사람의 몫이지만, 한 가지 확실한 것은 시간이 지나면서 필요에 맞게 개발되고 성장하는 모듈형 백오피스를 생각하면 그리 복잡하게 만들 필요가 없다는 점입니다.

일반적으로 모듈 단위 개발은 매우 복잡하지만, Netuno는 동일한 데이터베이스 위에서 여러 애플리케이션을 개발할 수 있게 하여 이 과정도 단순화하므로, 기존 백오피스에 영향을 주지 않고 기존 백오피스를 확장하기 위한 독립적인 보조 모듈을 개발하는 데에도 훌륭한 솔루션입니다.

Netuno는 동일한 애플리케이션에서 여러 데이터베이스를 쉽게 통합하고 관리할 수 있으므로 다른 데이터베이스로 정보를 가져오고 내보내기도 쉽습니다.

따라서 기존 백오피스에 추가되는 "모듈"과 같은 Netuno 애플리케이션에서 백오피스의 복잡성을 더 잘 분리할 수 있습니다.

## 결론

의심할 여지 없이 Netuno의 주요 목표 중 하나는 백오피스 개발을 최대한 단순화하고, 기존 프로젝트와 신규 프로젝트 모두에 통합하는 것입니다. 신규 프로젝트에서는 다른 기술과도 잘 통합할 수 있습니다.

Netuno는 모든 개발을 Netuno에서 해야 하는 폐쇄형 플랫폼이 아닙니다. 오히려 Netuno는 다음과 같은 제한 사항을 극복하기 위해 특정한 필요를 충족하는 데 간단히 사용할 수 있습니다.

- 비용
- 시간

어떤 다른 기술과도 통합될 수 있습니다.

따라서 문제가 자금 부족이거나 납기일이 너무 촉박하고, 게다가 복잡성이 크고 여러 기술이 통합되어 있다면, Netuno는 비용과 시간 문제를 해결하여 일을 더 쉽게 만들어 줄 또 하나의 기술로 보아야 합니다.
