Netuno는 데이터베이스 수준뿐만 아니라 프로그래밍 코드 수준, 그리고 운영 체제 수준에서도 폴리글롯입니다.

이러한 다양성 덕분에 사용될 수 있는 선택지가 늘어납니다.

여러 데이터베이스, 프로그래밍 언어, 운영 체제를 지원함으로써 각각의 상황에 맞게 적응하면서도 개발을 위한 일관된 환경을 보장하여 개발을 용이하게 합니다.

## 데이터베이스

여러 종류의 서로 다른 데이터베이스를 통합하는 데 사용될 수 있으며, 심지어 동일한 프로젝트에서 서로 다른 프로그래밍 언어로 개발할 수도 있습니다.

서로 다른 데이터베이스를 통합하는 것은 다른 시스템의 데이터베이스에서 데이터를 조회하거나 변경할 때 데이터를 통합하기 위해 매우 흔히 하는 일입니다.

![데이터베이스 로고](/docs/assets/business/databases.jpg "다양한 데이터베이스")

Netuno는 다음 데이터베이스를 지원합니다:

- H2 Database
- PostgreSQL
- MariaDB
- MySQL
- Microsoft SQL Server
- Oracle

## 프로그래밍 언어

서로 다른 프로그래밍 언어를 지원하는 것이 프로그래밍 언어를 혼용한다는 의미에서 그다지 흥미롭게 보이지 않을 수 있지만, 가능하며 그렇게 해야 한다는 뜻은 아닙니다.

실제로 특정 프로그래밍 언어에 국한된 지배적인 기술이 있는 프로젝트를 수행하는 것은 종종 까다로우며, 따라서 해당 프로그래밍 언어에만 전적으로 능숙한 인력을 구해야 합니다.

Netuno를 사용하면 더 넓은 선택의 폭을 갖게 되며, 전략 변경이나 유능한 기술 인력 부족, 특정 작업 개발 시 더 큰 민첩성 확보 등 합리적인 여러 상황으로 인해 새로운 프로그래밍 언어를 사용해야 하더라도 모든 작업이 낭비되지 않습니다.

일반적으로 이는 생각조차 하기 어려운 일인데, 여러 프로그래밍 언어로 구성된 시스템의 유지보수가 걱정되기 시작하기 때문입니다. 하지만 이것이 로우코드이기 때문에 그러한 걱정은 그다지 중요하지 않게 됩니다. 왜냐하면:

* 프로그래밍 언어는 결국 논리와 알고리즘 수준에서 유사합니다.
* 프로그래밍 언어는 다를 수 있지만 Netuno의 리소스는 동일하며 언어에 관계없이 같은 방식으로 사용됩니다.

따라서 한 기술자가 특정 프로그래밍 언어에 매우 익숙하더라도 다른 언어로 유지보수를 수행하는 데 아무런 장애가 없으며, 개입 범위를 훨씬 더 확장해야 하거나 심지어 다시 작성해야 하는 경우에는 선호하는 언어로 개발하고 해당 개발을 이미 사용 중인 언어에 통합하는 것을 선택할 수 있습니다.

![프로그래밍 언어 로고](/docs/assets/business/languages.jpg "프로그래밍 언어")

Netuno는 다음 프로그래밍 언어로 개발을 지원합니다:

- Groovy
- Java
- JavaScript
- Kotlin
- Python
- Ruby

## 운영 체제

Netuno는 여러 운영 체제와 함께 작동하고 환경 구성 지원을 통해 개발이 전반적으로 올바르게 작동하도록 보장하며, 개발, 테스트, 품질, 운영 등의 환경으로 구성할 수 있습니다.

운영 체제나 환경의 변경은 Netuno와 애플리케이션의 올바른 작동에 영향을 주지 않습니다.

![운영 체제 로고](/docs/assets/business/operationsystems.jpg "다양한 운영 체제")

Netuno가 지원하는 운영 체제는 다음과 같습니다:

* Linux
* Mac OS X
* Windows
