# 데이터 연결

작업과 시간 기록 사이에 관계를 만들어 **누가** **어떤 작업**을 수행했고 **얼마나 많은 시간**이 소요되었는지 확인하세요.

이 단계를 마치면 **기록** 폼이 **작업** 테이블과 연결되어 기록 목록에서 연결된 작업을 직접 확인할 수 있습니다.

## 사전 요구 사항

시작하기 전에 다음을 완료했는지 확인하세요:

- `이름` 필드가 있는 **작업** 폼 생성.
- 근무 시간의 기본 필드가 있는 **기록** 폼 생성.
- **데이터베이스**에서 해당 테이블 구성.

:::tip
데이터 연결에 대한 자세한 내용은 [인터페이스 가이드: 관계](/docs/academy/ui/relationships-between-forms)를 참조하세요.
:::

지금까지 작업 관리와 시간 기록을 만들었지만, 각 목록은 여전히 독립적으로 동작합니다.  

각 시간 기록이 어떤 작업이 어떤 직원에 의해 어느 기간에 수행되었는지 명확히 나타내도록 이들을 연결하는 것이 중요합니다.

이 단계에서는 다음을 수행합니다:

- **기록** 폼에 `select` 유형 필드를 만듭니다.
- 해당 필드가 **작업** 테이블과 연결되도록 구성합니다.
- 일부 데이터를 업데이트하여 관계가 실제로 동작하는 모습을 확인합니다.

## `select` 유형 필드

각 시간 기록에 연결된 작업을 선택할 수 있는 필드를 추가합니다.

1. **구축** 환경에서 **기록** 폼을 열고 필드 관리로 이동합니다.
2. 다음 구성으로 새 필드를 만듭니다:
   - **필드 제목**: `작업`
   - **컬럼 이름**: `작업_id`
   - **유형**: `select`
3. 모든 기록이 작업과 연결되도록 **필수** 옵션을 활성화합니다.
4. 동일한 작업에 대한 기록이 많을 수 있으므로 **고유 값** 옵션은 비활성화된 상태로 둡니다.

:::note
전체 데이터 모델에서 일관된 명명 규칙을 유지하기 위해 `작업_id`라는 이름을 권장합니다.
:::

## `_id` 접미사 사용

다른 기록을 참조하는 필드 이름은 `_id`로 끝나야 합니다.  
이 규칙을 따르면 해당 필드가 다른 테이블과의 관계를 나타낸다는 것을 쉽게 식별할 수 있고 데이터 모델이 더 체계적으로 유지됩니다.

:::warning
관계 필드에는 `작업` 또는 `ref_작업`과 같은 일반적인 이름은 피하세요.  
`_id`로 표준화하면 데이터를 분석하거나 통합을 만들 때 혼동을 줄이는 데 도움이 됩니다.
:::

## 링크 관계 구성

`작업_id` 필드를 작업 테이블과 연결하는 **링크**를 구성합니다.

1. 새로 만든 필드(`작업_id`)에서 **링크** 구성 섹션까지 스크롤합니다.
2. **추가**를 클릭합니다.
3. 열리는 창에서:
   - **작업** 옵션을 선택합니다.
   - 그다음 **이름** 필드를 선택합니다.
   - 창을 닫아 적용합니다.

완료하면 **링크**는 다음과 같이 정의됩니다:

```text
작업:이름
```

의미는 다음과 같습니다:

- **작업** 테이블과 관계가 설정됩니다.
- 인터페이스에서 `작업` 필드에서 선택하면 작업의 **이름** 필드 값이 표시됩니다.

필드 구성을 저장하려면 **저장** 버튼을 클릭합니다.

:::tip
가능하면 기술적 또는 숫자 식별자 대신 관련 정보를 표시하기 위해 설명적인 필드(예: `이름`)를 사용하세요.
:::

## 기록 업데이트

관계 필드가 구성되면 데이터를 조정하여 결과를 확인합니다.

1. **기록** 폼 보기로 이동합니다.
2. 이제 결과 테이블에 **작업**이라는 새 컬럼이 있으며 처음에는 비어 있습니다.
3. 일부 기록을 편집합니다:
   - 결과 테이블의 행을 클릭하여 편집 폼을 엽니다.
   - **작업** 필드에서 해당 작업을 선택합니다.
   - 저장하려면 **저장**을 클릭합니다.

**저장 후:**

- 결과 테이블의 **작업** 컬럼에 연결된 작업 이름이 표시됩니다.
- 각 **기록**이 **작업**과 명확하게 연결되어 각 활동에 소요된 시간을 더 완전하게 분석할 수 있습니다.

:::note
작업이 정의되지 않은 기록이 많다면 데이터 정책에 따라 배치로 업데이트하거나 임시 기본 작업을 정의하는 것을 고려하세요.
:::

### 예상 결과

**기록** 목록에는 다음이 표시되어야 합니다:

- 연결된 작업 이름으로 채워진 **작업** 컬럼.
- 각 행은 해당 작업과 함께 시간 기록을 나타내어 시간이 어디에 투입되었는지 더 쉽게 식별할 수 있습니다.
