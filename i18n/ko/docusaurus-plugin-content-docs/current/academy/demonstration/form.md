# 폼

이 데모 단계에서는 **작업** 폼을 만들고 첫 번째 데이터 필드를 구성합니다.

:::info 참고
폼에 대한 자세한 설명은 [인터페이스 가이드: 폼](/docs/academy/ui/forms)을 참고하세요.
:::

## 목표

이 단계를 완료하면 다음을 갖추게 됩니다:

- **작업**이라는 이름의 폼.
- 데이터베이스에 연결된 테이블.
- 작업 이름을 저장하기 위한 필수 필드.
- 레코드를 생성, 편집, 검색 및 삭제할 수 있는 준비된 인터페이스.

## 사전 요구사항

다음을 확인하세요:

- 데모 애플리케이션이 이미 생성되었습니다.
- 구성 단계가 이미 완료되었습니다.
- 플랫폼의 개발 영역에 있습니다.

## 폼 생성

1. 오른쪽 상단에서 **빌드**를 클릭합니다.
2. 메인 메뉴에서 **관리 > 폼**으로 이동합니다.
3. **폼 제목**에 `작업`을 입력합니다.
4. **테이블 이름**에서 **자동** 옵션을 활성화합니다.
5. **저장**을 클릭합니다.

:::note
- **폼 제목**은 사이드 메뉴에 표시되는 이름을 정의합니다.
- **테이블 이름**은 데이터베이스에서 사용되는 기술적 식별자를 정의합니다.
:::

저장 후, **작업** 폼이 왼쪽 사이드 메뉴에서 사용 가능해집니다.

## 첫 번째 필드 생성

폼이 생성된 상태에서:

1. 사이드 메뉴에서 **작업**을 클릭합니다.
2. **표시 이름**에 `이름`을 입력합니다.
3. 기술적 이름이 소문자로 자동 생성되었는지 확인합니다.
4. **기본 키** 옵션을 활성화합니다 (고유 필드).
5. **Null 허용 안 함** 옵션을 활성화합니다 (필수 필드).
6. **유형**에서 `text`를 선택합니다.
7. **저장**을 클릭합니다.

:::tip
- **기본 키**는 각 레코드에 대해 고유한 값을 보장합니다.
- **Null 허용 안 함**은 입력을 필수로 만듭니다.
- `text` 유형은 일반 텍스트를 저장할 수 있게 합니다.
::: 

## 결과 확인

미리보기 영역을 열고 다음을 확인하세요:

- **작업** 폼이 사용 가능합니다.
- **이름** 필드가 입력을 위해 표시됩니다.
- 새 레코드를 생성할 수 있습니다.
- **이름** 필드는 필수입니다.

:::info 예상 결과
구성이 올바르면, 폼은 레코드 생성, 편집, 검색 및 삭제 작업을 수행할 준비가 됩니다.
:::
