# 데이터베이스

이 단계에서는 앞서 정의한 **작업** 폼에서 자동으로 생성된 **데이터베이스**를 살펴봅니다.

**이름** 필드가 있는 **작업** 폼을 생성하면 Netuno는 폼 생성 시 정의한 이름에 따라 데이터베이스에 `이름` 컬럼이 있는 `작업` 테이블을 생성했습니다.

필드의 **기술 이름**(예: `작업`, `이름`, `작업_id`)은 프로그래밍과 SQL 쿼리에서 사용되며, 인터페이스에 표시되는 표시 이름과 일치하지 않습니다.

## 쿼리

이 섹션에서는 Netuno 관리 인터페이스를 사용하여 데이터베이스에서 직접 쿼리를 실행합니다.

1. **구축** 환경에 접속합니다.
2. 메뉴에서 **관리 > 쿼리**를 클릭합니다.
3. 쿼리 편집기에서 아래 명령을 붙여 넣고 실행합니다.

### 간단한 쿼리

작업의 이름만 조회합니다:

```sql
SELECT 이름
FROM 작업;
```

작업 테이블의 모든 필드를 조회합니다:

```sql
SELECT *
FROM 작업;
```

기록 테이블의 모든 필드를 조회합니다:

```sql
SELECT *
FROM 기록;
```

작업자 테이블의 모든 필드를 조회합니다:

```sql
SELECT *
FROM 작업자;
```

**실행**을 클릭하면 Netuno는 세미콜론(`;`)으로 구분된 **각** 명령에 대해 결과 테이블을 생성합니다.  
이 기능은 여러 쿼리를 한 번에 실행하려 할 때 유용합니다.

### 관계를 포함한 쿼리

이제 모든 테이블을 관계짓는 쿼리를 실행합니다:

```sql
SELECT
  작업.이름,
  기록.시작,
  기록.끝,
  작업자.이름
FROM 작업
INNER JOIN 기록
  ON 작업.id = 기록.작업_id
INNER JOIN 작업자
  ON 작업자.id = 기록.작업자_id;
```

이 쿼리는 다음을 반환합니다:

- 작업 이름.
- 각 기록의 시작과 끝.
- 각 기록에 연결된 작업자 이름.

테이블 간 관계를 통해 애플리케이션의 서로 다른 엔터티 정보를 결합할 수 있음을 보여 줍니다.

## 다이어그램

데이터베이스 구조를 더 직관적으로 보려면 Netuno의 **다이어그램**을 사용하세요.

1. **구축** 환경에 접속합니다.
2. 메뉴에서 **관리 > 다이어그램**을 클릭합니다.

다이어그램에서는 다음을 할 수 있습니다:

- 확대 또는 축소.
- 다이어그램을 이미지로 내보내기.

이 작업은 다이어그램 패널 오른쪽의 버튼에서 사용할 수 있습니다.

Netuno는 필드의 **링크** 구성(예: 다른 테이블을 가리키는 `select` 유형 필드)을 기반으로 관계 화살표가 있는 선을 자동으로 생성합니다.

## 모범 사례

Netuno에서 데이터베이스를 모델링할 때 다음 모범 사례를 따르세요:

- 관계를 나타내는 필드에는 `_id` 접미사를 사용하세요. 예:
  - `작업_id`
  - `작업자_id`
- `작업들`, `기록들`, `작업자들`처럼 테이블과 필드 이름에 복수형을 사용하지 마세요.

복수형을 피하면 다음에 도움이 됩니다:

- 이름을 더 짧고 읽기 쉽게 유지합니다.
- 쿼리를 작성할 때 모호성을 줄입니다.
- 특히 여러 관계가 있을 때 폼과 다이어그램에서 읽기 쉽게 합니다.

:::tip 명명 규칙
기본적으로 폼, 테이블, 필드에는 항상 **단수 이름**을 사용하세요.  
예: `작업`, `기록`, `작업자`, `작업_id`, `작업자_id`.
:::
