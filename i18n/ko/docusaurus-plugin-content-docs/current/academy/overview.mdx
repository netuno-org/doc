# Netuno 개요

## 소개

**Netuno**에 오신 것을 환영합니다!

새로운 기술을 도입하는 것은 시장에 선택지가 너무 많아 어려운 일일 수 있습니다. Netuno는 최고의 도구와 솔루션을 한곳에 모아 개발을 단순화함으로써 이 문제를 해결하기 위해 만들어졌습니다.

우리는 생산성에 초점을 둔 플랫폼입니다. Netuno의 가장 큰 가속 요소 중 하나는 시간이 오래 걸리는 컴파일이나 빌드 과정이 없다는 점입니다.

우리는 주요 데이터베이스와 통합된 다양한 프로그래밍 언어를 사용할 수 있는 유연하고 매끄러운 개발 경험을 제공합니다.

Netuno의 **로우코드** 환경은 폴리글랏을 지원하므로 각 서비스의 특정 요구 사항에 가장 적합한 언어를 선택할 수 있습니다.

> 우리의 모토는 간단합니다: **더 적은 코드로 더 많은 일을 합니다.**

## 업무 생산성

Netuno는 다음 핵심 원칙을 통해 개발 병목을 제거합니다:

- **안전한 도구 선택:** 초기 조사 및 구성 시간을 줄여 줍니다. Netuno는 이미 현재 가장 효율적인 솔루션으로 구성되어 제공됩니다.

- **폴리글랏 유연성:** 동일한 생태계 안에서 선호하는 프로그래밍 언어로 작업하고, 각 웹 서비스에 맞게 준비된 다양한 리소스를 활용할 수 있습니다.

- **빠른 웹 서비스 생성:** 로우코드 접근 방식으로 복잡한 REST API를 신속하게 개발할 수 있습니다.

- **간편한 통합:** 백엔드를 빠르게 개발하고 어떤 프런트엔드, 모바일 애플리케이션, 기업 포털 또는 온라인 스토어에도 쉽게 연결할 수 있습니다.

- **실시간 업데이트(핫 리로드):** 개발 속도가 빠른 이유는 서버를 다시 시작할 필요가 없다는 점에도 있습니다. Netuno 생태계에서는 컴파일과 재시작이 없습니다. 코드 변경은 즉시 실시간으로 반영됩니다.

* **신속한 개발:** 개발하는 동시에 API를 테스트할 수 있습니다. Netuno에 코드를 저장하고 곧바로 프런트엔드에서 요청해 보세요.

* **비즈니스 규칙에 집중:** 기본 인프라와 연결은 Netuno가 처리하도록 맡기세요. 시스템이 최종 사용자에게 더 많은 가치를 제공하는 방법에 집중하세요.

## 백오피스

플랫폼은 폼 인터페이스 생성과 데이터베이스 구조화를 하나로 통합하여 개발 여정을 단순화합니다.

이 접근 방식은 학습 곡선을 크게 줄여 개발자가 비즈니스 로직에 집중하는 동안 플랫폼이 인프라를 관리할 수 있게 합니다.

따라서 수동 SQL 스크립트를 작성하거나 반복적인 CRUD(Create, Read, Update, Delete) 화면을 만들 필요가 없습니다.

폼을 설계하는 것은 동시에 데이터베이스를 모델링하고 완전한 관리 인터페이스를 생성하는 일입니다.

Netuno는 바로 사용할 수 있는 관리 생태계를 제공하며, 여기에는 다음이 포함됩니다:

| 기능 | 설명 |
| :--- | :--- |
| **관계** | 다이어그램, 외래 키 및 테이블 간 연결을 자동으로 관리합니다. |
| **고급 검색** | 레코드를 빠르게 찾을 수 있는 정교한 필터를 제공합니다. |
| **파일 관리** | 이미지 및 문서 업로드를 위한 기본 컴포넌트입니다. |
| **내보내기** | 보고서에 호환되는 형식으로 데이터를 추출합니다. |
| **보안** | 액세스 프로필 제어 및 통합 인증을 제공합니다. |

Netuno는 **오픈 소스**이며, 무료로 협업하며 도구의 모든 잠재력을 탐색하여 높은 생산성으로 복잡한 작업을 수행할 수 있습니다. [지금 시작하기](/docs/get-started/installation).

## 데이터베이스

Netuno는 백오피스 생성과 데이터베이스 구조를 통합하여 데이터 관리를 단순화합니다. 이 구성은 테이블 생성을 위해 복잡한 SQL 스크립트를 수동으로 작성할 필요가 없습니다.

시각적 인터페이스를 통해 필드와 관계를 정의할 수 있으며, 플랫폼은 이러한 정의를 데이터베이스와 동기화하여 관리 인터페이스와 데이터 다이어그램을 자동으로 생성합니다.

## 데이터 다이어그램

Netuno는 애플리케이션의 데이터 모델을 나타내는 동적 다이어그램을 자동으로 생성합니다. 이 기능은 정보 아키텍처와 테이블 간 연결을 시각화하는 데 필수적입니다.

## 쿼리

Netuno는 강력하고 직관적인 데이터베이스 콘솔을 제공하여 개발자가 데이터와 직접 상호 작용할 수 있게 합니다.

복잡하거나 자주 사용하는 명령을 저장해 두었다가 나중에 빠르게 액세스할 수 있습니다.
시스템은 실행된 명령의 기록을 유지하므로 감사 및 이전 쿼리 로직 복구가 용이합니다.

콘솔에서는 여러 명령을 동시에 실행할 수 있습니다. 명령을 구분하고 Netuno가 각 명령을 올바르게 해석하도록 하려면 이중 세미콜론 구분자 `;;`를 사용하세요.

## 로우코드 및 폴리글랏 개발


Netuno는 유연한 아키텍처로 두각을 나타내며, 각 프로젝트가 여러 프로그래밍 언어를 동시에 사용할 수 있게 합니다.

여러 개의 독립적인 애플리케이션(프로젝트)을 만들고, 각 애플리케이션 안에서 Netuno가 지원하는 가장 인기 있는 시장 언어를 사용해 서비스를 작성할 수 있습니다.

플랫폼은 서버의 서비스 폴더에 생성된 파일 확장자를 기준으로 사용할 실행 엔진을 자동으로 식별합니다. 예:

- `.js` - JavaScript
- `.py` - Python
- `.rb` - Ruby
- `.kts` - Kotlin Script
- `.groovy` - Groovy
