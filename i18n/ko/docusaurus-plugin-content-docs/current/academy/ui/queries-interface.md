Netuno의 쿼리 도구는 SQL(Structured Query Language)을 통해 애플리케이션 데이터베이스와 직접 상호 작용할 수 있는 강력한 기능입니다.

이 기능은 비즈니스 로직을 테스트하고, 저장된 정보를 검증하며, 보고서나 복잡한 인터페이스 구성 요소의 기반을 마련하는 데 필수적입니다. Netuno는 현재 **PostgreSql, H2 Database 및 MySQL**의 세 가지 데이터베이스 관리 시스템을 지원합니다.

## 1 - 쿼리 섹션

“빌드” 모드에서 사이드 메뉴의 “관리” 영역으로 이동한 후 “쿼리” 섹션을 클릭합니다.

![쿼리 인터페이스 화면](/docs/assets/academy/ui/queries/query-queries-interface-pt.png)

## 2 - 명령 영역

이 영역은 프로젝트 데이터베이스와 직접 상호 작용하는 환경입니다. 여기서는 정확하고 즉각적으로 데이터를 조회, 검색, 분석하는 명령을 실행할 수 있습니다.

사용하는 구문이 Netuno 환경에 구성된 데이터베이스와 호환되는지 확인하세요.

![쿼리 데이터베이스 쿼리 영역](/docs/assets/academy/ui/queries/query-database-query-area-pt.png)

## 3 - 검증 영역

검증 영역은 코드의 구문과 실행에 대한 즉각적인 피드백을 제공합니다.

- **성공(녹색):** 쿼리가 구문 또는 구조 오류 없이 실행되면 메시지가 녹색 배경으로 표시됩니다. 이는 데이터가 처리되어 시각화할 준비가 되었음을 나타냅니다.

![쿼리 검증 영역 성공](/docs/assets/academy/ui/queries/query-validation-area-success-pt-at.png)

- **실패 또는 오류(빨간색):** 실행에 장애가 있는 경우(구문 오류, 잘못된 열 이름, 권한 부족 등) 메시지가 빨간색 배경으로 표시됩니다. 색상 외에도 시스템은 진단을 돕기 위해 기술 오류 로그를 표시합니다.

![쿼리 검증 영역 실패](/docs/assets/academy/ui/queries/query-validation-area-fail-pt-at.png)

## 4 - 결과 영역

데이터베이스에 요청한 정보가 구조화된 형태로 표시되는 곳입니다. 테이블 내용을 확인하고 쿼리 로직이 예상한 레코드를 반환하는지 검증할 수 있습니다.

![쿼리 결과 영역](/docs/assets/academy/ui/queries/query-result-area-pt.png)

## 5 - 작업 버튼

이 섹션에서는 SQL 스크립트를 실행, 저장, 관리하는 데 사용할 수 있는 도구를 자세히 설명하여 워크플로를 최적화하고 복잡한 쿼리를 재사용할 수 있도록 합니다.

실시간 명령 실행뿐만 아니라 기록 및 저장된 스크립트 라이브러리를 통한 스마트한 생산성 관리도 가능합니다.

![쿼리 작업 버튼](/docs/assets/academy/ui/queries/query-action-buttons-pt-at.png)

### 5.1 버튼 - 실행

- **기능:** “명령” 영역에 있는 스크립트를 데이터베이스로 보내 처리합니다.

- **피드백:** 실행 후 시스템은 성공 메시지(녹색)를 표시하고 요청된 데이터로 “결과 영역”을 자동으로 채웁니다.

### 5.2 버튼 - 기록

- **기능:** 최근 실행된 쿼리를 기록하고 각 작업의 실행 시간(밀리초)과 “날짜/시간” 기록을 표시합니다.

- **빠른 불러오기:** 기록 목록에서 항목을 클릭하면 해당 스크립트가 “명령” 영역에 다시 삽입되어 실행하거나 편집할 수 있습니다.

![쿼리 명령 기록 버튼](/docs/assets/academy/ui/queries/query-command-history-button-pt-at.png)

### 5.3 버튼 - 저장

**기능:** 유용한 스크립트를 저장하고 영구 템플릿으로 변환할 수 있습니다. 자주 실행해야 하는 복잡한 쿼리에 유용합니다.

**저장 절차:**

- 편집기에서 스크립트를 준비한 후 저장을 클릭합니다.

- “명령 저장” 모달 창에서 쿼리 기능을 식별할 수 있는 명확한 “이름”을 입력합니다(예: “가격별 상품 필터링”).

- 모달 안의 저장 버튼을 클릭하여 저장을 확인합니다.

![쿼리 명령 저장 버튼](/docs/assets/academy/ui/queries/query-save-command-button-pt-at.png)

### 5.4 버튼 - 등록

**기능:** 이전에 저장된 모든 스크립트를 나열할 수 있습니다.

- **스크립트 불러오기:** 원하는 스크립트를 클릭하여 “명령” 영역에 추가합니다.

- **삭제:** 각 항목 옆의 휴지통 아이콘을 사용하여 확인 후 해당 항목을 영구적으로 제거합니다.

![쿼리 등록된 명령 버튼](/docs/assets/academy/ui/queries/query-registered-commands-button-pt-at.png)
