콘텐츠 편집기에서 코드 없이 관리하는 키/값 파라미터 시스템입니다.

## 소개

**설정**은 백오피스의 콘텐츠 편집기에서 관리하는 키/값 파라미터 시스템으로, 코드를 건드리지 않고도 자주 바뀌거나 언어별로 달라지는 웹사이트 값(예: 전화번호, 주소, 소셜 미디어 링크, 로고 이미지)을 다루기 위해 만들어졌습니다.

백오피스의 세 가지 폼으로 구성됩니다:

- **유형** (`configuration_parameter_type`)
- **파라미터** (`configuration_parameter`)
- **설정값** (`configuration`)

## 유형

파라미터가 어떤 종류의 값을 받는지 정의합니다. **코드** (`code`)와 **이름** (`name`)만 있습니다. 기본적으로 다음 값들이 이미 생성되어 있습니다:

| 코드 | 이름 |
|---|---|
| `boolean` | 불리언 |
| `number` | 숫자 |
| `image` | 이미지 |
| `color` | 색상 |
| `text` | 텍스트 |
| `html` | HTML |

## 파라미터

설정 "키"를 정의합니다 — **코드** (`code`, 코드에서 값을 가져올 때 사용), **설명**, 그리고 **유형**(위 유형 중 하나)입니다. 예: 텍스트 유형의 `전화번호` 파라미터.

## 설정값

특정 **언어**에 대한 파라미터의 **값**입니다 — 파라미터 유형에 따라 **값** (`value`, 텍스트) 또는 **이미지** (`value_img`)입니다.

### 언어 없는 값 (일반 폴백)

설정값의 **언어** 필드가 비어 있으면, 해당 값은 그 파라미터에 대해 자체 값이 정의되지 않은 **모든 언어의 폴백**으로 사용됩니다. 이렇게 하면 동일한 값(예: 모든 언어에서 같은 전화번호)을 언어마다 따로 중복해서 넣을 필요가 없습니다 — 언어와 연결하지 않고 한 번만 정의하고, 실제로 다른 경우에만 언어별로 개별 값을 정의하면 됩니다.

## 프로그래밍 방식으로

`website/src/common/Cluar.js` 클래스는 설정을 읽는 함수를 제공합니다:

- `Cluar.configuration(parameter)` — 현재 언어에서 파라미터의 값을 가져옵니다. 해당 언어에 값이 없으면 언어 없는 값(폴백)을 사용하고, 둘 다 없으면 파라미터 이름 자체를 반환합니다(누락된 설정을 빠르게 알아채는 데 유용합니다).
- `Cluar.configurationNumber(parameter)` — 동일하지만 값을 숫자로 변환합니다(숫자가 아니면 0).
- `Cluar.configurationMultilines(parameter)` — 동일하지만 줄바꿈을 `<br>`로 변환합니다.
