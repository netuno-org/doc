## 개요

기존 페이지에서 **복제** 옵션을 통해 새 페이지를 만들 수 있습니다. 복제 양식에서는 다음을 지정해야 합니다:

- 새 페이지의 **제목**과 **링크**(link).
- **원본 버전** — 원본 페이지의 어느 버전에서 콘텐츠를 복사할지.
- **언어** — 선택적으로 원본 페이지의 언어와 다르게 지정할 수 있습니다.
- 새 페이지를 즉시 **게시**할지 여부.

확인하면 CLUAR가 해당 버전의 모든 컴포넌트 구조(배너, 콘텐츠, 목록, 슬라이더, 기능 및 각각의 액션)를 새 페이지로 복제합니다.

## 용도

실제로 페이지의 "번역"을 만드는 방법은 다음과 같습니다. 새 페이지를 처음부터 구성하는 대신, 다른 언어로 이미 존재하는 페이지를 선택해 새 언어로 복제한 다음 텍스트를 조정합니다. 같은 언어 내에서 유사한 페이지를 빠르게 만드는 데에도 사용할 수 있습니다(예: 동일한 구조의 여러 캠페인 페이지).

:::info 콘텐츠 번역
복제는 페이지의 **구조**(동일한 컴포넌트, 동일한 순서)를 복제하지만 **텍스트를 번역하지는 않습니다** — 각 컴포넌트(배너, 콘텐츠, 목록, 슬라이더, 기능)의 필드는 원본 콘텐츠로 유지되며, 각 컴포넌트에 들어가 직접 번역해야 합니다. 복제 시 콘텐츠 자동 번역은 예정되어 있지만 아직 개발되지 않았습니다.
:::
