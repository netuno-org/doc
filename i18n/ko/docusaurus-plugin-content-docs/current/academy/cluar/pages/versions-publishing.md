## 버전

각 페이지에는 하나 이상의 **버전**(`page_version`)이 있으며, 각 버전은 자체 상태(초안 / 게시됨)를 가집니다. 이를 통해 게시된 내용에 영향을 주지 않고 새로운 콘텐츠 버전을 편집할 수 있습니다. 버전이 게시됨으로 표시되어야만 해당 페이지의 활성 버전이 됩니다.

콘텐츠 구성 요소(배너, 콘텐츠, 목록, 슬라이더, 기능)는 항상 페이지에 직접 속하는 것이 아니라 특정 버전(`page_version_id`)에 속합니다. 즉, 초안 버전의 구성 요소를 편집해도 게시된 내용에는 영향을 주지 않습니다.

## 게시

페이지를 게시할 때 CLUAR는 다음을 수행합니다:

1. 게시된 버전의 활성 구성 요소(배너, 콘텐츠, 목록, 슬라이더, 기능 및 해당 액션)를 모두 수집합니다.
2. 해당 콘텐츠로 JSON 구조 파일을 생성합니다.
3. 프로덕션에서 페이지 URL(언어별)에 대해 정적 `index.html`을 사전 렌더링하며, SEO 및 Open Graph 메타 태그가 이미 채워져 있습니다. 사이트 자체가 React 기반 SPA이므로 소셜 미디어 공유와 검색 엔진에 중요합니다.
