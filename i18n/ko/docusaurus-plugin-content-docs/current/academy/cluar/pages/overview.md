**페이지**는 CLUAR의 중심 엔티티로, 웹사이트의 URL을 나타냅니다. 각 페이지는 하나의 언어에만 속합니다. 단일한 "다국어" 페이지는 존재하지 않으며, 각 언어에는 자체 페이지(자체 `link`, 제목, 콘텐츠 등 포함)가 있고, 이들은 오직 [복제](/docs/academy/cluar/pages/cloning) 작업을 통해서만 서로 연결됩니다.

각 페이지는 조직에 속합니다. 페이지에는 하위 페이지가 있을 수 있으며, 하위 페이지는 기본적으로 상위 페이지의 조직에 속합니다.

## 필드

| 필드 | 설명 |
|---|---|
| **제목** (`title`) | 페이지 제목. |
| **링크** (`link`) | 페이지 URL(예: `/회사-소개`). |
| **언어** (`language_id`) | 이 페이지가 속한 언어. |
| **상위** (`parent_id`) | 상위 페이지로, 계층/브레드크럼 및 하위 메뉴를 구성하는 데 사용됩니다. |
| **템플릿** (`template`) | 페이지를 렌더링하는 데 사용되는 템플릿([템플릿](/docs/academy/cluar/templates) 참조). 양식의 선택 항목이며 `website/src/pages/Template/`에 있는 기존 폴더로 동적으로 채워집니다. |
| **상태** (`status_id`) | 초안 또는 게시됨 — 현재 버전의 상태를 반영합니다. |
| **메뉴** (`menu`) | 선택하면 페이지가 탐색 메뉴에 표시됩니다. |
| **메뉴 제목** (`menu_title`) | 메뉴에 표시할 대체 제목(비어 있으면 페이지 제목 사용). |
| **탐색 가능** (`navigable`) | 페이지에 직접 접근할 수 있는지 여부를 제어합니다(메뉴에 표시되지 않더라도). |
| **순서** (`sorter`) | "형제" 페이지(동일한 `parent_id`) 사이에서 페이지의 위치. |
| **설명** / **키워드** | SEO 메타 태그(`<meta name="description">` / `<meta name="keywords">`). |
| **소셜 미디어용 설명** / **소셜 미디어용 이미지** | 페이지가 공유될 때 Open Graph 태그(`og:description`, `og:image`)에 사용됩니다. |

## 다음 단계
