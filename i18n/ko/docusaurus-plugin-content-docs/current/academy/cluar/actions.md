컴포넌트와 연결된 CTA(버튼/링크)를 생성하고 재사용하는 방법입니다.

## 소개

**액션**은 기본적으로 재사용 가능한 **CTA**(call-to-action)입니다. 즉, 제목, 텍스트, 이미지, 대상(`link`)이 있는 버튼/링크이며, 배너, 콘텐츠, 목록, 슬라이더(항목 내), 기능과 같은 [컴포넌트](/docs/academy/cluar/components/overview)에 연결할 수 있습니다.

## 필드

| 필드 | 설명 |
|---|---|
| **제목** (`title`) | 액션의 제목으로, 헤더(`<h4>`)로 렌더링됩니다. |
| **콘텐츠** (`content`) | 액션의 설명 텍스트로, 단락(`<p>`)으로 렌더링됩니다. |
| **표시 문구** (`indication`) | 링크/CTA 자체의 텍스트입니다. 클릭 가능한 버튼 **안에** 표시되는 내용입니다(예: "자세히 보기", "지금 구매"). |
| **이미지** (`image`) | 액션과 연결된 이미지입니다(예: 아이콘). |
| **링크** (`link`) | 액션의 대상(URL)입니다. CTA를 클릭했을 때 이동할 곳입니다. |
| **언어** (`language_id`) | 이 액션이 속한 언어입니다. |
| **파라미터** (`parameter_id`) | 이 액션을 다른 언어의 동등한 액션과 그룹화합니다. 아래를 참조하세요. |

## 파라미터

**파라미터**(`action_parameter`, 단지 `código`와 `descrição`만 포함)는 그룹화 역할을 합니다. 여러 액션 — 각각 해당 언어로 되어 있지만 **동일한 기능/대상**을 나타내는 — 이 같은 파라미터를 공유합니다.

이것은 다른 언어로 [페이지 복제](/docs/academy/cluar/pages/cloning)를 할 때 사용됩니다. 원본 페이지의 컴포넌트에 연결된 각 액션에 대해 CLUAR는 기존 액션 중에서 **동일한 파라미터**를 가지며 복제 대상 **언어**에 있는 액션을 찾습니다. 찾으면 해당 액션(이미 번역된 버전)을 복제된 컴포넌트에 자동으로 연결합니다. 나중에 수동으로 추가할 필요가 없습니다.

:::info 먼저 대상 언어로 액션을 만들어야 합니다
자동 연결은 복제하려는 언어에 동일한 파라미터를 가진 액션이 이미 존재할 때만 작동합니다. 아직 존재하지 않으면 해당 액션은 복제된 컴포넌트에 연결되지 않으며, 정의되지 않은 것처럼 됩니다. 즉, 파라미터는 액션을 자동으로 번역하거나 생성하지 않고, 각 언어로 이미 생성된 동등한 액션을 연결할 뿐입니다.
:::

예를 들어, 포르투갈어의 "Saiba mais" 액션과 동일한 파라미터 `learn-more`를 사용하는 영어의 "Learn more" 액션이 있습니다. 포르투갈어 페이지를 영어로 복제하면 첫 번째 액션이 연결되어 있던 배너에는 두 번째 액션이 자동으로 연결됩니다.
