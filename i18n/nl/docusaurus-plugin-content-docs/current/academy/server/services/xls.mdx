Aangepaste Excel-bestanden verwerken.

## Inleiding

Netuno genereert Excel-bestanden die compatibel zijn met LibreOffice, OpenOffice, Microsoft Office, Google Drive, enz., via de [XLS](/docs/library/resources/xls)-functie. Deze biedt een low-code-abstractie van [Apache POI](https://poi.apache.org/) voor de verschillende programmeertalen die Netuno ondersteunt.

We kunnen zowel XLSX-, XLS- als ODS-bestanden genereren.

De applicatie die bij Netuno wordt geleverd en **demo** heet (de demonstratieapplicatie) bevat talrijke voorbeelden van mogelijke code-implementaties in verschillende talen, inclusief een demonstratie van het exporteren van werkbladen via de service `export-excel`, die zich bevindt in:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-excel`
]} />

Om de XLS-voorziening te initialiseren:

<PolyglotCode
    codes={[

            `

## Opmaak

Het definiëren van visuele opmaakstijlen, dat wil zeggen de opmaak van datums, tijden, geld, enzovoort, moet gebeuren vóór het definiëren van celwaarden, omdat je bij het definiëren van celwaarden ook de opmaakstijl kunt koppelen.

Zoals wordt gedemonstreerd in het voorbeeld dat bij de applicatie `demo` wordt geleverd, worden de opmaakstijlen direct aan het begin van de code gedefinieerd.

## Uiterlijk

Het definiëren van visuele uiterlijkstijlen, dat wil zeggen het uiterlijk van cellen zoals kleuren, lettertype, randen, uitlijning, enzovoort, moet gebeuren vóór het definiëren van celwaarden, omdat je bij het definiëren van celwaarden ook de uiterlijkstijl kunt koppelen.

Zoals wordt gedemonstreerd in het voorbeeld dat bij de applicatie `demo` wordt geleverd, worden de uiterlijkstijlen direct aan het begin van de code gedefinieerd.

<PolyglotCode

## Cellen samenvoegen

Om cellen in een gebied samen te voegen gebruiken we de methode `mergedRegion`.

De volgorde van de parameters is:

1. Beginrij
2. Beginkolom
3. Eindrij
4. Eindkolom

> De numerieke positioneringsreferenties beginnen altijd bij **nul**.

In het onderstaande voorbeeld worden alle cellen van kolom 10 tot en met kolom 15 op rij 3 samengevoegd:

<PolyglotCode
    codes={[

            code: `

        },
    ]}
/>

## Getabelleerde gegevens invoegen

We kunnen een gegevenstabel invoegen met de methode `addDataTable`.

Omdat de eerste twee parameters de positie bepalen waar de gegevenstabel moet worden ingevoegd, zijn dit de rij- en kolomnummers.

> Let op dat de positionering in de code van rijen en kolommen altijd vanaf **nul** begint.
>
> Dat wil zeggen, rij 1 is positie `0` en kolom A is ook positie `0`.

Vervolgens geven we een lijst met rijen door, waarbij elke rij een andere lijst voor de kolommen bevat; pas dan voegen we een map met de celwaarde toe.

Volledig voorbeeld:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                werkmap.addDataTable(
                    6, 1,
                    _val.list() // Rijen
                        .add(
                            _val.list() // Kolom
                                .add(
                                    _val.map() // Cel
                                        .set("value", "Naam")
                                )
                                .add(
                                    _val.map()
                                        .set("value", "Leeftijd")
                                )
                        )
                        .add( // Andere rij
                            _val.list()
                                .add( // Eerste kolom
                                    _val.map()
                                        .set("value", "Maria")
                                )
                                .add( // Tweede kolom
                                    _val.map()
                                        .set("value", 26)
                                )
                        )
                )
            `
        },
    ]}
/>

### Formules

Om formules in te voegen gebruiken we de sleutel `formula` in de map met celdefinities.

In dit voorbeeld wordt in de laatste cel de som van alle waarden van de andere cellen berekend:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                werkmap.addDataTable(
                    6, 1,
                    _val.list()
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 45))
                                .add(_val.map().set("value", 26))
                        )
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 51))
                                .add(_val.map().set("value", 30))
                        )
                        .add(
                            _val.list()
                                .add(
                                    _val.map().set("value", "Totaal")
                                )
                                .add(
                                    _val.map().set("formula", "SUM(B7:C8)")
                                )
                        )
                )
            `
        },
    ]}
/>

Om de kolomletter op basis van het kolomnummer te verkrijgen kan de methode `columnReference` worden gebruikt, wat kan helpen bij het definiëren van de formules. Dezelfde methode kan ook worden gebruikt om het kolomnummer op basis van de referentieletter te verkrijgen, bijvoorbeeld:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                werkmap.addDataTable(
                    6, _xls.columnReference('B'),
                    _val.list()
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 45))
                                .add(_val.map().set("value", 26))
                        )
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 51))
                                .add(_val.map().set("value", 30))
                        )
                        .add(
                            _val.list()
                                .add(
                                    _val.map().set("value", "Totaal")
                                )
                                .add(
                                    _val.map().set(
                                        "formula",
                                        "SUM("+ _xls.columnReference(1) +"7:"+ _xls.columnReference(2) +"8)"
                                )
                            )
                        )
                )
            `
        },
    ]}
/>

Om het gegenereerde bestand in de map `storage/filesystem` van de applicatie te openen:

<PolyglotCode
    codes={[

/>

In de bovenstaande voorbeelden bevat de constante `werkmap` het bewerkingsobject met de context van het betreffende bestand, zodat je elk type manipulatie kunt uitvoeren.

Wanneer je klaar bent met de wijzigingen, genereer je het nieuwe bestand.

> Het is niet mogelijk hetzelfde geopende bestand rechtstreeks te wijzigen; er moet een nieuw bestand met een ander pad worden gegenereerd.

Om hetzelfde bestand rechtstreeks te wijzigen, kan dit met de `inputStream`.

Hier volgt een voorbeeld van hoe je de waarde van een cel wijzigt:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const bestandInvoer = _app.file("bestand.xlsx").inputStream()
                const werkmap = _xls.open(bestandInvoer)

                werkmap.setCellData(
                    10, 1,
                    _val.map()
                        .set(
                            "value",
                            werkmap.getCellData(10, 1).getInt("value") + 10
                        )
                )

                bestandInvoer.close() // Sluit het geopende bestand.
                werkmap.save(_app.file("bestand.xlsx")) // Slaat de nieuwe versie op.
                `
        },
    ]}
/>

## Bestand lezen

Het extraheren van gegevens uit Excel-bestanden gebeurt met de methode `read`.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const gegevens = _xls.read(_app.file("bestand.xlsx"))
            `
        },
    ]}
/>

De gegevens worden verkregen in een structuur van objecten van het type Values met lijsten voor de werkbladen, rijen en kolommen, en maps (sleutel en waarde) voor de cellen.

Om alle gegevens te bekijken kunnen we ze als data-uitvoer van de service plaatsen:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _out.json(gegevens)
            `
        },
    ]}
/>

Om de iteratie uit te voeren moeten we in gedachten houden dat de gegevensstructuur in de volgende volgorde is georganiseerd:

1. `sheets` - Werkbladen
2. `rows` - Rijen
3. `columns` - Kolommen

Voorbeeld van een volledige iteratie:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                for (const werkblad of gegevens.getValues("sheets")) {
                    _out.println(\`<h4>Werkblad: \${werkblad.getInt("index")} - \${werkblad.getString("name")}</h4>\`)
                    for (const rij of werkblad.getValues("rows")) {
                        _out.println(\`<h4>Rij: \${rij.getInt("row")}</h4>\`)
                        _out.println("<p>")
                        for (const kolom of rij.getValues("columns")) {

Het celtype wordt verkregen via de code:

- `kolom.getString("type")`

En de ondersteunde typen zijn:

- `string` - Tekstinhoud.
- `numeric` - Numerieke inhoud of datum en/of tijd.
- `boolean` - Waar of onwaar.
- `blank` - Lege cel.
- `formula` - Cel die een formule bevat.
- `error` - Fout bij het verwerken van de cel.

### Aanvullende parameters

Voor elk celtype hebben we enkele aanvullende parameters.

`string` - Celtype met tekstuele inhoud.

- `value` - Tekst van de cel.
- `richValue` - Opmaak van de cel.

`numeric` - Celtype met numerieke inhoud, of datums en ook tijden.

- `value` - Waarde van de numerieke inhoud van de cel.
  
Bij datums en tijden zijn er nog deze aanvullende parameters:

- `localDateTime` - Java Time LocalDateTime-object dat de datum- en tijdwaarde van de cel voorstelt.
- `localDate` - Java Time LocalDate-object dat de datumwaarde van de cel voorstelt.
- `localTime` - Java Time LocalTime-object dat de tijdwaarde van de cel voorstelt.
- `instant` - Java Time Instant-object dat de datum- en/of tijdwaarde van de cel voorstelt.
- `date` - Java Date-object dat de datum- en/of tijdwaarde van de cel voorstelt.

`boolean` - Celtype met booleaanse inhoud, dat wil zeggen waar of onwaar.

- `value` - Waarde van het type _boolean_, `true` of `false`.

`blank` - Celtype zonder inhoud; bevat daarom geen aanvullende parameters.

`formula` - Celtype dat berekeningsformules bevat.

- `value` - Eindwaarde die uit de berekening resulteert.
- `formula` - Bevat de formule-expressie die voor de berekening is gebruikt.

`error` - Celtype dat een fout bevat.

- `value` - Bytewaarde van de gegenereerde fout.
- `code` - Als er fouten zijn in de formuleberekening, wordt hier de code van de opgetreden fout gegeven.
