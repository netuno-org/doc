Aangepaste PDF-bestanden verwerken.

## Inleiding

Netuno genereert PDF-bestanden met ondersteuning voor afbeeldingen, tabellen, lettertypen en nog veel meer, via de [PDF](/docs/library/resources/pdf)-functie die een low-code-abstractie van [iTextPDF](https://itextpdf.com/) biedt voor de verschillende programmeertalen die Netuno ondersteunt.

De applicatie die met Netuno wordt meegeleverd en **demo** (demonstratieapplicatie) heet, bevat veel voorbeelden van mogelijke code-implementaties in verschillende talen, waaronder de demonstratie van PDF-export via de service `export-pdf`, die zich bevindt in:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-pdf`
]} />

## Initialisatie

## HTTP-header

Om een service in de REST-API te maken die een PDF-bestand als uitvoer retourneert, moet je de `Content-Type`-parameter van het HTTP-protocol aan de header toevoegen.

Voorbeeld van hoe je de inhoud als PDF definieert:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("pdf")
            `
        },
    ]}
/>

De code `pdf` is een afkorting voor:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("application/pdf")
            `
        },
    ]}
/>

## Alinea

Voegt een nieuwe alinea toe aan het document:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    _pdf.paragraph("Mijn tekst hier...")
                        .setFontSize(15)
                )
            `
        },
    ]}
/>

Om een alinea op een vaste positie toe te voegen:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    pdfDocument.add(
                        _pdf.paragraph("Mijn vaste tekst...")
                            .setFixedPosition(100, 500, 200)
                            .setFontSize(15)
                    )
                )
            `
        },
    ]}
/>

In de bovenstaande code is in de methode `setFixedPosition` de eerste parameter de X-positie (`100`), de tweede parameter de Y-positie (`500`) en de derde parameter de breedte (`200`).

**Let op:** als Y op de waarde `0` wordt gezet, betekent dit dat het onderaan de pagina staat; om het omhoog te verplaatsen moet je de Y-waarde verhogen. Hoe hoger de Y-waarde, hoe hoger het verschijnt, maar als deze te hoog is en voorbij de paginalengte komt, is het niet zichtbaar.

> Documentatie met alle methoden van het [iText-alineaobject](https://api.itextpdf.com/iText/java/8.0.3/com/itextpdf/layout/element/Paragraph.html).

## Tabel

Het is mogelijk tabellen te maken, waarmee een gegevensset leesbaarder kan worden gepresenteerd.

Het aantal kolommen van de tabel wordt gedefinieerd met de parameter: `_pdf.table(aantalKolommen)`

In het onderstaande voorbeeld is `aantalKolommen` het getal `1`, dus één kolom.

Omdat we twee cellen aan de tabel toevoegen, gaat de tweede cel naar de volgende rij.

Merk op:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    _pdf.table(1)
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Persoon")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBorder(_pdf.border("solid", 2))
                                .setBackgroundColor(_pdf.colorRGB(1, 0, 0))
                        )
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Nicole")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBackgroundColor(_pdf.colorGray(0.5))
                        )
                )
            `
        },
    ]}
/>

Met de methode `addCell` kun je de definities van de cellen met hun respectieve inhoud invoegen.

> Documentatie met alle methoden van het [iText-celobject](https://api.itextpdf.com/iText/java//8.0.3/com/itextpdf/layout/element/Cell.html).

## Document sluiten en opslaan

Het document wordt pas volledig opgeslagen of gegenereerd wanneer de methode `close` wordt aangeroepen, als volgt:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.close()
            `
        },
    ]}
/>

Waar het document wordt gegenereerd, wordt bij de initialisatie bepaald; daarom bepalen we bij de initialisatie van het document waar het uiteindelijke document wordt gegenereerd: in de uitvoer van de service (`output`) of in een bestand.

## Bestand lezen

Om een PDF-document te lezen en de tekstinformatie eruit te halen.

We gebruiken de methode `extract`, die alle gegevens van het PDF-bestand in een JSON-object ophaalt.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const pdfGegevens = _pdf.extract(_app.file("bestand-1.pdf"))

                _out.json(pdfGegevens)
            `
        },
        {
            lang: 'python',
            code: `
                pdfGegevens = _pdf.extract(_app.file("bestand-1.pdf"))

                _out.json(pdfGegevens)
            `
        },
        {
            lang: 'ruby',
            code: `
                pdfGegevens = _pdf.extract(_app.file("bestand-1.pdf"))

                _out.json(pdfGegevens)
            `
        },
        {
            lang: 'kotlin',
            code: `
                val pdfGegevens = _pdf.extract(_app.file("bestand-1.pdf"))

                _out.json(pdfGegevens)
            `
        },
        {
            lang: 'groovy',
            code: `
                def pdfGegevens = _pdf.extract(_app.file("bestand-1.pdf"))

                _out.json(pdfGegevens)
            `
        },
    ]}
/>

De geretourneerde JSON heeft de sleutel `content` met alle tekstinhoud van het PDF-bestand en de sleutel `metadata` met de verschillende eigenschappen van het PDF-bestand.

Hier is een voorbeeld van de JSON die door `extract` wordt geretourneerd:

```json
{
  "content": "Alle tekstinhoud van het PDF-bestand komt hier...",
  "metadata":{
    "Content-Type":"application/pdf",
    "dc:format":"application/pdf; version=1.4",
    "dc:title":"Linux 1",
    "pdf:PDFVersion":"1.4",
    "pdf:charsPerPage":"580",
    "pdf:containsDamagedFont":"false",
    "pdf:containsNonEmbeddedFont":"false",
    "pdf:docinfo:producer":"Skia/PDF m125 Google Docs Renderer",
    "pdf:docinfo:title":"Bestand 1",
    "pdf:encrypted":"false",
    "xmpTPg:NPages":"3",
    ...
  }
}
```

Er zijn nog veel andere gegevens die in `metadata` worden opgehaald, maar die in de `...` zijn weggelaten om het voorbeeld niet te lang te maken.
