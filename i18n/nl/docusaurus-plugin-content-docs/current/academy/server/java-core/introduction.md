Netuno is ontwikkeld in Java, dus vanuit Java kunnen we nieuwe functionaliteiten creëren.

We kunnen bijvoorbeeld nieuwe native services creëren, of zelfs nieuwe low-code programmeerfuncties die
beschikbaar zijn in alle polyglot programmeertalen, zoals JavaScript, Python, Ruby, Groovy en Kotlin.

In Java kunnen we ook multi-applicatie webservices creëren die beschikbaar zijn in alle Netuno-applicaties.

Elke techniek of bibliotheek uit het Java-ecosysteem kan worden gebruikt om elk type functionaliteit te creëren.

> We raden aan dat je voordat je deze tutorial start, enige basiskennis van _Java_ hebt.
