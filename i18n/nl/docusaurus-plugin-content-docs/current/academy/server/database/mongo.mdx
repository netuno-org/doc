## Inleiding

<a href="https://www.mongodb.com/" target="_blank">MongoDB</a> is een documentgeoriënteerde NoSQL-database. In plaats van tabellen en rijen worden de gegevens opgeslagen in documenten in een JSON-achtig formaat, wat een grote flexibiliteit in het datamodel mogelijk maakt.

Netuno biedt de resource [_mongo](/docs/library/resources/mongo) voor de integratie met MongoDB, met een low-code abstractie bovenop de officiële MongoDB-client voor Java, beschikbaar voor de verschillende programmeertalen die door Netuno worden ondersteund: **JavaScript, Python, Ruby, Kotlin en Groovy**.

> Voordat je verdergaat, is het aanbevolen om te weten hoe je services in Netuno maakt; zie de tutorial [REST - Web Services](/docs/academy/server/services/rest).

Een voorbeeldimplementatie van de hier gepresenteerde bewerkingen is beschikbaar in de voorbeeldservice `mongo.js`, die zich bevindt in:

## MongoDB installeren

### Met Docker

Ervan uitgaande dat je Docker hebt geïnstalleerd, hoef je alleen de MongoDB-image te downloaden en een nieuwe container te starten:

```shell
docker pull mongo
docker run -d --name mongo -p 27017:27017 mongo
```

Op deze manier is MongoDB toegankelijk op `localhost:27017` zonder authenticatie.

Om de databasegebruiker aan te maken volgens de configuratie van de applicatie, voer je uit:

```shell
docker exec -it mongo mongosh products_db --eval 'db.createUser({ user: "products_user", pwd: "12345678", roles: [{ role: "readWrite", db: "products_db" }] })'
```

### Met Ubuntu

MongoDB is niet opgenomen in de officiële Ubuntu-repositories, daarom is het nodig om de officiële repository toe te voegen vóór de installatie:

```shell
sudo apt-get install gnupg curl
curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.asc | sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg --dearmor
echo "deb [ signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] http://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
sudo apt-get update
sudo apt-get install -y mongodb-org
```

Na de installatie kun je de service starten met:

```shell
sudo systemctl start mongod
```

### Met Windows

- <a href="https://www.mongodb.com/try/download/community" target="_blank">Download de MongoDB Community Server</a>.

Voer de gedownloade installer uit en activeer in de stap **Service Configuration** de optie **Install MongoD as a Service** zodat MongoDB automatisch opstart. MongoDB is toegankelijk op `localhost:27017` zonder authenticatie.

> Raadpleeg de [officiële MongoDB-documentatie](https://www.mongodb.com/docs/manual/installation/) voor andere distributies en versies.

## Configuratie van de applicatie

De configuratie van de MongoDB-verbindingen gebeurt in het configuratiebestand van de applicatie, afhankelijk van de omgeving:

- `config/_development.json`

> Lees meer over de [configuratiebestanden](/docs/academy/explore/configuration) van de applicatie.

Voeg in het configuratiebestand het blok `mongo` toe, waarbij elke sleutel een verbinding identificeert:

```javascript
{
    ...
    "mongo": {
        "store": "mongodb://store_user:12345678@localhost/store_db",
        "products": {
            "username": "products_user",
            "password": "12345678",
            "host": "127.0.0.1",
            "port": "27017",
            "database": "products_db"
        }
    },
    ...
}
```

Een verbinding kan op twee manieren worden gedefinieerd:

- **Als verbindings-URL** — de waarde is simpelweg een string, bijvoorbeeld `"mongodb://store_user:12345678@localhost/store_db"`.
- **Als configuratieobject** — met de velden:
  - `url` — indien gedefinieerd, wordt het rechtstreeks als verbindings-URL gebruikt, waarbij de andere velden worden genegeerd.
  - `protocol` — het protocol van de verbinding, standaard `mongodb`.
  - `username` en `password` — de toegangsgegevens.
  - `host` — het adres van de server, standaard `localhost`.
  - `port` — de poort van de verbinding, standaard `27017`.
  - `database` — de naam van de database, standaard de naam van de verbindingssleutel.
  - `params` — extra verbindingsparameters die aan de URL worden toegevoegd, bijvoorbeeld `{ "authSource": "admin" }`. Ze worden alleen toegepast wanneer de URL wordt opgebouwd uit de velden van het object.

> De verbinding hoeft niet de hoofddatabase van de applicatie te zijn. In tegenstelling tot de configuratie `db` is het blok `mongo` onafhankelijk en maakt het meerdere gelijktijdige verbindingen mogelijk.

### Filters

De factory `_mongo.filters()` biedt de belangrijkste query-operatoren van MongoDB:

| Operator | Beschrijving |
|---|---|
| `eq("veld", waarde)` | Gelijk aan de waarde. |
| `ne("veld", waarde)` | Verschillend van de waarde. |
| `gt("veld", waarde)` | Groter dan de waarde. |
| `gte("veld", waarde)` | Groter dan of gelijk aan de waarde. |
| `lt("veld", waarde)` | Kleiner dan de waarde. |
| `lte("veld", waarde)` | Kleiner dan of gelijk aan de waarde. |
| `in("veld", waarde1, waarde2, ...)` | Gelijk aan een van de waarden. |
| `nin("veld", waarde1, waarde2, ...)` | Verschillend van alle waarden. |
| `and(filter1, filter2, ...)` | Komt overeen met alle filters. |
| `or(filter1, filter2, ...)` | Komt overeen met ten minste één van de filters. |
| `not(filter)` | Komt niet overeen met het filter. |
| `regex("veld", "patroon")` | Komt overeen met de reguliere expressie. |
| `exists("veld")` | Het veld bestaat in het document. |
| `text("zoekopdracht")` | Tekstzoekopdracht. |
| `type("veld", "type")` | Het veld is van het opgegeven type. |
| `mod("veld", deler, rest)` | De rest van de deling van het veld door de deler is gelijk aan de waarde. |
| `where("expressie")` | Komt overeen met de documenten die voldoen aan een JavaScript-expressie, bijvoorbeeld `"this.price > 100"`. |
| `size("veld", n)` | Het matrixveld heeft precies `n` elementen. |

De beschikbare aggregatiefasen zijn de volgende:

| Fase | Beschrijving |
|---|---|
| `match(filter)` | Selecteert alleen de documenten die overeenkomen met het filter. |
| `group("$veld", accumulatoren)` | Groepeert de documenten per veld en past de accumulatoren toe. |
| `project(projectie)` | Voegt velden toe, verwijdert of wijzigt ze in de documenten. |
| `sort(sortering)` | Sorteert de documenten. |
| `limit(n)` | Beperkt tot de eerste `n` documenten. |
| `skip(n)` | Slaat de eerste `n` documenten over. |
| `count()` | Telt het aantal documenten. |
| `lookup("collectie", "lokaalVeld", "vreemdVeld", "als")` | Voert een join uit met een andere collectie. |

En de meest gebruikte accumulatoren:

| Accumulator | Beschrijving |
|---|---|
| `sum("veld", "$expressie")` | Som van de waarden. |
| `avg("veld", "$expressie")` | Gemiddelde van de waarden. |
| `min("veld", "$expressie")` | Minimale waarde. |
| `max("veld", "$expressie")` | Maximale waarde. |
| `first("veld", "$expressie")` | Waarde van het eerste document. |
| `last("veld", "$expressie")` | Waarde van het laatste document. |
| `top("veld", sortering, "$expressie")` | Bovenste waarde volgens de sortering. |
| `bottom("veld", sortering, "$expressie")` | Onderste waarde volgens de sortering. |

> In de accumulatoren verwijst de expressie met prefix `$` naar het veld van een invoerdocument, bijvoorbeeld `"$price"`.

## Conclusie

Met de resource `_mongo` biedt Netuno een low-code en polyglot abstractie bovenop de officiële MongoDB-client voor Java, waarmee je kunt werken met documenten, filters, sorteringen, projecties, updates, indexen en aggregaties in JavaScript, Python, Ruby, Kotlin en Groovy.

Voor meer details over alle beschikbare methoden, raadpleeg de documentatie van de resource [_mongo](/docs/library/resources/mongo) en van de klasse [MongoCollection](/docs/library/objects/MongoCollection).
