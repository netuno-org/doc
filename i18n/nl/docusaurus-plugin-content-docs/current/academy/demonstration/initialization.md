# Initialisatie 

Initialisatie van de Demo-applicatie

Om met deze tutorial te beginnen, is de eerste stap het starten van de server van de **Demo**-applicatie en het voorbereiden van de ontwikkelomgeving.


### Start de server 

Open de terminal van uw besturingssysteem en navigeer naar de hoofdmap waar het Netuno-platform is geïnstalleerd (bijvoorbeeld `📁 /netuno`).

Voer de onderstaande opdracht uit om de server te starten:

```bash
./netuno server
```

:::info Alternatieve initialisatie
Als de hoofdopdracht niet werkt of de Demo-applicatie niet standaard wordt geladen, forceer dan de initialisatie door de applicatieparameter op te geven:
:::

```bash
./netuno server app=demo
```

### Kies de code-editor
U kunt de code-editor van uw voorkeur gebruiken om zowel de backend als de frontend van uw applicatie te ontwikkelen.

Als u er nog geen heeft, raden we de volgende gratis en open-source opties aan:

- VS Code: <a href="https://code.visualstudio.com/" target="_blank">code.visualstudio.com</a>
- VS Codium: <a href="https://vscodium.com/" target="_blank">vscodium.com</a>
- WebStorm: <a href="https://www.jetbrains.com/webstorm/" target="_blank">jetbrains.com/webstorm</a>


#### Open de projectmap
Zoek met de code-editor de map van de Demo-applicatie en open deze: `📁 apps/demo`.

Deze map bevat alle bestanden en configuraties van de nieuwe applicatie. Alleen binnen deze map vindt alle ontwikkeling plaats.

### Volgende stappen

Nu de server draait en de bestanden in de code-editor zijn geopend, is de omgeving klaar. Ga verder naar de volgende stap van de tutorial om de applicatie te verkennen en aan te passen.
