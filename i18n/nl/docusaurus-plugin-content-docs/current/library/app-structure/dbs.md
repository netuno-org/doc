Organisatie van de databasebestanden.

## Map voor Database

De map `📂 dbs` is bedoeld om de databasebestanden van uw applicatie op te slaan.

Bij databases van het type H2 Database worden alle bestanden automatisch in deze map gegenereerd.

Deze map is handig om alles met betrekking tot databases op te slaan, bijvoorbeeld back-ups, scripts,
dumps, diagrammen, enz.

Alle documentatie met betrekking tot de database die het project van de applicatie moet vergezellen, wordt aanbevolen
om in deze map te worden georganiseerd.
