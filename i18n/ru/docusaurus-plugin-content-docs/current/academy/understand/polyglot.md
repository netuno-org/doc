Netuno является полиглотом как на уровне баз данных, так и на уровне языков программирования, а также на уровне операционной системы.

Благодаря всему этому разнообразию увеличивается количество вариантов, где его можно использовать.

Поддерживая различные базы данных, языки программирования и операционные системы, он упрощает разработку, позволяя адаптироваться к каждой из ситуаций, но обеспечивая целостную среду для разработки.

## Базы данных

Его можно использовать для интеграции нескольких типов различных баз данных и даже разрабатывать с использованием разных языков программирования в одном проекте.

Интеграция разных баз данных вполне обычна для объединения данных при чтении или изменении данных в базе данных другой системы.

![Логотипы баз данных](/docs/assets/business/databases.jpg "Различные базы данных")

Netuno поддерживает следующие базы данных:

- H2 Database
- PostgreSQL
- MariaDB
- MySQL
- Microsoft SQL Server
- Oracle

## Языки программирования

Поддержка разных языков программирования может показаться не очень интересной в смысле смешивания языков программирования, но это возможно, и это не означает, что так нужно делать.

На практике часто сложно реализовывать проекты, где доминирующая технология ограничена одним языком программирования, поэтому приходится искать людей, исключительно компетентных в этом языке программирования.

С Netuno у нас в итоге появляется больше возможностей: вся работа не пропадает впустую, если потребуется использовать новый язык программирования из-за смены стратегии, нехватки компетентных специалистов, необходимости быстрее разработать что-то конкретное или в других ситуациях, где это может иметь смысл.

Обычно это было бы немыслимо, потому что поддержка системы с несколькими языками программирования начинает вызывать беспокойство, но поскольку это low-code, такая проблема становится не столь актуальной, потому что:

* Языки программирования в конечном итоге похожи с точки зрения логики и алгоритмов.
* Язык программирования может быть разным, но ресурсы Netuno остаются теми же и используются одинаково независимо от языка.

Таким образом, даже если специалист очень привык работать с одним языком программирования, ничто не помешает ему выполнять сопровождение на другом. Если потребуется значительно расширить его участие или даже всё переделать, он сможет выбрать разработку на своём предпочитаемом языке и интегрировать свою разработку с уже используемым языком.

![Логотипы языков программирования](/docs/assets/business/languages.jpg "Языки программирования")

Netuno поддерживает разработку на следующих языках программирования:

- Groovy
- Java
- JavaScript
- Kotlin
- Python
- Ruby

## Операционные системы

Netuno, работая с множеством операционных систем и поддерживая конфигурации среды, позволяет гарантировать корректное функционирование разработок сквозным образом и организовывать их в среды разработки, тестирования, обеспечения качества, производства и другие.

Смена операционной системы или среды не влияет на корректную работу Netuno и приложений.

![Логотипы операционных систем](/docs/assets/business/operationsystems.jpg "Различные операционные системы")

Операционные системы, поддерживаемые Netuno:

* Linux
* Mac OS X
* Windows
