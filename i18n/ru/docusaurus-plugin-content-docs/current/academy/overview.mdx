# Обзор Netuno

## Введение

Добро пожаловать в **Netuno**!

Мы знаем, что внедрение новых технологий может быть сложной задачей из-за большого количества доступных на рынке вариантов. Netuno создан для решения этой проблемы: он упрощает разработку, объединяя лучшие инструменты и решения в одном месте.

Мы — платформа, ориентированная на продуктивность. Один из главных ускорителей в Netuno — отсутствие длительных процессов компиляции или сборки.

Мы предлагаем плавный и гибкий опыт разработки для использования различных языков программирования, интегрированных с основными базами данных.

**Low-code**-среда Netuno является мультиязычной, позволяя выбирать язык, который лучше всего подходит для конкретной задачи каждого сервиса.

> Наш девиз прост: **меньше строк кода — больше результат.**

## Продуктивность работы

Netuno устраняет узкие места разработки благодаря следующим принципам:

-  **Надёжный выбор инструментов:** Мы сокращаем время на исследование и начальную настройку. Netuno уже структурирован с использованием наиболее эффективных современных решений.

- **Мультиязычная гибкость:** Работайте с предпочитаемым языком программирования в рамках одной экосистемы, используя широкий набор готовых ресурсов для каждого конкретного веб-сервиса.

- **Быстрое создание веб-сервисов:** Low-code-подход позволяет быстро разрабатывать сложные REST API.

- **Простая интеграция:** Быстро разрабатывайте бэкенд и легко подключайте его к любому фронтенду, мобильным приложениям, корпоративным порталам или интернет-магазинам.

- **Обновление в реальном времени (Hot Reload):** Скорость разработки также обусловлена тем, что не нужно перезапускать сервер. В экосистеме Netuno нет компиляций и перезапусков. Изменения кода применяются мгновенно и в реальном времени.

* **Скорость разработки:** Тестируйте API одновременно с разработкой. Сохраните код в Netuno и сразу же выполните запрос из своего фронтенда.

* **Фокус на бизнес-логике:** Позвольте Netuno позаботиться о базовой инфраструктуре и подключениях. Сосредоточьтесь на том, как ваша система может приносить больше пользы конечному пользователю.

## Бэк-офис

Платформа упрощает путь разработки, объединяя создание интерфейсов форм с автоматическим структурированием базы данных.

Этот подход резко снижает кривую обучения, позволяя разработчикам сосредоточиться на бизнес-логике, пока платформа управляет инфраструктурой.

Это избавляет от необходимости писать SQL-скрипты вручную или создавать повторяющиеся экраны CRUD (создание, чтение, обновление, удаление).


Создавая форму, вы одновременно моделируете базу данных и генерируете полноценный административный интерфейс.

Netuno предоставляет готовую к использованию административную экосистему, включающую:

| Функциональность | Описание |
| :--- | :--- |
| **Связи** | Автоматическое управление диаграммами, внешними ключами и связями между таблицами. |
| **Расширенный поиск** | Уточнённые фильтры для быстрого поиска записей. |
| **Управление файлами** | Встроенные компоненты для загрузки изображений и документов. |
| **Экспорт** | Извлечение данных в совместимых форматах для отчётов. |
| **Безопасность** | Управление профилями доступа и встроенная аутентификация. |

Netuno имеет **открытый исходный код** и позволяет бесплатно и совместно раскрывать весь потенциал инструмента для выполнения сложных задач с высокой продуктивностью. [Начните сейчас](/docs/get-started/installation).

## База данных

Netuno упрощает управление данными, объединяя создание бэк-офиса со структурой базы данных. Такое построение не требует ручного написания сложных SQL-скриптов для создания таблиц.

Через визуальный интерфейс можно определять поля и связи, а платформа синхронизирует эти определения с базой данных, автоматически генерируя интерфейс администрирования и диаграмму данных.

## Диаграмма данных

Netuno автоматически генерирует динамическую диаграмму, отображающую модель данных вашего приложения. Этот ресурс важен для визуализации информационной архитектуры и связей между таблицами.

## Запросы

Netuno предоставляет мощную и интуитивно понятную консоль базы данных, позволяя разработчикам напрямую взаимодействовать с данными быстро и организованно.

Можно сохранять сложные или часто используемые команды для быстрого доступа в будущем.
Система ведёт историю выполненных команд, упрощая аудит и восстановление предыдущих логик запросов.

Консоль позволяет выполнять несколько команд одновременно. Чтобы разделить инструкции и гарантировать, что Netuno правильно интерпретирует каждую из них, используйте разделитель из двух точек с запятой `;;`.

## Low-code-разработка и мультиязычность


Netuno выделяется гибкой архитектурой, позволяющей каждому проекту одновременно использовать несколько языков программирования.

Можно создавать несколько независимых приложений (проектов) и внутри каждого писать сервисы, используя самые популярные рыночные языки, поддерживаемые Netuno.

Платформа автоматически определяет, какой движок выполнения использовать, на основе расширения файла, созданного в папке сервисов сервера, например:

- `.js` — JavaScript
- `.py` — Python
- `.rb` — Ruby
- `.kts` — Kotlin Script
- `.groovy` — Groovy
