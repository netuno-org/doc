# Форма

На этом этапе демонстрации вы создадите форму **Задача** и настроите первое поле данных.

:::info Справка
Более подробное объяснение о формах см. в [Руководстве по интерфейсу: Формы](/docs/academy/ui/forms).
:::

## Цель

После завершения этого этапа у вас будет:

- Форма с названием **Задача**.
- Связанная таблица в базе данных.
- Обязательное поле для хранения названия задачи.
- Интерфейс, готовый для создания, редактирования, поиска и удаления записей.

## Предварительные требования

Убедитесь, что:

- Демонстрационное приложение уже создано.
- Этап настройки уже завершён.
- Вы находитесь в области разработки платформы.

## Создать форму

1. В правом верхнем углу нажмите **Построить**.
2. В главном меню перейдите в **Управление > Формы**.
3. В поле **Название формы** укажите `Задача`.
4. В поле **Имя таблицы** включите опцию **Авто**.
5. Нажмите **Сохранить**.

:::note
- **Название формы** определяет имя, отображаемое в боковом меню.
- **Имя таблицы** определяет технический идентификатор, используемый в базе данных.
:::

После сохранения форма **Задача** станет доступна в левом боковом меню.

## Создать первое поле

После создания формы:

1. В боковом меню нажмите **Задача**.
2. В поле **Отображаемое имя** укажите `Название`.
3. Убедитесь, что техническое имя было автоматически сгенерировано строчными буквами.
4. Включите опцию **Первичный ключ** (уникальное поле).
5. Включите опцию **Не NULL** (обязательное поле).
6. В поле **Тип** выберите `text`.
7. Нажмите **Сохранить**.

:::tip
- **Первичный ключ** гарантирует уникальные значения для каждой записи.
- **Не NULL** делает заполнение обязательным.
- Тип `text` позволяет хранить простой текст.
:::

## Проверить результат

Откройте область просмотра и убедитесь, что:

- Форма **Задача** доступна.
- Поле **Название** отображается для заполнения.
- Можно создать новую запись.
- Поле **Название** обязательно.

:::info Ожидаемый результат
Если настройка выполнена правильно, форма будет готова к операциям создания, редактирования, поиска и удаления записей.
:::
