# Настройка приложения

Это руководство описывает начальные шаги по настройке языка приложения Demo, базы данных и включению автоматических команд, выполняемых вместе с сервером.

Все изменения вносятся в файл конфигурации `_development.json` приложения **Demo**, расположенный в папке /apps/demo/**config**.

### Предварительные требования

Перед редактированием конфигурации убедитесь в следующем:

- Приложение Demo уже создано и инициализировано.
- Вы находитесь в корне проекта Netuno.
- В редакторе кода открыт файл `/apps/demo/config/development.json`.
- После сохранения изменений вы сможете перезапустить сервер.

## Настройка языков

### 1. Приложение

В файле конфигурации найдите поля `language` и `locale`, чтобы изменить язык приложения.

```json title="/apps/demo/config/development.json"
{
  "language": "pt_PT",
  "locale": "pt_PT"
}
```

Укажите значения в соответствии с нужным языком:

- **Португальский**: `pt_PT` или `pt_BR`
- **Английский**: `en_GB` или `en_US`

### 2. База данных

Найдите объект **"db"**, а затем настройки **"default"**.

Измените поле **"name"**, чтобы указать соответствующую базу данных:

- `demo_pt`: база данных на португальском.
- `demo_en`: база данных на английском.

```json title="/apps/demo/config/development.json"
{
 ...
"db": {
        "default": {
            "password": "",
            "engine": "h2",
            "port": "",
            "host": "",
            "name": "demo_pt",
            "username": "sa"
        }
    },
...
}
```

### 3. Включение нескольких команд

Netuno позволяет одновременно выполнять несколько команд при запуске сервера, отображая их вывод в одной консоли.

По умолчанию в приложении **Demo** команда `bun run watch` уже настроена, но отключена. Эта команда автоматически компилирует любые изменения, внесённые в файлы кода бэк-офиса.

Чтобы включить её, найдите массив **"commands"** и измените значение поля **enabled** с false на **true**.
 
```json title="/apps/demo/config/development.json"
"commands": [
        {
            "enabled": true,
            "path": "ui",
            "command": "bun run watch"
        }
    ],
```

### Параметры объекта "commands"

- `enabled`: включает (true) или отключает (false) автоматическое выполнение команды.
- `path`: задаёт путь (папку) приложения, в которой будет выполняться команда.
- `command`: задаёт команду, которая будет выполняться в терминале.

:::tip
Вы можете добавить другие команды в массив `"commands"`, если сохраните ту же структуру объекта.
:::


После сохранения файла конфигурации перезапустите сервер Netuno, чтобы применить изменения.


## Ожидаемый результат

После перезапуска сервера проверьте следующие пункты:

- Приложение Demo использует настроенный язык.
- В консоли отображается выполнение команды `bun run watch`, если она включена.
