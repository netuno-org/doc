## Введение

Разработка фронтенда, то есть того, что визуально обрабатывается браузером, выполняется внутри папки **ui**.

По умолчанию в этой папке находится среда разработки, созданная на <a href="https://reactjs.org/" target="_blank">ReactJS</a> с <a href="https://ant.design/" target="_blank">Ant.Design</a> и <a href="http://lesscss.org/" target="_blank">Less</a>, компилируемая с использованием <a href="https://vite.dev/" target="_blank">Vite</a>.

Хотя стандартная среда настроена под эти технологии, поскольку они довольно широко используются сегодня, она не ограничена ими.

Если вы хотите использовать другую технологию, например **VueJS**, **MaterialUI**, **Sass**, **Bootstrap**, **TypeScript** и т. д., достаточно изменить внутри папки `📂 ui` настройки `📂 package.json` и `📂 vite.config.js` на предпочитаемые вами технологии.

> Подробнее об [интегрированном и централизованном терминале](/docs/academy/explore/centralized-terminal).

## Расширение сервиса

После создания сервиса **работники** в `📂 server/services/работники.js` через Visual Studio Code, который предоставляет информацию в <a href="https://pt.wikipedia.org/wiki/JSON" target="_blank">JSON</a> по адресу:

* <a href="http://localhost:9000/services/trabalhadores" target="_blank">http://localhost:9000/services/работники</a>

Следующий шаг — расширить его, чтобы отобразить данные в интерфейсе браузера.

С этими данными мы отобразим их в таблице и на графике.

Предполагая, что у вас открыт Visual Studio Code или другой текстовый редактор с приложением **Демо**.

Откройте в редакторе следующий файл:

`📂 ui/src/containers/КонтейнерПанели/index.jsx`

Мы изменим этот существующий код.

### Подготовка `state`

В самом начале компонента `КонтейнерПанели` внутри `function` находится определение его _state_.

Добавьте новую запись для хранения данных работников следующим образом:

```jsx
            // 👇 Добавьте новые строки кода ниже:
            const [работники, setРаботники] = useState([]);
            const [загрузка, setЗагрузка] = useState(false);
```

То есть добавьте новую строку состояния `const [работники, setРаботники] = useState([]);`.

### Создание функции `загрузитьРаботников`

Ниже обратите внимание, что есть функция с именем `загрузитьРаботников`; эта функция получает данные работников, которые в настоящее время отображаются на дашборде.

> Эта функция используется для загрузки данных работников.

Вставьте код ниже:

```jsx
    /**
    *** 🚀 Загружает данные работников.
    ***    Через выполнение сервиса:
    **     http://localhost:9000/services/работники
    */
    const загрузитьРаботников = () => {
        setРаботники([]);
        setЗагрузка(true);
        _service({
            url: intl.locale.indexOf('ru') == 0 ? '/services/работники' : '/services/workers',
            success: (ответ) => {
                setРаботники(ответ.json);
                setЗагрузка(false);
            },
            fail: (ошибка) => {
                setЗагрузка(false);
                console.error('Ошибка в сервисе работников.', ошибка);
                message.error(intl.formatMessage({ id: `${messages}.loading_error` }));
            }
        });
    };
```

Что делает этот код выше: он передаёт данные **работников** в _state_ компонента в <a href="https://reactjs.org/" target="_blank">ReactJS</a>, а именно через выполнение сервиса **работники**, который, получая данные в <a href="https://pt.wikipedia.org/wiki/JSON" target="_blank">JSON</a>, сохраняет их в _state_ через выполнение `setРаботники`.

Итоговый код должен быть структурирован следующим образом:

```jsx
    useEffect(() => {
        ...
    }, []);

    const загрузитьРаботников = () => {
        ...
    }

    return ( 
        ...
    );
```

> Где `...` — это различные строки кода, опущенные внутри соответствующих блоков.

### Выполнение хука `useEffect`

Теперь осталось выполнить наш хук `useEffect`, когда компонент «монтируется»; этот хук выполняется, когда компонент создаётся в визуальном представлении браузера.

Для этого достаточно чуть выше добавить строку кода `загрузитьРаботников();` внутри хука `useEffect` следующим образом:

```jsx
    useEffect(() => {
        загрузитьРаботников();
    }, []);
```

Эта новая строка кода вызовет функцию, которая выполняет сервис <a href="http://localhost:9000/services/trabalhadores" target="_blank">http://localhost:9000/services/работники</a>, созданный ранее, чтобы получить данные в JSON и сохранить их в `state` (_состояние_) компонента для отображения в `return` (_представление_).

## Отображение данных

Осталось визуально отобразить данные в интерфейсе, который пользователь видит в браузере.

Чтобы отобразить данные в браузере, нам нужно изменить `return`, который обрабатывает визуальный вид компонентов в <a href="https://reactjs.org/" target="_blank">ReactJS</a>.

В конце кода `КонтейнерПанели` вы найдёте: `return ( ... );`

Давайте изменим его, добавив всего одну строку кода для ещё одного компонента `ВизуализацияДанных`, который будет отображать данные о **работниках**; код должен выглядеть следующим образом:

```jsx
    // 🔍 Найдите в существующем коде:
    return (
    <div ref={ref}>
      { загрузка == false ?
        <ВизуализацияДанных data={работники} />
        : <Spin/>
      }
      <СписокСервисов />
    </div>
  );
```

Обратите внимание, что нужно добавить только строку ниже:

```jsx
<ВизуализацияДанных data={работники} />
```

Таким образом, `ВизуализацияДанных` получит данные, полученные через сервис **работники** по JSON, которые сохранились в `state`.
