# База данных

На этом этапе мы рассмотрим **базу данных**, автоматически созданную из формы **Задача**, определённой ранее.

При создании формы **Задача** с полем **Название** Netuno создал в базе данных таблицу `zadacha` с колонкой `nazvanie` в соответствии с именами, заданными при создании формы.

**Технические имена** полей (например, `zadacha`, `nazvanie`, `zadacha_id`) используются в программировании и SQL-запросах и не соответствуют отображаемым именам в интерфейсе.

## Запросы

В этом разделе мы выполним запросы напрямую в базе данных через интерфейс управления Netuno.

1. Перейдите в среду **Сборка**.
2. В меню нажмите **Управление > Query**.
3. В редакторе запросов вставьте и выполните команды ниже.

### Простые запросы

Выведите только названия задач:

```sql
SELECT nazvanie
FROM zadacha;
```

Выведите все поля таблицы задач:

```sql
SELECT *
FROM zadacha;
```

Выведите все поля таблицы записей:

```sql
SELECT *
FROM zapis;
```

Выведите все поля таблицы работников:

```sql
SELECT *
FROM rabotnik;
```

При нажатии **Выполнить** Netuno создаёт таблицу результатов для **каждой** команды, разделённой точкой с запятой (`;`).  
Это удобно, когда нужно выполнить несколько запросов за один раз.

### Запрос со связями

Теперь выполните запрос, который связывает все таблицы:

```sql
SELECT
  zadacha.nazvanie,
  zapis.nachalo,
  zapis.konets,
  rabotnik.nazvanie
FROM zadacha
INNER JOIN zapis
  ON zadacha.id = zapis.zadacha_id
INNER JOIN rabotnik
  ON rabotnik.id = zapis.rabotnik_id;
```

Этот запрос возвращает:

- Название задачи.
- Начало и конец каждой записи.
- Имя работника, связанного с каждой записью.

Он показывает, как связи между таблицами позволяют объединять информацию из разных сущностей приложения.

## Диаграмма

Чтобы нагляднее увидеть структуру базы данных, используйте **Диаграмму** Netuno.

1. Перейдите в среду **Сборка**.
2. В меню нажмите **Управление > Диаграмма**.

В Диаграмме можно:

- Увеличивать или уменьшать масштаб.
- Экспортировать диаграмму как изображение.

Эти действия доступны на кнопках в правой части панели диаграммы.

Netuno автоматически создаёт линии со стрелками связей на основе настройки **Связи** в полях (например, полей типа `select`, указывающих на другие таблицы).

## Рекомендации

При моделировании базы данных в Netuno следуйте этим рекомендациям:

- Используйте суффикс `_id` в полях, представляющих связи, например:
  - `zadacha_id`
  - `rabotnik_id`
- Избегайте использования имён таблиц и полей во множественном числе, например `zadachi`, `zapisi` или `rabotniki`.

Отказ от множественного числа помогает:

- Сохранять имена короче и понятнее.
- Уменьшать неоднозначность при написании запросов.
- Упрощать чтение в формах и диаграммах, особенно при наличии множества связей.

:::tip Соглашение об именовании
По умолчанию всегда используйте **имена в единственном числе** для форм, таблиц и полей.  
Примеры: `zadacha`, `zapis`, `rabotnik`, `zadacha_id`, `rabotnik_id`.
:::
