# Инициализация 

Инициализация приложения Демо

Чтобы начать это руководство, первым шагом будет запуск сервера приложения **Демо** и подготовка среды разработки.


### Запустите сервер 

Откройте терминал вашей операционной системы и перейдите в корневую папку, где установлена платформа Netuno (например, `📁 /netuno`).

Выполните приведенную ниже команду, чтобы запустить сервер:

```bash
./netuno server
```

:::info Альтернатива запуска
Если основная команда не работает или приложение Демо не загружается по умолчанию, принудительно запустите его, указав параметр приложения:
:::

```bash
./netuno server app=демо
```

### Выберите редактор кода
Вы можете использовать редактор кода по своему усмотрению для разработки как бэкенда, так и фронтенда вашего приложения.

Если у вас его еще нет, рекомендуем следующие бесплатные варианты с открытым исходным кодом:

- VS Code: <a href="https://code.visualstudio.com/" target="_blank">code.visualstudio.com</a>
- VS Codium: <a href="https://vscodium.com/" target="_blank">vscodium.com</a>
- WebStorm: <a href="https://www.jetbrains.com/webstorm/" target="_blank">jetbrains.com/webstorm</a>


#### Откройте папку проекта
Открыв редактор кода, найдите и откройте каталог приложения Демо: `📁 apps/демо`.

Эта папка содержит все файлы и настройки нового приложения. Вся разработка будет вестись исключительно внутри этого каталога.
