## Пользовательский интерфейс (`ui`)

В интерфейсе управления данными Netuno можно внедрять пользовательский код для выполнения индивидуальных настроек и манипуляций.

Разработка ведётся в коде программы внутри папки `ui` в корневой папке приложения.

### addPageLoad()

Страницу нельзя безопасно изменять, пока приложение не будет «готово».

Метод будет вызван, когда страница загрузится.

```javascript
netuno.addPageLoad(() => {
   console.log('делаю что-то');
});
```

### addContentLoad()

Когда загружаются формы или отчёты, интерфейс изменяется с соответствующим содержимым — будь то форма данных, поиск или фильтрация данных отчёта.

Как только загружается какой-либо контент, вызывается метод, которому передаётся контейнер, содержащий отображаемый контент.

```javascript
netuno.addContentLoad((контейнер) => {
   if (контейнер.is('[netuno-form-search]')) {
       console.log('делаю что-то, когда элемент существует');
   }
});
```
