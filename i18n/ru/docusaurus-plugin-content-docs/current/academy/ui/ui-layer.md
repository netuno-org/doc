Установка и компиляция дашборда и общего интерфейса приложений.

## Контекст

Приложения Netuno по умолчанию уже включают набор продвинутых технологий для фронтенда, среди которых [React](https://react.dev/), [Vite](https://vite.dev/), [Less](https://lesscss.org/) 
и [Ant.Design](https://ant.design/).

Внутри приложений есть папка `📁 ui` (_user interface_, пользовательский интерфейс), где мы разрабатываем
дашборды и другие компоненты фронтенда.

## Перед началом

Убедитесь, что у вас установлен [Bun](https://bun.sh/) — это обязательное условие. Подробнее:

- [Установить Bun](/docs/academy/website/bun)

## Установка модулей зависимостей

Чтобы установить все зависимости, которые идут по умолчанию, перейдите в папку `📁 ui` (_user interface_) внутри вашего 
разрабатываемого приложения, например:

```shell
cd apps/мое_приложение/ui/
```

Выполните команду установки модулей зависимостей:

```shell
bun install
```

> [Bun](https://bun.sh) — это улучшенная и более оптимизированная альтернатива NPM.

## Автоматическая компиляция

Перейдите в папку `📁 ui` (_user interface_) вашего разрабатываемого приложения, например:

```shell
cd apps/мое_приложение/ui/
```

Чтобы автоматически компилировать фронтенд при каждом изменении кода, выполните:

```shell
bun run watch
```

> Убедитесь, что у вас установлен [Bun](https://bun.sh/).
 
## Автоматическая интеграция фронтенда с Netuno

Netuno позволяет запускать UI вместе с процессом сервера приложения Netuno.

> Все сообщения компиляции React будут интегрированы в тот же терминал, что и приложение Netuno.

Для этого достаточно активировать настройку в `commands` приложения Netuno в `📂 config/_development.json`,
то есть в `command` с `path` равным `ui` установить `enabled` в `true` следующим образом:

```json title="config/_development.json"
{
  ...
  "commands": [
    {
      "enabled": true,
      "path": "ui",
      "command": "bun run watch"
    }
  ],
  ...
}
```

> После редактирования файлов конфигурации приложения Netuno необходимо перезапустить сервер, чтобы он применил 
> новые изменения.

Затем запустите/перезапустите сервер с вашим приложением Netuno, чтобы проверить его работу.

Теперь всё будет интегрировано в один централизованный терминал, что избавит вас от необходимости держать несколько 
разрозненных терминалов. Подробнее:

- [Централизованный терминал](/docs/academy/explore/centralized-terminal)

## Другие технологии фронтенда

В папке `📁 ui` можно настроить любую технологию фронтенда или добавить любой необходимый новый модуль 
зависимостей.

Если вы не хотите использовать ни одну из стандартных технологий, можете заменить их любой другой, особенно
адаптировав файлы:

- `package.json`
- `vite.config.js`
