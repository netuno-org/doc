## Подключение к нескольким базам данных

Netuno позволяет приложению подключаться к нескольким базам данных.

Таким образом, вы сможете работать с данными через разные подключения и разные типы баз данных.

Netuno поддерживает подключение к таким базам данных, как:

- PostgreSQL
- MariaDB
- H2DataBase
- Microsoft SQL Server
- Oracle _(скоро)_

## База данных DEFAULT

Чтобы приложения работали корректно, всегда необходимо наличие базы данных, настроенной как default (по умолчанию).

Напомним, что настройки приложений находятся в файлах:

```
/web/app/ВАШЕ_ПРИЛОЖЕНИЕ/config/_development.json
/web/app/ВАШЕ_ПРИЛОЖЕНИЕ/config/_production.json
/web/app/ВАШЕ_ПРИЛОЖЕНИЕ/config/_ВАША_СРЕДА.json
```

Там вы найдете конфигурацию подключения к базе данных _default_ следующим образом:

```
    ...
    "db": {
        "default": {
            "password": "*****",
            "engine": "psql|mariadb|h2|mssql",
            "host": "localhost",
            "name": "база_данных",
            "username": "пользователь"
        }
    },
    ...
```

Поэтому чтобы добавить дополнительные подключения к другим базам данных, достаточно повторить эту конфигурацию, заменив имя _default_ на другое желаемое имя.

Например, представьте, что у вас есть приложение, в котором база данных по умолчанию находится в PostgreSQL, но также необходимо подключиться к базе данных MariaDB от WordPress (_сайт-wp_) и к другой базе данных Microsoft SQL Server от приложения .Net/C# (_приложение-dotnet-mssql_)...

Конфигурация этого приложения для подключения к этим нескольким базам данных будет выглядеть так:

```
    ...
    "db": {
        "default": {
            "password": "*****",
            "engine": "psql",
            "host": "localhost",
            "name": "база_данных",
            "username": "пользователь"
        },
        "сайт-wp": {
            "password": "*****",
            "engine": "mariadb",
            "host": "localhost",
            "name": "база_данных",
            "username": "пользователь"
        },
        "приложение-dot-net": {
            "password": "*****",
            "engine": "mssql",
            "host": "localhost",
            "name": "база_данных",
            "username": "пользователь"
        }
    },
    ...
```

Чтобы взаимодействовать с каждым из этих приложений, достаточно использовать ресурс _db следующим образом:

```
var dbПоУмолчанию = _db.init()

var dbСайтWP = _db.init("сайт-wp")

var dbПриложениеDotNet = _db.init("приложение-dot-net")
```

Каждая переменная содержит экземпляр ресурса *_db*, связанный с базой данных, соответствующей ключу, который идентифицирует подключение, определенное в настройках приложения.

Таким образом, используя эти переменные, вы сможете выполнять операции с базой данных, такие как запросы, вставки, обновления и удаления.

Для получения дополнительной информации об операциях с базой данных обратитесь к документации ресурса: [_db](/docs/library/resources/db)
