## Введение

<a href="https://www.mongodb.com/" target="_blank">MongoDB</a> — это документоориентированная NoSQL база данных. Вместо таблиц и строк данные хранятся в документах в формате, похожем на JSON, что обеспечивает большую гибкость модели данных.

Netuno предоставляет ресурс [_mongo](/docs/library/resources/mongo) для интеграции с MongoDB с low-code-абстракцией над официальным клиентом MongoDB для Java, доступный для различных языков программирования, поддерживаемых Netuno: **JavaScript, Python, Ruby, Kotlin и Groovy**.

> Перед началом рекомендуется ознакомиться с тем, как создавать сервисы в Netuno, см. руководство [REST — веб-сервисы](/docs/academy/server/services/rest).

Пример реализации операций, представленных здесь, доступен в примере сервиса `mongo.js`, который находится по пути:

## Установка MongoDB

### С помощью Docker

Если Docker установлен, достаточно загрузить образ MongoDB и запустить новый контейнер:

```shell
docker pull mongo
docker run -d --name mongo -p 27017:27017 mongo
```

Таким образом, MongoDB будет доступен по адресу `localhost:27017` без аутентификации.

Чтобы создать пользователя базы данных в соответствии с конфигурацией приложения, выполните:

```shell
docker exec -it mongo mongosh товары_бд --eval 'db.createUser({ user: "товары_пользователь", pwd: "12345678", roles: [{ role: "readWrite", db: "товары_бд" }] })'
```

### В Ubuntu

MongoDB не включён в официальные репозитории Ubuntu, поэтому перед установкой необходимо добавить официальный репозиторий:

```shell
sudo apt-get install gnupg curl
curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.asc | sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg --dearmor
echo "deb [ signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] http://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
sudo apt-get update
sudo apt-get install -y mongodb-org
```

После установки можно запустить службу с помощью:

```shell
sudo systemctl start mongod
```

### В Windows

- <a href="https://www.mongodb.com/try/download/community" target="_blank">Скачать MongoDB Community Server</a>.

Запустите скачанный установщик и на шаге **Service Configuration** включите **Install MongoD as a Service**, чтобы MongoDB запускался автоматически. MongoDB будет доступен по адресу `localhost:27017` без аутентификации.

> Обратитесь к [официальной документации MongoDB](https://www.mongodb.com/docs/manual/installation/) для других дистрибутивов и версий.

## Настройка приложения

Настройка подключений MongoDB выполняется в файле конфигурации приложения в соответствии с окружением:

- `config/_development.json`

> Подробнее о [файлах конфигурации](/docs/academy/explore/configuration) приложения.

В файле конфигурации добавьте блок `mongo`, где каждый ключ идентифицирует подключение:

```javascript
{
    ...
    "mongo": {
        "магазин": "mongodb://магазин_пользователь:12345678@localhost/магазин_бд",
        "товары": {
            "username": "товары_пользователь",
            "password": "12345678",
            "host": "127.0.0.1",
            "port": "27017",
            "database": "товары_бд"
        }
    },
    ...
}
```

Подключение можно определить двумя способами:

- **Как URL подключения** — значение представляет собой просто строку, например `"mongodb://магазин_пользователь:12345678@localhost/магазин_бд"`.
- **Как объект конфигурации** — с полями:
  - `url` — если задан, используется напрямую как URL подключения, остальные поля игнорируются.
  - `protocol` — протокол подключения, по умолчанию `mongodb`.
  - `username` и `password` — учётные данные для доступа.
  - `host` — адрес сервера, по умолчанию `localhost`.
  - `port` — порт подключения, по умолчанию `27017`.
  - `database` — имя базы данных, по умолчанию имя ключа подключения.
  - `params` — дополнительные параметры подключения, добавляемые к URL, например `{ "authSource": "admin" }`. Применяются только когда URL строится из полей объекта.

> Подключение не обязано быть основной базой данных приложения. В отличие от конфигурации `db`, блок `mongo` независим и позволяет использовать несколько подключений одновременно.

### Фильтры

Фабрика `_mongo.filters()` предоставляет основные операторы запросов MongoDB:

| Оператор | Описание |
|---|---|
| `eq("поле", значение)` | Равно значению. |
| `ne("поле", значение)` | Не равно значению. |
| `gt("поле", значение)` | Больше значения. |
| `gte("поле", значение)` | Больше или равно значению. |
| `lt("поле", значение)` | Меньше значения. |
| `lte("поле", значение)` | Меньше или равно значению. |
| `in("поле", значение1, значение2, ...)` | Равно любому из значений. |
| `nin("поле", значение1, значение2, ...)` | Не равно ни одному из значений. |
| `and(фильтр1, фильтр2, ...)` | Соответствует всем фильтрам. |
| `or(фильтр1, фильтр2, ...)` | Соответствует хотя бы одному из фильтров. |
| `not(фильтр)` | Не соответствует фильтру. |
| `regex("поле", "шаблон")` | Соответствует регулярному выражению. |
| `exists("поле")` | Поле существует в документе. |
| `text("поиск")` | Текстовый поиск. |
| `type("поле", "тип")` | Поле имеет указанный тип. |
| `mod("поле", делитель, остаток)` | Остаток от деления поля на делитель равен значению. |
| `where("выражение")` | Соответствует документам, удовлетворяющим выражению JavaScript, например `"this.цена > 100"`. |
| `size("поле", n)` | Поле-массив содержит ровно `n` элементов. |

Доступны следующие типы проекций:

| Проекция | Описание |
|---|---|
| `include("поле", ...)` | Включает только указанные поля. |
| `exclude("поле", ...)` | Исключает указанные поля. |
| `excludeId()` | Исключает поле `_id`. |

| `slice("поле", смещение, n)` | Включает `n` элементов поля-массива, начиная после первых `смещение` элементов. |

| `elemMatch("поле", фильтр)` | Включает только первый элемент массива, соответствующий фильтру. |
| `computed("поле", выражение)` | Добавляет вычисляемое поле на основе выражения агрегации. |

| Оператор | Описание |

| `rename("поле", "новоеИмя")` | Переименовывает поле. |
| `push("поле", значение)` | Добавляет значение в массив. |
| `combine(обновление1, обновление2, ...)` | Объединяет несколько обновлений в одно. |

## Агрегации

Для более сложного анализа `aggregate()` позволяет выполнять конвейер агрегации, где каждый этап определяется фабрикой `_mongo.aggregates()`, а аккумуляторы — `_mongo.accumulators()`.

Например, чтобы сгруппировать товары по категории и просуммировать цену в каждой группе:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const документы = коллекция.aggregate(
                    _mongo.aggregates().match(
                        _mongo.filters().eq("категория", "компьютеры")
                    ),
                    _mongo.aggregates().group(
                        "$категория",
                        _mongo.accumulators().sum("итого", "$цена")
                    ),
                    _mongo.aggregates().sort(
                        _mongo.sorts().descending("итого")
                    )
                ).all()
            `
        },
        {
            lang: 'python',
            code: `
                документы = коллекция.aggregate(
                    _mongo.aggregates().match(
                        _mongo.filters().eq("категория", "компьютеры")
                    ),
                    _mongo.aggregates().group(
                        "$категория",
                        _mongo.accumulators().sum("итого", "$цена")
                    ),
                    _mongo.aggregates().sort(
                        _mongo.sorts().descending("итого")
                    )
                ).all()
            `
        },
        {
            lang: 'ruby',
            code: `
                документы = коллекция.aggregate(

                    ),
                    _mongo.aggregates().sort(

        },
        {
            lang: 'kotlin',
            code: `
                val документы = коллекция.aggregate(
                    _mongo.aggregates().match(
                        _mongo.filters().eq("категория", "компьютеры")
                    ),
                    _mongo.aggregates().group(
                        "$категория",

Доступны следующие этапы агрегации:

| Этап | Описание |
|---|---|
| `match(фильтр)` | Выбирает только документы, соответствующие фильтру. |
| `group("$поле", аккумуляторы)` | Группирует документы по полю и применяет аккумуляторы. |
| `project(проекция)` | Добавляет, удаляет или изменяет поля в документах. |
| `sort(сортировка)` | Сортирует документы. |
| `limit(n)` | Ограничивает первыми `n` документами. |
| `skip(n)` | Пропускает первые `n` документов. |
| `count()` | Считает количество документов. |
| `lookup("коллекция", "локальноеПоле", "внешнееПоле", "как")` | Выполняет join с другой коллекцией. |

И наиболее часто используемые аккумуляторы:

| Аккумулятор | Описание |
|---|---|
| `sum("поле", "$выражение")` | Сумма значений. |
| `avg("поле", "$выражение")` | Среднее значений. |
| `min("поле", "$выражение")` | Минимальное значение. |
| `max("поле", "$выражение")` | Максимальное значение. |
| `first("поле", "$выражение")` | Значение первого документа. |
| `last("поле", "$выражение")` | Значение последнего документа. |
| `top("поле", сортировка, "$выражение")` | Верхнее значение согласно сортировке. |
| `bottom("поле", сортировка, "$выражение")` | Нижнее значение согласно сортировке. |

> В аккумуляторах выражение с префиксом `$` ссылается на поле входного документа, например `"$цена"`.

## Операции с опциями

Фабрики `*Options()` ресурса `_mongo` возвращают стандартные объекты опций драйвера MongoDB, и их методы можно вызывать цепочкой напрямую. Например, `upsert(true)` вставляет документ, когда фильтр не соответствует ни одному существующему документу:

                    _mongo.updates().set("количество", 8),
                    _mongo.findOneAndUpdateOptions().upsert(true)
                )
            `
        },
        {
            lang: 'python',
            code: `

                )
            `
        },
        {
            lang: 'ruby',
            code: `
                старый = коллекция.findOneAndUpdate(
                    _mongo.filters().eq("название", "Монитор"),
                    _mongo.updates().set("количество", 8),
                    _mongo.findOneAndUpdateOptions().upsert(true)

            `
        },

            lang: 'kotlin',
            code: `
                val старый = коллекция.findOneAndUpdate(
                    _mongo.filters().eq("название", "Монитор"),

Когда документ вставляется, `findOneAndUpdate()` возвращает `null`.

Доступные фабрики опций: `insertOneOptions()`, `insertManyOptions()`, `updateOptions()`, `findOneAndUpdateOptions()`, `replaceOptions()`, `findOneAndReplaceOptions()`, `deleteOptions()`, `findOneAndDeleteOptions()`, `countOptions()`, `estimatedDocumentCountOptions()`, `dropCollectionOptions()` и `textSearchOptions()`.
