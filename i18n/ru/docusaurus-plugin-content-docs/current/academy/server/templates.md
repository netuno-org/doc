## Перед началом
Прежде чем создавать сервисы, вызывающие шаблоны, убедитесь, что умеете создавать **REST-веб-сервисы**; если нет, перейдите по следующей ссылке:

* [REST-веб-сервисы](/docs/academy/server/services/rest)

Также рекомендуется перед началом этого руководства убедиться, что у вас есть базовые знания _**JavaScript**_.

## Использование шаблонов в сервисах

В этом руководстве мы рассмотрим создание шаблонов и действия, необходимые для их вызова в вашем сервисе.

При создании сервиса в Netuno у вас есть возможность обращаться к созданным вами шаблонам, то есть в зависимости от результата вы можете перенаправить свой сервис в HTML-шаблон с данными.

В этом примере у нас будет базовый HTML-шаблон, и мы передадим данные из сервиса в этот шаблон.

## Создание шаблона

![шаблон1.png](/docs/assets/templates1.png)

После перехода в указанный выше каталог создадим файл `.html`; в этом примере он будет называться `shablon.html`.

Далее приведено содержимое этой страницы:

```html
<!-- Подключение заголовка Netuno -->
_{include=_|includes/head}

<!-- Определение стилей -->

<style>
body, html {
  margin: 10px;
}

h1, b {
  color: #8182E6;
}
</style>

<!-- Начало body HTML -->
<h1>Заголовок шаблона</h1>

<!-- Когда нужно передать данные из сервиса в шаблон, используйте _{&peremennaya} -->
<p>Привет, я <b>_{&data=imya}</b> и получаю <b>_{&data=dannye}</b> из сервиса!</p>

<!-- Конец body HTML -->

<!-- Подключение нижнего колонтитула Netuno -->
_{include=_|includes/foot}
```

Наконец, создаётся сервис с вызовом шаблона с помощью следующей функции:

`_template.output('imya_shablona', peremennye(neobyazatelno));`

Ниже приведён пример сервиса ‘service.js’:

```javascript
// Инициализировать объект 'dannye', чтобы он мог принимать данные
var dannye = _val.init()
    
// Присвоить значения объекту 'dannye'
    .set("imya", "shablon")
    .set("dannye", "dannye")

// Эта функция позволяет выполнить вызов шаблона
_template.output("shablon", dannye);
```

> Если ваш шаблон находится в подкаталоге, укажите в функции: `_template.output('katalog/imya_shablona')`

Наконец, достаточно вызвать сервис в браузере, и появится примерно следующее:

![шаблон2.png](/docs/assets/templates2.png)

> Обратите внимание, что в зависимости от браузера ранее показанные результаты могут отличаться.

Если у вас есть вопросы, не стесняйтесь связаться с нами через контакты, указанные в конце страницы.

Удачной разработки!
