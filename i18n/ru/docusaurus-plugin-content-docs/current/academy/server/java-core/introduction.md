Netuno разработан на Java, поэтому на основе Java мы можем создавать новые функциональные возможности.

Например, мы можем создавать новые нативные сервисы или даже новые возможности low-code программирования, которые
доступны во всех полиглотных языках программирования, таких как JavaScript, Python, Ruby, Groovy и Kotlin.

На Java мы также можем создавать мультиприложенческие веб-сервисы, которые доступны во всех приложениях Netuno.

Любую технику или библиотеку из экосистемы Java можно использовать для создания любых типов функциональных возможностей.

> Перед началом этого руководства мы советуем вам иметь базовые представления о _Java_.
