## Введение

Netuno позволяет изменять стандартные адреса, например:

- Адрес интерфейса администрирования, `admin`.
- Адрес публичных файлов, таких как изображения, CSS и JS, `public`.
- Адрес сервисов REST API, `services`.

## Конфигурация

Перейдите в разрабатываемом приложении к файлу конфигурации окружения. В этом примере мы будем использовать файл окружения разработки, расположенный по пути:

- 📂 `config/_development.json`

Проверьте, нет ли уже конфигурации URL; если её нет, добавьте в конец файла конфигурации (в формате JSON) параметры конфигурации URL, например:

```json
{
    ...
    "url": {
        "admin": "/admin/",
        "public": "/public/",
        "services": "/api/"
    },
    ...
}
```

### admin

Определяет префикс адреса URL интерфейса администрирования, по умолчанию — просто `/`.

### public

Определяет префикс адреса URL статических файлов, которые являются публичными, таких как изображения, стили CSS и код JavaScript, по умолчанию — `/public`.

### services

Определяет начальный адрес URL веб-сервисов REST API, по умолчанию — `/services`.

## Заключение

Настройка URL важна как для того, чтобы сделать их более интуитивными, так и для того, чтобы сделать их более сложными и повысить безопасность.

Например, в адресе администрирования можно использовать префикс со случайной последовательностью символов, тогда доступ к адресу получит только тот, кто знает его наизусть; это затрудняет доступ и помогает избежать атак.
