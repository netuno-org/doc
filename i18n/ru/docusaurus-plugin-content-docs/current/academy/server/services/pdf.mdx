Обработка пользовательских PDF-файлов.

## Введение

Netuno создаёт PDF-файлы с поддержкой изображений, таблиц, шрифтов и многого другого через ресурс [PDF](/docs/library/resources/pdf), который предоставляет low-code-абстракцию над [iTextPDF](https://itextpdf.com/) для различных языков программирования, поддерживаемых Netuno.

Приложение, поставляемое с Netuno под названием **demo** (демонстрационное приложение), содержит множество примеров возможных реализаций кода на разных языках, включая демонстрацию экспорта в PDF через сервис `export-pdf`, который находится по пути:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-pdf`
]} />

## Инициализация

Прежде всего нужно создать объект, который будет содержать контекст нового создаваемого документа; по умолчанию размер страниц — A4.

При создании документа определяется, где он будет создан.

Если ничего не задано, он будет создан в выводе данных сервиса, например:

## HTTP-заголовок

Чтобы создать сервис в REST API, который возвращает PDF-файл как вывод данных, нужно добавить в заголовок параметр `Content-Type` протокола HTTP.

Пример определения содержимого как PDF:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("pdf")
            `
        },
    ]}
/>

Код `pdf` — это сокращение для:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("application/pdf")
            `
        },
    ]}
/>

## Абзац

Добавляет новый абзац в документ:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    _pdf.paragraph("Мой текст здесь...")
                        .setFontSize(15)
                )
            `
        },
    ]}
/>

Чтобы добавить абзац в фиксированной позиции:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    pdfDocument.add(
                        _pdf.paragraph("Мой фиксированный текст...")
                            .setFixedPosition(100, 500, 200)
                            .setFontSize(15)
                    )
                )
            `
        },
    ]}
/>

В приведённом выше коде в методе `setFixedPosition` первый параметр — это позиция X (`100`), второй параметр — позиция Y (`500`), а третий параметр — ширина (`200`).

**Внимание:** если Y задан значением `0`, это означает, что элемент находится внизу страницы; чтобы поднять его, нужно увеличить значение Y. Чем больше значение Y, тем выше он будет отображаться, но если оно слишком велико и выходит за пределы длины страницы, элемент не будет виден.

> Документация со всеми методами объекта [Paragraph iText](https://api.itextpdf.com/iText/java/8.0.3/com/itextpdf/layout/element/Paragraph.html).

## Таблица

Можно создавать таблицы, что позволяет представить набор данных более наглядно.

Количество столбцов таблицы задаётся параметром: `_pdf.table(количествоСтолбцов)`

В примере ниже `количествоСтолбцов` равно `1`, то есть один столбец.

Поскольку мы добавляем в таблицу две ячейки, вторая ячейка переходит на следующую строку.

Обратите внимание:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    _pdf.table(1)
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Человек")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBorder(_pdf.border("solid", 2))
                                .setBackgroundColor(_pdf.colorRGB(1, 0, 0))
                        )
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Николь")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBackgroundColor(_pdf.colorGray(0.5))
                        )
                )
            `
        },
    ]}
/>

Метод `addCell` позволяет вставлять определения ячеек с соответствующим содержимым.

> Документация со всеми методами объекта [Cell iText](https://api.itextpdf.com/iText/java//8.0.3/com/itextpdf/layout/element/Cell.html).

## Закрытие и сохранение документа

Документ полностью сохраняется или создаётся только при вызове метода `close` следующим образом:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.close()
            `
        },
    ]}
/>

Место создания документа определяется при инициализации, поэтому именно при инициализации документа мы задаём, где будет создан итоговый документ: в выводе данных сервиса (`output`) или в файле.

## Чтение файла

Чтобы прочитать PDF-документ, извлекая текстовую информацию.

Используем метод `extract`, который получает все данные PDF-файла в объект JSON.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'python',
            code: `
                pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'ruby',
            code: `
                pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'kotlin',
            code: `
                val pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'groovy',
            code: `
                def pdfData = _pdf.extract(_app.file("file-1.pdf"))

                _out.json(pdfData)
            `
        },
    ]}
/>

Возвращаемый JSON содержит ключ `content` со всем текстовым содержимым PDF-файла и ключ `metadata` с различными свойствами PDF-файла.

Вот пример JSON, возвращаемого `extract`:

```json
{
  "content": "Всё текстовое содержимое PDF-файла здесь...",
  "metadata":{
    "Content-Type":"application/pdf",
    "dc:format":"application/pdf; version=1.4",
    "dc:title":"Linux 1",
    "pdf:PDFVersion":"1.4",
    "pdf:charsPerPage":"580",
    "pdf:containsDamagedFont":"false",
    "pdf:containsNonEmbeddedFont":"false",
    "pdf:docinfo:producer":"Skia/PDF m125 Google Docs Renderer",
    "pdf:docinfo:title":"Файл 1",
    "pdf:encrypted":"false",
    "xmpTPg:NPages":"3",
    ...
  }
}
```

Есть много других данных, получаемых в `metadata`, но они опущены в `...`, чтобы пример не стал слишком длинным.

Мы можем извлечь всё содержимое PDF-файла в виде сплошного текста с помощью метода:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `

        },

Пример его использования для чтения файла в корне приложения:

<PolyglotCode
