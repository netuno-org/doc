Перед тем как продолжить, убедитесь, что вы умеете создавать **REST веб-сервисы**. Если нет, перейдите по следующей ссылке:

Также рекомендуется перед началом этого руководства убедиться, что у вас есть базовые знания по _**JavaScript**_.

## Что такое UID

UID (_unique identifier_), как следует из названия, — это уникальная строка во всём вашем приложении. Она также известна как GUID (_global unique identifier_).

Чтобы продемонстрировать генерацию UID, создадим сервис.

## Генерация UID

Теперь продемонстрируем создание случайного UID. Это довольно просто, потому что Netuno уже содержит функцию, специально созданную для этой цели:

```javascript
_out.println(
  _uid.generate()
)
```

> Обратите внимание, что функция `_out.println()` нужна только для отображения результата на экране при вызове сервиса в браузере.
