Интерфейс командной строки Netuno — основной инструмент для управления вашей средой разработки. С его помощью можно быстро просматривать сведения о системе, управлять приложениями и настраивать сервер.

#### Предварительные требования

- **Терминал:** У вас должен быть открыт терминал (Командная строка, PowerShell или Bash) в корневой папке, в которую был установлен Netuno.

Это начальные команды для проверки готовности вашей среды к использованию.

| ОПЦИЯ    | ОПИСАНИЕ    |
|----------|--------------|
| `help` | Позволяет просмотреть все команды, доступные в Netuno. |
| `version` | Позволяет просмотреть текущую версию Netuno. |

#### Список доступных команд

Если вы не уверены, какие операции можно выполнить, используйте команду помощи. Она вернёт полный список функций.

```shell
./netuno help
```
#### Просмотр версии Netuno

Важно знать, какую версию вы используете, чтобы обеспечить совместимость с определёнными скриптами и модулями.

```shell
./netuno version
```

## Установка

Перед началом разработки необходимо установить движок Netuno в вашу среду. Для получения дополнительной информации перейдите на нашу страницу [Установка](/docs/get-started/installation).

В этом разделе описаны параметры, которые можно использовать в процессе установки для автоматизации или оптимизации.

| ОПЦИЯ | ОПИСАНИЕ |
|----------|--------------|
| `checksum` | Обновляет контрольную сумму (checksum) всех файлов установленного пакета. |
| `force` | Принудительно заменяет все файлы, даже если существуют локальные изменения.|
| `graal=true/false` | Определяет использование GraalVM для повышения производительности выполнения приложений. |
| `path=[Каталог]`| Вручную задаёт путь (папку), в которую будет установлен Netuno.|
| `remove` | Полностью удаляет все файлы, связанные с Netuno, из системы.|
| `version=[версия]`| Выбирает конкретную версию для установки. Используйте latest для версии разработки.|
| `yes`| Автоматически отвечает «ДА» на все подтверждения, игнорируя предупреждения о потере данных.|

#### Пример обновления контрольной суммы:

```shell
./netuno install checksum
```

#### Пример принудительной перезаписи всех локальных изменений:

```shell
./netuno install force
```

#### Пример отключения GraalVM: 

```shell
./netuno install graal=false
```

> GraalVM по умолчанию активна и автоматически скачивается при установке Netuno.

#### Пример задания пути установки:

```shell
./netuno install path ='каталогNetuno'
```
#### Пример удаления всех папок Netuno:

```shell
./netuno install remove
```

#### Пример выбора версии Netuno, которую нужно установить:

```shell
./netuno install version='latest'
```

##### Пример ответа «ДА» на все вопросы: 
```shell
./netuno install yes 
```

## Сервер

После завершения установки запустите сервер, чтобы приступить к разработке приложений.

Чтобы запустить сервер с настройками по умолчанию, выполните следующую команду в корневой папке Netuno:

```shell
./netuno server
```

> По умолчанию сервер использует порт 9000. Как только терминал сообщит, что система готова, вы сможете открыть панель управления по ссылке: http://localhost:9000/

В этом разделе описаны параметры, которые можно использовать при запуске сервера.

ОПЦИЯ | ОПИСАНИЕ |
|----------|--------------|
| `app=[имя_приложения]` | Определяет, какое приложение должно быть запущено |
| `host=[IP/имя_хоста]` | Позволяет изменить имя хоста Netuno |
| `launch=true/false` | Определяет, должен ли Netuno автоматически открывать браузер |
| `npm` | Автоматически выполняет команду 'npm watch' для компиляции фронтенда приложения в реальном времени |
| `port=[номер]` | Задаёт порт запуска сервера |
| `secret=[пароль]` | Задаёт защитный пароль для доступа к удалённому управлению сервером |
| `web=[папка]` | Изменяет предопределённую корневую папку проекта (web home) |

По умолчанию Netuno использует папку **'webapp'** для хранения всех файлов, необходимых для его работы.

**Внимание при изменении каталога:** Если вы используете параметр web=[папка] для изменения имени корневой папки, помните, что вам также нужно физически переименовать папку в вашей файловой системе. Команда лишь указывает коду Netuno, где искать файлы; она не переименовывает папки автоматически.

#### Пример запуска сервера для конкретного приложения:

```shell
./netuno server app=моеприложение
```

#### Пример изменения имени хоста (host):

```shell
./netuno server host=localhost
```

#### Пример определения, должен ли Netuno автоматически открывать браузер:

```shell
./netuno server launch=false
```

>По умолчанию Netuno открывает браузер и запускает ссылку http://localhost:9000.

#### Пример выполнения npm для автоматической сборки фронтенда

```shell
./netuno server npm
```

#### Пример изменения порта:

```shell
./netuno server port=10000
```

#### Пример задания пароля для доступа к удалённому управлению сервером:

```shell
./netuno server secret='п#р@ль'
```

#### Пример изменения папки веб-сайта по умолчанию:

```shell
./netuno server web=webapp
```

## Лицензия

Чтобы начать разработку с Netuno, необходимо зарегистрировать вашу среду.

Для управления лицензией используйте базовую команду:

```shell
./netuno license
```

> В настоящее время Netuno предлагает три типа лицензии: **Community, Standard и Enterprise**.

В этом разделе описаны действия, доступные для настройки или проверки вашей лицензии.

| ОПЦИЯ    | ОПИСАНИЕ    |
|----------|--------------|
| `create , change` | Запускает процесс создания новой лицензии или изменения текущей |
| `key` | Показывает активный лицензионный ключ в вашей среде |
| `mail=[ваш@mail.com]` | Задаёт адрес электронной почты, связанный с учётной записью лицензии |
| `type=[community/standard/enterprise]`  | Определяет тип лицензии|


#### Пример создания лицензии:

```shell
./netuno license create
```

#### Пример просмотра лицензионного ключа: 

```shell
./netuno license key
```
##### Пример указания вашей электронной почты и типа лицензии:

```shell
./netuno license mail='ваш@mail.com' type='community'
```

## Приложение

Когда сервер настроен, а лицензия активна, вы можете расширить свою экосистему, создавая новые решения.

```shell
./netuno app
```

Сгенерированные файлы будут автоматически организованы в структуре папок Netuno.

Чтобы получить доступ к файлам приложения или отредактировать их, перейдите по следующему пути от корня системы: **webapp / apps / [имя_вашего_приложения]**

#### Структура папок

- **webapp**: Это корневая папка, содержащая все файлы, необходимые для работы Netuno.

- **apps**: Специальная папка, в которой хранятся все разработанные или демонстрационные приложения.

- **[имя_вашего_приложения]**: Отдельная папка приложения, которое вы только что создали.

По умолчанию в Netuno есть демонстрационное приложение, которое отображается при запуске сервера Netuno.

| ОПЦИЯ    | ОПИСАНИЕ    |
|----------|--------------|
| `database=[имя_базы_данных]` | Задаёт имя базы данных |
| `engine=[имя]` | Задаёт тип базы данных |
| `host=[адрес]` | Задаёт адрес базы данных. |
| `language=[язык]`  | Задаёт язык приложения |
| `locale=[локаль]` | Задаёт локаль приложения |
| `name=[имя]`  | Позволяет создать приложение или перестроить существующее приложение |
| `password=[пароль]`  | Задаёт пароль для базы данных |
| `port=[номер]`  | Задаёт порт базы данных |
| `username=[имя]`  | Задаёт имя пользователя базы данных |

#### Пример задания имени базы данных:

```shell
./netuno app database=сотрудник
```

> Имя базы данных может содержать цифры и буквы; если имя состоит из нескольких слов, они должны разделяться символом «_», следующим образом.
>
> **Пример:** сотрудник_бд

#### Пример задания типа базы данных:

```shell
./netuno app engine=pg
```
Существуют следующие типы баз данных:
> - PostgreSQL - **pg**
> - MariaDB - **mariadb**
> - Microsoft SQL Server - **mssql**
> - H2 Database - **h2**

#### Пример задания адреса сервера базы данных:

```shell
./netuno app host=localhost
```

#### Пример задания языка и локали:

```shell
./netuno app language=pt_PT locale=pt_PT
```
Существуют следующие языки:
> - Португальский - pt_PT
> - Бразильский - pt_BR
> - Английский - en_US
> - Испанский - es_ES

#### Пример создания приложения или перестроения существующего приложения:

```shell
./netuno app name=демо
```

#### Пример задания пароля базы данных:

```shell
./netuno app password=пароль
```

#### Пример задания порта базы данных:

```shell
./netuno app port=5432
```
По умолчанию порты соответствуют:  

> - PostgreSql - **5432**
> - MariaDB -**3306**
> - Microsoft SQL Server - **1433**

#### Пример задания имени пользователя базы данных:

```shell
./netuno username=root
```
