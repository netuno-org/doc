Помните, что нужно, чтобы продолжать развиваться в Netuno.

Документация в целом постоянно улучшается и старается быть максимально простой и вводной.

Но предполагается, что у вас есть некоторые базовые знания и опыт в определённых областях, таких как:

* База данных: запросы в целом, insert, update и delete;
* Веб-сервисы с GET и POST;
* <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a> и <a href="https://reactjs.org/" target="_blank">ReactJS</a>;

Если у вас нет каких-либо из этих компетенций, мы постараемся помочь их развить.

Всегда ищите помощь на GitHub или в Discord, смотрите указания в нижней части сайта.

## База данных

С Netuno вы сможете работать с различными типами баз данных и углублять свои знания.

Только при хорошем знании баз данных можно создавать приложения со сложными структурами для сбора и управления большими объёмами данных.

Так у вас появится автономия, чтобы надёжно создавать самую важную часть — базу данных.

Создание хорошо организованной и оптимизированной базы данных имеет решающее значение как для опыта конечных пользователей, так и для производительности — от разработки до выполнения.

## Сервисы

Если у вас уже есть знания в одном из следующих языков программирования, таких как <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a> или <a href="https://groovy-lang.org/" target="_blank">Groovy</a>, вы сможете быстро создавать сложные и надёжные веб-сервисы, используя различные ресурсы, которые Netuno предоставляет для программирования в стиле **low code**.

В папке приложений, особенно в папке **server**, вы можете программировать на этих различных языках.

Достаточно использовать соответствующее расширение:

* **.js** &nbsp; <a href="https://developer.mozilla.org/pt-PT/docs/Web/JavaScript" target="_blank">JavaScript</a>
* **.ts** &nbsp; <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>
* **.py** &nbsp; <a href="https://www.jython.org/" target="_blank">Python</a>
* **.rb** &nbsp; <a href="https://www.jruby.org/" target="_blank">Ruby</a>
* **.kts** &nbsp; <a href="https://kotlinlang.org/" target="_blank">Kotlin</a>
* **.groovy** &nbsp; <a href="https://groovy-lang.org/" target="_blank">Groovy</a>

Изучите примеры веб-сервисов, которые поставляются с демонстрационным приложением **demo**, в:

- `/apps/demo/server/services/samples`

Также изучите документацию нашей **библиотеки**, чтобы подробно познакомиться с доступными ресурсами.


## Пользовательский интерфейс

Разработка веб-фронтенда за последние годы претерпела множество изменений, и использование <a href="https://vite.dev/" target="_blank">Vite</a> стало стандартом.

Наш выбор технологий, таких как <a href="https://reactjs.org/" target="_blank">ReactJS</a>, <a href="https://bun.sh/" target="_blank">Bun</a>, <a href="https://ant.design/" target="_blank">Ant.Design</a> и <a href="http://lesscss.org/" target="_blank">Less</a>, — это технологии, которые повышают производительность и пользуются широкой поддержкой.

Чтобы углубить знания в этих технологиях, изучайте различные документации в текстовом и видеоформате, доступные в интернете.

Поскольку это технологии с большими сообществами, найти хороший материал для начала обучения несложно.

Напоминаем, что с Netuno даже при небольших знаниях уже можно достичь больших результатов: это даёт фронтенд-разработчику возможность разрабатывать весь бэкенд и наоборот, а также позволяет выбрать разработку всего лишь на одном языке программирования, например <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>.

## Заключение

Netuno упрощает разработку веб-приложений: даже один человек с небольшими знаниями баз данных, веб-сервисов и фронтенда сможет самостоятельно разрабатывать сложные приложения.

Кроме того, для больших команд, где есть люди с более высокой компетенцией в каждой из областей, он в целом обеспечивает значительный рост производительности.

Netuno также можно использовать как backoffice для баз данных или как сервер REST API для развязанных фронтендов и мобильных приложений.

Экономьте время и разрабатывайте, больше сосредоточившись на логике бизнес-правил, и с уже имеющимися знаниями вы добьётесь большего.
