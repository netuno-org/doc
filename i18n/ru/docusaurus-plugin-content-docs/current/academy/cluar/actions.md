Как создавать и повторно использовать CTA (кнопки/ссылки), связанные с компонентами.

## Введение

**Действие** — это по сути повторно используемый **CTA** (call-to-action) — кнопка/ссылка с заголовком, текстом, изображением и назначением (`link`) — который можно связать с [Компонентами](/docs/academy/cluar/components/overview), такими как Баннер, Контент, Листинг, Слайдер (в элементах) и Функциональность.

## Поля

| Поле | Описание |
|---|---|
| **Заголовок** (`title`) | Заголовок действия, отображается как заголовок (`<h4>`). |
| **Содержимое** (`content`) | Описательный текст действия, отображается как абзац (`<p>`). |
| **Надпись** (`indication`) | Текст самой ссылки/CTA — то, что отображается **внутри** кликабельной кнопки (например, «Узнать больше», «Купить сейчас»). |
| **Изображение** (`image`) | Изображение, связанное с действием (например, иконка). |
| **Ссылка** (`link`) | Назначение действия (URL) — куда ведёт CTA при клике. |
| **Язык** (`language_id`) | Язык, к которому относится это действие. |
| **Параметр** (`parameter_id`) | Объединяет это действие с его эквивалентами на других языках — см. ниже. |

## Параметр

**Параметр** (`action_parameter`, содержит только `código` и `descrição`) — это группировщик: несколько действий — каждое на своём языке, но представляющих **одну и ту же функциональность/назначение** — совместно используют один и тот же Параметр.

Это используется при [клонировании страницы](/docs/academy/cluar/pages/cloning) на другой язык: для каждого действия, связанного с компонентом исходной страницы, CLUAR ищет среди существующих действий то, которое имеет **тот же Параметр** и находится на **целевом языке** клонирования. Если находит, автоматически связывает это действие (уже переведённую версию) с клонированным компонентом — без необходимости добавлять его вручную позже.

:::info Сначала нужно создать действие на целевом языке
Автоматическое связывание работает только при условии, что действие с тем же Параметром уже существует на языке, на который выполняется клонирование. Если его ещё нет, действие просто не связывается с клонированным компонентом — остаётся так, как будто оно не было определено. То есть Параметр не переводит и не создаёт действие автоматически; он только связывает уже существующие эквивалентные действия после того, как они были созданы на каждом языке.
:::

Например: действие «Saiba mais» с параметром `uznat-bolshe` на португальском и другое действие «Learn more» с тем же параметром `uznat-bolshe` на английском — при клонировании страницы с португальского на английский баннер, с которым было связано первое действие, автоматически получает второе.
