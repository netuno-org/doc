## Версии

Каждая страница имеет одну или несколько **версий** (`page_version`), каждая из которых имеет собственное состояние (Черновик / Опубликована). Это позволяет редактировать новую версию контента, не затрагивая опубликованное — только когда версия помечена как «Опубликована», она становится активной версией страницы.

Компоненты контента (Баннер, Контент, Листинг, Слайдер, Функциональность) всегда принадлежат конкретной версии (`page_version_id`), а не странице напрямую. То есть редактирование компонента в черновой версии не влияет на опубликованное.

## Публикация

При публикации страницы CLUAR:

1. Собирает все активные компоненты опубликованной версии (баннеры, контенты, листинги, слайдеры, функциональности, с соответствующими действиями).
2. Создаёт файл структуры в формате JSON с этим контентом.
3. В продакшене предварительно рендерит статический `index.html` для URL страницы (для каждого языка), уже с заполненными метатегами SEO и Open Graph — это важно для публикации в социальных сетях и для поисковых систем, поскольку сам сайт является SPA на React.
