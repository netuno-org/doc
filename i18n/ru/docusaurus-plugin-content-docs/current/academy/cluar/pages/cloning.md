## Что это

На основе существующей страницы можно создать новую с помощью опции **Клонировать**. В форме клонирования необходимо указать:

- **Заголовок** и **Ссылку** (link) новой страницы.
- **Исходная версия** — из какой версии оригинальной страницы будет скопировано содержимое.
- **Язык** — при необходимости отличный от языка оригинальной страницы.
- Должна ли новая страница быть **опубликована** сразу.

После подтверждения CLUAR дублирует всю структуру компонентов (Баннер, Контент, Список, Слайдер, Функциональность, с соответствующими действиями) этой версии на новую страницу.

## Для чего это нужно

Именно так на практике создаётся «перевод» страницы: вместо того чтобы собирать новую страницу с нуля, выбирают уже существующую страницу на другом языке, клонируют её на новый язык, а затем корректируют тексты. Это также позволяет быстро создавать похожие страницы в рамках одного языка (например, несколько страниц кампании с одинаковой структурой).

:::info Перевод содержимого
Клонирование дублирует **структуру** страницы (те же компоненты в том же порядке), но **не переводит текст** — поля каждого компонента (Баннер, Контент, Список, Слайдер, Функциональность) остаются с оригинальным содержимым, и нужно заходить в каждый из них и переводить вручную. Автоматический перевод содержимого при клонировании уже запланирован, но ещё не разработан.
:::
