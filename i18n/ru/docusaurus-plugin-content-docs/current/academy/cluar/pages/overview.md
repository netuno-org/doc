**Страница** — центральная сущность CLUAR: она представляет URL веб-сайта. Каждая страница принадлежит только одному языку — не существует единой «многоязычной» страницы; у каждого языка есть своя собственная страница (со своей собственной ссылкой (`link`), заголовком, содержимым и т.д.), и они связываются между собой только действием [клонирования](/docs/academy/cluar/pages/cloning).

Каждая страница принадлежит организации. У страниц могут быть подстраницы, которые по умолчанию принадлежат организации родительской страницы.

## Поля

| Поле | Описание |
|---|---|
| **Заголовок** (`title`) | Заголовок страницы. |
| **Ссылка** (`link`) | URL страницы (например, `/o-nas`). |
| **Язык** (`language_id`) | Язык, к которому относится эта страница. |
| **Родитель** (`parent_id`) | Родительская страница, используемая для построения иерархии/хлебных крошек и подменю. |
| **Шаблон** (`template`) | Шаблон, используемый для рендеринга страницы (см. [Шаблоны](/docs/academy/cluar/templates)). Это выпадающий список в форме, динамически заполняемый существующими папками в `website/src/pages/Template/`. |
| **Статус** (`status_id`) | Черновик или Опубликована — отражает состояние текущей версии. |
| **Меню** (`menu`) | Если отмечено, страница отображается в навигационном меню. |
| **Заголовок меню** (`menu_title`) | Альтернативный заголовок для отображения в меню (если пусто, используется заголовок страницы). |
| **Доступна для навигации** (`navigable`) | Управляет тем, доступна ли страница напрямую (даже если она не отображается в меню). |
| **Порядок** (`sorter`) | Позиция страницы среди её «сестёр» (с тем же `parent_id`). |
| **Описание** / **Ключевые слова** | SEO-метатеги (`<meta name="description">` / `<meta name="keywords">`). |
| **Описание для социальных сетей** / **Изображение для социальных сетей** | Используются в тегах Open Graph (`og:description`, `og:image`), когда страницей делятся. |

## Следующий шаг

У каждой страницы есть несколько версий, и она проходит через процесс публикации — см. [Версии и публикация](/docs/academy/cluar/pages/versions-publishing).
