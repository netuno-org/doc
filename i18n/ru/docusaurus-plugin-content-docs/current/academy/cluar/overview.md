CLUAR — это CMS с открытым исходным кодом, построенная на [Netuno](https://www.netuno.org/), для создания многоязычных веб-сайтов. Визуальные компоненты страниц (баннеры, списки, слайдеры и т. д.) разрабатываются на ReactJS, с [Ant Design](https://ant.design/) для интерфейса, [React Router](https://reactrouter.com/) для навигации и [Less](https://lesscss.org/) для стилей — а контентом (страницами, текстами, изображениями, языками, меню) управляют через бэк-офис без необходимости программировать.

Код доступен в [репозитории CLUAR на GitHub](https://github.com/netuno-org/cluar) — мы приветствуем вклад в проект.

## Модель контента

Контент CLUAR следует структуре **Страница → Версия → Компоненты**:

- Каждая **Страница** представляет URL сайта (`link`), с заголовком, меню, SEO и т. д.
- Каждая страница имеет одну или несколько **Версий**, которые позволяют работать над черновиком, не влияя на уже опубликованное.
- Внутри каждой версии размещаются **Компоненты** контента — Баннер, Контент, Список, Слайдер и Функциональность — это блоки, которые фактически отображаются на странице, каждый со своим визуальным типом и, опционально, связанными действиями (кнопками/ссылками).

## Архитектура проекта

Проект разделён на четыре части:

- **`server`** — приложение Netuno: сущности данных, REST-сервисы и скрипты начальной настройки (`setup`).
- **`website`** — сайт на ReactJS, который получает данные через REST и отображает страницы.
- **`ui`** — расширения для бэк-офиса Netuno, специфичные для CLUAR.
- **`config`** — конфигурация окружения (база данных, аутентификация, общие параметры).
