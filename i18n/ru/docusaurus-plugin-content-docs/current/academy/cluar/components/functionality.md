Конкретные функциональные возможности, доступные для включения на страницу, например формы и карты.

## Введение

**Функциональность** отличается от других компонентов: вместо визуальных вариаций одного и того же содержимого каждый тип представляет собой **конкретную функциональность** для добавления на страницу — сегодня это контактная форма или карта.

Используется тот же механизм, общий для всех компонентов, описанный в [Обзоре](/docs/academy/cluar/components/overview) и [Типах компонентов](/docs/academy/cluar/components/types) — но здесь при выборе Типа выбирается **какая функциональность** отображается на странице, а не просто другой стиль.

## Поля

Помимо [общих полей](/docs/academy/cluar/components/overview#общие-поля) (Тип, Порядок, Режим редактирования, Инвертировать фон, Действия), у Функциональности есть:

| Поле | Описание |
|---|---|
| **Заголовок** (`title`) | Заголовок блока. |
| **Содержимое** (`content` / `html_content`) | Текст блока. |
| **Изображение** (`image`) | Связанное изображение (используется не всеми типами). |

## Доступные типы

### Контактная форма (`ContactForm`)

Отображает контактную форму (имя, адрес электронной почты, сообщение), защищённую reCAPTCHA. При отправке данные передаются в сервис `contact` на сервере, который сохраняет их в сущности `contact` (видна в бэк-офисе) и позволяет настроить оповещения по электронной почте.

### Карта контактов (`ContactMap`)

Отображает интерактивную карту с использованием [Mapbox](https://www.mapbox.com/). Использует конфигурацию `settings.cluar.website.mapbox` (см. [Конфигурация](/docs/academy/cluar/configuration)) — в частности, `accessToken` (обязателен для работы карты) и параметр `dark` (светлая или тёмная тема карты).
