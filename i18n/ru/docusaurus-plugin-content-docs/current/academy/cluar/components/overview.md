**Компоненты** — это блоки содержимого, из которых состоит [Страница](/docs/academy/cluar/pages/overview) в рамках [Версии](/docs/academy/cluar/pages/versions-publishing). Существует 5 типов:

- **Баннер**
- **Контент**
- **Список** (с элементами)
- **Слайдер** (с элементами)
- **Функциональность**

У каждого есть собственная сущность (`page_banner`, `page_content`, `page_listing`, `page_slider`, `page_functionality`), собственная форма в бэк-офисе и собственный React-компонент на сайте.

## Общие поля

Хотя у каждого компонента есть собственные поля, большинство из них имеет похожую основу:

| Поле | Описание |
|---|---|
| **Тип** (`type`) | Определяет, какой визуальный вариант используется для отображения этого компонента — см. [Типы компонентов](/docs/academy/cluar/components/types). |
| **Порядок** (`sorter`) | Позиция компонента на странице. |
| **Режим редактирования** (`edit_mode`) | Определяет, является ли содержимое (`content`) простым текстом или HTML (`html_content`). |
| **Инвертировать фон заголовка / содержимого** (`title_invert_background`, `content_invert_background`) | Инвертирует цветовую схему (светлая/тёмная) **редактора** текста заголовка/содержимого — полезно при написании текста, который будет размещён на тёмном фоне (например, на тёмном изображении в баннере), чтобы видеть текст с контрастом во время редактирования. Не изменяет цвет уже опубликованного на странице содержимого. |
| **Действия** | Кнопки/ссылки, связанные с компонентом — см. [Действия](/docs/academy/cluar/actions). Не все типы поддерживают действия — см. [Типы компонентов](/docs/academy/cluar/components/types). |
