Самый универсальный компонент CLUAR для текста и изображений.

## Введение

**Контент** — это самый универсальный текстово-изобразительный компонент CLUAR: он используется для простых текстовых блоков, текста с изображением рядом или только изображения — в зависимости от выбранного типа.

Он следует тому же механизму, общему для всех компонентов, который описан в [Обзоре](/docs/academy/cluar/components/overview) и [Типах компонентов](/docs/academy/cluar/components/types).

## Поля

Помимо [общих полей](/docs/academy/cluar/components/overview#общие-поля) (Тип, Порядок, Режим редактирования, Инвертировать фон, Действия), у Контента есть:

| Поле | Описание |
|---|---|
| **Заголовок** (`title`) | Заголовок блока контента. |
| **Содержимое** (`content` / `html_content`) | Текст блока. |
| **Изображение** (`image`) | Связанное изображение (не используется в типах только с текстом). |
| **Alt изображения** (`image_alt`) | Альтернативный текст изображения. |
| **Заголовок изображения** (`image_title`) | Атрибут `title` изображения. |
| **Максимальная ширина изображения** (`image_max_width`) | Ограничивает ширину изображения в пикселях — полезно, чтобы изображение не растягивалось слишком сильно на широких экранах, особенно в типах, где изображение располагается рядом с текстом. |

## Доступные типы

В отличие от Баннера, у Контента есть несколько типов, ориентированных на разные варианты расположения изображения и текста:

- **Стандартный** (`Default`)
- **Текст** (`TextContent`) — только текст, без изображения.
- **Изображение** (`ImageContent`) — только изображение, без текста.
- **Изображение слева** (`ImageLeft`)
- **Изображение справа** (`ImageRight`)
- **Изображение сверху** (`ImageTop`)
- **Изображение снизу** (`ImageBottom`)

Подробнее о том, как работают типы и как создать новый, см. в разделе [Типы компонентов](/docs/academy/cluar/components/types).
