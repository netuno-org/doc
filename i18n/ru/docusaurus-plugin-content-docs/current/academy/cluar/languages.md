Как CLUAR управляет языками веб-сайта и многоязычным контентом.

## Введение

CLUAR по умолчанию многоязычен: каждая **Страница** привязана к языку, а на веб-сайте отображается переключатель, позволяющий посетителю переключаться между доступными языками.

Языки управляются в бэк-офисе через форму **Язык**.

## Поля

| Поле | Описание |
|---|---|
| **Код** (`code`) | Международный код языка (например, `PT`, `EN`). Это значение используется для привязки контента (страниц, словаря, настроек) к этому языку. |
| **Локаль** (`locale`) | Полная локаль (например, `pt`, `en`). Это значение используется в ссылке на страницы и при переключении языка через код. |
| **По умолчанию** (`default`) | Отмечает этот язык как предпочтительный для веб-сайта — именно он загружается по умолчанию. |
| **Описание** (`description`) | Название языка, отображаемое посетителю (например, "Португальский"). |

## Выбор языка на веб-сайте

В проекте сейчас есть два переключателя языка:

- **Шапка публичного сайта** (`website/src/base/Header`) — традиционный переключатель, сделанный с помощью [Меню Ant Design](https://ant.design/components/menu/). При смене языка выполняется переход на `/{locale}/`. Показывает только языки, для которых уже опубликованы страницы (через `Cluar.pages()`), чтобы не отображать пустые варианты.
- **`LanguageSwitch`** (`website/src/components/LanguageSwitch`) — используется внутри Закрытой области (`ReservedArea`). Это более простой выпадающий список: переключает активный язык и перезагружает текущую страницу без перехода на другой маршрут.

## Программно

Класс `website/src/common/Cluar.js` предоставляет функции для работы с языками:

- `Cluar.defaultLanguage()` — получает язык, отмеченный как язык по умолчанию.
- `Cluar.currentLanguage()` — получает текущий активный язык.
- `Cluar.changeLanguage(codigoOuLocalizacao)` — программно активирует другой язык (принимает как `code`, так и `locale`).
- `Cluar.languages()` — получает список всех языков.
