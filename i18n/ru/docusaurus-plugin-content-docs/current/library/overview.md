Netuno — это low-code платформа для быстрого создания веб-сервисов, которая упрощает управление данными с помощью встроенного визуального интерфейса и обеспечивает создание высокопроизводительных веб-приложений.

Она сокращает усилия и время разработки, а также производственные затраты в сферах администрирования, управления и промышленности.

![Структура Netuno](/docs/assets/introducao1.png)

Узнайте, как Netuno улучшает ваш опыт программирования, чтобы программирование было творческим, а не повторяющимся, сохраняя уровень производительности от разработки до выполнения:

> Платформа Netuno бесплатна, [начните прямо сейчас](/docs/get-started/installation).

## Формы и поля

Создание модели данных упрощается благодаря движку форм в веб-среде. Определение форм создаёт таблицы в базе данных, а их поля определяют столбцы. Можно настраивать типы данных, свойства полей, а также их связи. Набор инструментов для веб-разработки предоставляет различные возможности, такие как запросы к базе данных, просмотр модели «сущность — связь» и другие.

## Управление доступом и разрешениями

Управление пользователями и их разрешениями настраивается в веб-среде и доступно через серверные сервисы Netuno. Также можно управлять доступом пользователей и групп к формам и отчётам.

## Библиотека ресурсов

Библиотека ресурсов предлагает широкий набор готовых к использованию возможностей. Среди них можно найти интеграции с PDF, Excel, Email, Firebase, а также планирование задач или генератор отчётов с Jasper.

## REST API

Слой связи сервера предоставляется через REST API. Предоставление сервисов через JSON позволяет Netuno взаимодействовать с множеством приложений различного характера, например одновременно обслуживать веб-клиенты и мобильные приложения через один и тот же интерфейс.

## Многоязычный слой сервисов

Пишите сервисы на <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://groovy-lang.org/" target="_blank">Groovy</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a> или <a href="https://pt.wikipedia.org/wiki/Java_(linguagem_de_programa%C3%A7%C3%A3o)" target="_blank">Java</a> — все они допустимы. Netuno устраняет изоляцию между языками программирования: одно и то же приложение поддерживает одновременный запуск сервисов на нескольких языках без увеличения нагрузки на обработку.

## Множество баз данных

Настройте несколько разных баз данных и используйте их одновременно. Netuno изначально поддерживает ряд реляционных СУБД, таких как <a href="https://www.h2database.com/html/main.html" target="_blank">H2DataBase</a>, <a href="https://www.postgresql.org/" target="_blank">PostgreSQL</a> и CockroachDB, <a href="https://mariadb.org/" target="_blank">MariaDB (_MySQL_)</a>, Microsoft SQL Server и Oracle. Вы сможете создать приложение, используя, например, PostgreSQL в качестве основной базы данных и интегрируясь с другими базами данных на MariaDB, а в середине проекта перейти на Microsoft SQL Server или Oracle без необходимости вносить какие-либо изменения в код.

> Обеспечивает нативную поддержку интеграции с MongoDB.

## Serverless

Netuno также является вашим сервером приложений. Одной командой запустите приложение, не тратя время на лицензирование, настройку и дополнительную разработку.

## Производительность при разработке и выполнении

Не нужно учиться работать с новым программным обеспечением для разработки через drag-and-drop или запоминать интерфейс нового фреймворка. Благодаря возможности программировать на 6 разных языках, иметь автогенерируемый слой данных и библиотеки, доступные для использования на лету, low-code от Netuno — лучшее решение для сжатых сроков.

Используя генераторы кода, оптимизированные для высокой производительности, и новейшую <a href="https://www.graalvm.org/" target="_blank">GraalVM</a>, сервер приложений становится невероятно быстрым независимо от используемого языка.
