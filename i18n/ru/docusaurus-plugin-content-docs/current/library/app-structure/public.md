## Публичная папка

Папка `📂 public` содержит содержимое UI (User Interface) на стороне клиента после компиляции, а также другие публичные файлы, такие как логотипы и значок.

Может содержать любой файл, к которому требуется публичный доступ.

## Структура папки

При входе в папку `📂 public` по умолчанию вы найдёте следующую структуру:

</pre>

## Изображения

Папка `📂 images` изначально содержит логотипы приложения и значок.

В этой папке можно размещать все публичные изображения вашего приложения.

### icon.png

Значок приложения, отображается на вкладке браузера (favicon).

### logo.png

Это изображение логотипа, которое отображается на странице входа в бэк-офис и на страницах ошибок.

### logo-main.png

Это изображение логотипа, которое отображается в заголовке (_header_) после входа в систему и перехода в бэк-офис.

## Скрипты

В папке `📂 scripts` находится итоговый JavaScript-код, созданный при компиляции UI; сюда же можно помещать другие публичные файлы JavaScript.

### ui.js

Файл `ui.js` — это итоговый скомпилированный код UI.

Обычно UI разрабатывается на React и LESS, а для компиляции итогового JavaScript-бандла — файла `ui.js` — используется [Vite](https://vite.dev/).

Инструкции по компиляции находятся в `ui/vite.config.js`; в этом файле содержатся сведения о том, как обрабатывается и создаётся `ui.js`.

### ui.js.map

Файл `ui.js.map` — это source maps UI; он важен для указания исходного кода при отладке ошибок в _консоли_ браузера.

## Стили
  
В папке `📂 styles` должны находиться CSS-файлы, используемые для стилизации приложения.

### main.css

`main.css` обычно используется для глобальных CSS или для изменения стандартных стилей Netuno.

### ui.css

`ui.css` — это CSS, созданный при компиляции UI.

Обычно UI разрабатывается на React и LESS, а для компиляции итогового CSS-бандла — `ui.css` — используется [Vite](https://vite.dev/).

Инструкции по компиляции находятся в `ui/vite.config.js`; в этом файле содержатся сведения о том, как создаётся `ui.css`.
