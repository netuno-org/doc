Организация файлов базы данных.

## Папка для базы данных

Папка `📂 dbs` предназначена для хранения файлов базы данных вашего приложения.

В случае баз данных типа H2 Database все файлы автоматически создаются в этой папке.

Эта папка полезна для хранения всего, что связано с базой данных, например резервные копии, скрипты, дампы, диаграммы и т. д.

Всю документацию, связанную с базой данных и которая должна сопровождать проект приложения, рекомендуется организовывать в этой папке.
