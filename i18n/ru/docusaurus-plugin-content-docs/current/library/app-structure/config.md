Общие настройки приложения.

## Папка конфигурации

Настройки приложения доступны в папке `📂 config`, где задаются общие параметры приложения и внешних интеграций.

Netuno поддерживает различные типы окружений; по умолчанию используются `development` (разработка) и `production` (производство).

Активное окружение определяется в `config.js`, который находится в корне установки Netuno:

```javascript title="netuno/config.js"
...
config.env = 'development'
...
```

Для определения окружения можно использовать любое имя, при этом приложения должны иметь одинаковое имя окружения в качестве имён файлов (`.json` и `.js` в папке `📂 config` приложения).

По умолчанию в этой папке находятся следующие файлы:

## _development.js

Внедрение кода JavaScript, которое позволяет выполнять динамическую настройку с помощью программной логики поверх параметров, определённых в файле `_development.json`. Например, задать какую-либо настройку на основе информации из базы данных, определить параметры поведения выполнения кода и многое другое.

Этот файл используется в зависимости от определения окружения — в случае `development` (разработка).

## _development.json

Определение параметров приложения, таких как язык, общие настройки ресурсов и интеграций. Например, настройки баз данных, Cron Jobs, интеграции с SMTP или удалёнными API, аутентификация и многие другие.

Этот файл используется в зависимости от определения окружения — в случае `development` (разработка).

## _production.js

Внедрение кода JavaScript позволяет выполнять динамическую настройку с помощью программной логики поверх параметров, определённых в `_production.js`. Например, задать конфигурацию с информацией из базы данных, параметры поведения выполнения кода и многое другое.

Этот файл используется в зависимости от определения окружения — в случае `production` (производство).

## _production.json

Определение параметров приложения, таких как язык, общие настройки ресурсов и интеграций. Например, настройки баз данных, Cron Jobs, интеграции с SMTP или удалёнными API, аутентификация и многие другие.

Этот файл используется в зависимости от определения окружения — в случае `production` (производство).
