# Команды сервера

Справочник по основным командам Netuno. Выполняйте их в **терминале** из папки, где установлен Netuno.

:::tip
Не знаете, как перейти в папку Netuno? См. руководство по [Установке](/docs/get-started/installation).
:::

---

## Запуск сервера

Запускает сервер с приложением `демонстрация`.

```bash
./netuno server
```

---

## Запуск сервера в приложении

Запускает сервер с конкретным приложением, заданным параметром `app`. Если приложение не указано, будет запущено демонстрационное приложение.

```bash
./netuno server app=APP_NAME
```

---

## Новое приложение

Создаёт новое приложение с нуля, запрашивая информацию и начальные настройки.

```bash
./netuno app
```

---

## Список команд

Выводит список всех доступных команд и параметров с соответствующими описаниями.

```bash
./netuno help
```

---

## Статистика производительности

Показывает последнюю информацию о производительности, сохранённую в `logs/stats-*`.

```bash
./netuno stats
```

---

## Обновление до стабильной версии

Обновляет Netuno до последней стабильной версии.

```bash
./install-stable
```

---

## Обновление до тестовой версии

Обновляет Netuno до последней версии в разработке.

```bash
./install-testing
```
