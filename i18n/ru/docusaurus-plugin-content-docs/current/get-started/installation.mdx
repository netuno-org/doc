# Введение

Добро пожаловать в руководство по установке **Netuno** — *low-code* платформы, мультиязычной и *с открытым исходным кодом*, разработанной для ускорения создания ваших проектов и упрощения настройки среды разработки.

Здесь вы быстро создаёте надёжные full-stack приложения, сочетая скорость low-code с мощью традиционного программирования.

## Быстрая установка 

Самый простой способ установить Netuno — использовать скрипт установки, предоставляемый платформой. Просто выполните команды в терминале в соответствии с вашей операционной системой.

<Tabs groupId="os">
    <TabItem value="linux-mac" label="Linux или macOS" default>

```bash
bash <(curl -fsSL https://netu.no/install.sh)
```

    </TabItem>
    <TabItem value="windows" label="Windows">

```powershell
powershell -c "irm https://netu.no/install.ps1|iex"
```

    </TabItem>
</Tabs>

## Запуск DEMO-приложения

После завершения установки выполните команду ниже внутри папки `netuno`, чтобы запустить сервер с демонстрационным приложением:

```bash
./netuno server
```

### Открыть приложение в браузере

После запуска браузер автоматически откроется с адресом локального сервера. Если этого не произошло, откройте вручную один из адресов ниже:

- [http://demo.local.netu.no:9000](http://demo.local.netu.no:9000)
- [http://localhost:9000](http://localhost:9000)

## Остановка сервера

Чтобы остановить сервер, нажмите в терминале клавиши:

**CTRL + C**

Чтобы запустить его снова, используйте ту же команду `./netuno server`.
