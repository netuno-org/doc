# Версии

Если вы только начинаете использовать Netuno, рекомендуем выполнить **стандартную установку**, чтобы гарантировать использование самой последней и стабильной версии платформы.

Netuno также позволяет устанавливать конкретные предыдущие версии или экспериментальные версии, которые ещё находятся в разработке, что полезно для тестовых сред или воспроизведения ошибок.

Перед установкой или обновлением до конкретной версии ознакомьтесь с официальным списком релизов:

- **Список версий:** [github.com/netuno-org/platform/releases](https://github.com/netuno-org/platform/releases)

:::tip Совет
Проверяйте примечания к релизу перед установкой конкретной версии, особенно в производственных средах.
:::

## Установка конкретной версии

Чтобы установить или обновить Netuno до конкретной версии, добавьте параметр `version` в команду установки с идентификатором нужной версии.

Выберите метод, который лучше всего подходит для вашей среды:

### Метод 1: Java-установщик

Используйте этот метод для новых установок:

```bash
java -jar netuno-setup.jar install version=20230417.0119
```

### Метод 2: Основной исполнитель

Используйте этот метод, если Netuno уже установлен и вы хотите обновить его до конкретной версии:

```bash
./netuno install version=20230417.0119
```

### Метод 3: netuno.jar

```bash
java -jar netuno.jar install version=20230417.0119
```

:::info
Замените `20230417.0119` на идентификатор нужной версии, доступный в **[списке релизов](https://github.com/netuno-org/platform/releases)**.

После выполнения команды Netuno автоматически запустит процесс установки указанной версии.
:::
