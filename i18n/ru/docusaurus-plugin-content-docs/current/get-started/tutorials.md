# Руководства

Изучите руководства платформы Netuno и на практике узнайте, как настраивать ресурсы, моделировать данные, создавать интерфейсы и разрабатывать бизнес-логику на бэкенде.

Эта страница объединяет основные материалы как для тех, кто только начинает, так и для тех, кто хочет углубить свои знания о платформе.

## Перед началом

Перед запуском любого руководства убедитесь, что ваша среда готова:

- **Netuno установлен** и запущен в локальной среде или среде разработки.
- **Есть доступ к административной панели** с соответствующими правами.
- **Рекомендуются базовые знания** по моделированию данных, HTTP и REST API, чтобы лучше усвоить технические материалы.

Перед продолжением ознакомьтесь с руководством по [Установке](./installation).

## Рекомендуемый порядок

Если это ваш первый опыт работы с Netuno, следуйте этой последовательности:

1. Познакомьтесь с графическим интерфейсом.
2. Научитесь создавать формы и поля.
3. Настройте связи между формами.
4. Перейдите к разрешениям и группам пользователей.
5. Изучите запросы и возможности бэкенда в соответствии с потребностями проекта.

## Backend

Netuno позволяет сочетать low-code с разработкой бэкенда на разных языках и в разных сценариях. Приведённые ниже руководства помогут вам создавать интеграции, манипулировать данными и реализовывать бизнес-логику.

### Предварительные требования

Перед переходом к этому разделу рекомендуется иметь представление о:

- Архитектуре клиент-сервер и протоколе HTTP.
- Структурах данных в JSON.
- Логике программирования на JavaScript, Python или другом языке, совместимом с вашим процессом разработки.

| [Отправка электронных писем](/docs/academy/server/services/sending-emails) | Настраивать отправку транзакционных писем через SMTP. | Средний |

:::tip Как выбрать руководство

Используйте руководства по **графическому интерфейсу**, когда цель — настроить приложение визуально, структурировать данные и управлять ресурсами через интерфейс.  
Используйте руководства по **бэкенду**, когда необходимо создать бизнес-логику, интеграции, аутентификацию, автоматизации или программный доступ к данным.
:::
