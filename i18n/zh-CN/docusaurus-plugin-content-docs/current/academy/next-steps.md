请记住在 Netuno 中持续进阶所需的要点。

文档总体而言会不断改进，并力求尽可能简单、入门友好。

但假定您已在某些领域具备一些基础知识和经验，例如：

* 数据库，例如一般查询、insert、update 和 delete；
* Web 服务，涉及 GET 和 POST；
* <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a> 和 <a href="https://reactjs.org/" target="_blank">ReactJS</a>；

如果您尚不具备其中某些能力，我们会尝试帮助您培养这些能力。

请始终在 GitHub 或 Discord 上寻求帮助，具体指引见网站页脚。

## 数据库

使用 Netuno，您可以处理多种类型的数据库并加深自己的知识。

只有具备良好的数据库知识，才能创建结构复杂的应用，以收集和管理大量数据。

这样您就能自主、稳健地构建最重要的部分——数据库。

构建组织良好且经过优化的数据库，会极大影响最终用户体验，也会影响从开发到运行阶段的性能。

## 服务

如果您已对以下任一编程语言有所了解，例如 <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>、<a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>、<a href="https://www.jython.org/" target="_blank">Python</a>、<a href="https://www.jruby.org/" target="_blank">Ruby</a>、<a href="https://kotlinlang.org/" target="_blank">Kotlin</a> 或 <a href="https://groovy-lang.org/" target="_blank">Groovy</a>，就可以利用 Netuno 为 **低代码** 编程提供的多种资源，快速创建复杂且健壮的 Web 服务。

在应用文件夹内，尤其是在 **server** 文件夹中，您可以使用这些不同语言进行编程。

只需使用相应的扩展名：

* **.js** &nbsp; <a href="https://developer.mozilla.org/pt-PT/docs/Web/JavaScript" target="_blank">JavaScript</a>
* **.ts** &nbsp; <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>
* **.py** &nbsp; <a href="https://www.jython.org/" target="_blank">Python</a>
* **.rb** &nbsp; <a href="https://www.jruby.org/" target="_blank">Ruby</a>
* **.kts** &nbsp; <a href="https://kotlinlang.org/" target="_blank">Kotlin</a>
* **.groovy** &nbsp; <a href="https://groovy-lang.org/" target="_blank">Groovy</a>

请探索 **demo** 演示应用中自带的 Web 服务示例，位于：

- `/apps/demo/server/services/samples`

也请探索我们 **库** 的文档，详细了解可用资源。


## 用户界面

近年来，Web 前端开发发生了许多变化，使用 <a href="https://vite.dev/" target="_blank">Vite</a> 已成为标准。

我们选择的技术，如 <a href="https://reactjs.org/" target="_blank">ReactJS</a>、<a href="https://bun.sh/" target="_blank">Bun</a>、<a href="https://ant.design/" target="_blank">Ant.Design</a> 和 <a href="http://lesscss.org/" target="_blank">Less</a>，都是能提高生产力并获得广泛采用的技术。

要深入学习这些技术，请探索互联网上提供的各种文本和视频文档。

由于这些技术拥有庞大的社区，不难找到优质的入门学习材料。

我们提醒您，使用 Netuno，即使只有少量知识，也能取得显著成果；这使前端开发者有能力开发整个后端，反之亦然，甚至可以选择仅用一种编程语言（如 <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>）开发所有内容。

## 结论

Netuno 简化了 Web 应用开发，即使只有一个人、仅具备少量数据库、Web 服务和前端知识，也能自主开发复杂应用。

对于大型团队也是如此：团队中每个领域都有能力更强的人，总体而言，这能大幅提高生产力。

Netuno 还可以用作数据库后台，或作为 REST API 服务器，为解耦的前端和移动应用提供服务。

节省时间，更专注于业务规则逻辑进行开发；凭借您已有的知识，您将走得更远。
