Netuno 在数据库层面、编程语言层面，甚至操作系统层面都是多语言的。

这种多样性扩大了它可以被应用到的场景。

通过支持多种数据库、编程语言和操作系统，它能适应各种不同的情况，同时为开发工作提供统一协调的环境，从而让开发变得更加轻松。

## 数据库

它可以用来集成多种不同类型的数据库，甚至可以在同一个项目中使用不同的编程语言进行开发。

集成不同的数据库非常常见，用于在查询或修改其他系统数据库中的数据时实现数据集成。

![数据库 Logo](/docs/assets/business/databases.jpg "多种数据库")

Netuno 支持以下数据库：

- H2 Database
- PostgreSQL
- MariaDB
- MySQL
- Microsoft SQL Server
- Oracle

## 编程语言

支持不同的编程语言，从混合使用编程语言的角度来看似乎并不太有趣，但这确实是可行的，而且并不意味着就应该这样做。

在实践中，很多时候开展项目会很困难，因为某项占主导地位的技术受限于某一种编程语言，因此必须专门寻找精通这种编程语言的人员。

有了 Netuno，我们最终拥有了更大的选择空间，即使因为战略变化、缺乏胜任的技术人员、或者为了在开发某些特定内容时获得更高的敏捷性等等各种合理的情况而需要使用一种新的编程语言，所有的工作也不会被浪费。

通常情况下这是不可想象的，因为维护一个使用多种编程语言的系统会开始令人担忧，但由于这是低代码（low-code），这种担忧就变得不那么重要了，因为：

* 编程语言在逻辑和算法层面上最终是相似的。
* 编程语言可以不同，但无论使用哪种语言，Netuno 的资源都是相同的，并且以相同的方式使用。

因此，即使某位技术人员非常习惯于使用某一种编程语言，如果需要对另一种语言进行维护也不会有任何障碍；如果其工作需要大幅扩展甚至重做，那么他可以选择用自己偏好的语言进行开发，并将其开发成果集成到现有的、正在使用的语言中。

![编程语言 Logo](/docs/assets/business/languages.jpg "编程语言")

Netuno 支持使用以下编程语言进行开发：

- Groovy
- Java
- JavaScript
- Kotlin
- Python
- Ruby

## 操作系统

Netuno 可运行于多种操作系统，并支持环境配置，从而保证开发成果能够跨平台正常运行，并可组织到开发、测试、质量、生产等环境中。

操作系统或环境的变更对 Netuno 和应用程序的正常运行没有影响。

![操作系统 Logo](/docs/assets/business/operationsystems.jpg "多种操作系统")

Netuno 支持的操作系统有：

* Linux
* Mac OS X
* Windows
