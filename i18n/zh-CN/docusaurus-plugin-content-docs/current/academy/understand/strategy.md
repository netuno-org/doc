尽情享用这款强大的 Web 开发工具，它将在项目开发过程中为您省去许多麻烦。

Netuno 是一个带有框架的服务器，配有后台管理系统，既能辅助开发，也能进行在线数据的行政管理和操作，而这一切都支持多应用方式。此外，它还支持多种数据库和多种编程语言。

出于这些以及其他原因，它被定位为一个平台，尤其适合以最佳且最新的技术来部署基于 Web 的项目。

![Netuno 是 Web 项目的发射平台](/docs/assets/business/introduction.jpg "Netuno 是 Web 项目的发射平台。")

因此，可以使用 Netuno 的场景非常多，而随着您在各种项目中逐步使用 Netuno，您会开始发现 Netuno 在解决各种复杂程度的问题上有多大的帮助，这方面没有极限。

Netuno 正被用于多种类型的项目，例如：

- 在工业领域，用于工厂信息采集。
- 在会计领域，用于流程和任务管理。
- 在服务器和虚拟机控制方面。
- 在托管服务和邮件服务控制方面。
- 在密码管理与共享方面。
- 在与 SAP 的集成中。
- 在与 BPM 的集成中。
- 作为 Android 和 iOS 移动应用的后台管理系统。
- 作为门户和在线商店的辅助后台与编排系统。
- 在报警系统中。
- 在报表生成中。
- 以及更多……

> 您知道 Netuno 是免费且开源的[？立即开始](/docs/get-started/installation)。

借助支持用户配置文件和组的自动数据管理界面，可以将 Netuno 用作后台管理系统，也可以用作面向最终用户的应用界面，因为它能快速创建项目的实验原型，开始测试并打磨数据结构，从而为将要进行的编程提供坚实的基础。

通过低代码构建 REST API 并支持 OpenAPI 3.0，满足当前与其他系统、移动应用、门户和在线商店集成的最新标准。

通过生成已集成 ReactJS 和 Ant.Design 的前端应用，可以为最终用户开发现代、直观且响应式的界面。

它将 NPM + WebPack 的执行与服务器集成在一起，因此在一个输出中就能了解发生了什么，并快速查看后端和前端层面的问题。

Netuno 的框架十分庞大，可快速开发开发中最常用的主要需求，并支持集成任何外部库，包括 Java、Kotlin、命令行、API 等。

它支持按开发、测试和生产环境进行配置，可通过代码自动生成数据库构建并允许自定义，可通过组件和自定义操作扩展自动生成的表单，生成数据库的图表可视化，支持通过浏览器执行数据库查询，以及许多其他功能。

Netuno 服务器已准备好提供与 Web 域关联的应用，并自定义端点（地址）。
