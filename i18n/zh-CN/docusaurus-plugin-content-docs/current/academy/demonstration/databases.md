# 数据库

在本阶段，我们将探索根据前面定义的 **任务** 表单自动创建的 **数据库**。

创建包含 **名称** 字段的 **任务** 表单时，Netuno 会根据表单创建时定义的名称，在数据库中创建包含 `名称` 列的 `任务` 表。

字段的 **技术名称**（例如 `任务`、`名称`、`任务_id`）用于编程和 SQL 查询，并不对应界面中显示的名称。

## 查询

本节中，我们将使用 Netuno 的管理界面直接在数据库中执行查询。

1. 进入 **构建** 环境。
2. 在菜单中，点击 **管理 > 查询**。
3. 在查询编辑器中，粘贴并执行以下命令。

### 简单查询

仅列出任务的名称：

```sql
SELECT 名称
FROM 任务;
```

列出任务表的所有字段：

```sql
SELECT *
FROM 任务;
```

列出记录表的所有字段：

```sql
SELECT *
FROM 记录;
```

列出员工表的所有字段：

```sql
SELECT *
FROM 员工;
```

点击 **执行** 后，Netuno 会为以分号（`;`）分隔的 **每个** 命令生成一个结果表。  
当您想一次执行多个查询时，这很有用。

### 关联查询

现在，执行一个关联所有表的查询：

```sql
SELECT
  任务.名称,
  记录.开始,
  记录.结束,
  员工.名称
FROM 任务
INNER JOIN 记录
  ON 任务.id = 记录.任务_id
INNER JOIN 员工
  ON 员工.id = 记录.员工_id;
```

该查询返回：

- 任务名称。
- 每条记录的开始和结束时间。
- 与每条记录关联的员工名称。

它展示了表之间的关系如何组合应用中不同实体的信息。

## 关系图

要更直观地查看数据库结构，请使用 Netuno 的 **关系图**。

1. 进入 **构建** 环境。
2. 在菜单中，点击 **管理 > 关系图**。

在关系图中，您可以：

- 放大或缩小。
- 将关系图导出为图片。

这些操作可通过关系图面板右侧的按钮完成。

Netuno 会根据字段中的 **链接** 配置自动创建带关系箭头的连线（例如指向其他表的 `select` 类型字段）。

## 最佳实践

在 Netuno 中建模数据库时，请遵循以下最佳实践：

- 在表示关系的字段中使用 `_id` 后缀，例如：
  - `任务_id`
  - `员工_id`
- 避免使用复数形式的表名和字段名，例如 `任务列表`、`记录列表` 或 `员工列表`。

避免使用复数有助于：

- 让名称更简短、更易读。
- 减少编写查询时的歧义。
- 让表单和关系图更易读，尤其是在存在多个关系时。

:::tip 命名规范
默认情况下，表单、表和字段始终使用 **单数名称**。  
示例：`任务`、`记录`、`员工`、`任务_id`、`员工_id`。
:::
