# 关联数据

在任务和工时记录之间创建关联，以了解**谁**执行了**哪项任务**以及**花费了多少时间**。

完成此步骤后，**记录**表单将与**任务**表关联，从而可以直接在记录列表中查看关联的任务。

## 前置条件

开始之前，请确认你已完成以下操作：

- 已创建包含 `名称` 字段的 **任务** 表单。
- 已创建包含基本工作时长字段的 **记录** 表单。
- 已在 **数据库** 中配置对应表。

:::tip
有关如何关联数据的更多详细信息，请参阅[界面指南：关联](/docs/academy/ui/relationships-between-forms)。
:::

到目前为止，你已经创建了任务管理和工时记录，但每个列表仍然独立运作。  

将它们关联起来很重要，这样每条工时记录都能清楚地表明某位员工在哪个时间段完成了哪项任务。

在此步骤中，你将：

- 在 **记录** 表单中创建一个 `select` 类型字段。
- 配置该字段，使其与 **任务** 表关联。
- 更新一些数据，以实际查看关联效果。

## `select` 类型字段

添加一个字段，用于选择每条工时记录关联的任务。

1. 在 **构建** 环境中，打开 **记录** 表单并访问字段管理。
2. 创建一个新字段，配置如下：
   - **字段标题**：`任务`
   - **列名**：`任务_id`
   - **类型**：`select`
3. 启用 **必填** 选项，以确保每条记录都关联到一项任务。
4. 保持 **唯一值** 选项处于禁用状态，因为同一任务会有许多记录。

:::note
建议使用名称 `任务_id`，以在整个数据模型中保持一致的命名规范。
:::

## 使用 `_id` 后缀

引用其他记录的字段名应以 `_id` 结尾。  
此规范便于识别该字段表示与另一张表的关系，并使数据模型更有条理。

:::warning
避免为关联字段使用 `任务` 或 `ref_任务` 这样的通用名称。  
使用 `_id` 进行标准化有助于在分析数据或创建集成时避免混淆。
:::

## 配置关联链接

配置 **链接**，它负责将 `任务_id` 字段与任务表关联起来。

1. 在新建字段（`任务_id`）中，滚动到 **链接** 配置部分。
2. 点击 **添加**。
3. 在打开的窗口中：
   - 选择 **任务** 选项。
   - 然后选择 **名称** 字段。
   - 关闭窗口以应用。

完成后，**链接** 将定义为：

```text
任务:名称
```

这意味着：

- 将与 **任务** 表建立关联。
- 在界面中，当在 `任务` 字段中选择时，将显示任务的 **名称** 字段值。

点击 **保存** 按钮以保存字段配置。

:::tip
尽可能使用描述性字段（如 `名称`）来显示关联信息，而不是技术标识符或数字标识符。
:::

## 更新记录

配置好关联字段后，调整数据以查看结果。

1. 访问 **记录** 表单的视图。
2. 注意，现在结果表有一个名为 **任务** 的新列，该列最初为空。
3. 编辑一些记录：
   - 单击结果表中的一行以打开编辑表单。
   - 在 **任务** 字段中，选择对应的任务。
   - 点击 **保存** 以保存。

**保存后：**

- 结果表中的 **任务** 列将显示关联任务的名称。
- 每条 **记录** 都将清晰地关联到一项 **任务**，从而可以更全面地分析每项活动所花费的时间。

:::note
如果存在许多未定义任务的记录，请考虑根据数据策略批量更新，或定义一个临时默认任务。
:::

### 预期结果

**记录** 列表应显示：

- **任务** 列中填入关联任务的名称。
- 每一行代表一条工时记录及其对应任务，从而更容易识别时间投入在哪里。
