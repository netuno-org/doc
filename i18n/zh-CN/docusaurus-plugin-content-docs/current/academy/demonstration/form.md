# 表单

在演示的这一阶段，你将创建 **任务** 表单并配置第一个数据字段。

:::info 参考
有关表单的更详细说明，请参阅 [界面指南：表单](/docs/academy/ui/forms)。
:::

## 目标

完成此阶段后，你将拥有：

- 一个名为 **任务** 的表单。
- 一个在数据库中关联的表。
- 一个用于存储任务名称的必填字段。
- 一个可用于创建、编辑、搜索和删除记录的界面。

## 前置条件

请确认：

- 演示应用已经创建。
- 配置阶段已经完成。
- 你位于平台的开发区域。

## 创建表单

1. 在右上角，点击 **构建**。
2. 在主菜单中，访问 **管理 > 表单**。
3. 在 **表单标题** 中，填写 `任务`。
4. 在 **表名** 中，启用 **自动** 选项。
5. 点击 **保存**。

:::note
- **表单标题** 定义侧边菜单中显示的名称。
- **表名** 定义数据库中使用的技术标识符。
:::

保存后，**任务** 表单将出现在左侧边菜单中。

## 创建第一个字段

表单创建完成后：

1. 在侧边菜单中，点击 **任务**。
2. 在 **显示名称** 中，填写 `名称`。
3. 确认技术名称已自动生成，且由小写字母组成。
4. 启用 **主键** 选项（唯一字段）。
5. 启用 **非空** 选项（必填字段）。
6. 在 **类型** 中，选择 `text`。
7. 点击 **保存**。

:::tip
- **主键** 确保每条记录的值唯一。
- **非空** 使该字段成为必填项。
- `text` 类型允许存储纯文本。
:::

## 验证结果

打开预览区域并确认：

- **任务** 表单可用。
- **名称** 字段出现以供填写。
- 可以创建新记录。
- **名称** 字段为必填项。

:::info 预期结果
如果配置正确，表单将可用于创建、编辑、搜索和删除记录的操作。
::::
