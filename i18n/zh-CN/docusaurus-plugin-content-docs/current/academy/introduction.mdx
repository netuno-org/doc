## 什么是 Netuno？

它是一个*低代码*、*开源*且完全免费的的平台。

我们的主要目标是助你在编程领域加速职业发展，通过掌握*全栈*开发，赋予你独立性与完全的自主能力。

该平台通过揭开*后端*的神秘面纱来推动*全栈*开发。它显著简化了以下开发工作中的多个层面：

* Web 解决方案与应用程序；
* *后台*系统；
* REST API。

在理解*全栈*生态之后，你会发现自己的天然禀赋更偏向于*前端*还是*后端*。同时，你也会成为一名更有能力的专业人员，能够与不同专业方向的团队进行互动、沟通与协作。

## 开始前的先决条件

借助 Netuno，学习曲线因消除了许多常见的技术障碍而变得平缓，但人的因素——你的创造力与智慧——仍然至关重要。

在开始学习之前，重要的是调整好预期，并确保你具备：

* **走出舒适区的意愿：** 持续学习是技术之旅的一部分。
* **兴趣与耐心：** 学习新技术和新概念需要时间、实践与投入。
* **专注与坚持：** 软件开发需要高度的专注。挑战会出现，但坚持是成功的关键。
* **追求优化的愿望：** 渴望以更快、更高效的方式打造稳健的解决方案。

:::tip 提示与最佳实践
* **不要在困难面前放弃：** 学习常常会间接地锻炼你的韧性。许多人在遇到障碍时便放弃了，但请记住：如果软件开发极其简单，那它早就被完全自动化了。你的人类思维不可或缺。
* **需要时随时寻求帮助：** 自信前行，但要知道在旅程的某些时刻感到迷茫是很正常的。当这种情况发生时，不要犹豫，去寻求支持。
:::


该平台专为你而打造，让你能够敏捷而智能地进行构建。

你**无需花钱**来学习或使用 Netuno 推广和讲授的技术。我们整个生态以及我们推荐的工具都是免费的。
