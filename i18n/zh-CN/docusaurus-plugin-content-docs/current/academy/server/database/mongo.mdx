## 简介

<a href="https://www.mongodb.com/" target="_blank">MongoDB</a> 是一个面向文档的 NoSQL 数据库。数据不是以表和行的形式存储，而是保存在类似 JSON 格式的文档中，这使得数据模型具有很大的灵活性。

Netuno 提供 [_mongo](/docs/library/resources/mongo) 资源用于与 MongoDB 集成，它在面向 Java 的官方 MongoDB 客户端之上提供低代码抽象，并可用于 Netuno 支持的各种编程语言：**JavaScript、Python、Ruby、Kotlin 和 Groovy**。

> 在继续之前，建议先了解如何在 Netuno 中创建服务，请参阅教程 [REST - Web 服务](/docs/academy/server/services/rest)。

此处介绍的操作的实现示例可在示例服务 `mongo.js` 中找到，该文件位于：

## 安装 MongoDB

### 使用 Docker

假设已安装 Docker，只需下载 MongoDB 镜像并启动一个新容器：

```shell
docker pull mongo
docker run -d --name mongo -p 27017:27017 mongo
```

这样，MongoDB 就可以在 `localhost:27017` 上访问，且无需身份验证。

要根据应用配置创建数据库用户，请执行：

```shell
docker exec -it mongo mongosh 产品_数据库 --eval 'db.createUser({ user: "产品_用户", pwd: "12345678", roles: [{ role: "readWrite", db: "产品_数据库" }] })'
```

### 使用 Ubuntu

MongoDB 未包含在 Ubuntu 官方软件仓库中，因此需要在安装前添加官方仓库：

```shell
sudo apt-get install gnupg curl
curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.asc | sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg --dearmor
echo "deb [ signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] http://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
sudo apt-get update
sudo apt-get install -y mongodb-org
```

安装完成后，可以使用以下命令启动服务：

```shell
sudo systemctl start mongod
```

### 使用 Windows

- <a href="https://www.mongodb.com/try/download/community" target="_blank">下载 MongoDB Community Server</a>。

运行下载的安装程序，并在 **Service Configuration** 步骤中启用 **Install MongoD as a Service**，以便 MongoDB 自动启动。这样，MongoDB 就可以在 `localhost:27017` 上访问，且无需身份验证。

> 其他发行版和版本请参阅 [MongoDB 官方文档](https://www.mongodb.com/docs/manual/installation/)。

## 应用配置

MongoDB 连接的配置在应用的配置文件中完成，具体取决于环境：

- `config/_development.json`

> 详细了解应用的[配置文件](/docs/academy/explore/configuration)。

在配置文件中，添加 `mongo` 块，其中每个键标识一个连接：

```javascript
{
    ...
    "mongo": {
        "商店": "mongodb://商店_用户:12345678@localhost/商店_数据库",
        "产品": {
            "username": "产品_用户",
            "password": "12345678",
            "host": "127.0.0.1",
            "port": "27017",
            "database": "产品_数据库"
        }
    },
    ...
}
```

连接可以通过两种方式定义：

- **作为连接 URL** — 值就是一个字符串，例如 `"mongodb://商店_用户:12345678@localhost/商店_数据库"`。
- **作为配置对象** — 包含以下字段：
  - `url` — 如果定义，则直接用作连接 URL，并忽略其他字段。
  - `protocol` — 连接协议，默认 `mongodb`。
  - `username` 和 `password` — 访问凭据。
  - `host` — 服务器地址，默认 `localhost`。
  - `port` — 连接端口，默认 `27017`。
  - `database` — 数据库名称，默认使用连接键的名称。
  - `params` — 添加到 URL 的额外连接参数，例如 `{ "authSource": "admin" }`。仅在根据对象字段构建 URL 时应用。

> 连接不必是应用的主数据库。与 `db` 配置不同，`mongo` 块是独立的，并允许同时存在多个连接。

### 过滤器

`_mongo.filters()` 工厂提供 MongoDB 的主要查询操作符：

| 操作符 | 描述 |
|---|---|
| `eq("字段", 值)` | 等于该值。 |
| `ne("字段", 值)` | 不等于该值。 |
| `gt("字段", 值)` | 大于该值。 |
| `gte("字段", 值)` | 大于或等于该值。 |
| `lt("字段", 值)` | 小于该值。 |
| `lte("字段", 值)` | 小于或等于该值。 |
| `in("字段", 值1, 值2, ...)` | 等于任意一个值。 |
| `nin("字段", 值1, 值2, ...)` | 不等于所有值。 |
| `and(过滤器1, 过滤器2, ...)` | 匹配所有过滤器。 |
| `or(过滤器1, 过滤器2, ...)` | 匹配至少一个过滤器。 |
| `not(过滤器)` | 不匹配该过滤器。 |
| `regex("字段", "模式")` | 匹配正则表达式。 |
| `exists("字段")` | 文档中存在该字段。 |
| `text("搜索")` | 文本搜索。 |
| `type("字段", "类型")` | 字段为指定类型。 |
| `mod("字段", 除数, 余数)` | 字段除以除数的余数等于该值。 |
| `where("表达式")` | 匹配满足 JavaScript 表达式的文档，例如 `"this.价格 > 100"`。 |
| `size("字段", n)` | 数组字段恰好有 `n` 个元素。 |

## 聚合

对于更高级的分析，`aggregate()` 允许执行聚合管道，其中每个阶段由 `_mongo.aggregates()` 工厂定义，累加器由 `_mongo.accumulators()` 定义。

例如，要按分类对产品分组并汇总每个分组的价格：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const 文档列表 = 集合.aggregate(
                    _mongo.aggregates().match(
                        _mongo.filters().eq("分类", "电脑")
                    ),
                    _mongo.aggregates().group(
                        "$分类",
                        _mongo.accumulators().sum("总计", "$价格")
                    ),
                    _mongo.aggregates().sort(
                        _mongo.sorts().descending("总计")
                    )
                ).all()
            `
        },
        {
            lang: 'python',
            code: `
                文档列表 = 集合.aggregate(
                    _mongo.aggregates().match(
                        _mongo.filters().eq("分类", "电脑")
                    ),

可用的聚合阶段如下：

| 阶段 | 描述 |
|---|---|
| `match(过滤器)` | 仅选择与过滤器匹配的文档。 |
| `group("$字段", 累加器)` | 按字段对文档分组并应用累加器。 |
| `project(投影)` | 在文档中添加、移除或更改字段。 |
| `sort(排序)` | 对文档排序。 |
| `limit(n)` | 限制为前 `n` 个文档。 |
| `skip(n)` | 跳过前 `n` 个文档。 |
| `count()` | 统计文档数量。 |
| `lookup("集合", "本地字段", "外部字段", "作为")` | 与另一个集合执行 join。 |

以及常用的累加器：

| 累加器 | 描述 |
|---|---|
| `sum("字段", "$表达式")` | 值之和。 |
| `avg("字段", "$表达式")` | 值的平均值。 |
| `min("字段", "$表达式")` | 最小值。 |
| `max("字段", "$表达式")` | 最大值。 |
| `first("字段", "$表达式")` | 第一个文档的值。 |
| `last("字段", "$表达式")` | 最后一个文档的值。 |
| `top("字段", 排序, "$表达式")` | 按排序取顶部的值。 |
| `bottom("字段", 排序, "$表达式")` | 按排序取底部的值。 |

> 在累加器中，带 `$` 前缀的表达式引用输入文档中的字段，例如 `"$价格"`。

## 带选项的操作

## 结论

通过 `_mongo` 资源，Netuno 在面向 Java 的官方 MongoDB 客户端之上提供了低代码、多语言抽象，允许在 JavaScript、Python、Ruby、Kotlin 和 Groovy 中处理文档、过滤器、排序、投影、更新、索引和聚合。

有关所有可用方法的更多详细信息，请参阅 [_mongo](/docs/library/resources/mongo) 资源和 [MongoCollection](/docs/library/objects/MongoCollection) 类的文档。
