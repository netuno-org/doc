处理自定义 Excel 文件。

## 简介

Netuno 通过 [XLS](/docs/library/resources/xls) 资源生成与 LibreOffice、OpenOffice、Microsoft Office、Google Drive 等兼容的 EXCEL 文件，该资源为 Netuno 支持的多种编程语言提供了对 [Apache POI](https://poi.apache.org/) 的低代码抽象。

我们可以生成 XLSX、XLS 或 ODS 文件。

Netuno 自带的名为 **demo** 的应用（演示应用）包含大量各种语言中可能实现方式的代码示例，其中包括通过 `export-excel` 服务导出电子表格的演示，该服务位于：

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-excel`
]} />

## 初始化

要初始化 XLS 资源：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const excel = _xls.create()
            `
        },
    ]}
/>

创建包含将要构建的新文件上下文的对象，并带有一个空白工作表。

## 格式化

视觉格式化样式（即日期、时间、货币等格式）的定义必须在定义单元格值之前完成，因为在定义单元格值时可以将格式样式一并关联。

因此，正如 `demo` 应用中附带的示例所演示的那样，格式化都在代码开头处定义。

## 外观

视觉外观样式（即单元格的颜色、字体、边框、对齐方式等外观）的定义必须在定义单元格值之前完成，因为在定义单元格值时可以将外观样式一并关联。

因此，正如 `demo` 应用中附带的示例所演示的那样，外观都在代码开头处定义。

定义颜色和对齐方式的示例：

<PolyglotCode

## 合并单元格

要在某个区域合并单元格，我们使用 `mergedRegion` 方法。

参数顺序如下：

1. 起始行
2. 起始列
3. 结束行
4. 结束列

> 位置的数字索引始终从 **零** 开始。

在下面的示例中，将合并第 3 行中从第 10 列到第 15 列的所有单元格：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.mergedRegion(2, 9, 2, 14)
            `
        },
    ]}
/>

## 插入表格数据

我们可以使用 `addDataTable` 方法插入数据表。

由于前两个参数定义了数据表应插入的位置，它们分别是行号和列号。

> 注意，代码中行和列的位置始终从 **零** 开始。
>
> 也就是说，第 1 行是位置 `0`，A 列也是位置 `0`。

接着我们传入一个行列表，其中每一行又包含一个用于列的列表，然后才添加一个包含单元格值的映射。

完整示例：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, 1,
                    _val.list() // 行
                        .add(
                            _val.list() // 列
                                .add(
                                    _val.map() // 单元格
                                        .set("value", "姓名")
                                )
                                .add(
                                    _val.map()
                                        .set("value", "年龄")
                                )
                        )
                        .add( // 另一行
                            _val.list()
                                .add( // 第一列
                                    _val.map()
                                        .set("value", "玛丽亚")
                                )
                                .add( // 第二列
                                    _val.map()
                                        .set("value", 26)
                                )
                        )
                )
            `
        },
    ]}
/>

### 公式

要插入公式，我们在单元格定义的映射中使用 `formula` 键。

在这个示例中，将在最后一个单元格中对其他所有单元格的值求和：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, 1,
                    _val.list()
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 45))
                                .add(_val.map().set("value", 26))
                        )
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 51))
                                .add(_val.map().set("value", 30))
                        )
                        .add(
                            _val.list()
                                .add(
                                    _val.map().set("value", "合计")
                                )
                                .add(
                                    _val.map().set("formula", "SUM(B7:C8)")
                                )
                        )
                )
            `
        },
    ]}
/>

要从列号获取列字母，可以使用 `columnReference` 方法，这有助于定义公式。该方法也可以用来从引用字母获取列号，例如：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, _xls.columnReference('B'),
                    _val.list()
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 45))
                                .add(_val.map().set("value", 26))
                        )
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 51))
                                .add(_val.map().set("value", 30))
                        )
                        .add(
                            _val.list()
                                .add(
                                    _val.map().set("value", "合计")
                                )
                                .add(
                                    _val.map().set(
                                        "formula",
                                        "SUM("+ _xls.columnReference(1) +"7:"+ _xls.columnReference(2) +"8)"
                                )
                            )
                        )
                )
            `
        },
    ]}
/>

### 激活

因此，为了避免像上面的示例那样在方法中不断指明应该处理哪个工作表，另一种做法是指定哪个是活动工作表。

> 所有单元格、图片和数据的处理方法，在**未**指定特定工作表时，都会使用当前激活的工作表。

以下是激活特定工作表的两种方式，首先是通过对象引用，然后是通过工作表索引：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.activeSheet(我的工作表) // 工作表的引用对象。
                excel.activeSheet(1) // 将被激活的工作表索引。
            `
        },
    ]}
/>

打开应用根目录中的文件：

<PolyglotCode

<PolyglotCode

在上面的示例中，常量 `excel` 将包含带有相应文件上下文的编辑对象，因此可以进行任何类型的操作。

完成修改后，执行新文件的生成。

> 无法直接修改同一个打开的文件，需要以不同的路径生成一个新文件。

要直接修改同一个文件，可以使用 `inputStream` 来实现。

以下是修改单元格值的示例：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const 文件输入 = _app.file("file.xlsx").inputStream()
                const excel = _xls.open(文件输入)

                excel.setCellData(
                    10, 1,
                    _val.map()
                        .set(
                            "value",
                            excel.getCellData(10, 1).getInt("value") + 10
                        )
                )

                文件输入.close() // 关闭已打开的文件。
                excel.save(_app.file("file.xlsx")) // 保存新版本。
                `
        },
    ]}
/>

## 读取文件

从 Excel 文件中提取数据使用 `read` 方法。

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const 数据 = _xls.read(_app.file("file.xlsx"))
            `
        },
    ]}
/>

数据以 Values 类型的对象结构获取，其中包含用于工作表、行和列的列表（List），以及用于单元格的映射（Map，键和值）。

要查看所有数据，我们可以将其作为服务的数据输出：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _out.json(数据)
            `
        },
    ]}
/>

要进行遍历，我们必须记住数据的结构按以下顺序组织：

1. `sheets` - 工作表
2. `rows` - 行
3. `columns` - 列

完整遍历的示例：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                for (const 工作表 of 数据.getValues("sheets")) {
                    _out.println(\`<h4>工作表: \${工作表.getInt("index")} - \${工作表.getString("name")}</h4>\`)
                    for (const 行 of 工作表.getValues("rows")) {
                        _out.println(\`<h4>行: \${行.getInt("row")}</h4>\`)
                        _out.println("<p>")
                        for (const 列 of 行.getValues("columns")) {
                            _out.print(\`\${列.getInt("row")}:\${列.getInt("column")}\`)
                            _out.print(\` # \${列.getString("address")}\`)
                            _out.print(\` # \${列.getString("type")}\`)
                            _out.print(\` # \${列.getString("value")}\`)
                            _out.println("<br>")
                        }
                        _out.println("</p>")
                    }
                }
            `
        },
        {
            lang: 'python',
            code: `
                for 工作表 in 数据.getValues("sheets"):
                    _out.println(f"<h4>工作表: {工作表.getInt('index')} - {工作表.getString('name')}</h4>")
                    for 行 in 工作表.getValues("rows"):
                        _out.println(f"<h4>行: {行.getInt('row')}</h4>")
                        _out.println("<p>")
                        for 列 in 行.getValues("columns"):
                            _out.print(f"{列.getInt('row')}:{列.getInt('column')}")
                            _out.print(f" # {列.getString('address')}")
                            _out.print(f" # {列.getString('type')}")

单元格的类型通过以下代码获取：

- `列.getString("type")`

支持的类型有：

- `string` - 文本内容。
- `numeric` - 数字或日期和/或时间内容。
- `boolean` - 真或假。
- `blank` - 空白单元格。
- `formula` - 包含公式的单元格。
- `error` - 单元格处理中的错误。

### 附加参数

每种单元格类型都有一些附加参数。

`string` - 具有文本内容的单元格类型。

- `value` - 单元格的文本。
- `richValue` - 单元格的格式。

`numeric` - 具有数字内容，或日期和时间的单元格类型。

- `value` - 单元格数字内容的值。
  
在日期和时间的情况下，我们还有以下附加参数：

- `localDateTime` - 表示单元格日期和时间值的 Java Time LocalDateTime 对象。
- `localDate` - 表示单元格日期值的 Java Time LocalDate 对象。
- `localTime` - 表示单元格时间值的 Java Time LocalTime 对象。
- `instant` - 表示单元格日期和/或时间值的 Java Time Instant 对象。
- `date` - 表示单元格日期和/或时间值的 Java Date 对象。

`boolean` - 具有布尔内容，即真或假的单元格类型。

- `value` - _boolean_ 类型的值，`true` 或 `false`。

`blank` - 无内容的单元格类型，因此不包含附加参数。

`formula` - 包含计算公式的单元格类型。

- `value` - 计算得出的最终结果值。
- `formula` - 包含用于计算的公式表达式。

`error` - 包含错误的单元格类型。

- `value` - 所产生错误的字节值。
- `code` - 如果公式计算中出现错误，这里提供所发生错误的代码。
