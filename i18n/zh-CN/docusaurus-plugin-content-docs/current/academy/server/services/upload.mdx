将文件上传到 API，并保存到文件夹或数据库中。

## 简介

当我们需要将文件发送到 REST API 服务时，在 Netuno 中有多种方式可以实现这种开发。

通常，文件会放在 HTTP 请求体中，并以 multipart 格式组织，这是前端最常见的做法，例如当我们填写表单并且其中有一个用于选择文件的字段时。

另一种方式是，当我们希望 REST API 完全使用 JSON 时，可以将文件字节以 Base64 编码作为 JSON 对象中的值发送。

## 文件

通过 `_req.file` 可以传入字段名，从而获取已上传文件的对象，如下所示：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const 我的文件 = _req.file("文件");
            `
        },
    ]}
/>

也就是说，`_req` 包含我们在 HTTP 请求体中接收到的所有数据。

通过 `file` 方法可以获取表示已上传文件的对象。

如果没有任何文件，获取到的值可能为 `null`。

## 如何在 JSON 中使用 Base64

要在发送给服务的 JSON 中上传文件，我们可以定义一个属性，其值为：

`data:image/png;base64,...`

其中 `...` 后跟以 Base64 编码的文件字节序列。

文件类型跟在 `data` 后面，例如：

- PNG：`image/png`。
- JPG：`image/jpeg`
- TXT：`text/plain`
- PDF：`application/pdf`
- XLSX：`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`

### 对象

如果文件位于 JSON 内部子对象结构中：

```json
{
  "人员": {
    "文件": "data:image/png;base64,..."
  }
}
```

可以按以下方式获取：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const 我的文件 = _req.getValues("人员").getFile("头像");
            `
        },
    ]}
/>

### 数组

如果文件位于 JSON 内部数组结构中：

```json
{
  "文件列表": [
    "data:image/png;base64,..."
  ]
}
```

可以按以下方式获取：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const 我的文件 = _req.getValues("文件列表").getFile(0);
            `
        },
    ]}
/>

## OpenAPI

Netuno 支持与 OpenAPI 集成，并使用 OpenAPI 定义来验证 HTTP 请求。

> 关于 [Netuno 中的 OpenAPI](/docs/academy/server/services/openapi) 的更多内容。

使用 `file` 类型时，Netuno 会验证该值是否以 JSON 中的文件格式开头，例如：

- `data:image/png;base64,...`

要验证是否在 JSON 对象的某个属性中接收文件：

```json title="post.in.json"
{
  "summary": "文件上传",
  "description": "在 JSON 对象中接收文件的服务。",
  "type": "object",
  "properties": {
    "文件": {
      "type": "file"
    }
  },
  "required": [
    "文件"
  ]
}
```

要验证是否在 JSON 数组中接收文件列表：

```json title="post.in.json"
{
  "summary": "多文件上传",
  "description": "在 JSON 数组中接收文件列表的服务。",
  "properties": {
    "文件列表": {
      "type": "array",
      "items": {
        "type": "file"
      }
    }
  },
  "required": [
    "文件列表"
  ]
}
```

## 保存文件

通常，当服务接收到文件时，我们需要将其保存，例如：

- **数据库**：与记录关联的文件，例如用户的文件。
- **Storage**：应用内部用于管理通用文件的文件夹。
- **文件夹**：将文件放到系统中的任意文件夹。

### 数据库

在表单字段管理中，Netuno 支持 `image` 和 `file` 类型，即：

- **Image**：通用图片文件，JPG 和 PNG。
- **File**：任意类型的文件。

假设“产品”表单中有一个“图片”字段，我们可以按以下方式保存通过上传发送的文件：

#### 从数据库下载文件

要呈现已存储的文件，我们应创建一个提供文件字节的服务。

对于保存到数据库中的文件（如上述示例），文件本身会放入应用的 Storage 中，而数据库中只存储文件的最终名称。

> 应用的 Storage 是一个用于存储和组织通用文件结构的文件夹。

因此，在上面的示例中，表单 `产品` 和字段 `图片` 的数据库文件存储在：

- `storage/database/产品/图片/*`

> Netuno 会自动管理存储文件的名称，以避免文件名重复。

要获取文件，可以创建一个展示产品图片文件的服务，例如：

<PolyglotCode
    file="services/产品/图片/get"
    codes={[

        lang: 'javascript',
        code: `

            // DB Form：
            const 数据库产品 = _db.form("产品")
                .where(_db.where("uid").equals(产品Uid))
                .first();
            // 使用经典 DB 的替代方式：
            // const 数据库产品 = _db.get("产品", 产品Uid)

            if (数据库产品 == null) {
                _header.status(404);
                _out.json(
                    _val.map()
                        .set("结果", false)
                        .set("错误", "产品未找到")
                );
                _exec.stop();

            const 数据库产品图片名称 = 数据库产品.getString("图片");

                "产品",
                "图片",
                数据库产品图片名称
            );

            if (存储产品图片文件.extension() == "jpg" || 存储产品图片文件.extension() == "jpeg") {
                _header.contentTypeJPG();
            } else {
                _header.contentTypePNG();
            }

            _header.noCache();

            _out.copy(存储产品图片文件.inputStream());
        `

### Storage

我们可以将文件直接保存到应用的 `storage` 中。

为了避免与数据库文件混在一起，我们应使用 `filesystem` 文件夹，它用于存储未与数据库关联的通用文件。

为了接收文件，本示例演示如何将 `POST` 服务中发送的文件直接存储到 Storage：

<PolyglotCode
    file="services/文件/post"
    codes={[
        {
            lang: 'javascript',
            code: `
                const 文件 = _req.getFile("文件");
                _storage.filesystem("服务器", "上传").ensurePath();
                文件.save(_storage.filesystem("服务器", "上传", 文件.name()));
            `
        },
    ]}
/>

文件存储在应用的 `storage` 文件夹中，路径为：

- `storage/filesystem/服务器/上传/*`

> [Storage](/docs/library/resources/storage) 资源用于获取文件夹和文件路径：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _storage.filesystem(
                    "服务器", // filesystem 中子文件夹的名称。
                    "上传", // 内部子文件夹的名称或路径。
                    文件.name() // 文件的最终名称。
                );
            `
        },
    ]}
/>

> 查看更多 [Storage](/docs/library/resources/storage) 文档。

### 文件夹

我们可以将文件直接保存到计算机上的任意文件夹。

在这种情况下，有两个非常有用的资源：

- `_app` - 可以获取应用中的任意文件夹或文件。
- `_os` - 可以获取计算机中的任意文件夹或文件。

> 查看相应资源 [App](/docs/library/resources/app) 和 [OS](/docs/library/resources/os) 的文档，这两个资源都有 `folder` 和 `file` 方法，分别用于指定文件夹或文件的路径。

为了接收文件，本示例演示如何将 `POST` 服务中发送的文件直接存储到应用中的某个文件夹：

<PolyglotCode
    file="services/文件/post"
    codes={[
        {
            lang: 'javascript',
            code: `
                const 文件 = _req.getFile("文件");
                const 文件夹 = _app.folder("临时");
                if (文件夹.exists() == false) {
                    文件夹.mkdir();
                }
                文件.save(_app.file(\`临时/\${文件.name()}\`));
            `
        },
        {
            lang: 'python',
            code: `

            `
        },
        {
            lang: 'ruby',
            code: `
                文件 = _req.getFile("文件")
                文件夹 = _app.folder("临时")

                end
                文件.save(_app.file("临时/#{文件.name()}"))
            `
        },
        {

## 结论

如你所见，我们可以将文件上传集成到 REST API 服务中，甚至与 OpenAPI 集成。

我们可以将文件保存到数据库、应用内的 `storage` 文件夹或计算机上的任意文件夹。

查看本教程中使用的、可用于操作文件的资源文档：

- [Storage](/docs/library/resources/storage)
- [App](/docs/library/resources/app)
- [OS](/docs/library/resources/os)

在数据库中，我们可以将图片保存到 `image` 类型字段，也可以将任意类型的文件保存到 `file` 类型字段；无论是图片还是通用文件，保存或获取文件的方式在各種情况下都相同。
