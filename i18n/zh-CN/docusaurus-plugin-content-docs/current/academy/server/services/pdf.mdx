处理自定义 PDF 文件。

## 简介

Netuno 通过 [PDF](/docs/library/resources/pdf) 资源生成支持图像、表格、字体等功能的 PDF 文件，该资源为 Netuno 支持的各种编程语言提供了 [iTextPDF](https://itextpdf.com/) 的低代码抽象。

Netuno 自带的 **demo** 应用（演示应用）包含大量各种语言可能实现的代码示例，其中包括通过位于以下位置的服务 `export-pdf` 导出 PDF 的演示：

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-pdf`
]} />

## 初始化

## 段落

向文档中添加一个新段落：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    _pdf.paragraph("我的文本...")
                        .setFontSize(15)
                )
            `
        },
    ]}
/>

要在固定位置添加段落：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    pdfDocument.add(
                        _pdf.paragraph("我的固定文本...")
                            .setFixedPosition(100, 500, 200)
                            .setFontSize(15)
                    )
                )
            `
        },
    ]}
/>

在上面的代码中，`setFixedPosition` 方法的第一个参数是 X 位置（`100`），第二个参数是 Y 位置（`500`），第三个参数是宽度（`200`）。

**注意：** 如果 Y 定义为值 `0`，表示位于页面底部；因此要向上移动，需要增大 Y 值。Y 值越大，显示位置越靠顶部；但如果过高而超出页面长度，则不可见。

> 包含 [iText 段落对象](https://api.itextpdf.com/iText/java/8.0.3/com/itextpdf/layout/element/Paragraph.html)所有方法的文档。

## 表格

可以创建表格，从而以更易读的方式呈现数据集。

表格的列数通过参数定义：`_pdf.table(列数)`

在下面的示例中，`列数` 为数字 `1`，即一列。

由于我们在表格中添加了两个单元格，因此第二个单元格会进入下一行。

请注意：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    _pdf.table(1)
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("人员")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBorder(_pdf.border("solid", 2))
                                .setBackgroundColor(_pdf.colorRGB(1, 0, 0))
                        )
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("妮可")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBackgroundColor(_pdf.colorGray(0.5))
                        )
                )
            `
        },
    ]}
/>

使用 `addCell` 方法可以插入单元格定义及其相应内容。

> 包含 [iText 单元格对象](https://api.itextpdf.com/iText/java//8.0.3/com/itextpdf/layout/element/Cell.html)所有方法的文档。

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.close()
            `
        },
    ]}
/>

文档的生成位置在初始化时定义，因此我们在文档初始化时定义最终文档的生成位置：是在服务的数据输出（`output`）中，还是在文件中。

## 读取文件

读取 PDF 文档并提取文本信息。

我们使用 `extract` 方法，它会将 PDF 文件的所有数据提取到一个 JSON 对象中。

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const pdfData = _pdf.extract(_app.file("文件-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'python',
            code: `
                pdfData = _pdf.extract(_app.file("文件-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'ruby',
            code: `
                pdfData = _pdf.extract(_app.file("文件-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'kotlin',
            code: `
                val pdfData = _pdf.extract(_app.file("文件-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'groovy',
            code: `
                def pdfData = _pdf.extract(_app.file("文件-1.pdf"))

                _out.json(pdfData)
            `
        },
    ]}
/>

返回的 JSON 中，`content` 键包含 PDF 文件的全部文本内容，`metadata` 键包含 PDF 文件的各种属性。

以下是 `extract` 返回的 JSON 示例：

```json
{
  "content": "PDF 文件的全部文本内容放在这里...",
  "metadata":{
    "Content-Type":"application/pdf",
    "dc:format":"application/pdf; version=1.4",
    "dc:title":"Linux 1",
    "pdf:PDFVersion":"1.4",
    "pdf:charsPerPage":"580",
    "pdf:containsDamagedFont":"false",
    "pdf:containsNonEmbeddedFont":"false",
    "pdf:docinfo:producer":"Skia/PDF m125 Google Docs Renderer",
    "pdf:docinfo:title":"文件 1",
    "pdf:encrypted":"false",
    "xmpTPg:NPages":"3",
    ...
  }
}
```

`metadata` 中还会获取许多其他数据，但为了不让示例过长，已在 `...` 中省略。

## 转换

可以通过编程方式将 PDF 转换为文本，甚至转换为 HTML。

### PDF 转文本

我们可以使用以下方法将 PDF 文件的所有内容提取为连续文本：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _pdf.toText(...)
            `
        },
    ]}
/>

使用该方法读取应用根目录中文件的示例：

<PolyglotCode
