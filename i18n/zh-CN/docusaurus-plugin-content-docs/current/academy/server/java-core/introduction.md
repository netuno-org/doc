Netuno 是基于 Java 开发的，因此我们可以借助 Java 创建新的功能。

例如，我们可以创建新的原生服务，甚至创建新的低代码编程资源，这些资源可在所有多语言编程语言中使用，例如 JavaScript、Python、Ruby、Groovy 和 Kotlin。

在 Java 中，我们还可以创建多应用 Web 服务，这些服务可在 Netuno 的所有应用中使用。

任何 Java 生态中的技术或库都可以用来创建任意类型的 功能。

> 我们建议在开始本教程之前，您最好具备一些 _Java_ 基础知识。
