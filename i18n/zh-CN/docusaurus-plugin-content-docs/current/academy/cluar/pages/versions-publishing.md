## 版本

每个页面都有一个或多个**版本**（`page_version`），每个版本都有自己的状态（草稿 / 已发布）。这样就能在不影响已发布内容的情况下编辑新版本的内容——只有当版本被标记为已发布时，它才会成为页面的活动版本。

内容组件（横幅、内容、列表、滑块、功能）始终属于某个特定版本（`page_version_id`），而不是直接属于页面。也就是说，在草稿版本中编辑某个组件不会影响已发布的内容。

## 发布

发布页面时，CLUAR 会：

1. 收集已发布版本中的所有活动组件（横幅、内容、列表、滑块、功能及其各自的操作）。
2. 用这些内容生成一个 JSON 结构文件。
3. 在生产环境中，为页面的 URL（按语言）预渲染一个静态 `index.html`，其中已填好 SEO 和 Open Graph 元标签——这对社交网络分享和搜索引擎很重要，因为网站本身是一个 React 单页应用（SPA）。
