如何创建和复用与组件关联的 CTA（按钮/链接）。

## 简介

**操作**本质上是一个可复用的 **CTA**（call-to-action，行动号召）——一个包含标题、文本、图像和目标地址（`link`）的按钮/链接——可关联到[组件](/docs/academy/cluar/components/overview)，如 Banner、内容、列表、Slider（在条目中）和功能。

## 字段

| 字段 | 描述 |
|---|---|
| **标题** (`title`) | 操作的标题，渲染为标题 (`<h4>`)。 |
| **内容** (`content`) | 操作的描述性文本，渲染为段落 (`<p>`)。 |
| **指示文本** (`indication`) | 链接/CTA 本身的文本——即显示在可点击按钮**内部**的文字（例如：“了解更多”、“立即购买”）。 |
| **图像** (`image`) | 与操作关联的图像（例如：图标）。 |
| **链接** (`link`) | 操作的目标地址（URL）——即点击 CTA 后前往的位置。 |
| **语言** (`language_id`) | 此操作所属的语言。 |
| **参数** (`parameter_id`) | 将此操作与其他语言中的对应操作归为一组——见下文。 |

## 参数

**参数**（`action_parameter`，仅包含 `código` 和 `descrição`）是一个分组机制：多个操作——每个操作位于其语言中，但代表**相同的功能/目标**——共享同一个参数。

这在将[页面克隆](/docs/academy/cluar/pages/cloning)到另一种语言时使用：对于与原页面组件关联的每个操作，CLUAR 会在现有操作中查找一个具有**相同参数**且处于克隆**目标语言**的操作。如果找到，就自动将该操作（已翻译版本）关联到克隆后的组件——之后无需手动添加。

:::info 需要先在目标语言中创建操作
自动关联仅在要克隆到的语言中已存在具有相同参数的操作时才会生效。如果尚不存在，该操作就不会关联到克隆后的组件——相当于未定义。也就是说，参数不会自动翻译或创建操作；它只会在各语言中已创建操作之后，将已有的等价操作关联起来。
:::

例如：一个葡萄牙语操作“Saiba mais”，参数为 `learn-more`，以及一个英语操作“Learn more”，参数同为 `learn-more`——将页面从葡萄牙语克隆到英语时，原本关联第一个操作的 Banner 会自动关联第二个操作。
