Netuno 是一个低代码平台，用于快速创建 Web 服务，通过集成的可视化界面简化数据管理，确保构建高性能的基于 Web 的应用程序。

它减少了开发所需的工作量和时间，也降低了行政、管理和工业领域的生产成本。

![Netuno 结构](/docs/assets/introducao1.png)

了解 Netuno 如何改善您的编程体验，让您的编程更具创造性而非重复性，并从开发到执行始终保持性能水平：

> Netuno 平台是免费的，[立即开始](/docs/get-started/installation)。

## 表单与字段

数据模型的创建通过 WEB 环境中的表单引擎得到简化。表单的定义会在数据库中生成表，其字段定义列。可以参数化数据类型、字段属性以及它们之间的关系。WEB 构建套件提供多种功能，例如数据库查询、实体-关联模型可视化等。

## 访问与权限管理

用户及其权限的管理可在 WEB 环境中配置，并可通过 Netuno 中的后端服务访问。还可以按用户和按组控制对表单和报表的访问。

## 资源库

资源库提供广泛的开箱即用功能。其中包括与 PDF、Excel、电子邮件、Firebase 的集成，甚至任务调度或使用 Jasper 的报表生成器。

## REST API

服务器的通信层通过 REST API 提供。通过 JSON 提供服务使 Netuno 能够与多种不同性质的应用程序通信，例如可以在同一接口上同时服务 WEB 客户端和移动应用。

## 多语言服务层

使用 <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>、<a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>、<a href="https://groovy-lang.org/" target="_blank">Groovy</a>、<a href="https://www.jython.org/" target="_blank">Python</a>、<a href="https://www.jruby.org/" target="_blank">Ruby</a>、<a href="https://kotlinlang.org/" target="_blank">Kotlin</a> 或 <a href="https://pt.wikipedia.org/wiki/Java_(linguagem_de_programa%C3%A7%C3%A3o)" target="_blank">Java</a> 编写服务，它们都是有效的。Netuno 消除了编程语言之间的隔离，同一个应用程序支持同时以多种语言运行服务，而不会增加处理负担。

## 多数据库

配置多个不同的数据库并同时使用它们。Netuno 原生支持多种关系型数据库引擎，如 <a href="https://www.h2database.com/html/main.html" target="_blank">H2DataBase</a>、<a href="https://www.postgresql.org/" target="_blank">PostgreSQL</a> 和 CockroachDB、<a href="https://mariadb.org/" target="_blank">MariaDB (_MySQL_)</a>、Microsoft SQL Server 和 Oracle。您可以例如使用 PostgreSQL 作为主数据库来创建应用程序，并与其他 MariaDB 数据库集成，而在项目进行中无需进行任何代码更改即可切换到 Microsoft SQL Server 或 Oracle。

> 原生支持与 MongoDB 集成。

## 无服务器

Netuno 也是您的应用服务器。只需一条命令即可运行您的应用程序，无需在许可、配置和额外开发上浪费时间。

## 开发与执行性能

您无需学习使用新的拖放式开发软件，也无需记住新框架的界面。凭借可以用 6 种不同语言编程、拥有自动生成的数据层以及可即时使用的库，Netuno 的低代码是应对紧迫截止日期的最佳解决方案。

利用针对高性能优化的代码生成器以及最新的 <a href="https://www.graalvm.org/" target="_blank">GraalVM</a>，应用服务器变得极其快速，无论您使用哪种语言。
