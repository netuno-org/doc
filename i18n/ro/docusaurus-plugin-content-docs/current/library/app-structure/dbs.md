Organizarea fișierelor bazei de date.

## Folder pentru baza de date

Folderul `📂 dbs` este destinat să păstreze fișierele bazei de date ale aplicației dvs.

În cazul bazelor de date de tip H2 Database, toate fișierele sunt generate automat în acest folder.

Acest folder este util pentru a păstra orice lucru legat de baza de date, de exemplu backup-uri, scripturi,
dump-uri, diagrame etc.

Toată documentația legată de baza de date care trebuie să însoțească proiectul aplicației este recomandat
să fie organizată în acest folder.
