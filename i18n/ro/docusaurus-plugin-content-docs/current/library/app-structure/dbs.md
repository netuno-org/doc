Organizarea fișierelor de baze de date.

## Folderul pentru baze de date

Folderul `📂 dbs` este destinat stocării fișierelor de baze de date ale aplicației dvs.

În cazul bazelor de date de tip H2 Database, toate fișierele sunt generate automat în acest folder.

Acest folder este util pentru a stoca orice legat de baze de date, de exemplu backup-uri, scripturi, dump-uri, diagrame etc.

Se recomandă ca toată documentația legată de baza de date, care trebuie să însoțească proiectul aplicației, să fie organizată în acest folder.
