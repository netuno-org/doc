Documentație și documente în general.

## Folderul Documentelor

În folderul `📂 docs` organizăm documentele generale ale aplicației.

Servește la organizarea fișierelor utile, cum ar fi documentație, design, arhitectură, integrări etc.

Orice lucru care este util pentru alte persoane ce lucrează și ele la dezvoltarea aplicației sau care este util în dezvoltarea de mentenanță ori evoluție.

Trebuie să țineți cont de faptul că fișierele binare prea mari pot polua și murdări definitiv repository-ul de cod, adică GIT. Pentru că orice fișier prea mare care ajunge în GIT crește considerabil istoricul modificărilor, astfel încât fișierele video, arhivele zip sau orice alt document foarte extins trebuie evitate pentru a nu supraîncărca GIT-ul și a crea neplăceri viitoare.
