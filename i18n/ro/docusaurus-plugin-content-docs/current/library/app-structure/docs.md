Documentație și documente în general.

## Folderul documentelor

În folderul `📂 docs` organizăm documentele generale ale aplicației.

Servește pentru organizarea fișierelor utile precum documentație, design, arhitectură, integrări etc.

Orice lucru care este util pentru celelalte persoane care lucrează de asemenea la dezvoltarea aplicației sau care este util în dezvoltarea pentru mentenanță ori evoluție.

Trebuie să țineți cont de faptul că fișierele binare prea mari pot polua și murdări definitiv repository-ul de cod, adică GIT. Deoarece orice fișier prea mare care ajunge în GIT crește considerabil istoricul modificărilor, așadar fișierele video, arhivele zip sau orice alt document foarte extins trebuie evitate pentru a nu supraîncărca GIT-ul și a crea constrângeri viitoare.
