Netuno este o platformă low-code pentru crearea rapidă de servicii web care facilitează gestionarea datelor printr-o interfață vizuală integrată, garantând crearea de aplicații bazate pe web cu performanță ridicată.

Reduce efortul și timpul de dezvoltare, precum și costurile de producție în domeniile administrație, management și industrial.

![Structura Netuno](/docs/assets/introducao1.png)

Aflați cum Netuno vă favorizează experiența de programare pentru a avea o programare creativă și nu repetitivă, menținând nivelurile de performanță de la dezvoltare până la execuție:

> Platforma Netuno este gratuită, [începeți acum](/docs/get-started/installation).

## Formulare și câmpuri

Crearea modelului de date este facilitată prin motorul de formulare în mediul WEB. Definirea formularelor dă naștere la tabele în baza de date, iar câmpurile lor definesc coloanele. Este posibil să parametrizați tipul de date, proprietățile câmpurilor, precum și relațiile acestora. _Suita_ de construcție WEB oferă diverse funcționalități, cum ar fi interogări către baza de date, vizualizarea Modelului Entitate-Asociere, printre altele.

## Gestionarea acceselor și permisiunilor

Gestionarea utilizatorilor și permisiunile acestora sunt configurabile în mediul WEB și sunt accesibile prin servicii backend în Netuno. De asemenea, este posibil să controlați accesul pe utilizator și pe grup la formulare și rapoarte.

## Biblioteca de resurse

Biblioteca de resurse prezintă o gamă largă de funcționalități gata de utilizare. Printre acestea puteți găsi de la integrări cu PDF, Excel, Email, Firebase până la programarea sarcinilor sau generator de rapoarte cu Jasper.

## API REST

Stratul de comunicare al serverului este furnizat prin API REST. Furnizarea serviciilor prin JSON permite Netuno să comunice cu multiple aplicații de natură diferită, putând, de exemplu, servi simultan clienți WEB și aplicații mobile prin aceeași interfață.

## Strat de servicii poliglot

Scrieți servicii în <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://groovy-lang.org/" target="_blank">Groovy</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a> sau în <a href="https://pt.wikipedia.org/wiki/Java_(linguagem_de_programa%C3%A7%C3%A3o)" target="_blank">Java</a>, toate sunt valabile. Netuno elimină izolarea dintre limbajele de programare, aceeași aplicație suportă servicii care rulează simultan în multiple limbaje fără ca acest lucru să crească greutatea procesării.

## Baze de date multiple

Configurați mai multe baze de date diferite și utilizați-le simultan. Nativ, Netuno suportă diverse motoare de baze de date relaționale precum <a href="https://www.h2database.com/html/main.html" target="_blank">H2DataBase</a>, <a href="https://www.postgresql.org/" target="_blank">PostgreSQL</a> și CockroachDB, <a href="https://mariadb.org/" target="_blank">MariaDB (_MySQL_)</a>, Microsoft SQL Server și Oracle. Veți putea crea aplicația folosind, de exemplu, PostgreSQL cu o bază de date principală și integra cu alte baze de date în MariaDB, iar la mijlocul unui proiect puteți trece la Microsoft SQL Server sau Oracle fără a fi nevoie să faceți nicio modificare de cod.

> Oferă suport nativ pentru integrarea cu MongoDB.

## Serverless

Netuno este, de asemenea, serverul aplicațional. Cu o singură comandă executați aplicația fără a pierde timp cu licențe, configurații și dezvoltări suplimentare.

## Performanță în dezvoltare și execuție

Nu trebuie să învățați să lucrați cu un software nou de dezvoltare prin drag and drop și nici să memorați interfața unui nou framework. Cu posibilitatea de a programa în 6 limbaje diferite, de a avea un strat de date generat automat și biblioteci disponibile pentru utilizare on-the-fly, low-code-ul Netuno este cea mai bună soluție pentru termenele dumneavoastră strânse.

Folosind generatoare de cod optimizate pentru performanță ridicată și cea mai recentă <a href="https://www.graalvm.org/" target="_blank">GraalVM</a>, serverul aplicațional devine incredibil de rapid, indiferent de limbajul pe care îl utilizați.
