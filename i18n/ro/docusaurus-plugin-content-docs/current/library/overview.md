Netuno este o platformă low-code pentru crearea rapidă de servicii web care facilitează gestionarea datelor cu o interfață vizuală integrată, garantând crearea de aplicații web cu performanță ridicată.

Reduce efortul și timpul de dezvoltare, precum și costurile de producție în domeniile administrației, gestiunii și industriei.

![Structura Netuno](/docs/assets/introducao1.png)

Aflați cum Netuno favorizează experiența dvs. de programare, astfel încât să aveți o programare creativă și nerepetitivă, menținând nivelurile de performanță de la dezvoltare până la execuție:

> Platforma Netuno este gratuită, [începeți acum](/docs/get-started/installation).

## Formulare și câmpuri

Crearea modelului de date este facilitată prin motorul de formulare în mediu WEB. Definirea formularelor generează tabele în baza de date, iar câmpurile lor definesc coloanele. Este posibil să parametrizați tipul de date, proprietățile câmpurilor, precum și relațiile acestora. _Suita_ de construcție WEB oferă diverse funcționalități, cum ar fi interogări către baza de date, vizualizarea Modelului Entitate-Asociere, printre altele.

## Gestionarea acceselor și permisiunilor

Gestionarea utilizatorilor și permisiunile acestora sunt configurabile în mediu WEB și sunt accesibile prin servicii de backend în Netuno. De asemenea, este posibil să controlați accesul pe utilizator și pe grup la formulare și rapoarte.

## Biblioteca de resurse

Biblioteca de resurse prezintă o gamă largă de funcționalități gata de utilizat. Printre acestea se pot găsi de la integratori cu PDF, Excel, Email, Firebase până la programarea sarcinilor sau generator de rapoarte cu Jasper.

## API REST

Stratul de comunicare al serverului este disponibilizat prin API REST. Disponibilizarea serviciilor prin JSON permite Netuno să comunice cu multiple aplicații de natură diferită, putând, de exemplu, servi simultan clienți WEB și aplicații mobile prin aceeași interfață.

## Strat de servicii poliglot

Scrieți servicii în <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://groovy-lang.org/" target="_blank">Groovy</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a> sau în <a href="https://pt.wikipedia.org/wiki/Java_(linguagem_de_programa%C3%A7%C3%A3o)" target="_blank">Java</a>, toate sunt valide. Netuno elimină izolarea dintre limbajele de programare, aceeași aplicație suportă servicii care rulează simultan în multiple limbaje fără a crește încărcarea procesării.

## Mai multe baze de date

Configurați mai multe baze de date diferite și utilizați-le simultan. În mod nativ, Netuno suportă diverse motoare de baze de date relaționale precum <a href="https://www.h2database.com/html/main.html" target="_blank">H2DataBase</a>, <a href="https://www.postgresql.org/" target="_blank">PostgreSQL</a> și CockroachDB, <a href="https://mariadb.org/" target="_blank">MariaDB (_MySQL_)</a>, Microsoft SQL Server și Oracle. Veți putea crea aplicația dvs. folosind, de exemplu, PostgreSQL cu o bază de date principală și integrând cu alte baze de date în MariaDB, iar la jumătatea unui proiect puteți trece la Microsoft SQL Server sau Oracle fără a fi nevoie să faceți vreo modificare de cod.

> Oferă suport nativ pentru integrarea cu MongoDB.

## Serverless

Netuno este, de asemenea, serverul dvs. de aplicații. Cu o singură comandă executați aplicația dvs. fără a pierde timp cu licențe, configurații și dezvoltări suplimentare.

## Performanță în dezvoltare și în execuție

Nu trebuie să învățați să lucrați cu un software nou de dezvoltare prin drag and drop, nici să memorizați interfața unei noi framework-uri. Cu posibilitatea de a programa în 6 limbaje diferite, de a avea un strat de date generat automat și biblioteci disponibile pentru a le folosi din mers, low-code-ul Netuno este cea mai bună soluție pentru termenele dvs. strânse.

Folosind generatoare de cod optimizate pentru performanță ridicată și recenta <a href="https://www.graalvm.org/" target="_blank">GraalVM</a>, serverul de aplicații devine incredibil de rapid, indiferent de limbajul pe care îl utilizați.
