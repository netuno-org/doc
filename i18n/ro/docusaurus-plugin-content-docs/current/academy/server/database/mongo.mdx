## Introducere

<a href="https://www.mongodb.com/" target="_blank">MongoDB</a> este o bază de date NoSQL orientată pe documente. În loc de tabele și rânduri, datele sunt stocate în documente în format similar cu JSON, ceea ce permite o mare flexibilitate în modelul datelor.

Netuno oferă resursa [_mongo](/docs/library/resources/mongo) pentru integrarea cu MongoDB, cu o abstractizare low-code peste clientul oficial MongoDB pentru Java, disponibilă pentru limbajele de programare suportate de Netuno: **JavaScript, Python, Ruby, Kotlin și Groovy**.

> Înainte de a continua, se recomandă să știți cum să creați servicii în Netuno; consultați tutorialul [REST - Servicii Web](/docs/academy/server/services/rest).

Un exemplu de implementare a operațiilor prezentate aici este disponibil în serviciul exemplu `mongo.js`, situat în:

## Instalarea MongoDB

### Cu Docker

Presupunând că aveți Docker instalat, este suficient să descărcați imaginea MongoDB și să porniți un container nou:

```shell
docker pull mongo
docker run -d --name mongo -p 27017:27017 mongo
```

Astfel, MongoDB devine accesibil la `localhost:27017` fără autentificare.

Pentru a crea utilizatorul bazei de date conform configurației aplicației, rulați:

```shell
docker exec -it mongo mongosh baza_produse --eval 'db.createUser({ user: "utilizator_produse", pwd: "12345678", roles: [{ role: "readWrite", db: "baza_produse" }] })'
```

### Cu Ubuntu

MongoDB nu este inclus în depozitele oficiale Ubuntu, așa că este necesar să adăugați depozitul oficial înainte de instalare:

```shell
sudo apt-get install gnupg curl
curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.asc | sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg --dearmor
echo "deb [ signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] http://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
sudo apt-get update
sudo apt-get install -y mongodb-org
```

După instalare, puteți porni serviciul cu:

```shell
sudo systemctl start mongod
```

### Cu Windows

- <a href="https://www.mongodb.com/try/download/community" target="_blank">Descărcați MongoDB Community Server</a>.

Rulați installerul descărcat și, la pasul **Service Configuration**, activați **Install MongoD as a Service** pentru ca MongoDB să pornească automat. MongoDB devine accesibil la `localhost:27017` fără autentificare.

> Consultați [documentația oficială MongoDB](https://www.mongodb.com/docs/manual/installation/) pentru alte distribuții și versiuni.

## Configurarea aplicației

Configurarea conexiunilor MongoDB se face în fișierul de configurare al aplicației, în funcție de mediu:

- `config/_development.json`

> Aflați mai multe despre [fișierele de configurare](/docs/academy/explore/configuration) ale aplicației.

În fișierul de configurare, adăugați blocul `mongo`, unde fiecare cheie identifică o conexiune:

```javascript
{
    ...
    "mongo": {
        "magazin": "mongodb://utilizator_magazin:12345678@localhost/baza_magazin",
        "produse": {
            "username": "utilizator_produse",
            "password": "12345678",
            "host": "127.0.0.1",
            "port": "27017",
            "database": "baza_produse"
        }
    },
    ...
}
```

O conexiune poate fi definită în două moduri:

- **Ca URL de conexiune** — valoarea este pur și simplu un string, de exemplu `"mongodb://utilizator_magazin:12345678@localhost/baza_magazin"`.
- **Ca obiect de configurare** — cu câmpurile:
  - `url` — dacă este definit, este utilizat direct ca URL de conexiune, ignorând celelalte câmpuri.
  - `protocol` — protocolul conexiunii, implicit `mongodb`.
  - `username` și `password` — credențialele de acces.
  - `host` — adresa serverului, implicit `localhost`.
  - `port` — portul conexiunii, implicit `27017`.
  - `database` — numele bazei de date, implicit numele cheii conexiunii.
  - `params` — parametri suplimentari ai conexiunii adăugați la URL, de exemplu `{ "authSource": "admin" }`. Sunt aplicați doar când URL-ul este construit din câmpurile obiectului.

> Conexiunea nu trebuie să fie baza de date principală a aplicației. Spre deosebire de configurația `db`, blocul `mongo` este independent și permite mai multe conexiuni simultan.

### Filtre

Fabrica `_mongo.filters()` oferă principalii operatori de interogare MongoDB:

| Operator | Descriere |
|---|---|
| `eq("câmp", valoare)` | Egal cu valoarea. |
| `ne("câmp", valoare)` | Diferit de valoare. |
| `gt("câmp", valoare)` | Mai mare decât valoarea. |
| `gte("câmp", valoare)` | Mai mare sau egal cu valoarea. |
| `lt("câmp", valoare)` | Mai mic decât valoarea. |
| `lte("câmp", valoare)` | Mai mic sau egal cu valoarea. |
| `in("câmp", valoare1, valoare2, ...)` | Egal cu oricare dintre valori. |
| `nin("câmp", valoare1, valoare2, ...)` | Diferit de toate valorile. |
| `and(filtru1, filtru2, ...)` | Se potrivește cu toate filtrele. |
| `or(filtru1, filtru2, ...)` | Se potrivește cu cel puțin unul dintre filtre. |
| `not(filtru)` | Nu se potrivește cu filtrul. |
| `regex("câmp", "model")` | Se potrivește cu expresia regulată. |
| `exists("câmp")` | Câmpul există în document. |
| `text("căutare")` | Căutare de text. |
| `type("câmp", "tip")` | Câmpul este de tipul specificat. |
| `mod("câmp", divizor, rest)` | Restul împărțirii câmpului la divizor este egal cu valoarea. |
| `where("expresie")` | Se potrivește cu documentele care satisfac o expresie JavaScript, de exemplu `"this.pret > 100"`. |
| `size("câmp", n)` | Câmpul de tip matrice are exact `n` elemente. |

Etapele de agregare disponibile sunt următoarele:

| Etapă | Descriere |
|---|---|
| `match(filtru)` | Selectează doar documentele care corespund filtrului. |
| `group("$câmp", acumulatori)` | Grupează documentele după câmp și aplică acumulatorii. |
| `project(proiecție)` | Adaugă, elimină sau modifică câmpuri în documente. |
| `sort(sortare)` | Sortează documentele. |
| `limit(n)` | Limitează la primele `n` documente. |
| `skip(n)` | Sare peste primele `n` documente. |
| `count()` | Numără documentele. |
| `lookup("colecție", "câmpLocal", "câmpStrăin", "ca")` | Execută un join cu o altă colecție. |

Iar acumulatorii cei mai utilizați:

| Acumulator | Descriere |
|---|---|
| `sum("câmp", "$expresie")` | Suma valorilor. |
| `avg("câmp", "$expresie")` | Media valorilor. |
| `min("câmp", "$expresie")` | Valoarea minimă. |
| `max("câmp", "$expresie")` | Valoarea maximă. |
| `first("câmp", "$expresie")` | Valoarea primului document. |
| `last("câmp", "$expresie")` | Valoarea ultimului document. |
| `top("câmp", sortare, "$expresie")` | Valoarea de top conform sortării. |
| `bottom("câmp", sortare, "$expresie")` | Valoarea de jos conform sortării. |

> În acumulatori, expresia cu prefixul `$` se referă la câmpul unui document de intrare, de exemplu `"$pret"`.

## Operații cu opțiuni

Fabricile `*Options()` ale resursei `_mongo` returnează obiectele de opțiuni implicite ale driverului MongoDB, iar puteți înlănțui metodele lor direct. De exemplu, `upsert(true)` inserează documentul când filtrul nu corespunde niciunui document existent:

    codes={[

                    _mongo.filters().eq("nume", "Monitor"),
                    _mongo.updates().set("cantitate", 8),
                    _mongo.findOneAndUpdateOptions().upsert(true)
                )
            `
        },
        {
            lang: 'python',
            code: `
                vechi = colectie.findOneAndUpdate(

                )
            `
        },
        {
            lang: 'ruby',
            code: `
                vechi = colectie.findOneAndUpdate(
                    _mongo.filters().eq("nume", "Monitor"),
                    _mongo.updates().set("cantitate", 8),

Fabricile de opțiuni disponibile sunt: `insertOneOptions()`, `insertManyOptions()`, `updateOptions()`, `findOneAndUpdateOptions()`, `replaceOptions()`, `findOneAndReplaceOptions()`, `deleteOptions()`, `findOneAndDeleteOptions()`, `countOptions()`, `estimatedDocumentCountOptions()`, `dropCollectionOptions()` și `textSearchOptions()`.

## Concluzie

Cu resursa `_mongo`, Netuno oferă o abstractizare low-code și poliglotă peste clientul oficial MongoDB pentru Java, permițând lucrul cu documente, filtre, sortări, proiecții, actualizări, indici și agregări în JavaScript, Python, Ruby, Kotlin și Groovy.

Pentru mai multe detalii despre toate metodele disponibile, consultați documentația resursei [_mongo](/docs/library/resources/mongo) și a clasei [MongoCollection](/docs/library/objects/MongoCollection).
