## Introducere

În codul de backend poliglot al platformei Netuno, putem manipula orice fișier sau folder.

Manipularea constă în a putea crea, redenumi și șterge fișiere și foldere, modifica conținutul fișierelor
și lista conținutul folderelor. În general, acestea sunt operațiile pe care de obicei trebuie să le facem programatic.

În platforma Netuno există resurse de programare low-code care permit manipularea folderelor și fișierelor
interne ale aplicației, dar și a oricăror fișiere și foldere din sistem în general, adică în afara aplicației.

Este util când trebuie să automatizăm un proces care trebuie să modifice vreun fișier oarecare, să vedem cum.

Resursele de programare poliglotă low-code care permit manipularea fișierelor sunt:

- `_app` - [Aplicație](/docs/library/resources/app)
- `_storage` - [Storage](/docs/library/resources/storage)
- `_os` - [Sistem de Operare](/docs/library/resources/os)

Prin aceste resurse avem metodele pentru:

- `.file` - Fișier existent.
- `.folder` - Folder existent.
- `.path` - Cale generică, poate fi atât un fișier, cât și un folder, care există sau nu există.

Cu aceste metode obținem un obiect de tip [File](/docs/library/objects/File), care oferă toate mijloacele pentru
manipularea fișierelor, folderelor și căilor în general, ceea ce permite realizarea operațiilor precum:

- Creare de fișiere și foldere.
- Ștergere de fișiere și foldere.
- Listare a conținutului folderelor.
- Redenumire de fișiere și foldere.
- Citire și scriere de date în fișiere.
- Eliminare de foldere și subfolderele și fișierele lor în mod recursiv.

## Aplicație

Pentru a realiza operațiile principale de manipulare a fișierelor și folderelor în structura aplicației,
folosim resursa `_app`:

#### Foldere în Aplicație

Garantează obținerea unui folder care există, de exemplu:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const folderulMeu = _app.folder("meu/folder")
            `
        },
    ]}
/>

#### Fișiere în Aplicație

Garantează obținerea unui fișier care există, de exemplu:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const fisierulMeu = _app.file("meu/folder/fisier.txt")
            `
        },
    ]}
/>

#### Căi în Aplicație

Obține o cale de fișier sau folder, independent de faptul că există sau nu, de exemplu:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const fisierNou = _app.path("meu/folder/fisier-nou.txt")
            `
        },
    ]}
/>

## Storage

Pentru a realiza operațiile principale de manipulare a fișierelor și folderelor în folderul `📁 storage` al aplicației,
folosim resursa `_storage`:

#### Foldere în Storage

Garantează obținerea unui folder care există, de exemplu:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                // Calea reală a folderului va fi:
                // storage/filesystem/server/meu/folder
                const storageFolderMeu = _storage.filesystem("server", "meu/folder")
                const folderulMeu = storageFolderMeu.folder()
            `
        },
    ]}
/>

#### Fișiere în Storage

Garantează obținerea unui fișier care există, de exemplu:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                // Calea reală a fișierului va fi:
                // storage/filesystem/server/meu/folder/fisier.txt
                const storageFisier = _storage.filesystem("server", "meu/folder", "fisier.txt")
                const fisier = storageFisier.file()
            `
        },
    ]}
/>

#### Căi în Storage

Obține o cale de fișier sau folder, independent de faptul că există sau nu, de exemplu:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                // Calea reală a noului folder va fi:
                // storage/filesystem/server/meu/folder-nou
                const storageFolder = _storage.filesystem("server", "meu/folder-nou")
                const folder = storageFolder.path()

                // Calea reală a noului fișier va fi:
                // storage/filesystem/server/meu/folder/fisier-nou.txt
                const storageFisier = _storage.filesystem("server", "meu/folder", "fisier-nou.txt")
                const fisier = storageFisier.path()
            `
        },
    ]}
/>

## Creare de Foldere

Metoda `mkdir` creează un folder.

În exemplul următor creează folderul specificat în rădăcina aplicației:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const folder = _app.path("temp")
                folder.mkdir()
            `
        },
    ]}
/>

Pentru a crea un subfolder în folderul existent, indicați calea completă separând ierarhia de
foldere cu `/`:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const subfolder = _app.path("temp/alta")
                subfolder.mkdir()
            `
        },
    ]}
/>

Iar `mkdirs` creează folderele anterioare și/sau subfolderele dacă nu există, astfel permite crearea unei structuri
de foldere în aplicație, de exemplu:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const caleFoldere = _app.path("temp/a/b/c")
                caleFoldere.mkdirs()
            `
        },
    ]}
/>

Resursa `_storage` are metoda [ensurePath](/docs/library/resources/storage#ensurepath) care verifică dacă
calea există, iar dacă nu există atunci o creează:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const fisier = _storage.filesystem(
                    "public",
                    "temp/subfolder",
                    "fisier.txt"
                )
                // Creează structura de foldere dacă nu există:
                fisier.ensurePath()
            `
        },
    ]}
/>

Prin urmare, `ensurePath` garantează că structura de foldere există.

## Eliminare de Fișiere și Foldere

Cu metoda `delete` putem elimina atât foldere, cât și fișiere, însă folderele trebuie să fie goale,
vedeți exemplul:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                // Elimină un folder gol:
                const folderGol = _app.folder("folder/gol")
                folderGol.delete()

                // Elimină un fișier:
                const fisier = _app.file("folder/fisier.txt")
                fisier.delete()

                // Elimină o cale, folder gol sau fișier:
                const cale = _app.path("folder1/fisier-sau-folder-gol")
                cale.delete()
            `
        },
    ]}
/>

Cu `deleteAll` se permite eliminarea a tot, adică toate fișierele, folderele și subfolderele în mod recursiv:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                // Elimină folderul și tot conținutul recursiv:
                const folderGol = _app.folder("folder/exemplu")
                folderGol.deleteAll()

                // Elimină calea unui folder și tot conținutul său intern,
                // inclusiv subfoldere și fișiere:
                const cale = _app.path("cale/folder")
                cale.deleteAll()
            `
        },
    ]}
/>

Pentru a elimina doar fișierele din interiorul folderului și a nu șterge nimic din subfoldere, avem `deleteFiles`, care permite
primirea unei extensii dacă doriți să eliminați doar fișierele cu o extensie specifică:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                // Elimină fișierele doar din interiorul folderului:
                const folder = _app.folder("folder/exemplu")
                folder.deleteFiles()

                // Elimină fișierele cu extensia JPG doar din interiorul folderului:
                const cale = _app.path("cale/folder")
                cale.deleteFiles("jpg")
`
        },
    ]}
/>

Pentru a elimina doar fișierele în mod recursiv și a menține structura de foldere, avem `deleteAllFiles`, care
de asemenea permite primirea unei extensii dacă doriți să eliminați doar un tip specific de fișier, vedeți aceste două
exemple:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                // Elimină toate fișierele din folder și subfoldere:
                const folder = _app.folder("folder/exemplu")
                folder.deleteAllFiles()

                // Elimină toate fișierele cu extensia JPG din folder și subfoldere:
                const cale = _app.path("cale/folder")
                cale.deleteAllFiles("jpg")
            `
        },
    ]}
/>

## Redenumire sau Mutare

Pentru a muta un folder, este același lucru cu a-l redenumi:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const folder = _app.folder("temp")
                folder.renameTo("test")
            `
        },
    ]}
/>

Pentru a redenumi un folder și a-l muta la alt nivel în ierarhia de foldere, este același lucru cu a muta folderul:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const folder = _app.folder("temp/a/b")
                folder.renameTo("test/z")
            `
        },
    ]}
/>

Și pentru a muta un subfolder fără a-i schimba numele, este suficient să indicați noua cale în metoda `renameTo`:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const folder = _app.folder("test/alta")
                folder.renameTo("alta")
            `
        },
    ]}
/>

## Salvarea Conținuturilor în Fișiere

Generarea conținuturilor în fișiere se face prin metoda `output` care furnizează un obiect de tip
[OutputStream](/docs/library/objects/OutputStream).

Pentru a scrie datele în `output` folosim metoda [printAndClose](/docs/library/objects/OutputStream#printandclose),
care scrie conținutul în fișier și închide fișierul salvând conținutul.

#### Scrierea unui Fișier Text

Vedeți exemplul despre cum să creați un fișier cu conținut text:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _app.path("temp").mkdir()
                const scriere = _app.path("temp/fisier.txt").output()
                scriere.printAndClose("Textul meu aici...")
            `
        },
    ]}
/>

> De fiecare dată când folosim `output` este generat un fișier nou, prin urmare dacă rulați din nou codul, fișierul
> va fi recreat.

#### Scrierea unui Fișier JSON

Vedeți cum putem salva date JSON în fișiere:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _app.path("temp").mkdir()
                const scriere = _app.path("temp/client.json").output()
                scriere.printAndClose(
                    _val.map()
                        .set("nume", "Maria Ioana")
                        .set(
                            "inregistrari",
                            _val.list()
                                .add(1).add(2).add(3)
                        )
                        .toJSON()
                )
            `
        },
    ]}
/>

Pentru a genera JSON indentat, adică formatat pe mai multe linii și tabulat, putem pasa numărul de spații
cu care se va face tabularea, de exemplu `.toJSON(4)`.

> Mai multe detalii despre metoda [toJSON în Values](/docs/library/objects/Values#tojsonindentfactor-int--string).

## Citirea Conținuturilor din Fișiere

Obținerea conținuturilor din fișiere se face prin metoda `input` care furnizează un obiect de tip
[InputStream](/docs/library/objects/InputStream).

Pentru a citi datele din `input` folosim metoda [readAllAndClose](/docs/library/objects/InputStream#readallandclose),
care procesează citirea conținutului din fișier și închide fișierul.

#### Citirea unui Fișier Text

Vedeți exemplul despre cum să citiți un fișier și să obțineți conținutul text:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const fisier = _app.file("temp/fisier.txt")
                const citire = fisier.input()
                _log.info(citire.readAllAndClose())
            `
        },
    ]}
/>

#### Citirea unui Fișier JSON

Vedeți cum putem procesa date JSON obținute din fișiere:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const fisier = _app.file("temp/fisier.txt")
                const citire = fisier.input()
                const date = _val.fromJSON(citire.readAllAndClose())
                _log.info("Date din Fișier:", date)
            `
        },
    ]}
/>

> Mai multe detalii despre metoda [fromJSON a resursei Val](/docs/library/resources/val#fromjson).

## Particularități ale Storage

Resursa storage are câteva metode pentru utilizare directă.

De exemplu, putem accesa prin storage:

- [Storage Output](/docs/library/resources/storage#output)
- [Storage Input](/docs/library/resources/storage#input)

Aceasta înseamnă că nu trebuie să obținem `file` sau `path` pentru a lucra cu `input` sau `output`.

#### Scrierea unui Fișier Text în Storage

La inițierea unui storage pentru un fișier putem realiza scrierea folosind metoda [output](/docs/library/resources/storage#output), care obține
o instanță a obiectului [OutputStream](/docs/library/objects/OutputStream) care permite procesarea și citirea datelor.

Apoi, cu `OutputStream`, metoda [printAndClose](/docs/library/objects/OutputStream#printandclose),
face scrierea de text (`string`) în fișier și îl închide.

Vedeți acest exemplu:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const txt = _storage.filesystem("server", "temp", "fisier.txt")
                txt.ensurePath()
                txt.output().printAndClose("Textul meu aici...")
            `
        },
    ]}
/>

#### Citirea unui Fișier Text în Storage

La inițierea unui storage pentru un fișier putem realiza citirea folosind metoda [input](/docs/library/resources/storage#input), care obține
o instanță a obiectului [InputStream](/docs/library/objects/InputStream) care permite procesarea și citirea datelor.

Apoi, cu `InputStream`, metoda [readAllAndClose](/docs/library/objects/InputStream#readallandclose),
face citirea întregului fișier și îl închide, returnând datele ca text (`string`).

Vedeți acest exemplu:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const txt = _storage.filesystem("server", "temp", "fisier.txt")
                _log.info(txt.input().readAllAndClose())
            `
        },
    ]}
/>

#### Crearea unui Fișier Aleatoriu în Storage

Resursa `_storage` permite generarea de nume de fișiere aleatorii, cu metoda [newRandomFile](/docs/library/resources/storage#newrandomfile).

Trebuie să inițiați un storage pentru calea unui folder, iar la executarea metodei `newRandomFile` se passează extensia
fișierului dorit.

Metoda returnează o nouă instanță de storage pentru fișierul aleatoriu generat automat, pentru a fi
utilizat în folderul inițial.

Vedeți cum să generați un fișier cu extensia `TXT` cu nume aleatoriu:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const folder = _storage.filesystem("server", "temp")
                const fisier = folder.newRandomFile("txt")
                fisier.output().printAndClose("Textul meu aici...")
            `
        },
    ]}
/>

## Concluzie

Cu framework-ul low-code poliglot al Netuno putem realiza toate operațiile principale cu foldere și fișiere
direct.

Când utilizați resursele specifice pentru manipularea fișierelor și folderelor în:

- `_app` - Aplicație
- `_storage` - Storage al Aplicației
- `_os` - Sistem de Operare

> Din motive de bune practici și organizare, trebuie să prioritizăm utilizarea **storage-ului**, excepțiile trebuie să fie
> doar cazuri punctuale și strict necesare.

Netuno procesează închiderea automată a input-urilor și output-urilor la sfârșitul procesării serviciilor, dar pentru bune
practici ar trebui să încercăm să le închidem întotdeauna.
