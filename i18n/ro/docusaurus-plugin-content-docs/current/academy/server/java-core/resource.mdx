În acest tutorial vom crea o resursă nativă pentru Netuno. Aceasta înseamnă că vom crea o clasă în Java care va fi în directorul de bază al Netuno și care va putea fi utilizată de orice aplicație din folderul `apps` folosind sintaxa `_foo.methodName(ars)`.

Exemplul pe care îl vom crea, urmând tutorialele anterioare, este resursa `_calculator`, care este o resursă exemplu pentru a executa operații aritmetice simple.

Pentru a începe, mai întâi este necesar să creăm structura de foldere a proiectului. În acest exemplu vom considera că proiectul va fi creat într-un folder numit `Calculator`. Atunci este necesar să creăm structura de foldere care oglindește numele pachetului (în exemplul nostru, `org.netuno.addon.calculator`). Structura noastră de foldere va fi așadar:

- `Calculator/src/main/java/org/netuno/addon/calculator/resource/`

În această structură vom crea o clasă Java numită `CalculatorResource`, care va defini resursa noastră nativă personalizată.

- ` Calculator/src/main/java/org/netuno/addon/calculator/resource/CalculatorResource.java`

Atunci pachetul definit în cadrul clasei va fi:

```java
package org.netuno.addon.calculator.resource;
```

Pentru ca clasa să definească o resursă nativă personalizată, această clasă trebuie să fie adnotată cu adnotarea `org.netuno.tritao.ResourceBase`. Parametrul `name` va fi numele resursei care poate fi accesată cu un underscore (`_`) înainte de nume (în cazul nostru, `_calculator`). Cel mai simplu mod de a crea resursa este extinzând clasa `org.netuno.tritao.resource.ResourceBase`:

```java
package org.netuno.addon.calculator.resource;

import org.netuno.tritao.resource.Resource;
import org.netuno.tritao.resource.ResourceBase;

@Resource(name = "calculator")
public class CalculatorResource extends ResourceBase {
    // ...
}
```

Extinderea clasei `ResourceBase` ne scutește de a mai inițializa resursa, fiind suficient să apelăm `super` cu argumentele corecte:

```java
package org.netuno.addon.calculator.resource;

import org.netuno.proteu.Proteu;
import org.netuno.tritao.hili.Hili;
import org.netuno.tritao.resource.Resource;
import org.netuno.tritao.resource.ResourceBase;

@Resource(name = "calculator")
public class CalculatorResource extends ResourceBase {
    // ...
    public CalculatorResource(Proteu proteu, Hili hili) {
        super(proteu, hili);
    }
}
```

Funcția `init` este obligatorie, iar în cadrul ei vom inițializa resursa apelând constructorul clasei noastre cu getterii clasei părinte:

```java
package org.netuno.addon.calculator.resource;

import org.netuno.proteu.Proteu;
import org.netuno.tritao.hili.Hili;
import org.netuno.tritao.resource.Resource;
import org.netuno.tritao.resource.ResourceBase;

@Resource(name = "calculator")
public class CalculatorResource extends ResourceBase {
    // ...
    public CalculatorResource(Proteu proteu, Hili hili) {
        super(proteu, hili);
    }

    public CalculatorResource init() {
        return new CalculatorResource(getProteu(), getHili());
    }
}
```

După aceea vom defini propriile noastre câmpuri și funcții:

```java
package org.netuno.addon.calculator.resource;

import org.netuno.proteu.Proteu;
import org.netuno.tritao.hili.Hili;
import org.netuno.tritao.resource.Resource;
import org.netuno.tritao.resource.ResourceBase;

@Resource(name = "calculator")
public class CalculatorResource extends ResourceBase {
    public double valoare = 0;

    public CalculatorResource(Proteu proteu, Hili hili) {
        super(proteu, hili);
    }

    public CalculatorResource init() {
        return new CalculatorResource(getProteu(), getHili());
    }

    public CalculatorResource seteaza(double v) {
        valoare = v;
        return this;
    }

    public CalculatorResource adauga(double v) {
        valoare += v;
        return this;
    }

    public CalculatorResource scade(double v) {
        valoare -= v;
        return this;
    }

    public double obtine() {
        return valoare;
    }
}
```

Acum trebuie doar să compilați clasa, asigurându-vă că fișierul `CalculatorResource.class` este în folderul:

- `netuno/core/web/WEB-INF/classes/org/netuno/addon/calculator/resource/`

Sau să produceți un fișier JAR, asigurându-vă că acesta este în folderul:

- `netuno/lib/`

Vom crea o aplicație de test pentru a folosi această resursă:

```bash
./netuno app name=calculator
```

Vom crea de asemenea un serviciu în această aplicație pentru a folosi resursa.
În exemplu, vom crea fișierul `netuno/apps/calculator/server/services/calculator-test.js`:

<PolyglotCode

Vom porni aplicația noastră:

```bash
./netuno server app=calculator
```

Și acum, când vom face un apel către acest serviciu:

- `http://localhost:9000/services/calculator-test`

Acesta va returna valoarea `130`.

Pentru a folosi o resursă în codul Java, unele clase precum `org.netuno.tritao.Web`
și `org.netuno.tritao.event.EventBase` oferă funcția `resource`, care inițializează această resursă.
În clasa în care doriți să folosiți resursa `calculator`, faceți:

```java
import org.netuno.addon.calculator.resource.CalculatorResource;

// ...
    CalculatorResource calculator = resource(CalculatorResource.class);
    calculator.seteaza(10);
    calculator.adauga(120);
    System.out.println(calculator.obtine());
// ...
```
