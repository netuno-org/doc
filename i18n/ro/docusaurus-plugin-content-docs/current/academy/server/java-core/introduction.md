Netuno este dezvoltat în Java, astfel încât din Java putem crea noi funcționalități.

De exemplu, putem crea noi servicii native, sau chiar noi resurse de programare low-code care sunt disponibile în toate limbajele de programare poliglot, cum ar fi JavaScript, Python, Ruby, Groovy și Kotlin.

În Java putem crea, de asemenea, servicii web multi-aplicație care sunt disponibile în toate aplicațiile Netuno.

Orice tehnică sau bibliotecă din ecosistemul Java poate fi utilizată pentru a crea orice tip de funcționalitate.

> Vă recomandăm ca înainte de a începe acest tutorial să aveți unele noțiuni de bază de _Java_.
