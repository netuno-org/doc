Netuno este dezvoltat în Java, așa că pornind de la Java putem crea funcționalități noi.

De exemplu, putem crea servicii native noi sau chiar resurse noi de programare low-code care sunt disponibile în toate limbajele de programare poliglote, precum JavaScript, Python, Ruby, Groovy și Kotlin.

În Java putem, de asemenea, să creăm servicii web multi-aplicaționale care sunt disponibile în toate aplicațiile Netuno.

Orice tehnică sau bibliotecă din ecosistemul Java poate fi utilizată pentru a crea orice tip de funcționalitate.

> Vă recomandăm ca, înainte de a începe acest tutorial, să aveți câteva noțiuni de bază de _Java_.
