Încărcați și descărcați fișiere, gestionați dosare la distanță.

## Introducere

Netuno are integrat în framework-ul său low-code un client FTP, care permite conectarea la servere, trimiterea și
primirea fișierelor, modificarea dosarelor, printre alte operații la distanță.

Suportă multiple conexiuni simultane și, de asemenea, FTPS.

Acest lucru se datorează implementării Java și open-source [Apache Commons Net](https://github.com/apache/commons-net), care
permite Netuno să ofere aceste funcționalități în toate limbajele de _script_ prin intermediul resursei `_ftp`.

> Mai multe despre resursa [FTP](/docs/library/resources/ftp) din Netuno.

## Configurare

Primul pas va fi configurarea datelor de acces FTP pe care Netuno le va utiliza pentru a realiza conexiunea.

Navigați în cadrul aplicației pe care o dezvoltați până la fișierul de configurare a mediului. În acest exemplu,
vom utiliza fișierul de mediu de dezvoltare localizat în:

- `config/_development.json`

Verificați dacă nu conține deja configurațiile pentru FTP; dacă acestea nu există încă, atunci la sfârșitul fișierului de
configurare (în format JSON) adăugați parametrii de configurare FTP:

```json title="config/_development.json"
{
  ...
  "ftp": {
    "default": {
      "enabled": true,
      "host": "serverul.meu.net",
      "port": 21,
      "username": "temp",
      "password": "$eCr37"
    }
  },
  ...
}
```

După salvarea modificărilor, este suficient să reporniți Netuno pentru a prelua modificările de configurare. Acestea sunt
configurațiile implicite pentru conexiune, după cum indică numele `default`.

Puteți adăuga mai multe configurații de conexiune FTP, dar doar una poate fi definită ca implicită.

Pentru a adăuga mai multe configurații de conexiune FTP, este suficient să repetați blocul de configurare implicit și să înlocuiți numele
`default` cu un alt nume ales de dvs.; vedeți exemplul:

```json title="config/_development.json"
{
  ...
  "ftp": {
    "default": {
      "enabled": true,
      "host": "serverul.meu.net",
      "port": 22,
      "username": "temp",
      "password": "$eCr37"
    },
    "altul": {
      "enabled": true,
      "host": "serverul.alt.net",
      "port": 22,
      "username": "temp",
      "password": "$eCr37"
    }
  },
  ...
}
```

O configurație similară exemplului de mai sus va permite utilizarea contului default atunci când este apelată în cod după cum urmează:

## Conexiune

Înainte de a face orice, este necesar să inițiați conexiunea FTP:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                ftp.connect()
            `
        },
    ]}
/>

## Director de lucru

Când efectuați operații pe FTP, este necesar să definiți ce dosar va fi utilizat.

Prin definirea directorului de lucru vom putea realiza diversele manipulări pornind de la acest dosar de bază.

Pentru a schimba directorul de lucru:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                ftp.changeWorkingDirectory("dosar/meu/de/baza")
            `
        },
    ]}
/>

Acum orice operație va fi efectuată în acest dosar sau pornind de la el.

## Crearea și ștergerea dosarelor

Pentru a crea un dosar, este suficient să indicați calea acestui dosar:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                ftp.createDirectory("dosar-temporar")
                ftp.createDirectory("dosar-temporar/sub-dosar")
            `
        },
    ]}
/>

Pentru a șterge sau elimina dosare:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                ftp.deleteDirectory("dosar-temporar/sub-dosar")
                ftp.deleteDirectory("dosar-temporar")
            `
        },
    ]}
/>

## Redenumire

Este posibil să redenumiți fișiere sau dosare; se transmite calea veche și apoi noua cale:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                ftp.rename("nume-vechi", "nume-nou")
            `
        },
    ]}
/>
