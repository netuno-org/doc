Procesarea fișierelor PDF personalizate.

## Introducere

Netuno generează fișiere PDF cu suport pentru imagini, tabele, fonturi și multe altele, prin resursa [PDF](/docs/library/resources/pdf) care permite o abstractizare low-code a [iTextPDF](https://itextpdf.com/) pentru diversele limbaje de programare acceptate de Netuno.

Aplicația care vine împreună cu Netuno, denumită **demo** (aplicație de demonstrație), conține numeroase exemple de implementări de cod în diverse limbaje, inclusiv demonstrația exportului în PDF prin serviciul `export-pdf`, care se află în:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-pdf`
]} />

## Inițializare

În primul rând, este necesar să se creeze obiectul care va conține contextul noului document ce este creat; în mod implicit, dimensiunea paginilor este A4.

## Antet HTTP

Exemplu de definire a conținutului ca PDF:

## Paragraf

Adaugă un paragraf nou în document:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentPdf.add(
                    _pdf.paragraph("Textul meu aici...")
                        .setFontSize(15)
                )
            `
        },
    ]}
/>

Pentru a adăuga un paragraf într-o poziție fixă:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentPdf.add(
                    documentPdf.add(
                        _pdf.paragraph("Textul meu fix...")
                            .setFixedPosition(100, 500, 200)
                            .setFontSize(15)
                    )
                )
            `
        },
    ]}
/>

În codul de mai sus, în metoda `setFixedPosition`, primul parametru este poziția X (`100`), al doilea parametru este poziția Y (`500`), iar al treilea parametru este lățimea (`200`).

**Atenție:** dacă Y este definit cu valoarea `0`, înseamnă că se află în partea de jos a paginii; prin urmare, pentru a urca trebuie crescută valoarea lui Y; cu cât valoarea lui Y este mai mare, cu atât va apărea mai sus, dar dacă este prea mare dincolo de lungimea paginii, atunci nu va fi vizibil.

> Documentație cu toate metodele obiectului [Paragraf din iText](https://api.itextpdf.com/iText/java/8.0.3/com/itextpdf/layout/element/Paragraph.html).

## Tabel

Este posibil să se creeze tabele, ceea ce permite prezentarea unui set de date într-o formă mai lizibilă.

Numărul de coloane al tabelului este definit cu parametrul: `_pdf.table(numarColoane)`

În exemplul de mai jos, `numarColoane` este numărul `1`, adică o coloană.

Deoarece adăugăm două celule în tabel, a doua celulă trece pe linia următoare.

Observați:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentPdf.add(
                    _pdf.table(1)
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Persoană")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBorder(_pdf.border("solid", 2))
                                .setBackgroundColor(_pdf.colorRGB(1, 0, 0))
                        )
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Nicole")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBackgroundColor(_pdf.colorGray(0.5))
                        )
                )
            `
        },
    ]}
/>

Metoda `addCell` permite inserirea definiției celulelor împreună cu conținutul lor respectiv.

> Documentație cu toate metodele obiectului [Celulă din iText](https://api.itextpdf.com/iText/java//8.0.3/com/itextpdf/layout/element/Cell.html).

## Închiderea și salvarea documentului

Documentul este salvat sau generat complet doar atunci când este apelată metoda `close`, astfel:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentPdf.close()
            `
        },
    ]}
/>

Locul unde este generat documentul este definit la inițializare; prin urmare, la inițializarea documentului definim unde va fi generat documentul final, fie în ieșirea de date a serviciului (`output`), fie într-un fișier.

## Citirea fișierului

Pentru a citi un document PDF, extrăgând informațiile text.

Utilizăm metoda `extract`, care obține toate datele fișierului PDF într-un obiect JSON.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const datePdf = _pdf.extract(_app.file("fișier-1.pdf"))

                _out.json(datePdf)
            `
        },
        {
            lang: 'python',
            code: `
                datePdf = _pdf.extract(_app.file("fișier-1.pdf"))

                _out.json(datePdf)
            `
        },
        {
            lang: 'ruby',
            code: `
                datePdf = _pdf.extract(_app.file("fișier-1.pdf"))

                _out.json(datePdf)
            `
        },
        {
            lang: 'kotlin',
            code: `
                val datePdf = _pdf.extract(_app.file("fișier-1.pdf"))

                _out.json(datePdf)
            `
        },
        {
            lang: 'groovy',
            code: `
                def datePdf = _pdf.extract(_app.file("fișier-1.pdf"))

                _out.json(datePdf)
            `
        },
    ]}
/>

JSON-ul returnat are cheia `content` cu tot conținutul text al fișierului PDF și are cheia `metadata` cu diversele proprietăți ale fișierului PDF.

Iată un exemplu de JSON returnat de `extract`:

```json
{
  "content": "Tot conținutul text al fișierului PDF apare aici...",
  "metadata":{
    "Content-Type":"application/pdf",
    "dc:format":"application/pdf; version=1.4",
    "dc:title":"Linux 1",
    "pdf:PDFVersion":"1.4",
    "pdf:charsPerPage":"580",
    "pdf:containsDamagedFont":"false",
    "pdf:containsNonEmbeddedFont":"false",
    "pdf:docinfo:producer":"Skia/PDF m125 Google Docs Renderer",
    "pdf:docinfo:title":"Fișier 1",
    "pdf:encrypted":"false",
    "xmpTPg:NPages":"3",
    ...
  }
}
```

Există multe alte date obținute în `metadata`, dar care au fost omise în `...` pentru ca exemplul să nu devină prea lung.

## Conversie

Este posibil să convertiți programatic PDF-ul în text sau chiar în HTML.

### PDF în text

Putem extrage tot conținutul fișierului PDF în text continuu utilizând metoda:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `

            `
        },
    ]}
/>

Exemplu de utilizare pentru a citi un fișier din rădăcina aplicației:

<PolyglotCode
