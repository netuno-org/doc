Procesați fișiere Excel personalizate.

## Introducere

Netuno generează fișiere EXCEL compatibile cu LibreOffice, OpenOffice, Microsoft Office, Google Drive etc., prin resursa [XLS](/docs/library/resources/xls) care permite o abstractizare low-code a [Apache POI](https://poi.apache.org/) pentru diferitele limbaje de programare acceptate de Netuno.

Putem genera atât fișiere XLSX, XLS, cât și ODS.

Aplicația care vine cu Netuno numită **demo** (aplicație de demonstrație) conține numeroase exemple de posibile implementări de cod în diverse limbaje, inclusiv demonstrația exportului de foi de calcul prin serviciul `export-excel` care se află în:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-excel`
]} />

## Inicializare

Pentru a inițializa resursa XLS:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const excel = _xls.create()
            `
        },
    ]}
/>

Creează obiectul care conține contextul noului fișier ce va fi construit, cu o foaie de calcul goală.

## Formatare

Definirea stilurilor de formatare vizuală, adică formatul de date, ore, bani, printre altele, trebuie făcută înainte de definirea valorilor celulelor, deoarece la definirea valorilor celulelor este posibil să se asocieze și stilul lor de formatare.

Așadar, după cum se demonstrează în exemplul care vine în aplicația `demo`, formatările sunt definite chiar la începutul codului.

Pentru a formata date:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const stilData = excel.cellStyleFormat("dd/mm/yy")
            `
        },
    ]}
/>

Pentru a formata ore:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const stilOra = excel.cellStyleFormat("hh:mm:ss")
            `
        },
    ]}
/>

Pentru a formata date cu ore:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const stilDataOra = excel.cellStyleFormat("dd/mm/yyyy hh:mm:ss")
            `
        },
    ]}
/>

Pentru a formata valori bănești în **euro**:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const stilBaniEuro = excel.cellStyleFormat("€#,##0.00;\\-€#,##0.00")
            `
        },
    ]}
/>

Pentru a formata valori bănești în **reali**:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const stilBaniReal = excel.cellStyleFormat("R$#,##0.00;\\-R$#,##0.00")

    ]}
/>

Pentru a formata valori în **procent**:

<PolyglotCode
    codes={[
        {

## Aspect

Definirea stilurilor de aspect vizual, adică aspectul celulelor precum culori, font, borduri, aliniere etc., trebuie făcută înainte de definirea valorilor celulelor, deoarece la definirea valorilor celulelor este posibil să se asocieze și stilul lor de aspect.

Așadar, după cum se demonstrează în exemplul care vine în aplicația `demo`, aspectele sunt definite chiar la începutul codului.

Exemplu pentru definirea culorilor și alinierii:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const stilAntet = excel.cellStyle()
                stilAntet.setFillPattern(_xls.fillPattern("solid-foreground"))
                stilAntet.setFillBackgroundColor(excel.color("black"))
                stilAntet.setAlignment(_xls.horizontalAlignment("center"))
            `
        },
    ]}
/>

> Documentație cu toate metodele obiectului de <a href="https://poi.apache.org/apidocs/dev/org/apache/poi/hssf/usermodel/HSSFCellStyle.html" target="_blank">Stiluri în Apache POI</a>.

Definirea stilului de borduri:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const stilDate = excel.cellStyle()
                stilDate.setBorderBottom(_xls.borderStyle("thin"))
                stilDate.setBorderTop(_xls.borderStyle("thin"))
                stilDate.setBorderLeft(_xls.borderStyle("thin"))
                stilDate.setBorderRight(_xls.borderStyle("thin"))
            `
        },
    ]}
/>

> Documentație cu toate metodele obiectului de <a href="https://poi.apache.org/apidocs/dev/org/apache/poi/hssf/usermodel/HSSFCellStyle.html" target="_blank">Stiluri în Apache POI</a>.

Creează un stil nou de font pentru text, asociază definițiile fontului cu un anumit stil de celulă deja existent:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const fontTitlu = excel.font()
                fontTitlu.setBold(true)
                fontTitlu.setFontHeightInPoints(14)
                fontTitlu.setColor(excel.color("yellow"))
                // Definește fontul pentru stilAntet
                stilAntet.setFont(fontTitlu)
            `
        },
    ]}
/>

> Documentație cu toate metodele obiectului de <a href="https://poi.apache.org/apidocs/dev/org/apache/poi/hssf/usermodel/HSSFFont.html" target="_blank">Font în Apache POI</a>.

## Îmbinare celule

Pentru a uni celule într-o regiune folosim metoda `mergedRegion`.

Ordinea parametrilor este:

1. Linia inițială
2. Coloana inițială
3. Linia finală
4. Coloana finală

> Referințele numerice de poziționare încep întotdeauna de la **zero**.

În acest exemplu de mai jos vor fi îmbinate toate celulele de la coloana 10 până la coloana 15 care se află pe linia 3:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.mergedRegion(2, 9, 2, 14)
            `
        },
    ]}
/>

## Inserare date tabelare

Putem insera un tabel de date folosind metoda `addDataTable`.

Deoarece primii doi parametri definesc poziția unde trebuie inserat tabelul de date, ei sunt numerele liniilor și coloanelor.

> Atenție, poziționarea în cod a liniilor și coloanelor începe întotdeauna de la **zero**.
>
> Adică, Linia 1 este poziția `0` și Coloana A este de asemenea poziția `0`.

În continuare transmitem o listă de linii, unde fiecare linie conține o altă listă pentru coloane, abia apoi adăugăm o hartă cu valoarea celulei.

Exemplu complet:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, 1,
                    _val.list() // Linii
                        .add(
                            _val.list() // Coloană
                                .add(
                                    _val.map() // Celulă
                                        .set("value", "Nume")
                                )
                                .add(
                                    _val.map()
                                        .set("value", "Vârstă")
                                )
                        )
                        .add( // Altă linie
                            _val.list()
                                .add( // Prima coloană
                                    _val.map()
                                        .set("value", "Maria")
                                )
                                .add( // A doua coloană
                                    _val.map()
                                        .set("value", 26)
                                )
                        )
                )
            `
        },
    ]}
/>

### Formule

Pentru a insera formule folosim cheia `formula` în harta de definiții a celulei.

În acest exemplu se va realiza suma în ultima celulă a tuturor valorilor celorlalte celule:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, 1,
                    _val.list()
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 45))
                                .add(_val.map().set("value", 26))
                        )
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 51))
                                .add(_val.map().set("value", 30))
                        )
                        .add(
                            _val.list()
                                .add(
                                    _val.map().set("value", "Total")
                                )
                                .add(
                                    _val.map().set("formula", "SUM(B7:C8)")
                                )
                        )
                )
            `
        },
    ]}
/>

Pentru a obține litera coloanei din numărul coloanei se poate folosi metoda `columnReference`, ceea ce poate ajuta la definirea formulelor. Aceeași metodă poate fi folosită și pentru a obține numărul coloanei din litera de referință, de exemplu:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, _xls.columnReference('B'),
                    _val.list()
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 45))
                                .add(_val.map().set("value", 26))
                        )
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 51))
                                .add(_val.map().set("value", 30))
                        )
                        .add(
                            _val.list()
                                .add(
                                    _val.map().set("value", "Total")
                                )
                                .add(
                                    _val.map().set(
                                        "formula",
                                        "SUM("+ _xls.columnReference(1) +"7:"+ _xls.columnReference(2) +"8)"
                                )
                            )
                        )
                )
            `
        },
    ]}
/>

### Activare

Astfel, pentru a evita să indicați constant în metode care este foaia de calcul care trebuie procesată, ca în exemplele de mai sus, alternativ este posibil să indicați care este foaia activă.

> Toate metodele de manipulare a celulelor, imaginilor și datelor folosesc foaia de calcul activată atunci când **nu** este indicată o foaie specifică.

Vedeți două moduri de a activa o foaie specifică, mai întâi cu referința obiectului și apoi cu indicele foii:

<PolyglotCode
    codes={[

                excel.activeSheet(1) // Indexul foii de calcul care va fi activată.
            `
        },
    ]}
/>

## Editare fișier

Putem edita fișiere deschizându-le, făcând modificările necesare și apoi salvând noul fișier editat.

Mai jos sunt câteva exemple despre cum este posibil să deschideți fișiere.

Deschideți un fișier în rădăcina aplicației:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const excel = _xls.open(_app.file("fisier.xlsx"))
            `
        },
    ]}
/>

Pentru a deschide fișierul generat în folderul `storage/filesystem` al aplicației:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const excel = _xls.open(_storage.filesystem("server", "fisier.xlsx"))
            `
        },
    ]}
/>

Și pentru a deschide fișierul în folderul `/tmp` din sistemul de fișiere al HDD-ului:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const excel = _xls.open(_os.file("/tmp/fisier.xlsx"))
            `
        },
    ]}
/>

În exemplele de mai sus constanta `excel` va conține obiectul de editare cu contextul fișierului respectiv, astfel încât este posibil să faceți orice tip de manipulare.

Când finalizați modificările, generați noul fișier.

> Nu este posibil să modificați direct același fișier deschis, fiind necesar să generați un fișier nou cu o cale diferită.

Pentru a modifica direct același fișier, atunci se poate face folosind `inputStream`.

Urmează un exemplu despre cum să modificați valoarea unei celule:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const fisierInput = _app.file("fisier.xlsx").inputStream()
                const excel = _xls.open(fisierInput)

                excel.setCellData(
                    10, 1,
                    _val.map()
                        .set(
                            "value",
                            excel.getCellData(10, 1).getInt("value") + 10
                        )
                )

                fisierInput.close() // Închide fișierul deschis.
                excel.save(_app.file("fisier.xlsx")) // Salvează noua versiune.
                `
        },
    ]}
/>

## Citire fișier

Extragerea datelor din fișiere Excel se face cu metoda `read`.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const date = _xls.read(_app.file("fisier.xlsx"))
            `
        },
    ]}
/>

Datele sunt obținute într-o structură de obiecte de tip Values care conține Liste, pentru foi, linii și coloane, și Hărți (cheie și valoare) pentru celule.

Pentru a vizualiza toate datele putem pune ca ieșire de date a serviciului:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _out.json(date)
            `
        },
    ]}
/>

Pentru a realiza interacțiunea trebuie să avem în minte că structura datelor este organizată în următoarea ordine:

1. `sheets` - Foi de calcul
2. `rows` - Linii
3. `columns` - Coloane

Exemplu de interacțiune completă:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                for (const foaie of date.getValues("sheets")) {
                    _out.println(\`<h4>Foaie de calcul: \${foaie.getInt("index")} - \${foaie.getString("name")}</h4>\`)
                    for (const linie of foaie.getValues("rows")) {
                        _out.println(\`<h4>Linie: \${linie.getInt("row")}</h4>\`)
                        _out.println("<p>")
                        for (const coloana of linie.getValues("columns")) {
                            _out.print(\`\${coloana.getInt("row")}:\${coloana.getInt("column")}\`)
                            _out.print(\` # \${coloana.getString("address")}\`)
                            _out.print(\` # \${coloana.getString("type")}\`)
                            _out.print(\` # \${coloana.getString("value")}\`)
                            _out.println("<br>")
                        }
                        _out.println("</p>")
                    }
                }
            `

Tipul celulei este obținut prin codul:

- `coloana.getString("type")`

Și tipurile acceptate sunt:

- `string` - Conținut text.
- `numeric` - Conținut numeric sau de dată și/sau oră.
- `boolean` - Adevărat sau fals.
- `blank` - Celulă goală.
- `formula` - Celulă care conține o formulă.
- `error` - Eroare la procesarea celulei.

### Parametri suplimentari

Pentru fiecare tip de celulă avem unii parametri suplimentari.

`string` - Tip de celulă cu conținut textual.

- `value` - Textul celulei.
- `richValue` - Formatările celulei.

`numeric` - Tip de celulă cu conținut numeric, sau date și, de asemenea, ore.

- `value` - Valoarea conținutului numeric al celulei.
  
În cazul datelor și orelor avem acești parametri suplimentari:

- `localDateTime` - Obiect Java Time LocalDateTime care reprezintă valoarea de dată și oră a celulei.
- `localDate` - Obiect Java Time LocalDate care reprezintă valoarea de dată a celulei.
- `localTime` - Obiect Java Time LocalTime care reprezintă valoarea de oră a celulei.
- `instant` - Obiect Java Time Instant care reprezintă valoarea de dată și/sau oră a celulei.
- `date` - Obiect Date din Java care reprezintă valoarea de dată și/sau oră a celulei.

`boolean` - Tip de celulă cu conținut boolean, adică adevărat sau fals.

- `value` - Valoarea de tip _boolean_, `true` sau `false`.

`blank` - Tip de celulă fără conținut, prin urmare nu conține parametri suplimentari.

`formula` - Tip de celulă care conține formule de calcul.

- `value` - Valoarea finală rezultată din calcul.
- `formula` - Conține expresia formulei utilizate pentru calcul.

`error` - Tip de celulă care conține eroare.

- `value` - Valoarea în octeți a erorii generate.
- `code` - În cazul în care există erori la calculul formulei, furnizează aici codul erorii apărute.
