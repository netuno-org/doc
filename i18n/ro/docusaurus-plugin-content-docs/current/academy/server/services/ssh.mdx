## Introducere

Netuno are integrat în framework-ul său low-code un client SSH, care permite conectarea la servere, executarea comenzilor, trimiterea și primirea fișierelor, modificarea folderelor, printre alte operațiuni la distanță.

Suportă multiple conexiuni simultane, precum și SCP și SFTP.

Acest lucru se datorează implementării Java și open-source
<a target="_blank" href="https://github.com/hierynomus/sshj/tree/master">SSHJ</a>, ceea ce permite Netuno
să ofere aceste funcționalități tuturor limbajelor de script prin resursa `_ssh`.

> Mai multe despre resursa [SSH](/docs/library/resources/ssh) din Netuno.

## Configurare

Primul pas va fi configurarea datelor de acces SSH pe care Netuno le va folosi pentru a realiza conexiunea.

Navigați în aplicația pe care o dezvoltați până la fișierul de configurare a mediului. În acest exemplu,
vom folosi fișierul de dezvoltare, localizat în:

- `config/_development.json`

Verificați dacă există configurări pentru SSH; dacă nu există, atunci la sfârșitul fișierului de configurare (în format JSON)
adăugați parametrii de configurare SSH, de exemplu:

```json
{
  ...
  "ssh": {
    "default": {
      "enabled": true,
      "host": "serverul.meu.net",
      "port": 22,
      "username": "root",
      "password": "$eCr37"
    }
  },
  ...
}
```

După salvarea modificărilor, este suficient să reporniți Netuno pentru a prelua modificările configurației. Acestea fiind
configurările implicite pentru conexiune, după cum indică numele cheii `default`.

Puteți adăuga mai multe configurări de conexiune SSH cu alte chei în JSON.

Pentru a adăuga mai multe configurări de conexiune SSH, este suficient să repetați blocul de configurare implicit și să înlocuiți cheia
`default` cu alta la alegerea dvs., de exemplu:

```json
{
  ...
  "ssh": {
    "default": {
      "enabled": true,
      "host": "serverul.meu.net",
      "port": 22,
      "username": "root",
      "password": "$eCr37"
    },
    "altul": {
      "enabled": true,
      "host": "serverul.meu-altul.net",
      "port": 22,
      "username": "root",
      "password": "$eCr37"
    }
  },
  ...
}
```

Configurarea de mai sus permite utilizarea contului `default` atunci când este codificat după cum urmează:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const ssh = _ssh.init()
            `
        },
    ]}
/>

Pentru a utiliza configurația `altul`, este suficient să adăugați cheia configurației ca parametru al funcției
`_ssh.init()`, după cum urmează:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const sshAltul = _ssh.init("altul")
            `
        },
    ]}
/>

> Dacă nu adăugați un nume de configurație ca parametru, va fi utilizată configurația contului `default`.

## Conexiune

Înainte de a face orice, este necesar să inițiați conexiunea SSH:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                ssh.connect()
            `
        },
    ]}
/>

## Comenzi

Pentru a executa comenzi, este necesar să inițiați o sesiune de comenzi:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const sshSesiune = ssh.initSession()
            `
        },
    ]}
/>

La executarea unei comenzi este furnizat un obiect care conține starea execuției și ieșirea de date
(output) aferentă, de exemplu:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const sshRezultatComanda = sshSesiune.exec("ls -rato")
                if (sshRezultatComanda.ok) {
                    _out.println("Executat cu succes:")
                    _out.println(sshRezultatComanda.output())
                } else {
                    _out.println("Comanda a eșuat:")
                    _out.println(sshRezultatComanda.error())
                }
            `
        },
        {
            lang: 'python',
            code: `
                sshRezultatComanda = sshSesiune.exec("ls -rato")
                if sshRezultatComanda.ok:
                    _out.println("Executat cu succes:")
                    _out.println(sshRezultatComanda.output())
                else:
                    _out.println("Comanda a eșuat:")
                    _out.println(sshRezultatComanda.error())
            `
        },
        {
            lang: 'ruby',
            code: `
                sshRezultatComanda = sshSesiune.exec("ls -rato")
                if sshRezultatComanda.ok
                    _out.println("Executat cu succes:")
                    _out.println(sshRezultatComanda.output())
                else
                    _out.println("Comanda a eșuat:")
                    _out.println(sshRezultatComanda.error())
                end
            `
        },
    ]}
/>

> Obiectul returnat de comandă este [SSHExecResult](/docs/library/objects/SSHExecResult).

Nu uitați să închideți întotdeauna sesiunea:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                sshSesiune.close()
            `
        },
    ]}
/>

## SCP

Prin SCP putem trimite și primi fișiere.

Pentru a crea un fișier text dintr-un string și a descărca conținutul fișierului creat, vedeți exemplul:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const sshSCP = ssh.initSCP()
                // Creează fișierul text.
                sshSCP.uploadText("salut.txt", "Salut! Conținutul meu aici...")
                // Descarcă și afișează conținutul fișierului.
                _out.println(sshSCP.downloadText("salut.txt"))
                sshSCP.close()
            `
        },
    ]}
/>

Pentru a realiza încărcarea (upload) fișierelor existente în aplicație:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const sshSCP = ssh.initSCP()
                // Trimite un fișier care se află în storage/filesystem.
                sshSCP.upload("foaie_calcul.xlsx", _storage.filesystem("server", "foaie_calcul.xlsx").file())
                // Trimite un fișier care se află în rădăcina aplicației.
                sshSCP.upload("document.pdf", _app.file("document.pdf"))
                sshSCP.close()
            `
        },
    ]}
/>

Pentru a descărca (download) fișiere de pe server în aplicație:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const sshSCP = ssh.initSCP()
                // Descarcă fișierul în storage/filesystem.
                sshSCP.download("foaie_calcul.xlsx", _storage.filesystem("server", "foaie_calcul.xlsx").file())
                // Descarcă fișierul în rădăcina aplicației.
                sshSCP.download("document.pdf", _app.file("document.pdf"))
                sshSCP.close()
            `
        },
    ]}
/>

## SFTP

SFTP este o formă de transfer și manipulare a fișierelor și folderelor care suportă aceleași funcționalități
ca FTP, dar folosind SSH.

Pentru a iniția o nouă sesiune SFTP:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const sftp = ssh.initSFTP()
            `
        },
    ]}
/>

> Inițiază obiectul [SSHSFTP](/docs/library/objects/SSHSFTP) care este clientul sesiunii.

Creați un folder nou la distanță:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                sftp.createDirectory("cale/folder-nou")
            `
        },
    ]}
/>

Creează sau înlocuiește fișierul remote cu conținutul text transmis:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                sftp.uploadText("folder/fișier.txt", "Conținutul meu!")
            `
        },
    ]}
/>

Obține conținutul text al unui fișier remote:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const continutFisierRemote = sftp.downloadText("folder/fișier.txt"))
                _out.println(continutFisierRemote)
            `
        },
    ]}
/>

Șterge definitiv un fișier remote:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                sftp.deleteFile("folder/fișier.txt")
            `
        },
    ]}
/>

Șterge definitiv folderul remote:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                sftp.deleteDirectory("folder")
            `
        },
    ]}
/>

Listează tot conținutul unui folder:

<PolyglotCode
    codes={[
        {

                for (const i of sftp.list("cale/folder")) {

                    } else {
                        _out.print("Altul: ")
                    }
                    _out.println(i.name)
                    _out.println("<br/>")
                }
            `
        },
        {
            lang: 'python',

                for i in sftp.list("cale/folder":

                        _out.print("Folder: ")
                    elif i.regularFile:
                        _out.print("Fișier: ")
                    else:
                        _out.print("Altul: ")
                    _out.println(i.name)
                    _out.println("<br/>")
                }
            `
        },

            lang: 'ruby',

                        _out.print("Altul: ")
                    end

                    _out.println("<br/>")
                end
            `
        },
        {
            lang: 'kotlin',

                sftp.list("cale/folder").forEach {
                    if (it.directory) {
                        _out.print("Folder: ")
                    } else if (it.regularFile) {
                        _out.print("Fișier: ")
                    } else {
                        _out.print("Altul: ")
                    }
                    _out.println(it.name)
                    _out.println("<br/>")
                }
            `
        },
        {
            lang: 'groovy',
            code: `
                for (i in sftp.list("cale/folder")) {
                    if (i.directory) {
                        _out.print("Folder: ")
                    } else if (i.regularFile) {
                        _out.print("Fișier: ")

                        _out.print("Altul: ")
                    }
                    _out.println(i.name)
                    _out.println("<br/>")

            `
        },
    ]}
/>
