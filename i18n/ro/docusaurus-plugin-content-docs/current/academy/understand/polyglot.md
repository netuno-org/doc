Netuno este poliglot atât la nivel de bază de date, cât și în cod de programare, dar și la nivel de sistem de operare.

Cu toată această diversitate, cresc opțiunile unde poate fi utilizat.

Prin suportarea mai multor baze de date, limbaje de programare și sisteme de operare, facilitează dezvoltarea reușind să se adapteze fiecăreia dintre situații, dar garantând un mediu coeziv pentru dezvoltări.

## Bază de date

Poate fi utilizat pentru a integra mai multe tipuri de baze de date diferite și chiar a fi dezvoltat cu limbaje de programare diferite în același proiect.

Integrarea bazelor de date diferite este destul de comună pentru a realiza integrarea datelor atunci când se consultă sau se modifică date în baze de date ale altui sistem.

![Logo-urile bazelor de date](/docs/assets/business/databases.jpg "Multiple baze de date")

Netuno suportă următoarele baze de date:

- H2 Database
- PostgreSQL
- MariaDB
- MySQL
- Microsoft SQL Server
- Oracle

## Limbaje de programare

Suportarea unor limbaje de programare diferite poate să nu pară foarte interesantă în sensul amestecării limbajelor de programare, dar este posibil și nu înseamnă că trebuie făcut astfel.

În practică, de multe ori este complicat să realizezi proiecte unde există o tehnologie dominantă limitată la un limbaj de programare, astfel încât este nevoie să găsești persoane exclusiv competente pentru acest limbaj de programare.

Cu Netuno ajungem să avem o ofertă mai mare, unde toată munca nu este irosită dacă este nevoie să se utilizeze un nou limbaj de programare derivat dintr-o schimbare de strategie, sau lipsa tehnicienilor competenți, sau câștigarea unei agilități mai mari la dezvoltarea a ceva specific, printre alte situații care ar putea avea sens.

De obicei, acest lucru ar fi de neconceput pentru că întreținerea unui sistem cu mai multe limbaje de programare începe să îngrijoreze, dar fiind low-code, această îngrijorare devine mult mai puțin relevantă, pentru că:

* Limbajele de programare ajung să fie asemănătoare la nivel de logică și algoritm.
* Limbajul de programare poate fi diferit, dar resursele Netuno sunt aceleași și utilizate în același mod indiferent de limbaj.

Astfel, chiar dacă un tehnician este foarte obișnuit să lucreze cu un limbaj de programare, nimic nu îl va împiedica să realizeze întreținerea în altul; dacă are nevoie să-și extindă mult mai mult intervenția sau chiar să refacă, atunci va putea opta să dezvolte în limbajul său preferat și să integreze dezvoltarea sa în limbajul deja existent în utilizare.

![Logo-urile limbajelor de programare](/docs/assets/business/languages.jpg "Limbaje de programare")

Netuno suportă dezvoltarea în următoarele limbaje de programare:

- Groovy
- Java
- JavaScript
- Kotlin
- Python
- Ruby

## Sisteme de operare

Netuno, lucrând cu multiple sisteme de operare și cu suport pentru configurații de mediu, permite garantarea funcționării corecte a dezvoltărilor în mod transversal și organizarea în medii de dezvoltare, testare, calitate, producție, printre altele.

Schimbarea sistemului de operare sau a mediului este indiferentă pentru funcționarea corectă a Netuno și a aplicațiilor.

![Logo-urile sistemelor de operare](/docs/assets/business/operationsystems.jpg "Multiple sisteme de operare")

Sistemele de operare suportate de Netuno sunt:

* Linux
* Mac OS X
* Windows
