Netuno este poliglot atât la nivel de bază de date, cât și la nivel de cod de programare, dar și la nivel de sistem de operare.

Cu toată această diversitate, cresc opțiunile de utilizare.

Prin suportarea mai multor baze de date, limbaje de programare și sisteme de operare, facilitează dezvoltarea, reușind să se adapteze fiecărei situații, dar garantând un mediu coerent pentru dezvoltări.

## Baze de date

Poate fi utilizat pentru a integra mai multe tipuri de baze de date diferite și chiar pentru a fi dezvoltat cu limbaje de programare diferite în același proiect.

Integrarea unor baze de date diferite este destul de comună pentru realizarea integrării datelor atunci când se consultă sau se modifică date din baza de date a altui sistem.

![Logourile bazelor de date](/docs/assets/business/databases.jpg "Multiple baze de date")

Netuno suportă următoarele baze de date:

- H2 Database
- PostgreSQL
- MariaDB
- MySQL
- Microsoft SQL Server
- Oracle

## Limbaje de programare

Suportarea unor limbaje de programare diferite poate să nu pară foarte interesantă în sensul amestecării limbajelor de programare, dar este posibil și nu înseamnă că trebuie făcut astfel.

În practică, de multe ori este complicat să realizezi proiecte în care există o tehnologie dominantă limitată la un limbaj de programare, astfel încât este necesar să găsești persoane exclusiv competente pentru acel limbaj de programare.

Cu Netuno, ajungem să avem o ofertă mai mare, în care toată munca nu este irosită dacă este nevoie să se utilizeze un limbaj de programare nou, derivat dintr-o schimbare de strategie, din lipsa tehnicienilor competenți, din dorința de a obține o mai mare agilitate la dezvoltarea a ceva specific, printre alte situații care pot avea sens.

De regulă, acest lucru ar fi de neconceput, deoarece întreținerea unui sistem cu mai multe limbaje de programare începe să devină îngrijorătoare, însă, fiind low-code, această preocupare nu mai este foarte relevantă, deoarece:

* Limbajele de programare ajung să fie similare la nivel de logică și algoritm.
* Limbajul de programare poate fi diferit, dar resursele Netuno sunt aceleași și sunt utilizate la fel indiferent de limbaj.

Astfel, chiar dacă un tehnician este foarte obișnuit să lucreze cu un anumit limbaj de programare, nimic nu îl va împiedica să facă întreținerea într-un altul; dacă are nevoie să își extindă mult mai mult intervenția sau chiar să refacă, atunci va putea alege să dezvolte în limbajul său preferat și să integreze dezvoltarea sa în limbajul deja existent în utilizare.

![Logourile limbajelor de programare](/docs/assets/business/languages.jpg "Limbaje de programare")

Netuno suportă dezvoltarea în următoarele limbaje de programare:

- Groovy
- Java
- JavaScript
- Kotlin
- Python
- Ruby

## Sisteme de operare

Netuno, lucrând cu multiple sisteme de operare și cu suport pentru configurații de mediu, permite garantarea funcționării corecte a dezvoltărilor într-un mod transversal și organizarea în medii de dezvoltare, testare, calitate, producție, printre altele.

Schimbarea sistemului de operare sau a mediului este indiferentă pentru funcționarea corectă a Netuno și a aplicațiilor.

![Logourile sistemelor de operare](/docs/assets/business/operationsystems.jpg "Multiple sisteme de operare")

Sistemele de operare suportate de Netuno sunt:

* Linux
* Mac OS X
* Windows
