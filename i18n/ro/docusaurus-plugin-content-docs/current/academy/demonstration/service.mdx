Cu Netuno este posibil să creați **_servicii web_** și să construiți orice tip de **API-uri <a href="https://pt.wikipedia.org/wiki/REST" target="_blank">REST</a>** complexe pentru integrarea datelor între sisteme.

:::info Ce este un serviciu web?
Un serviciu web permite sistemelor să schimbe informații online într-un mod standardizat. În Netuno, fiecare fișier din `server/services/` devine automat un endpoint accesibil via HTTP.
:::

## De ce să folosiți servicii web?

Utilizarea serviciilor asincrone aduce beneficii clare pentru experiența utilizatorului:

- **Încărcare mai rapidă:** serverul livrează structura vizuală a paginii imediat, fără a aștepta procesarea tuturor datelor.
- **Date dinamice la cerere:** frontend-ul solicită doar datele necesare, atunci când este nevoie.
- **Integrare între sisteme:** un serviciu creat în Netuno poate fi consumat de orice aplicație externă (mobile, alt sistem web etc.).
- **Experiență mai bună pentru utilizator:** utilizatorul nu trebuie să aștepte procesarea completă a paginii înainte de a vedea ceva pe ecran.

## Cerințe preliminare

Înainte de a începe, asigurați-vă că:

- Netuno este instalat și rulează local.
- Aplicația `demo` a fost creată conform descrierii din [Creați Aplicație](../app-create).
- Există date înregistrate în **Sarcini** și asociate cu **Inregistrari** (necesar pentru ca răspunsul să nu fie gol).

## Configurați Editorul de Cod

Pentru a crea și edita servicii în Netuno, utilizați un editor de cod preferat. Recomandăm **[Visual Studio Code](https://code.visualstudio.com/download)** deoarece este gratuit, ușor și foarte intuitiv, dar orice editor compatibil cu JavaScript/Python/Groovy va funcționa normal.

## Deschideți Aplicația Demo {#abrir-a-aplicacao-demo}

1. Deschideți **Visual Studio Code**.
2. Faceți clic pe pictograma **Fișiere** din panoul din stânga.
3. Selectați **Deschide Folder** (File > Open Folder).
4. Navigați la folderul de instalare Netuno.
5. Selectați directorul: **`apps/demo`**
6. Faceți clic pe **Deschide**.

Structura de foldere a aplicației `demo` va fi încărcată în panoul din stânga.

## Creați Serviciul

Serviciile sunt procesate pe partea de **server**. Pentru a crea un serviciu nou:

1. În panoul de fișiere, extindeți structura până găsiți folderul `server/services/`.
2. Faceți clic dreapta pe folderul `services`.
3. Selectați **Fișier Nou** `New File`.
4. Denumiți fișierul în funcție de limbajul dorit:

Implementați serviciul adăugând codul de mai jos în fișierul creat. Acest serviciu interoghează baza de date și returnează o listă de lucrători cu totalul orelor înregistrate, în format **JSON**.

### Înțelegerea Codului

| Obiect/Metodă | Descriere |
|---|---|
| `_db.query()` | Execută o interogare SQL și returnează o listă de obiecte în format cheie-valoare (coloană → dată). |
| `_val.list()` | Creează o listă mutabilă pentru a acumula rezultatele. |
| `_val.map()` | Creează un obiect de mapare (cheie-valoare) pentru fiecare rând de rezultat. |
| `_out.json()` | Serializează obiectul în JSON și trimite răspunsul la cererile HTTP. |

:::warning Date necesare
Asigurați-vă că există date înregistrate în **Sarcini** și asociate cu **Inregistrari**. În caz contrar, endpoint-ul va returna o listă goală `[]`.
:::

## Executați și Testați Serviciul

Cu Netuno în execuție, accesați endpoint-ul în browser:

:::tip Sfat pentru vizualizarea JSON
Recomandăm **[Firefox](https://www.mozilla.org/)** pentru a testa endpoint-uri direct în browser, deoarece formatează și afișează răspunsul JSON într-un mod lizibil cu evidențierea sintaxei. Alternativ, folosiți extensii precum **JSON Viewer** în Chrome sau instrumente precum **[Postman](https://www.postman.com/)** pentru teste mai avansate.
:::

Răspunsul așteptat va fi un JSON similar cu:

```json
[
  { "nume": "Ana Popescu", "total": 12 },
  { "nume": "Carol Ionescu", "total": 28 },
  { "nume": "Ion Popescu", "total": 45 }
]
```
