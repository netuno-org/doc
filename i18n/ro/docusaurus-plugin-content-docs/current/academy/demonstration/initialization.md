# Inițializare 

Inițializarea aplicației Demo

Pentru a începe acest tutorial, primul pas este să porniți serverul aplicației **Demo** și să pregătiți mediul de dezvoltare.


### Porniți serverul 

Deschideți terminalul sistemului de operare și navigați până la directorul rădăcină în care este instalată platforma Netuno (de exemplu, `📁 /netuno`).

Executați comanda de mai jos pentru a porni serverul:

```bash
./netuno server
```

:::info Alternativă de pornire
Dacă comanda principală nu funcționează sau aplicația Demo nu este încărcată implicit, forțați pornirea specificând parametrul aplicației:
:::

```bash
./netuno server app=demo
```

### Alegeți editorul de cod
Puteți utiliza editorul de cod preferat pentru a dezvolta atât backend-ul, cât și frontend-ul aplicației dvs.

Dacă nu aveți încă unul, recomandăm următoarele opțiuni gratuite și cu sursă deschisă:

- VS Code: <a href="https://code.visualstudio.com/" target="_blank">code.visualstudio.com</a>
- VS Codium: <a href="https://vscodium.com/" target="_blank">vscodium.com</a>
- WebStorm: <a href="https://www.jetbrains.com/webstorm/" target="_blank">jetbrains.com/webstorm</a>


#### Deschideți directorul proiectului
Cu editorul de cod deschis, localizați și deschideți directorul aplicației Demo: `📁 apps/demo`.

Acest director conține toate fișierele și configurațiile noii aplicații. Dezvoltarea se va realiza exclusiv în interiorul acestui director.

### Pașii următori

Cu serverul pornit și fișierele deschise în editorul de cod, mediul este pregătit. Treceți la următoarea etapă a tutorialului pentru a începe să explorați și să modificați aplicația.
