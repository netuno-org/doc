## O que é

A partir de uma página existente, é possível criar uma nova através da opção **Clonar**. No formulário de clonagem, é preciso indicar:

- **Título** e **Ligação** (link) da nova página.
- **Versão de origem** — de qual versão da página original o conteúdo será copiado.
- **Idioma** — opcionalmente diferente do idioma da página original.
- Se a nova página deve ser **publicada** de imediato.

Ao confirmar, o CLUAR duplica toda a estrutura de componentes (Banner, Conteúdo, Listagem, Slider, Funcionalidade, com as respetivas ações) dessa versão para a nova página.

## Para que serve

É assim que, na prática, se cria a "tradução" de uma página: em vez de montar uma página nova do zero, escolhe-se a página já existente noutro idioma, clona-se para o novo idioma, e depois ajustam-se os textos. Também serve para criar rapidamente páginas parecidas dentro do mesmo idioma (ex.: várias páginas de campanha com a mesma estrutura).

:::info Tradução dos conteúdos
A clonagem duplica a **estrutura** da página (os mesmos componentes, na mesma ordem), mas **não traduz o texto** — os campos de cada componente (Banner, Conteúdo, Listagem, Slider, Funcionalidade) ficam com o conteúdo original, e é preciso entrar em cada um e traduzir manualmente. A tradução automática dos conteúdos ao clonar já está prevista, mas ainda não foi desenvolvida.
:::
