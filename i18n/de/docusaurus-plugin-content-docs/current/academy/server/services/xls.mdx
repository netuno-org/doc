Benutzerdefinierte Excel-Dateien verarbeiten.

## Einführung

Netuno erzeugt EXCEL-Dateien, die mit LibreOffice, OpenOffice, Microsoft Office, Google Drive usw. kompatibel sind, über die Funktion [XLS](/docs/library/resources/xls), die eine Low-Code-Abstraktion von [Apache POI](https://poi.apache.org/) für die verschiedenen von Netuno unterstützten Programmiersprachen ermöglicht.

Es können sowohl XLSX-, XLS- als auch ODS-Dateien erzeugt werden.

Die mit Netuno gelieferte Anwendung **demo** (Demo-Anwendung) enthält zahlreiche Beispiele möglicher Codeimplementierungen in verschiedenen Sprachen, einschließlich der Demonstration des Exports von Tabellen über den Dienst `export-excel`, der sich hier befindet:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-excel`
]} />

## Initialisierung

Um die XLS-Funktion zu initialisieren:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const excel = _xls.create()
            `
        },
    ]}
/>

Erstellt das Objekt, das den Kontext der neuen zu erstellenden Datei mit einem leeren Arbeitsblatt enthält.

## Formatierung

Die Definition von visuellen Formatierungsstilen, also Formate für Datumsangaben, Uhrzeiten, Geldbeträge und weitere, muss vor der Definition der Zellwerte erfolgen, denn beim Festlegen der Zellwerte kann der jeweilige Formatierungsstil zugeordnet werden.

Daher werden die Formatierungen, wie im Beispiel der Anwendung `demo` gezeigt, gleich zu Beginn des Codes definiert.

Zum Formatieren von Datumsangaben:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const stilDatum = excel.cellStyleFormat("dd/mm/yy")
            `
        },
    ]}
/>

Zum Formatieren von Uhrzeiten:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const stilUhrzeit = excel.cellStyleFormat("hh:mm:ss")
            `
        },
    ]}
/>

Zum Formatieren von Datumsangaben mit Uhrzeiten:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const stilDatumUhrzeit = excel.cellStyleFormat("dd/mm/yyyy hh:mm:ss")
            `
        },
    ]}
/>

Zum Formatieren von Geldbeträgen in **Euro**:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const stilGeldEuro = excel.cellStyleFormat("€#,##0.00;\\-€#,##0.00")
            `
        },
    ]}
/>

Zum Formatieren von Geldbeträgen in **brasilianischen Real**:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const stilGeldReal = excel.cellStyleFormat("R$#,##0.00;\\-R$#,##0.00")
            `
        },
    ]}
/>

Zum Formatieren von Werten in **Prozent**:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const stilProzent = excel.cellStyleFormat("0.00%")
            `
        },
    ]}
/>

## Darstellung

Die Definition von visuellen Darstellungsstilen, also das Aussehen von Zellen wie Farben, Schriftart, Rahmen, Ausrichtung und weitere, muss vor der Definition der Zellwerte erfolgen, denn beim Festlegen der Zellwerte kann der jeweilige Darstellungsstil zugeordnet werden.

Daher werden die Darstellungen, wie im Beispiel der Anwendung `demo` gezeigt, gleich zu Beginn des Codes definiert.

Beispiel für die Definition von Farben und Ausrichtung:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const stilKopf = excel.cellStyle()
                stilKopf.setFillPattern(_xls.fillPattern("solid-foreground"))
                stilKopf.setFillBackgroundColor(excel.color("black"))
                stilKopf.setAlignment(_xls.horizontalAlignment("center"))

        },
    ]}
/>

<PolyglotCode
    codes={[

## Zellen zusammenführen

Um Zellen in einem Bereich zusammenzuführen, verwenden wir die Methode `mergedRegion`.

Die Reihenfolge der Parameter ist:

1. Startzeile
2. Startspalte
3. Endzeile
4. Endspalte

> Die numerischen Positionsreferenzen beginnen immer bei **null**.

In diesem Beispiel unten werden alle Zellen von Spalte 10 bis Spalte 15 in Zeile 3 zusammengeführt:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.mergedRegion(2, 9, 2, 14)
            `
        },
    ]}
/>

## Tabellarische Daten einfügen

Wir können eine Datentabelle mit der Methode `addDataTable` einfügen.

Da die ersten beiden Parameter die Position definieren, an der die Datentabelle eingefügt werden soll, sind sie die Zeilen- und Spaltennummern.

> Beachten Sie, dass die Positionierung im Code von Zeilen und Spalten immer bei **null** beginnt.
>
> Das heißt, Zeile 1 ist Position `0` und Spalte A ist ebenfalls Position `0`.

Als Nächstes übergeben wir eine Liste von Zeilen, wobei jede Zeile eine weitere Liste für die Spalten enthält, und erst dann fügen wir eine Map mit dem Wert der Zelle hinzu.

Vollständiges Beispiel:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, 1,
                    _val.list() // Zeilen
                        .add(
                            _val.list() // Spalte
                                .add(
                                    _val.map() // Zelle
                                        .set("value", "Name")
                                )
                                .add(
                                    _val.map()
                                        .set("value", "Alter")
                                )
                        )
                        .add( // Weitere Zeile
                            _val.list()
                                .add( // Erste Spalte
                                    _val.map()
                                        .set("value", "Maria")
                                )
                                .add( // Zweite Spalte
                                    _val.map()
                                        .set("value", 26)
                                )
                        )
                )
            `
        },
    ]}
/>

### Darstellung

In der Map der Zellen können wir die bereits erstellten Stile zuordnen, indem wir beispielsweise die im Abschnitt Darstellung und Formatierung zuvor definierten Stile verwenden.

Im Folgenden ein Beispiel, wie die Stile den Zellen zugeordnet werden:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, 1,
                    _val.list()
                        .add(
                            _val.list()
                                .add(
                                    _val.map()
                                        .set("value", "Name")
                                        .set("style", stilKopf)
                                )
                                .add(
                                    _val.map()
                                        .set("value", "Alter")
                                        .set("style", stilKopf)
                                )
                        )
                )
            `
        },
    ]}
/>

### Formeln

Zum Einfügen von Formeln verwenden wir den Schlüssel `formula` in der Map der Zelldefinitionen.

In diesem Beispiel wird in der letzten Zelle die Summe aller Werte der anderen Zellen berechnet:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, 1,
                    _val.list()
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 45))
                                .add(_val.map().set("value", 26))
                        )
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 51))
                                .add(_val.map().set("value", 30))
                        )
                        .add(
                            _val.list()
                                .add(
                                    _val.map().set("value", "Gesamt")
                                )
                                .add(
                                    _val.map().set("formula", "SUM(B7:C8)")
                                )
                        )
                )
            `
        },
    ]}
/>

Um den Buchstaben der Spalte aus der Spaltennummer zu erhalten, kann die Methode `columnReference` verwendet werden, was bei der Definition der Formeln helfen kann. Dieselbe Methode kann auch verwendet werden, um die Spaltennummer aus dem Referenzbuchstaben zu erhalten, zum Beispiel:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.addDataTable(
                    6, _xls.columnReference('B'),
                    _val.list()
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 45))
                                .add(_val.map().set("value", 26))
                        )
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 51))
                                .add(_val.map().set("value", 30))
                        )
                        .add(
                            _val.list()
                                .add(
                                    _val.map().set("value", "Gesamt")
                                )
                                .add(
                                    _val.map().set(
                                        "formula",
                                        "SUM("+ _xls.columnReference(1) +"7:"+ _xls.columnReference(2) +"8)"
                                )
                            )
                        )
                )
            `
        },
    ]}
/>

### Aktivieren

Um zu vermeiden, dass in den Methoden ständig angegeben werden muss, welches Arbeitsblatt verarbeitet werden soll, wie in den obigen Beispielen, kann alternativ angegeben werden, welches Arbeitsblatt aktiv ist.

> Alle Methoden zur Manipulation von Zellen, Bildern und Daten verwenden das aktivierte Arbeitsblatt, wenn **kein** bestimmtes Arbeitsblatt angegeben wird.

Sehen Sie zwei Möglichkeiten, ein bestimmtes Arbeitsblatt zu aktivieren, zuerst mit der Objektreferenz und dann mit dem Index des Arbeitsblatts:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                excel.activeSheet(meinArbeitsblatt) // Objektreferenz des Arbeitsblatts.
                excel.activeSheet(1) // Index des Arbeitsblatts, das aktiviert werden soll.
            `
        },
    ]}
/>

## Datei bearbeiten

Wir können Dateien bearbeiten, indem wir sie öffnen, die erforderlichen Änderungen vornehmen und anschließend die neue bearbeitete Datei speichern.

Nachfolgend einige Beispiele, wie Dateien geöffnet werden können.

Eine Datei im Stammverzeichnis der Anwendung öffnen:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const excel = _xls.open(_app.file("datei.xlsx"))
            `
        },
    ]}
/>

Um die im Ordner `storage/filesystem` der Anwendung erzeugte Datei zu öffnen:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const excel = _xls.open(_storage.filesystem("server", "datei.xlsx"))
            `
        },
    ]}
/>

Und außerdem, um die Datei im Ordner `/tmp` aus dem Dateisystem der Festplatte zu öffnen:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const excel = _xls.open(_os.file("/tmp/datei.xlsx"))
            `
        },
    ]}
/>

In den obigen Beispielen enthält die Konstante `excel` das Bearbeitungsobjekt mit dem Kontext der jeweiligen Datei, sodass jede Art von Manipulation möglich ist.

Wenn Sie die Änderungen abgeschlossen haben, erzeugen Sie die neue Datei.

> Es ist nicht möglich, dieselbe geöffnete Datei direkt zu ändern; es ist erforderlich, eine neue Datei mit einem anderen Pfad zu erzeugen.

Um dieselbe Datei direkt zu ändern, kann dies mit dem `inputStream` erfolgen.

Nachfolgend ein Beispiel, wie der Wert einer Zelle geändert wird:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const dateiEingabe = _app.file("datei.xlsx").inputStream()
                const excel = _xls.open(dateiEingabe)

                excel.setCellData(
                    10, 1,
                    _val.map()
                        .set(
                            "value",
                            excel.getCellData(10, 1).getInt("value") + 10
                        )
                )

                dateiEingabe.close() // Schließt die geöffnete Datei.
                excel.save(_app.file("datei.xlsx")) // Speichert die neue Version.
                `
        },
    ]}
/>

## Datei lesen

Die Extraktion von Daten aus Excel-Dateien erfolgt mit der Methode `read`.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const daten = _xls.read(_app.file("datei.xlsx"))
            `
        },
    ]}
/>

Die Daten werden in einer Struktur von Objekten vom Typ Values mit Listen für Arbeitsblätter, Zeilen und Spalten sowie Maps (Schlüssel und Wert) für die Zellen abgerufen.

Um alle Daten anzuzeigen, können wir sie als Datenausgabe des Dienstes ausgeben:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _out.json(daten)
            `
        },
    ]}
/>

Um die Interaktion durchzuführen, müssen wir bedenken, dass die Datenstruktur in folgender Reihenfolge organisiert ist:

1. `sheets` - Arbeitsblätter
2. `rows` - Zeilen
3. `columns` - Spalten

Beispiel einer vollständigen Interaktion:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                for (const arbeitsblatt of daten.getValues("sheets")) {
                    _out.println(\`<h4>Arbeitsblatt: \${arbeitsblatt.getInt("index")} - \${arbeitsblatt.getString("name")}</h4>\`)
                    for (const zeile of arbeitsblatt.getValues("rows")) {
                        _out.println(\`<h4>Zeile: \${zeile.getInt("row")}</h4>\`)
                        _out.println("<p>")
                        for (const spalte of zeile.getValues("columns")) {
                            _out.print(\`\${spalte.getInt("row")}:\${spalte.getInt("column")}\`)
                            _out.print(\` # \${spalte.getString("address")}\`)
                            _out.print(\` # \${spalte.getString("type")}\`)
                            _out.print(\` # \${spalte.getString("value")}\`)

Der Zelltyp wird über folgenden Code abgerufen:

- `spalte.getString("type")`

Und die unterstützten Typen sind:

- `string` - Textinhalt.
- `numeric` - Numerischer Inhalt oder Datum und/oder Uhrzeit.
- `boolean` - Wahr oder falsch.
- `blank` - Leere Zelle.
- `formula` - Zelle, die eine Formel enthält.
- `error` - Fehler bei der Verarbeitung der Zelle.

### Zusätzliche Parameter

Für jeden Zelltyp gibt es einige zusätzliche Parameter.

`string` - Zelltyp mit textlichem Inhalt.

- `value` - Text der Zelle.
- `richValue` - Formatierungen der Zelle.

`numeric` - Zelltyp mit numerischem Inhalt oder Datumsangaben und außerdem Uhrzeiten.

- `value` - Wert des numerischen Inhalts der Zelle.
  
Im Fall von Datumsangaben und Uhrzeiten gibt es diese zusätzlichen Parameter:

- `localDateTime` - Objekt vom Typ Java Time LocalDateTime, das den Datums- und Uhrzeitwert der Zelle repräsentiert.
- `localDate` - Objekt vom Typ Java Time LocalDate, das den Datumswert der Zelle repräsentiert.
- `localTime` - Objekt vom Typ Java Time LocalTime, das den Uhrzeitwert der Zelle repräsentiert.
- `instant` - Objekt vom Typ Java Time Instant, das den Datums- und/oder Uhrzeitwert der Zelle repräsentiert.
- `date` - Date-Objekt von Java, das den Datums- und/oder Uhrzeitwert der Zelle repräsentiert.

`boolean` - Zelltyp mit booleschem Inhalt, also wahr oder falsch.

- `value` - Wert vom Typ _boolean_, `true` oder `false`.

`blank` - Zelltyp ohne Inhalt, enthält daher keine zusätzlichen Parameter.

`formula` - Zelltyp, der Berechnungsformeln enthält.

- `value` - Endgültiger Wert, der sich aus der Berechnung ergibt.
- `formula` - Enthält den Ausdruck der für die Berechnung verwendeten Formel.

`error` - Zelltyp, der einen Fehler enthält.

- `value` - Byte-Wert des erzeugten Fehlers.
- `code` - Falls Fehler bei der Formelberechnung auftreten, wird hier der Code des aufgetretenen Fehlers angegeben.
