Individuelle PDF-Dateien verarbeiten.

## Einführung

Netuno erzeugt PDF-Dateien mit Unterstützung für Bilder, Tabellen, Schriftarten und vieles mehr über die [PDF](/docs/library/resources/pdf)-Ressource, die eine Low-Code-Abstraktion von [iTextPDF](https://itextpdf.com/) für die verschiedenen von Netuno unterstützten Programmiersprachen ermöglicht.

Die mit Netuno gelieferte Anwendung namens **demo** (Demonstrationsanwendung) enthält zahlreiche Beispiele für mögliche Codeimplementierungen in verschiedenen Sprachen, einschließlich der Demonstration des PDF-Exports über den Dienst `export-pdf`, der sich hier befindet:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-pdf`
]} />

## Initialisierung

Zunächst muss das Objekt erstellt werden, das den Kontext des neuen Dokuments enthält; standardmäßig ist das Seitenformat A4.

Beim Erstellen des Dokuments wird festgelegt, wohin es ausgegeben wird.

Wenn nichts festgelegt wird, wird es in der Datenausgabe des Dienstes erzeugt, zum Beispiel:

## HTTP-Header

Um einen Dienst in der REST-API zu erstellen, der eine PDF-Datei als Datenausgabe zurückgibt, muss im Header der Parameter `Content-Type` des HTTP-Protokolls hinzugefügt werden.

Beispiel für das Festlegen des Inhalts als PDF:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("pdf")
            `
        },
    ]}
/>

Der Code `pdf` ist eine Abkürzung für:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("application/pdf")
            `
        },
    ]}
/>

## Absatz

Fügt einen neuen Absatz zum Dokument hinzu:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDokument.add(
                    _pdf.paragraph("Mein Text hier...")
                        .setFontSize(15)
                )
            `
        },
    ]}
/>

Um einen Absatz an einer festen Position hinzuzufügen:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDokument.add(
                    pdfDokument.add(
                        _pdf.paragraph("Mein fester Text...")
                            .setFixedPosition(100, 500, 200)
                            .setFontSize(15)
                    )
                )
            `
        },
    ]}
/>

Im obigen Code ist in der Methode `setFixedPosition` der erste Parameter die X-Position (`100`), der zweite Parameter die Y-Position (`500`) und der dritte Parameter die Breite (`200`).

**Achtung:** Wenn Y auf den Wert `0` gesetzt wird, bedeutet das, dass es sich am unteren Rand der Seite befindet; um nach oben zu gelangen, muss der Y-Wert erhöht werden. Je größer der Y-Wert, desto weiter oben erscheint es. Wenn er jedoch zu hoch über die Seitenlänge hinausgeht, ist es nicht sichtbar.

> Dokumentation mit allen Methoden des [iText-Absatzobjekts](https://api.itextpdf.com/iText/java/8.0.3/com/itextpdf/layout/element/Paragraph.html).

## Tabelle

Es ist möglich, Tabellen zu erstellen, wodurch sich Datensätze übersichtlicher darstellen lassen.

Die Anzahl der Tabellenspalten wird mit dem Parameter definiert: `_pdf.table(spaltenAnzahl)`

Im folgenden Beispiel ist `spaltenAnzahl` die Zahl `1`, also eine Spalte.

Da wir zwei Zellen zur Tabelle hinzufügen, geht die zweite Zelle in die nächste Zeile.

Beachten Sie:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDokument.add(
                    _pdf.table(1)
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Person")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBorder(_pdf.border("solid", 2))
                                .setBackgroundColor(_pdf.colorRGB(1, 0, 0))
                        )
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Nicole")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBackgroundColor(_pdf.colorGray(0.5))
                        )
                )
            `
        },
    ]}
/>

Mit der Methode `addCell` lassen sich die Definitionen der Zellen mit ihrem jeweiligen Inhalt einfügen.

> Dokumentation mit allen Methoden des [iText-Zellobjekts](https://api.itextpdf.com/iText/java//8.0.3/com/itextpdf/layout/element/Cell.html).

## Dokument schließen und speichern

Das Dokument wird erst dann vollständig gespeichert oder erzeugt, wenn die Methode `close` aufgerufen wird, und zwar so:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDokument.close()
            `
        },
    ]}
/>

Wo das Dokument erzeugt wird, wird bei der Initialisierung festgelegt; daher definieren wir bei der Initialisierung des Dokuments, wo das endgültige Dokument erzeugt wird – ob in der Datenausgabe des Dienstes (`output`) oder in einer Datei.

## Datei lesen

Um ein PDF-Dokument zu lesen und die Textinformationen zu extrahieren.

Wir verwenden die Methode `extract`, die alle Daten der PDF-Datei in einem JSON-Objekt abruft.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const pdfDaten = _pdf.extract(_app.file("datei-1.pdf"))

                _out.json(pdfDaten)
            `
        },
        {
            lang: 'python',
            code: `
                pdfDaten = _pdf.extract(_app.file("datei-1.pdf"))

                _out.json(pdfDaten)
            `
        },
        {
            lang: 'ruby',
            code: `
                pdfDaten = _pdf.extract(_app.file("datei-1.pdf"))

                _out.json(pdfDaten)
            `
        },
        {
            lang: 'kotlin',
            code: `
                val pdfDaten = _pdf.extract(_app.file("datei-1.pdf"))

                _out.json(pdfDaten)
            `
        },
        {
            lang: 'groovy',
            code: `
                def pdfDaten = _pdf.extract(_app.file("datei-1.pdf"))

                _out.json(pdfDaten)
            `
        },
    ]}
/>

Das zurückgegebene JSON enthält den Schlüssel `content` mit dem gesamten Textinhalt der PDF-Datei und den Schlüssel `metadata` mit den verschiedenen Eigenschaften der PDF-Datei.

Hier ein Beispiel für das von `extract` zurückgegebene JSON:

```json
{
  "content": "Der gesamte Textinhalt der PDF-Datei kommt hierhin...",
  "metadata":{
    "Content-Type":"application/pdf",
    "dc:format":"application/pdf; version=1.4",
    "dc:title":"Linux 1",
    "pdf:PDFVersion":"1.4",
    "pdf:charsPerPage":"580",
    "pdf:containsDamagedFont":"false",
    "pdf:containsNonEmbeddedFont":"false",
    "pdf:docinfo:producer":"Skia/PDF m125 Google Docs Renderer",
    "pdf:docinfo:title":"Datei 1",
    "pdf:encrypted":"false",
    "xmpTPg:NPages":"3",
    ...
  }
}
```

Es gibt viele weitere Daten, die im `metadata` abgerufen werden, aber in den `...` weggelassen wurden, damit das Beispiel nicht zu lang wird.

## Konvertieren

Es ist möglich, das PDF programmatisch in Text oder sogar in HTML zu konvertieren.

### PDF zu Text

Wir können den gesamten Inhalt der PDF-Datei mit der folgenden Methode als fortlaufenden Text extrahieren:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _pdf.toText(...)
            `
        },
    ]}
/>

Beispiel für die Verwendung zum Lesen einer Datei im Stammverzeichnis der Anwendung:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _out.print(_pdf.toText(_app.file("mein-dokument.pdf")))
            `
        },
    ]}
/>

Oder auch mit einer Datei im `storage` der Anwendung:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _out.print(_pdf.toText(_storage.filesystem("server", "mein-dokument.pdf")))
            `
        },
    ]}
/>
