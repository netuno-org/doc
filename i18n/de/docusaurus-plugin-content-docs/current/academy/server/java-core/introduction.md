Netuno wird in Java entwickelt, daher können wir ausgehend von Java neue Funktionalitäten erstellen.

Zum Beispiel können wir neue native Dienste oder sogar neue Low-Code-Programmierfunktionen erstellen, die in allen polyglotten Programmiersprachen wie JavaScript, Python, Ruby, Groovy und Kotlin verfügbar sind.

In Java können wir auch anwendungsübergreifende Webdienste erstellen, die in allen Netuno-Anwendungen verfügbar sind.

Jede Technik oder Bibliothek aus dem Java-Ökosystem kann genutzt werden, um jede Art von Funktionalität zu erstellen.

> Wir empfehlen, dass Sie vor dem Start dieses Tutorials einige Grundkenntnisse in _Java_ haben.
