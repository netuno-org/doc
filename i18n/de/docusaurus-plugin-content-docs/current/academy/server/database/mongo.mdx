## Einführung

<a href="https://www.mongodb.com/" target="_blank">MongoDB</a> ist eine dokumentenorientierte NoSQL-Datenbank. Anstelle von Tabellen und Zeilen werden die Daten in Dokumenten im JSON-ähnlichen Format gespeichert, was eine große Flexibilität im Datenmodell ermöglicht.

Netuno bietet die Ressource [_mongo](/docs/library/resources/mongo) für die Integration mit MongoDB, mit einer Low-Code-Abstraktion über den offiziellen MongoDB-Client für Java, verfügbar für die verschiedenen von Netuno unterstützten Programmiersprachen: **JavaScript, Python, Ruby, Kotlin und Groovy**.

> Bevor Sie fortfahren, sollten Sie wissen, wie man Dienste in Netuno erstellt. Sehen Sie sich das Tutorial [REST – Webdienste](/docs/academy/server/services/rest) an.

Ein Beispiel für die Implementierung der hier vorgestellten Operationen ist im Beispieldienst `mongo.js` verfügbar, der sich hier befindet:

## Installation von MongoDB

### Mit Docker

Angenommen, Docker ist installiert, genügt es, das MongoDB-Image herunterzuladen und einen neuen Container zu starten:

```shell
docker pull mongo
docker run -d --name mongo -p 27017:27017 mongo
```

Auf diese Weise ist MongoDB unter `localhost:27017` ohne Authentifizierung erreichbar.

Um den Datenbankbenutzer gemäß der Anwendungskonfiguration zu erstellen, führen Sie aus:

```shell
docker exec -it mongo mongosh produkte_db --eval 'db.createUser({ user: "produkte_benutzer", pwd: "12345678", roles: [{ role: "readWrite", db: "produkte_db" }] })'
```

### Mit Ubuntu

MongoDB ist nicht in den offiziellen Ubuntu-Repositories enthalten, daher ist es notwendig, das offizielle Repository vor der Installation hinzuzufügen:

```shell
sudo apt-get install gnupg curl
curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.asc | sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg --dearmor
echo "deb [ signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] http://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
sudo apt-get update
sudo apt-get install -y mongodb-org
```

Nach der Installation können Sie den Dienst mit folgendem Befehl starten:

```shell
sudo systemctl start mongod
```

### Mit Windows

- <a href="https://www.mongodb.com/try/download/community" target="_blank">MongoDB Community Server herunterladen</a>.

Führen Sie den heruntergeladenen Installer aus und aktivieren Sie im Schritt **Service Configuration** die Option **Install MongoD as a Service**, damit MongoDB automatisch startet. MongoDB ist unter `localhost:27017` ohne Authentifizierung erreichbar.

> Weitere Distributionen und Versionen finden Sie in der [offiziellen MongoDB-Dokumentation](https://www.mongodb.com/docs/manual/installation/).

## Anwendungskonfiguration

Die Konfiguration der MongoDB-Verbindungen erfolgt in der Konfigurationsdatei der Anwendung, je nach Umgebung:

- `config/_development.json`

> Mehr über die [Konfigurationsdateien](/docs/academy/explore/configuration) der Anwendung erfahren Sie hier.

Fügen Sie in der Konfigurationsdatei den Block `mongo` hinzu, wobei jeder Schlüssel eine Verbindung identifiziert:

```javascript
{
    ...
    "mongo": {
        "laden": "mongodb://laden_benutzer:12345678@localhost/laden_db",
        "produkte": {
            "username": "produkte_benutzer",
            "password": "12345678",
            "host": "127.0.0.1",
            "port": "27017",
            "database": "produkte_db"
        }
    },
    ...
}
```

Eine Verbindung kann auf zwei Arten definiert werden:

- **Als Verbindungs-URL** – der Wert ist einfach eine Zeichenkette, zum Beispiel `"mongodb://laden_benutzer:12345678@localhost/laden_db"`.
- **Als Konfigurationsobjekt** – mit den Feldern:
  - `url` – wenn definiert, wird er direkt als Verbindungs-URL verwendet und die anderen Felder werden ignoriert.
  - `protocol` – das Protokoll der Verbindung, standardmäßig `mongodb`.
  - `username` und `password` – die Zugangsdaten.
  - `host` – die Serveradresse, standardmäßig `localhost`.
  - `port` – der Port der Verbindung, standardmäßig `27017`.
  - `database` – der Name der Datenbank, standardmäßig der Name des Verbindungsschlüssels.
  - `params` – zusätzliche Verbindungsparameter, die an die URL angehängt werden, zum Beispiel `{ "authSource": "admin" }`. Sie werden nur angewendet, wenn die URL aus den Feldern des Objekts erstellt wird.

> Die Verbindung muss nicht die Hauptdatenbank der Anwendung sein. Anders als die Konfiguration `db` ist der Block `mongo` unabhängig und ermöglicht mehrere gleichzeitige Verbindungen.

### Filter

Die Factory `_mongo.filters()` bietet die wichtigsten MongoDB-Abfrageoperatoren:

| Operator | Beschreibung |
|---|---|
| `eq("feld", wert)` | Gleich dem Wert. |
| `ne("feld", wert)` | Ungleich dem Wert. |
| `gt("feld", wert)` | Größer als der Wert. |
| `gte("feld", wert)` | Größer oder gleich dem Wert. |
| `lt("feld", wert)` | Kleiner als der Wert. |
| `lte("feld", wert)` | Kleiner oder gleich dem Wert. |
| `in("feld", wert1, wert2, ...)` | Gleich einem der Werte. |
| `nin("feld", wert1, wert2, ...)` | Ungleich allen Werten. |
| `and(filter1, filter2, ...)` | Entspricht allen Filtern. |
| `or(filter1, filter2, ...)` | Entspricht mindestens einem der Filter. |
| `not(filter)` | Entspricht nicht dem Filter. |
| `regex("feld", "muster")` | Entspricht dem regulären Ausdruck. |
| `exists("feld")` | Das Feld existiert im Dokument. |
| `text("suche")` | Textsuche. |
| `type("feld", "typ")` | Das Feld hat den angegebenen Typ. |
| `mod("feld", teiler, rest)` | Der Rest der Division des Feldes durch den Teiler ist gleich dem Wert. |
| `where("ausdruck")` | Entspricht Dokumenten, die einen JavaScript-Ausdruck erfüllen, zum Beispiel `"this.preis > 100"`. |
| `size("feld", n)` | Das Array-Feld hat genau `n` Elemente. |

Die verfügbaren Aggregationsstufen sind die folgenden:

| Stufe | Beschreibung |
|---|---|
| `match(filter)` | Wählt nur die Dokumente aus, die dem Filter entsprechen. |
| `group("$feld", akkumulatoren)` | Gruppiert die Dokumente nach dem Feld und wendet die Akkumulatoren an. |
| `project(projektion)` | Fügt Felder in Dokumenten hinzu, entfernt oder ändert sie. |
| `sort(sortierung)` | Sortiert die Dokumente. |
| `limit(n)` | Begrenzt auf die ersten `n` Dokumente. |
| `skip(n)` | Überspringt die ersten `n` Dokumente. |
| `count()` | Zählt die Anzahl der Dokumente. |
| `lookup("collection", "lokalesFeld", "fremdesFeld", "als")` | Führt einen Join mit einer anderen Collection durch. |

Und die am häufigsten verwendeten Akkumulatoren:

| Akkumulator | Beschreibung |
|---|---|
| `sum("feld", "$ausdruck")` | Summe der Werte. |
| `avg("feld", "$ausdruck")` | Durchschnitt der Werte. |
| `min("feld", "$ausdruck")` | Minimalwert. |
| `max("feld", "$ausdruck")` | Maximalwert. |
| `first("feld", "$ausdruck")` | Wert des ersten Dokuments. |
| `last("feld", "$ausdruck")` | Wert des letzten Dokuments. |
| `top("feld", sortierung, "$ausdruck")` | Oberster Wert gemäß der Sortierung. |
| `bottom("feld", sortierung, "$ausdruck")` | Unterster Wert gemäß der Sortierung. |

> In den Akkumulatoren bezieht sich der Ausdruck mit dem Präfix `$` auf das Feld eines Eingabedokuments, zum Beispiel `"$preis"`.

## Operationen mit Optionen

Die Factories `*Options()` der Ressource `_mongo` geben die Standard-Optionsobjekte des MongoDB-Treibers zurück, und Sie können ihre Methoden direkt verketten. Zum Beispiel fügt `upsert(true)` das Dokument ein, wenn der Filter keinem vorhandenen Dokument entspricht:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const old = collection.findOneAndUpdate(
                    _mongo.filters().eq("name", "Monitor"),
                    _mongo.updates().set("menge", 8),
                    _mongo.findOneAndUpdateOptions().upsert(true)
                )
            `
        },
        {
            lang: 'python',
            code: `
                old = collection.findOneAndUpdate(
                    _mongo.filters().eq("name", "Monitor"),
                    _mongo.updates().set("menge", 8),
                    _mongo.findOneAndUpdateOptions().upsert(true)
                )
            `
        },
        {
            lang: 'ruby',
            code: `
                old = collection.findOneAndUpdate(
                    _mongo.filters().eq("name", "Monitor"),
                    _mongo.updates().set("menge", 8),
                    _mongo.findOneAndUpdateOptions().upsert(true)
                )
            `
        },
        {
            lang: 'kotlin',
            code: `
                val old = collection.findOneAndUpdate(
                    _mongo.filters().eq("name", "Monitor"),
                    _mongo.updates().set("menge", 8),
                    _mongo.findOneAndUpdateOptions().upsert(true)
                )
            `
        },
        {
            lang: 'groovy',
            code: `
                def old = collection.findOneAndUpdate(
                    _mongo.filters().eq("name", "Monitor"),

                    _mongo.findOneAndUpdateOptions().upsert(true)

Wenn das Dokument eingefügt wird, gibt `findOneAndUpdate()` `null` zurück.

Die verfügbaren Options-Factories sind: `insertOneOptions()`, `insertManyOptions()`, `updateOptions()`, `findOneAndUpdateOptions()`, `replaceOptions()`, `findOneAndReplaceOptions()`, `deleteOptions()`, `findOneAndDeleteOptions()`, `countOptions()`, `estimatedDocumentCountOptions()`, `dropCollectionOptions()` und `textSearchOptions()`.
