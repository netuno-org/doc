Behalten Sie im Kopf, was nötig ist, um sich in Netuno weiterzuentwickeln.

Die Dokumentation wird im Allgemeinen ständig verbessert und ist bemüht, so einfach und einsteigerfreundlich wie möglich zu sein.

Es wird jedoch davon ausgegangen, dass Sie über gewisse Grundkenntnisse und etwas Erfahrung in bestimmten Bereichen verfügen, wie zum Beispiel:

* Datenbanken, etwa Abfragen im Allgemeinen, INSERT, UPDATE und DELETE;
* Web-Services mit GET und POST;
* <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a> und <a href="https://reactjs.org/" target="_blank">ReactJS</a>;

Falls Ihnen eine dieser Kompetenzen fehlt, versuchen wir, Ihnen beim Aufbau zu helfen.

Suchen Sie stets Hilfe auf GitHub oder Discord; beachten Sie die Hinweise in der Fußzeile der Website.

## Datenbank

Mit Netuno können Sie mit verschiedenen Arten von Datenbanken arbeiten und Ihre Kenntnisse vertiefen.

Nur mit guten Datenbankkenntnissen ist es möglich, Anwendungen mit komplexen Strukturen zu erstellen, um große Datenmengen zu erfassen und zu verwalten.

So erlangen Sie die Autonomie, den wichtigsten Teil – die Datenbank – auf robuste Weise zu erstellen.

Der Aufbau einer gut organisierten und optimierten Datenbank macht den gesamten Unterschied für die Erfahrung der Endnutzer sowie für die Performance von der Entwicklung bis zur Ausführung.

## Dienste

Wenn Sie bereits Kenntnisse in einer der folgenden Programmiersprachen wie <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a> oder <a href="https://groovy-lang.org/" target="_blank">Groovy</a> haben, können Sie schnell komplexe und robuste Web-Services mit den verschiedenen Ressourcen erstellen, die Netuno für die **Low-Code**-Programmierung bietet.

Innerhalb des Anwendungsordners, insbesondere im Ordner **server**, können Sie in diesen verschiedenen Sprachen programmieren.

Verwenden Sie einfach die entsprechende Dateiendung:

* **.js** &nbsp; <a href="https://developer.mozilla.org/pt-PT/docs/Web/JavaScript" target="_blank">JavaScript</a>
* **.ts** &nbsp; <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>
* **.py** &nbsp; <a href="https://www.jython.org/" target="_blank">Python</a>
* **.rb** &nbsp; <a href="https://www.jruby.org/" target="_blank">Ruby</a>
* **.kts** &nbsp; <a href="https://kotlinlang.org/" target="_blank">Kotlin</a>
* **.groovy** &nbsp; <a href="https://groovy-lang.org/" target="_blank">Groovy</a>

Erkunden Sie die Beispiele für Web-Services, die in der Anwendung **Demo**_nstration_ enthalten sind, unter:

- `/apps/demo/server/services/samples`

Und erkunden Sie auch die Dokumentation unserer **Bibliothek**, um die verfügbaren Ressourcen im Detail kennenzulernen.


## Benutzeroberfläche

Die Frontend-Entwicklung im Web hat in den letzten Jahren viele Veränderungen erfahren, und die Verwendung von <a href="https://vite.dev/" target="_blank">Vite</a> ist zum Standard geworden.

Unsere Technologieentscheidungen für <a href="https://reactjs.org/" target="_blank">ReactJS</a>, <a href="https://bun.sh/" target="_blank">Bun</a>, <a href="https://ant.design/" target="_blank">Ant.Design</a> und <a href="http://lesscss.org/" target="_blank">Less</a> sind Technologien, die eine Produktivitätssteigerung mit großer Akzeptanz bringen.

Um Ihre Kenntnisse in diesen Technologien zu vertiefen, erkunden Sie die verschiedenen Dokumentationen in Text- und Videoform, die im Internet verfügbar sind.

Da es sich um Technologien mit großen Communities handelt, ist es nicht schwer, gutes Material zum Einstieg zu finden.

Wir erinnern daran, dass mit Netuno selbst mit ein wenig Wissen bereits große Ergebnisse erzielt werden können, was dem Frontend-Programmierer die Möglichkeit gibt, das gesamte Backend zu entwickeln, und umgekehrt; zudem kann man sich dafür entscheiden, alles nur mit einer einzigen Programmiersprache wie <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a> zu entwickeln.

## Fazit

Netuno erleichtert die Entwicklung von Webanwendungen, bei denen eine einzige Person mit geringen Kenntnissen in Datenbanken, Web-Services und Frontend komplexe Anwendungen eigenständig entwickeln kann.

Auch für große Teams, in denen es Personen mit größerer Kompetenz in den einzelnen Bereichen gibt, bringt es im Allgemeinen eine große Produktivitätssteigerung.

Netuno kann auch als Backoffice für Datenbanken oder als Server für REST-APIs für entkoppelte Frontends und mobile Anwendungen verwendet werden.

Sparen Sie Zeit und entwickeln Sie mit stärkerem Fokus auf die Geschäftslogik; mit dem Wissen, das Sie bereits haben, werden Sie weiterkommen.
