Netuno ist polyglott sowohl auf Datenbank- als auch auf Programmiersprachenebene, aber auch auf Betriebssystemebene.

Mit dieser ganzen Vielfalt erhöhen sich die Einsatzmöglichkeiten.

Durch die Unterstützung verschiedener Datenbanken, Programmiersprachen und Betriebssysteme wird die Entwicklung erleichtert, da man sich an jede Situation anpassen kann, aber eine kohärente Umgebung für die Entwicklungen gewährleistet.

## Datenbank

Es kann verwendet werden, um verschiedene Arten unterschiedlicher Datenbanken zu integrieren, und sogar mit unterschiedlichen Programmiersprachen im selben Projekt entwickelt werden.

Die Integration unterschiedlicher Datenbanken ist recht üblich, um Datenintegration durchzuführen, wenn Daten in der Datenbank eines anderen Systems abgefragt oder geändert werden.

![Logos der Datenbanken](/docs/assets/business/databases.jpg "Mehrere Datenbanken")

Netuno unterstützt die folgenden Datenbanken:

- H2 Database
- PostgreSQL
- MariaDB
- MySQL
- Microsoft SQL Server
- Oracle

## Programmiersprachen

Die Unterstützung unterschiedlicher Programmiersprachen mag im Sinne des Vermischens von Programmiersprachen nicht sehr interessant erscheinen, aber es ist möglich und bedeutet nicht, dass es so gemacht werden sollte.

In der Praxis ist es oft kompliziert, Projekte durchzuführen, bei denen eine dominierende Technologie auf eine Programmiersprache beschränkt ist, daher müssen ausschließlich für diese Programmiersprache kompetente Personen gefunden werden.

Mit Netuno haben wir letztlich ein größeres Angebot, bei dem nicht die gesamte Arbeit verloren geht, falls eine neue Programmiersprache aufgrund einer Strategieänderung, fehlender kompetenter Fachkräfte, größerer Agilität bei der Entwicklung von etwas Bestimmtem oder anderen Situationen, die sinnvoll sein können, eingesetzt werden muss.

Normalerweise wäre dies undenkbar, weil die Wartung eines Systems mit verschiedenen Programmiersprachen Sorgen bereitet, aber da dies Low-Code ist, wird diese Sorge deutlich weniger relevant, weil:

* Die Programmiersprachen in Bezug auf Logik und Algorithmus letztlich ähnlich sind.
* Die Programmiersprache unterschiedlich sein kann, aber die Ressourcen von Netuno dieselben sind und unabhängig von der Sprache auf dieselbe Weise verwendet werden.

So wird selbst ein Techniker, der sehr an die Arbeit mit einer Programmiersprache gewöhnt ist, nichts daran hindern, die Wartung in einer anderen durchzuführen; falls er seine Intervention viel weiter ausdehnen oder sogar neu erstellen muss, kann er sich dafür entscheiden, in seiner bevorzugten Sprache zu entwickeln und seine Entwicklung in die bereits verwendete Sprache zu integrieren.

![Logos der Programmiersprachen](/docs/assets/business/languages.jpg "Programmiersprachen")

Netuno unterstützt die Entwicklung in den folgenden Programmiersprachen:

- Groovy
- Java
- JavaScript
- Kotlin
- Python
- Ruby

## Betriebssysteme

Da Netuno mit mehreren Betriebssystemen arbeitet und Umgebungskonfigurationen unterstützt, kann es das korrekte Funktionieren der Entwicklungen übergreifend gewährleisten und in Entwicklungs-, Test-, Qualitäts-, Produktionsumgebungen usw. organisieren.

Die Änderung des Betriebssystems oder der Umgebung ist für das korrekte Funktionieren von Netuno und der Anwendungen unerheblich.

![Logos der Betriebssysteme](/docs/assets/business/operationsystems.jpg "Mehrere Betriebssysteme")

Die von Netuno unterstützten Betriebssysteme sind:

* Linux
* Mac OS X
* Windows
