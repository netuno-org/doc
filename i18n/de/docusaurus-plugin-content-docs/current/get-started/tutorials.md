# Tutorials

Entdecken Sie die Tutorials der Netuno-Plattform und lernen Sie in der Praxis, wie Sie Ressourcen konfigurieren, Daten modellieren, Oberflächen erstellen und Geschäftslogik im Backend entwickeln.

Diese Seite bündelt die wichtigsten Inhalte für Einsteiger und für alle, die die Nutzung der Plattform vertiefen möchten.

## Bevor Sie beginnen

Bevor Sie mit einem Tutorial beginnen, prüfen Sie, ob Ihre Umgebung bereit ist:

- **Netuno installiert** und in der lokalen oder Entwicklungsumgebung ausgeführt.
- **Zugang zum administrativen Panel** mit geeigneten Berechtigungen.
- **Empfohlene Grundkenntnisse** in Datenmodellierung, HTTP und REST-APIs, um die technischen Inhalte besser nutzen zu können.

Lesen Sie vor dem Fortfahren die Anleitung zur [Installation](./installation).

## Empfohlene Reihenfolge

Wenn dies Ihre erste Erfahrung mit Netuno ist, folgen Sie dieser Reihenfolge:

1. Lernen Sie die grafische Oberfläche kennen.
2. Erfahren Sie, wie Sie Formulare und Felder erstellen.
3. Konfigurieren Sie Beziehungen zwischen Formularen.
4. Fahren Sie mit Berechtigungen und Benutzergruppen fort.
5. Erkunden Sie Abfragen und Backend-Funktionen nach Bedarf des Projekts.

### Voraussetzungen

Bevor Sie zu diesem Abschnitt übergehen, sollten Sie mit Folgendem vertraut sein:

- Client-Server-Architektur und HTTP-Protokoll.
- Datenstrukturen in JSON.
- Programmierlogik in JavaScript, Python oder einer anderen Sprache, die mit Ihrem Entwicklungsablauf kompatibel ist.

Verwenden Sie die Tutorials zur **grafischen Oberfläche**, wenn das Ziel ist, die Anwendung visuell zu konfigurieren, Daten zu strukturieren und Ressourcen über die Oberfläche zu verwalten.

:::

## Nächste Schritte

Nachdem Sie die ersten Tutorials abgeschlossen haben, besuchen Sie die [Netuno-Akademie](/docs/academy/overview), um Ihr Wissen in spezifischen Bereichen der Plattform zu vertiefen.

Wenn Sie einen Fehler (Bug) finden oder Vorschläge für neue Funktionen haben, können Sie gerne [ein Issue auf GitHub eröffnen](https://github.com/netuno-org/doc). Unser Team und unsere Community helfen Ihnen gerne.
