Netuno は Java で開発されているため、Java から新しい機能を作成できます。

例えば、新しいネイティブサービスや、JavaScript、Python、Ruby、Groovy、Kotlin といったすべてのポリグロットプログラミング言語で利用可能な新しいローコードプログラミング機能を作成できます。

Java では、Netuno のすべてのアプリケーションで利用可能なマルチアプリケーション Web サービスを作成することもできます。

あらゆる種類の機能を作成するために、Java エコシステムのあらゆる技術やライブラリを利用できます。

> このチュートリアルを開始する前に、_Java_ の基本をいくつか理解しておくことをお勧めします。
