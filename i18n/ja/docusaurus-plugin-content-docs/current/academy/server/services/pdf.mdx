カスタムPDFファイルを処理します。

## はじめに

Netunoは、Netunoがサポートするさまざまなプログラミング言語向けに [iTextPDF](https://itextpdf.com/) の低コード抽象化を可能にする [PDF](/docs/library/resources/pdf) リソースを通じて、画像、表、フォントなどをサポートするPDFファイルを生成します。

Netunoに付属する **demo** というアプリケーション（デモアプリケーション）には、さまざまな言語でのコード実装例が多数含まれています。これには、次の場所にある `export-pdf` サービスを通じたPDFエクスポートのデモも含まれます：

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-pdf`
]} />

## HTTPヘッダー

REST APIでPDFファイルをデータ出力として返すサービスを作成するには、HTTPプロトコルの `Content-Type` パラメータをヘッダーに追加する必要があります。

コンテンツをPDFとして定義する例：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("pdf")
            `
        },
    ]}
/>

`pdf` というコードは次の略称です：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("application/pdf")
            `
        },
    ]}
/>

## 段落

ドキュメントに新しい段落を追加します：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    _pdf.paragraph("ここにテキスト...")
                        .setFontSize(15)
                )
            `
        },
    ]}
/>

固定位置に段落を追加するには：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    pdfDocument.add(
                        _pdf.paragraph("固定テキスト...")
                            .setFixedPosition(100, 500, 200)
                            .setFontSize(15)
                    )
                )
            `
        },
    ]}
/>

上記のコードでは、`setFixedPosition` メソッドの最初のパラメータがX位置（`100`）、2番目のパラメータがY位置（`500`）、3番目のパラメータが幅（`200`）です。

**注意：** Yを `0` に設定するとページの最下部になります。上に移動するにはYの値を大きくします。Yの値が大きいほど上に表示されますが、ページの長さを超えて大きすぎると表示されません。

> [iTextの段落](https://api.itextpdf.com/iText/java/8.0.3/com/itextpdf/layout/element/Paragraph.html)オブジェクトのすべてのメソッドに関するドキュメント。

## 表

表を作成できるため、データの集合をより読みやすく提示できます。

表の列数はパラメータ `_pdf.table(列数)` で定義します。

以下の例では `列数` は `1`、つまり1列です。

表に2つのセルを追加しているため、2番目のセルは次の行に移動します。

ご覧ください：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.add(
                    _pdf.table(1)
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("人物")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBorder(_pdf.border("solid", 2))
                                .setBackgroundColor(_pdf.colorRGB(1, 0, 0))
                        )
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("ニコル")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBackgroundColor(_pdf.colorGray(0.5))
                        )
                )
            `
        },
    ]}
/>

`addCell` メソッドを使用すると、セルの定義とそれぞれの内容を挿入できます。

> [iTextのセル](https://api.itextpdf.com/iText/java//8.0.3/com/itextpdf/layout/element/Cell.html)オブジェクトのすべてのメソッドに関するドキュメント。

## ドキュメントを閉じて保存

ドキュメントは、`close` メソッドが呼び出されたときにのみ完全に保存または生成されます。次のようにします：

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                pdfDocument.close()
            `
        },
    ]}
/>

ドキュメントをどこに生成するかは初期化時に定義されます。したがって、最終ドキュメントをサービスのデータ出力（`output`）に生成するかファイルに生成するかは、ドキュメントの初期化時に定義します。

## ファイルの読み取り

PDFドキュメントを読み取り、テキスト情報を抽出するには。

`extract` メソッドを使用します。これはPDFファイルのすべてのデータをJSONオブジェクトとして取得します。

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const pdfData = _pdf.extract(_app.file("ファイル-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'python',
            code: `
                pdfData = _pdf.extract(_app.file("ファイル-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'ruby',
            code: `
                pdfData = _pdf.extract(_app.file("ファイル-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'kotlin',
            code: `
                val pdfData = _pdf.extract(_app.file("ファイル-1.pdf"))

                _out.json(pdfData)
            `
        },
        {
            lang: 'groovy',
            code: `
                def pdfData = _pdf.extract(_app.file("ファイル-1.pdf"))

                _out.json(pdfData)
            `
        },
    ]}
/>

返されるJSONには、PDFファイルのすべてのテキスト内容を持つ `content` キーと、PDFファイルのさまざまなプロパティを持つ `metadata` キーがあります。

`extract` によって返されるJSONの例を次に示します：

```json
{
  "content": "PDFファイルのすべてのテキスト内容がここに表示されます...",
  "metadata":{
    "Content-Type":"application/pdf",
    "dc:format":"application/pdf; version=1.4",
    "dc:title":"Linux 1",
    "pdf:PDFVersion":"1.4",
    "pdf:charsPerPage":"580",
    "pdf:containsDamagedFont":"false",
    "pdf:containsNonEmbeddedFont":"false",
    "pdf:docinfo:producer":"Skia/PDF m125 Google Docs Renderer",
    "pdf:docinfo:title":"ファイル1",
    "pdf:encrypted":"false",
    "xmpTPg:NPages":"3",
    ...
  }
}
```

`metadata` で取得されるデータは他にも多数ありますが、例が長くなりすぎないよう `...` では省略しています。
