## UIDとは

UID（一意の識別子）は、その名のとおり、アプリケーション全体で一意の文字列です。GUID（グローバル一意識別子）とも呼ばれます。

UIDの生成を例示するために、サービスを作成します。

## UIDの生成

次に、ランダムなUIDの作成を示します。Netunoにはこの目的のために特別に用意された関数がすでに含まれているため、非常に簡単です：

```javascript
_out.println(
  _uid.generate()
)
```

> `_out.println()` 関数は、ブラウザでサービスを呼び出したときに結果を画面に表示できるようにするためのものです
