## はじめに

Netunoでは、標準のアドレスを変更できます。たとえば：

- 管理インターフェースのアドレス `admin`
- 画像、CSS、JSなどの公開ファイルのアドレス `public`
- REST APIサービスのアドレス `services`

## 設定

開発中のアプリケーション内で、環境設定ファイルまで移動します。この例では、次の場所にある開発環境ファイルを使用します：

- 📂 `config/_development.json`

URL設定がまだ存在しないことを確認し、存在しない場合は設定ファイルの末尾にURL設定パラメータを（JSON形式で）追加します。例：

```json
{
    ...
    "url": {
        "admin": "/admin/",
        "public": "/public/",
        "services": "/api/"
    },
    ...
}
```

### admin

管理インターフェースのURLアドレスのプレフィックスを定義します。標準では `/` のみです。

### public

画像、CSSスタイル、JavaScriptコードなどの公開される静的ファイルのURLアドレスのプレフィックスを定義します。標準は `/public` です。

### services

REST APIのWebサービスの開始URLアドレスを定義します。標準は `/services` です。

## まとめ

URLのカスタマイズは、より直感的にするためにも、より複雑にしてセキュリティを高めるためにも重要です。

たとえば、管理アドレスにランダムな文字列のプレフィックスを付けることができます。そうすれば、その文字列を覚えている人だけがアクセスアドレスにアクセスできるため、アクセスが難しくなり、攻撃を防げます。
