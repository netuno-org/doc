Netuno のインターフェースは、それぞれ異なる目的を持つ 2 つのワークエリアに分かれています。最終的なアプリケーション（フロントエンド）の結果を操作・表示するための*表示*モードと、アプリケーションを開発するための*構築*モードです。

### 表示

これは、ユーザーがアプリケーションのビジュアル部分を操作するフロントエンド環境です。

#### 1 - 構築

このボタンで、アプリケーションの開発モードにアクセスできます。

#### 2 - ドロップダウンメニュー

セッションを管理するためのオプションを選択できます。たとえば、ログアウト、アカウントのパスワード変更、ユーザーとグループのデータの確認などです。

#### 3 - マイワークスペース

ここは中央のエリアで、`public` フォルダでプログラムされた Web フロントエンドアプリケーションが表示されます。

#### 4 - テーブルとフォーム

このエリアでは、すべてのデータテーブルにアクセスできます。クリックすると、フォームを通じてデータを直接表示、追加、編集、削除できます。

![表示画面](/docs/assets/academy/ui/get-to-know/view-pt.png)

### 構築

アプリケーションのあらゆる側面を、大量のコードを書くことなく設定・管理できるローコード環境です。

#### 1 - 表示

「表示」モードに即座に戻り、変更の影響をリアルタイムで確認できます。

#### 2 - ドロップダウンメニュー

アプリケーションからログアウトできます。

#### 3 - マイワークスペース

ここは中央のエリアで、`public` フォルダでプログラムされた Web フロントエンドアプリケーションが表示されます。

#### 4 - 管理

このセクションでは、フォーム、レポート、クエリ、ダイアグラムを管理できます。

#### 5 - デバッグ

このセクションでは、実行時のスクリプトの動作を監視および検査できます。これにより、問題の特定、変数値の追跡、コードの実行フローの理解が可能になります。

#### 6 - フィールド管理

このセクションでは、データテーブルの構造を管理できます。フィールドの追加、編集、削除を行い、それぞれのデータ型（テキスト、数値、日付など）を定義できます。
