## ユーザーインターフェース（`ui`）

Netunoのデータ管理インターフェースでは、カスタマイズや独自の操作を行うためのカスタムコードを注入できます。

開発は、アプリケーションのルートフォルダー内にある`ui`フォルダー内でコーディングして行います。

### addPageLoad()

アプリケーションが「準備完了」になるまで、ページを安全に操作することはできません。

このメソッドは、ページが読み込まれたときに呼び出されます。

```javascript
netuno.addPageLoad(() => {
   console.log('何かをする');
});
```

### addContentLoad()

フォームやレポートが読み込まれると、データフォーム、検索、またはレポートのデータをフィルタリングするときなど、それぞれのコンテンツでインターフェースが変更されます。

コンテンツが読み込まれるとすぐにこのメソッドが呼び出され、表示されるコンテンツを格納するコンテナが渡されます。

```javascript
netuno.addContentLoad((container) => {
   if (container.is('[netuno-form-search]')) {
       console.log('要素が存在するときに何かをする');
   }
});
```
