Netunoはデータベースやプログラミングコードのレベルだけでなく、オペレーティングシステムのレベルでもポリグロットです。

この多様性により、利用できる場面の選択肢が広がります。

さまざまなデータベース、プログラミング言語、オペレーティングシステムをサポートすることで、それぞれの状況に適応しながら開発を容易にし、開発のための一貫した環境を保証します。

## データベース

さまざまな種類の異なるデータベースを統合するために使用でき、同じプロジェクト内で異なるプログラミング言語で開発することも可能です。

異なるデータベースを統合することは、別システムのデータベースのデータを参照または変更する際のデータ統合を行う上で非常に一般的です。

![データベースのロゴ](/docs/assets/business/databases.jpg "複数のデータベース")

Netunoは以下のデータベースをサポートしています:

- H2 Database
- PostgreSQL
- MariaDB
- MySQL
- Microsoft SQL Server
- Oracle

## プログラミング言語

異なるプログラミング言語をサポートすることは、プログラミング言語を混在させるという意味ではあまり興味深くないように思えるかもしれませんが、可能であり、そうしなければならないというわけではありません。

実際には、特定のプログラミング言語に限定された支配的な技術があるプロジェクトを遂行することはしばしば困難であり、そのため、そのプログラミング言語に専ら精通した人材を確保する必要があります。

Netunoではより多くの選択肢を持つことになり、戦略の変更、有能な技術者の不足、特定のものを開発する際のより高い俊敏性の獲得など、理にかなう他の状況に由来して新しいプログラミング言語を使用する必要が生じても、すべての作業が無駄になりません。

通常、これは考えられないことです。なぜなら、複数のプログラミング言語を抱えるシステムの保守は懸念事項になり始めるからです。しかし、これがlow-codeであるため、その懸念はあまり重要ではなくなります。なぜなら:

* プログラミング言語は、論理やアルゴリズムのレベルでは結局似通ったものになります。
* プログラミング言語は異なっていても、Netunoのリソースは同じであり、言語に関係なく同じ方法で使用されます。

したがって、技術者が特定のプログラミング言語での作業に非常に慣れていても、別の言語で保守を行うことを妨げるものは何もありません。自分の介入をさらに大きく拡張する必要がある場合や、やり直す必要がある場合は、好みの言語で開発し、その開発を既に使用されている言語に統合することを選べます。

![プログラミング言語のロゴ](/docs/assets/business/languages.jpg "プログラミング言語")

Netunoは以下のプログラミング言語での開発をサポートしています:

- Groovy
- Java
- JavaScript
- Kotlin
- Python
- Ruby

## オペレーティングシステム

Netunoは複数のオペレーティングシステムで動作し、環境設定をサポートすることで、開発が横断的に正しく機能することを保証し、開発、テスト、品質、本番などの環境に整理できます。

オペレーティングシステムや環境の変更は、Netunoおよびアプリケーションの正しい動作に影響しません。

![オペレーティングシステムのロゴ](/docs/assets/business/operationsystems.jpg "複数のオペレーティングシステム")

Netunoがサポートするオペレーティングシステムは:

* Linux
* Mac OS X
* Windows
