Netunoのコマンドラインインターフェースは、開発環境を管理するための主要なツールです。これを通じて、システム情報の照会、アプリケーションの管理、サーバーの設定をすばやく行えます。

#### 前提条件

- **ターミナル:** Netunoをインストールしたルートフォルダで、ターミナル（コマンドプロンプト、PowerShell、Bash）を開いておく必要があります。

環境が使用可能か確認するための初期コマンドは次のとおりです。

| オプション    | 説明    |
|----------|--------------|
| `help` | Netunoで利用可能なすべてのコマンドを表示します。 |
| `version` | 現在のNetunoのバージョンを表示します。 |

#### 利用可能なコマンドの一覧表示

実行できる操作が分からない場合は、ヘルプコマンドを使用してください。利用可能な機能の完全なリストが返されます。

```shell
./netuno help
```
#### Netunoのバージョン確認

特定のスクリプトやモジュールとの互換性を確保するには、使用しているバージョンを把握しておくことが重要です。

```shell
./netuno version
```

## インストール

開発を開始する前に、Netunoエンジンを環境にインストールする必要があります。詳細については、[インストール](/docs/get-started/installation)ページをご覧ください。

このセクションでは、インストールプロセスを自動化または最適化するために使用できるパラメータについて詳しく説明します。

| オプション | 説明 |
|----------|--------------|
| `checksum` | インストール済みパッケージ内のすべてのファイルのチェックサム (checksum) を更新します。 |
| `force` | ローカルに変更がある場合でも、すべてのファイルを強制的に置き換えます。|
| `graal=true/false` | アプリケーション実行時のパフォーマンスを向上させるためにGraalVMを使用するかどうかを定義します。 |
| `path=[ディレクトリ]`| Netunoをインストールするパス（フォルダ）を手動で定義します。|
| `remove` | システムからNetunoに関連するすべてのファイルを完全に削除します。|
| `version=[バージョン]`| インストールする特定のバージョンを選択します。開発版には latest を使用してください。|
| `yes`| すべての確認に自動的に「はい」と回答し、データ損失に関する警告を無視します。|

#### チェックサムを更新する例:

```shell
./netuno install checksum
```

#### すべてのローカル変更を強制的に置き換える例:

```shell
./netuno install force
```

#### GraalVMを無効にする例: 

```shell
./netuno install graal=false
```

> GraalVMはデフォルトで有効になっており、Netunoのインストール時に自動的にダウンロードされます。

#### インストールパスを定義する例:

```shell
./netuno install path ='netunoDir'
```
#### Netunoのすべてのフォルダを削除する例:

```shell
./netuno install remove
```

#### インストールするNetunoのバージョンを選択する例:

```shell
./netuno install version='latest'
```

##### すべての質問に「はい」と回答する例: 
```shell
./netuno install yes 
```

## サーバー

インストールが完了したら、サーバーを起動してアプリケーションの開発を開始します。

デフォルト設定でサーバーを起動するには、Netunoのルートフォルダで以下のコマンドを実行します:

```shell
./netuno server
```

> デフォルトでは、サーバーはポート9000を使用します。ターミナルにシステムの準備ができたことが表示されたら、次のリンクから管理パネルにアクセスできます: http://localhost:9000/

このセクションでは、サーバーの起動プロセス中に使用できるパラメータについて詳しく説明します。

オプション | 説明 |
|----------|--------------|
| `app=[アプリ名]` | 起動するアプリケーションを明示的に定義します |
| `host=[IP/ホスト名]` | Netunoのホスト名を変更できます |
| `launch=true/false` | Netunoがブラウザを自動的に開くかどうかを定義します |
| `npm` | アプリのフロントエンドをリアルタイムでコンパイルするために 'npm watch' コマンドを自動実行します |
| `port=[番号]` | サーバーの起動ポートを定義します |
| `secret=[パスワード]` | サーバーのリモート管理へのアクセスを許可するためのセキュリティパスワードを定義します |
| `web=[フォルダ]` | 既定のプロジェクトルートフォルダ（webホーム）を変更します |

デフォルトでは、Netunoは **'webapp'** フォルダを使用して、動作に必要なすべてのファイルを保存します。

**ディレクトリ変更時の注意:** `web=[フォルダ]` パラメータを使用してルートフォルダ名を変更する場合は、ファイルシステム上でも実際にフォルダ名を変更する必要があることに注意してください。このコマンドはNetunoのコードにファイルを探す場所を指示するだけで、フォルダ名を自動的に変更するものではありません。

#### 特定のアプリケーションのサーバーを起動する例:

```shell
./netuno server app=myapp
```

#### ホスト名を変更する例:

```shell
./netuno server host=localhost
```

#### Netunoがブラウザを自動的に起動するかどうかを定義する例:

```shell
./netuno server launch=false
```

>デフォルトでは、Netunoはブラウザを開き、http://localhost:9000 を起動します。

#### フロントエンドを自動構築するためにnpmを実行する例

```shell
./netuno server npm
```

#### ポートを変更する例:

```shell
./netuno server port=10000
```

#### サーバーのリモート管理にアクセスするためのパスワードを定義する例:

```shell
./netuno server secret='p#ssw@rd'
```

#### Webのデフォルトフォルダを変更する例:

```shell
./netuno server web=webapp
```

## ライセンス

Netunoでの開発を開始するには、環境を登録する必要があります。

ライセンスを管理するには、基本コマンドを使用します:

```shell
./netuno license
```

> 現在、Netunoは **Community、Standard、Enterprise** の3種類のライセンスを提供しています。

このセクションでは、ライセンスの設定または確認に使用できるアクションについて詳しく説明します。

| オプション    | 説明    |
|----------|--------------|
| `create , change` | 新しいライセンスを作成する、または現在のライセンスを変更するプロセスを開始します |
| `key` | 環境で有効なライセンスキーを表示します |
| `mail=[メールアドレス]` | ライセンスアカウントに関連付けられたメールアドレスを定義します |
| `type=[community/standard/enterprise]`  | ライセンスの種類を定義します|


#### ライセンスを作成する例:

```shell
./netuno license create
```

#### ライセンスキーを表示する例: 

```shell
./netuno license key
```
##### メールアドレスとライセンスの種類を定義する例:

```shell
./netuno license mail='taro@example.com' type='community'
```

## アプリケーション

サーバーが設定され、ライセンスが有効になったら、新しいソリューションを作成してエコシステムを拡張できます。

```shell
./netuno app
```

生成されたファイルは、Netunoのフォルダ構造内に自動的に整理されます。

アプリケーションのファイルにアクセスまたは編集するには、システムルートから次のパスに移動します: **webapp / apps / [アプリ名]**

#### フォルダ構成

- **webapp**: Netunoの動作に必要なすべてのファイルを含むルートフォルダです。

- **apps**: 開発済みまたはデモ用のすべてのアプリケーションが保存される専用フォルダです。

- **[アプリ名]**: 作成したアプリケーション専用のフォルダです。

デフォルトでは、Netunoサーバーの起動時に表示されるデモアプリケーションが用意されています。

| オプション    | 説明    |
|----------|--------------|
| `database=[データベース名]` | データベースの名前を定義します |
| `engine=[名前]` | データベースの種類を定義します |
| `host=[アドレス]` | データベースのアドレスを定義します。 |
| `language=[言語]`  | アプリケーションの言語を定義します |
| `locale=[ロケール]` | アプリケーションのロケールを定義します |
| `name=[名前]`  | アプリケーションを作成する、または既存のアプリケーションを再構築できます |
| `password=[パスワード]`  | データベースのパスワードを定義します |
| `port=[番号]`  | データベースのポートを定義します |
| `username=[名前]`  | データベースのユーザー名を定義します |

#### データベース名を定義する例:

```shell
./netuno app database=employee
```

> データベース名には数字と文字を含めることができます。名前に複数の単語が含まれる場合は、次のように "_" で区切る必要があります。
>
> **例:** employee_db

#### データベースの種類を定義する例:

```shell
./netuno app engine=pg
```
次のデータベースの種類があります:
> - PostgreSQL - **pg**
> - MariaDB - **mariadb**
> - Microsoft SQL Server - **mssql**
> - H2 Database - **h2**

#### データベースサーバーのアドレスを定義する例:

```shell
./netuno app host=localhost
```

#### 言語とロケールを定義する例:

```shell
./netuno app language=pt_PT locale=pt_PT
```
次の言語があります:
> - ポルトガル語 - pt_PT
> - ブラジルポルトガル語 - pt_BR
> - 英語 - en_US
> - スペイン語 - es_ES

#### アプリケーションを作成する、または既存のアプリケーションを再構築する例:

```shell
./netuno app name=demo
```

#### データベースのパスワードを定義する例:

```shell
./netuno app password=secret
```

#### データベースのポートを定義する例:

```shell
./netuno app port=5432
```
デフォルトでは、ポートは次のようになります:  

> - PostgreSql - **5432**
> - MariaDB -**3306**
> - Microsoft SQL Server - **1433**

#### データベースのユーザー名を定義する例:

```shell
./netuno username=root
```
