CLUAR で最も汎用的なテキストおよび画像コンポーネントです。

## はじめに

**コンテンツ**は CLUAR で最も汎用的なテキスト/画像コンポーネントです — 選択したタイプに応じて、シンプルなテキストブロック、横に画像を伴うテキスト、または画像のみに使用されます。

すべてのコンポーネントに共通する同じ仕組みに従います。詳細は[概要](/docs/academy/cluar/components/overview) と[コンポーネントタイプ](/docs/academy/cluar/components/types) で説明しています。

## フィールド

[共通フィールド](/docs/academy/cluar/components/overview#共通フィールド)（タイプ、順序、編集モード、背景反転、アクション）に加えて、コンテンツには次のフィールドがあります:

| フィールド | 説明 |
|---|---|
| **タイトル** (`title`) | コンテンツブロックのタイトル。 |
| **コンテンツ** (`content` / `html_content`) | ブロックのテキスト。 |
| **画像** (`image`) | 関連付けられた画像（テキストのみのタイプでは使用されません）。 |
| **画像の代替テキスト** (`image_alt`) | 画像の代替テキスト。 |
| **画像のタイトル** (`image_title`) | 画像の `title` 属性。 |
| **画像の最大幅** (`image_max_width`) | 画像の幅をピクセル単位で制限します — ワイド画面で画像が必要以上に引き伸ばされないようにするのに便利で、特に画像がテキストの横に配置されるタイプで役立ちます。 |

## 利用可能なタイプ

Banner とは異なり、コンテンツには画像とテキストのさまざまな配置に特化した複数のタイプがあります:

- **標準** (`Default`)
- **テキスト** (`TextContent`) — テキストのみで、画像はありません。
- **画像** (`ImageContent`) — 画像のみで、テキストはありません。
- **画像を左に配置** (`ImageLeft`)
- **画像を右に配置** (`ImageRight`)
- **画像を上に配置** (`ImageTop`)
- **画像を下に配置** (`ImageBottom`)

タイプの動作と新しいタイプの作成方法の詳細は、[コンポーネントタイプ](/docs/academy/cluar/components/types) を参照してください。
