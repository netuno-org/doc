フォームや地図など、ページに追加できる具体的な機能です。

## はじめに

**機能**は他のコンポーネントとは異なります。同じ内容の視覚的なバリエーションではなく、各タイプがページに追加する**具体的な機能**です。現在は、お問い合わせフォームまたは地図です。

すべてのコンポーネントに共通する仕組みに従います。詳細は[概要](/docs/academy/cluar/components/overview)と[コンポーネントの種類](/docs/academy/cluar/components/types)で説明していますが、ここでは「種類」を選択する際に、単に異なるスタイルではなく、**どの機能**をページに表示するかを選択します。

## フィールド

[共通フィールド](/docs/academy/cluar/components/overview#共通フィールド)（種類、順序、編集モード、背景を反転、アクション）に加えて、機能には以下があります：

| フィールド | 説明 |
|---|---|
| **タイトル** (`title`) | ブロックのタイトル。 |
| **コンテンツ** (`content` / `html_content`) | ブロックのテキスト。 |
| **画像** (`image`) | 関連付けられた画像（すべての種類で使用されるわけではありません）。 |

## 利用可能な種類

### お問い合わせフォーム (`ContactForm`)

お問い合わせフォーム（名前、メールアドレス、メッセージ）を表示し、reCAPTCHA で保護します。送信されると、データをサーバー上の `contact` サービスに送信します。このサービスは `contact` エンティティに保存し（バックオフィスで表示可能）、メールによるアラートを設定できます。

### お問い合わせマップ (`ContactMap`)

[Mapbox](https://www.mapbox.com/) を使用したインタラクティブな地図を表示します。設定 `settings.cluar.website.mapbox` を使用します（[設定](/docs/academy/cluar/configuration)を参照）。特に `accessToken`（地図の動作に必須）と `dark` オプション（地図のライトテーマまたはダークテーマ）があります。

## 次のステップ

5つのコンポーネントを確認したら、[アクション](/docs/academy/cluar/actions)に進みます。アクションはほとんどのコンポーネントに関連付けることができます。
