コンポーネントに関連付ける CTA（ボタン/リンク）を作成および再利用する方法。

## はじめに

**アクション** は、本質的には再利用可能な **CTA**（call-to-action）です — タイトル、テキスト、画像、遷移先（`link`）を持つボタン/リンクで、バナー、コンテンツ、リスト、スライダー（項目内）、機能などの[コンポーネント](/docs/academy/cluar/components/overview)に関連付けることができます。

## フィールド

| フィールド | 説明 |
|---|---|
| **タイトル** (`title`) | アクションのタイトル。見出し (`<h4>`) としてレンダリングされます。 |
| **コンテンツ** (`content`) | アクションの説明テキスト。段落 (`<p>`) としてレンダリングされます。 |
| **表示テキスト** (`indication`) | リンク/CTA 自体のテキスト — クリック可能なボタンの**内部**に表示される文言です（例:「詳しくはこちら」「今すぐ購入」）。 |
| **画像** (`image`) | アクションに関連付けられた画像（例: アイコン）。 |
| **リンク** (`link`) | アクションの遷移先（URL）— CTA をクリックしたときに移動する先です。 |
| **言語** (`language_id`) | このアクションが属する言語。 |
| **パラメータ** (`parameter_id`) | このアクションを他言語の同等アクションとグループ化します — 以下を参照。 |

## パラメータ

**パラメータ** (`action_parameter`、`código` と `descrição` のみを持つ) はグループ化の仕組みです。複数のアクション — それぞれの言語にありながら、**同じ機能/遷移先**を表すもの — が同じパラメータを共有します。

これは[ページを複製](/docs/academy/cluar/pages/cloning)して別の言語にするときに使用されます。元のページのコンポーネントに関連付けられた各アクションについて、CLUAR は既存のアクションの中から、**同じパラメータ**を持ち、複製先の**言語**であるアクションを探します。見つかった場合、そのアクション（すでに翻訳済みのバージョン）を複製されたコンポーネントに自動的に関連付けます — 後から手動で追加する必要はありません。

:::info 先に複製先の言語でアクションを作成する必要があります
自動関連付けは、複製先の言語に同じパラメータを持つアクションがすでに存在する場合にのみ機能します。まだ存在しない場合、そのアクションは複製されたコンポーネントに関連付けられません — 定義されていなかったかのようになります。つまり、パラメータはアクションを自動翻訳したり作成したりするものではなく、各言語で作成済みの同等アクション同士を結び付けるだけです。
:::

例: 日本語の「詳しくはこちら」というアクション（パラメータ `more-info`）と、英語の「Learn more」というアクション（同じくパラメータ `more-info`）があるとします — 日本語のページを英語に複製すると、最初のアクションが関連付けられていたバナーには、自動的に2番目のアクションが関連付けられます。
