ウェブサイトのインターフェースの固定テキストを翻訳する方法。

## はじめに

**辞書**は、ウェブサイトのインターフェースにおける固定テキストの翻訳システムです — ラベル、メッセージ、ボタンのテキストなど、ページのコンテンツではなくコードに「埋め込まれた」テキストでありながら、各言語で存在する必要があるものです。

バックオフィスの2つのフォームが関係します:

- **エントリ** (`translation_entry`)
- **辞書** (`translation`)

## エントリ

翻訳の「キー」を定義します — **コード**（`code`、値を取得するためにコード内で使用）と**説明**。例: エントリ `otoiawase-form-seikou` は、お問い合わせフォームの成功メッセージに使用されます（Funcionalidade の [`ContactForm`](/docs/academy/cluar/components/functionality) に表示されるのはまさにこのエントリです）。

## 辞書

特定の**言語**（`language_id`）に対するエントリの**翻訳値**です — フィールド**値**（`value`、HTMLを受け付けます）。

:::info 汎用値／言語に依存しない値はありません
[設定](/docs/academy/cluar/settings) とは異なり、辞書には言語を指定しないフォールバックの仕組みが**ありません** — 各エントリは、使用する各言語に対して明示的に値を定義する必要があります。ある言語で翻訳が欠けている場合、表示されるテキストは汎用値ではなく、エントリのコード自体（例: `otoiawase-form-seikou`）になります。
:::

## プログラムから

クラス `website/src/common/Cluar.js` は、辞書のエントリを読み取る関数を提供しており、翻訳が存在しない場合はすべてエントリのコードを結果として返します（翻訳漏れに気づくのに便利です）:

- `Cluar.translation(エントリ)` — 現在の言語で翻訳された値を、保存されたとおりに取得します（HTMLを含む場合があります）。
- `Cluar.plainTranslation(エントリ)` — 同じですが、`<p>` と `<br>` タグを削除します。インターフェースのラベル（ボタン、フォームフィールド、通知）で最もよく使われます。
- `Cluar.plainTitle(エントリ)` — 同じですが、`<p>` タグのみを削除します。
- `Cluar.plainHTML(エントリ)` — すべてのHTMLタグを削除します。
- `Cluar.translationNoParagraph(エントリ)` — `<p>` タグのみを削除します（`plainTitle` と同等）。
