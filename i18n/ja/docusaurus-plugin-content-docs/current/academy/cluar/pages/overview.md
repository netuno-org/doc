**ページ**は CLUAR の中心的なエンティティであり、ウェブサイトの URL を表します。各ページは単一の言語に属します — 単一の「多言語」ページは存在せず、各言語が独自のページ（独自の `link`、タイトル、コンテンツなど）を持ち、それらは[クローン作成](/docs/academy/cluar/pages/cloning)アクションによってのみ相互にリンクされます。

各ページは組織に属します。ページにはサブページを作成でき、サブページはデフォルトで親ページと同じ組織に属します。

## フィールド

| フィールド | 説明 |
|---|---|
| **タイトル** (`title`) | ページのタイトル。 |
| **リンク** (`link`) | ページの URL（例: `/会社概要`）。 |
| **言語** (`language_id`) | このページが属する言語。 |
| **親** (`parent_id`) | 親ページ。階層/パンくずリストおよびサブメニューの構築に使用されます。 |
| **テンプレート** (`template`) | ページのレンダリングに使用されるテンプレート（[テンプレート](/docs/academy/cluar/templates)を参照）。フォーム内のセレクトであり、`website/src/pages/Template/` にある既存のフォルダーで動的に選択肢が設定されます。 |
| **状態** (`status_id`) | 下書きまたは公開済み — 現在のバージョンの状態を反映します。 |
| **メニュー** (`menu`) | チェックすると、ページがナビゲーションメニューに表示されます。 |
| **メニュータイトル** (`menu_title`) | メニューに表示する代替タイトル（空の場合はページのタイトルを使用）。 |
| **ナビゲート可能** (`navigable`) | ページに直接アクセスできるかどうか（メニューに表示されていなくても）を制御します。 |
| **順序** (`sorter`) | 同じ `parent_id` を持つ「兄弟」ページ間でのページの位置。 |
| **説明** / **キーワード** | SEO 用メタタグ（`<meta name="description">` / `<meta name="keywords">`）。 |
| **ソーシャルメディア用の説明** / **ソーシャルメディア用の画像** | ページが共有されるときに Open Graph タグ（`og:description`、`og:image`）で使用されます。 |

## 次のステップ

各ページには複数のバージョンがあり、公開フローを経ます — [バージョンと公開](/docs/academy/cluar/pages/versions-publishing)を参照してください。
