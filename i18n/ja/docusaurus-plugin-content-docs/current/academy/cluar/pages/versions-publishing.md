## バージョン

各ページには1つ以上の**バージョン**（`page_version`）があり、それぞれが独自の状態（下書き / 公開）を持ちます。これにより、公開済みの内容に影響を与えずに新しいバージョンのコンテンツを編集できます。バージョンが公開済みとしてマークされたときにのみ、そのバージョンがページのアクティブなバージョンになります。

コンテンツコンポーネント（バナー、コンテンツ、リスト、スライダー、機能）は常に特定のバージョン（`page_version_id`）に属し、ページに直接属するわけではありません。つまり、下書きバージョンでコンポーネントを編集しても、公開済みの内容には影響しません。

## 公開

ページを公開すると、CLUARは次の処理を行います。

1. 公開されたバージョンのすべてのアクティブなコンポーネント（バナー、コンテンツ、リスト、スライダー、機能、およびそれぞれのアクション）を収集します。
2. その内容を含むJSON構造ファイルを生成します。
3. 本番環境では、ページのURL（言語ごと）向けに静的な`index.html`を事前レンダリングします。このときSEOおよびOpen Graphのメタタグはすでに設定されています — サイト自体がReactのSPAであるため、ソーシャルメディアでの共有や検索エンジンにとって重要です。
