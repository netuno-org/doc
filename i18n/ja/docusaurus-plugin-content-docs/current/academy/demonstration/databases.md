# データベース

このステップでは、以前に定義した**タスク**フォームから自動的に作成された**データベース**を確認します。

**名前**フィールドを持つ**タスク**フォームを作成すると、Netuno はフォーム作成時に定義した名前に従って、データベースに `name` 列を持つ `task` テーブルを作成しました。

フィールドの**技術名**（例: `task`、`name`、`task_id`）は、プログラミングや SQL クエリで使用され、インターフェースに表示される名前とは一致しません。

## クエリ

このセクションでは、Netuno の管理インターフェースを使用して、データベースで直接クエリを実行します。

1. **構築**環境にアクセスします。
2. メニューで**管理 > クエリ**をクリックします。
3. クエリエディターで、以下のコマンドを貼り付けて実行します。

### シンプルなクエリ

`task` の `name` だけを一覧表示します:

```sql
SELECT name
FROM task;
```

`task` テーブルのすべてのフィールドを一覧表示します:

```sql
SELECT *
FROM task;
```

`entry` テーブルのすべてのフィールドを一覧表示します:

```sql
SELECT *
FROM entry;
```

`worker` テーブルのすべてのフィールドを一覧表示します:

```sql
SELECT *
FROM worker;
```

**実行**をクリックすると、Netuno はセミコロン (`;`) で区切られた**各**コマンドの結果テーブルを生成します。  
これは、複数のクエリを一度に実行したい場合に便利です。

### リレーションシップを含むクエリ

次に、すべてのテーブルを関連付けるクエリを実行します:

```sql
SELECT
  task.name,
  entry.started_at,
  entry.finished_at,
  worker.name
FROM task
INNER JOIN entry
  ON task.id = entry.task_id
INNER JOIN worker
  ON worker.id = entry.worker_id;
```

このクエリは次を返します:

- タスクの名前。
- 各エントリの開始と終了。
- 各エントリに関連付けられたワーカーの名前。

テーブル間のリレーションシップによって、アプリケーションの異なるエンティティの情報をどのように組み合わせられるかを示しています。

## ダイアグラム

データベース構造をより直感的に確認するには、Netuno の**ダイアグラム**を使用します。

1. **構築**環境にアクセスします。
2. メニューで**管理 > ダイアグラム**をクリックします。

ダイアグラムでは、次のことができます:

- ズームイン/ズームアウトする。
- ダイアグラムを画像としてエクスポートする。

これらの操作は、ダイアグラムパネルの右側にあるボタンから利用できます。

Netuno は、フィールドの**リンク**設定に基づいて、リレーションシップの矢印が付いた線を自動的に作成します（例えば、他のテーブルを指す `select` 型のフィールドなど）。

## ベストプラクティス

Netuno でデータベースをモデリングする際は、次のベストプラクティスに従ってください:

- リレーションシップを表すフィールドには `_id` 接尾辞を使用します。例:
  - `task_id`
  - `worker_id`
- テーブル名やフィールド名に複数形を使用しないでください（例: `tasks`、`entries`、`workers`）。

複数形を避けることで、次のことが容易になります:

- 名前をより短く読みやすく保つ。
- クエリを書くときの曖昧さを減らす。
- 特に複数のリレーションシップがある場合に、フォームやダイアグラムでの読みやすさを向上させる。

:::tip 命名規則
原則として、フォーム、テーブル、フィールドには常に**単数形の名前**を使用してください。  
例: `task`、`entry`、`worker`、`task_id`、`worker_id`。
:::
