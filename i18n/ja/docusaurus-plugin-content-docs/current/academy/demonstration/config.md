# アプリケーションを設定する

このガイドでは、デモアプリケーションの言語、データベース、およびサーバーと同時に実行される自動コマンドを有効にするための初期設定手順を説明します。

すべての変更は、**デモ**アプリケーションの設定ファイル `_development.json` で行います。このファイルは /apps/demo/**config** フォルダーにあります。

### 前提条件

設定を編集する前に、以下の点を確認してください:

- デモアプリケーションがすでに作成され、初期化されていること。
- Netuno プロジェクトのルートディレクトリにいること。
- `/apps/demo/config/development.json` をコードエディターで開いていること。
- 変更を保存した後にサーバーを再起動できること。

## 言語の設定

### 1. アプリケーション

設定ファイル内で `language` と `locale` のフィールドを探して、アプリケーションの言語を変更します。

```json title="/apps/demo/config/development.json"
{
  "language": "pt_PT",
  "locale": "pt_PT",
}
```

希望する言語に応じて値を設定してください:

- **ポルトガル語**: `pt_PT` または `pt_BR`
- **英語**: `en_GB` または `en_US`

### 2. データベース

**"db"** オブジェクトを探し、次に **"default"** の設定を探します。

**"name"** フィールドを変更して、対応するデータベースを指定します:

- `demo_pt`: ポルトガル語のデータベース。
- `demo_en`: 英語のデータベース。

```json title="/apps/demo/config/development.json"
{
 ...
"db": {
        "default": {
            "password": "",
            "engine": "h2",
            "port": "",
            "host": "",
            "name": "demo_pt",
            "username": "sa"
        }
    },
...
}
```

### 3. 複数コマンドの有効化

Netuno では、サーバーの起動時に複数のコマンドを同時に実行し、その出力を同じコンソールに表示することができます。

デフォルトでは、**デモ**アプリケーションには `bun run watch` コマンドが設定されていますが、無効になっています。このコマンドは、バックオフィスのコードファイルに加えられた変更を自動的にコンパイルします。

有効にするには、**"commands"** 配列を探し、**enabled** フィールドの値を false から **true** に変更します。
 
```json title="/apps/demo/config/development.json"
"commands": [
        {
            "enabled": true,
            "path": "ui",
            "command": "bun run watch"
        }
    ],
```

### "commands" オブジェクトのパラメーター

- `enabled`: コマンドの自動実行を有効 (true) または無効 (false) にします。
- `path`: コマンドを実行するアプリケーション内のパス (フォルダー) を指定します。
- `command`: ターミナルで実行されるコマンドを指定します。

:::tip
同じオブジェクト構造を維持していれば、`"commands"` 配列内に他のコマンドを追加することもできます。
:::


設定ファイルを保存した後、変更を適用するために Netuno サーバーを再起動してください。


## 期待される結果

サーバーを再起動した後、以下の点を確認してください:

- デモアプリケーションが設定した言語になっている。
- コマンドが有効になっていれば、コンソールに `bun run watch` の実行が表示される。
