# フォーム

このデモのステップでは、**タスク**フォームを作成し、最初のデータフィールドを設定します。

:::info 参考
フォームの詳細については、[インターフェースガイド: フォーム](/docs/academy/ui/forms)を参照してください。
:::

## 目的

このステップを完了すると、次の状態になります:

- **タスク**という名前のフォーム。
- データベースに関連付けられたテーブル。
- タスク名を保存するための必須フィールド。
- レコードの作成、編集、検索、削除が可能なインターフェース。

## 前提条件

次のことを確認してください:

- デモアプリケーションがすでに作成されている。
- 設定ステップがすでに完了している。
- プラットフォームの開発エリアにいる。

## フォームを作成する

1. 右上隅にある**構築**をクリックします。
2. メインメニューから**管理 > フォーム**にアクセスします。
3. **フォームタイトル**に`タスク`と入力します。
4. **テーブル名**で**自動**オプションを有効にします。
5. **保存**をクリックします。

:::note
- **フォームタイトル**はサイドメニューに表示される名前を定義します。
- **テーブル名**はデータベースで使用される技術識別子を定義します。
:::

保存後、**タスク**フォームが左側のサイドメニューに表示されます。

## 最初のフィールドを作成する

フォームを作成したら:

1. サイドメニューで**タスク**をクリックします。
2. **表示名**に`名前`と入力します。
3. 技術名が小文字で自動生成されていることを確認します。
4. **主キー**（一意のフィールド）オプションを有効にします。
5. **非NULL**（必須フィールド）オプションを有効にします。
6. **型**で`text`を選択します。
7. **保存**をクリックします。

:::tip
- **主キー**は各レコードに一意の値を保証します。
- **非NULL**は入力を必須にします。
- `text`型ではプレーンテキストを保存できます。
:::

## 結果を確認する

プレビュー領域を開き、次のことを確認します:

- **タスク**フォームが利用できます。
- **名前**フィールドが入力用に表示されます。
- 新しいレコードを作成できます。
- **名前**フィールドは必須です。

:::info 期待される結果
設定が正しければ、フォームはレコードの作成、編集、検索、削除の操作に使用できる状態になります。
:::
