# Netuno の概要

## はじめに

**Netuno** へようこそ！

新しいテクノロジーを導入する際には、市場に多くの選択肢があるため課題となることがあることは承知しています。Netuno はこの問題を解決するために生まれ、最高のツールとソリューションを一か所に集約することで開発を簡素化します。

私たちは生産性に焦点を当てたプラットフォームです。Netuno の最大の加速要因の一つは、時間のかかるコンパイルやビルドのプロセスがないことです。

主要なデータベースと統合されたさまざまなプログラミング言語を使用できる、流動的で柔軟な開発体験を提供します。

Netuno の **ローコード** 環境はポリグロットであり、各サービスの特定のニーズに最適な言語を選択できます。

> 私たちのモットーはシンプルです：**少ないコード行で、より多くを実現します。**

## 仕事における生産性

Netuno は次の柱によって開発のボトルネックを解消します：

-  **安全なツール選択:** 初期調査と設定にかかる時間を削減します。Netuno はすでに、今日最も効率的なソリューションを備えた構成になっています。

- **ポリグロットな柔軟性:** 同じエコシステム内で好みのプログラミング言語を使用し、各 Web サービスに特化した豊富な既製リソースを活用できます。

- **Web サービスの迅速な作成:** ローコードアプローチにより、複雑な REST API を迅速に開発できます。

- **手間のかからない統合:** バックエンドを迅速に開発し、任意のフロントエンド、モバイルアプリ、企業ポータル、オンラインストアに簡単に接続できます。

- **リアルタイム更新（ホットリロード）:** 開発の速さは、サーバーを再起動する必要がないことにもよります。Netuno のエコシステムでは、コンパイルや再起動はありません。コードの変更は即座にリアルタイムで反映されます。

* **開発の俊敏性:** 開発しながら同時に API をテストできます。Netuno にコードを保存し、その場でフロントエンドからリクエストを送信できます。

* **ビジネスルールへの集中:** 基本的なインフラストラクチャと接続は Netuno に任せてください。システムがエンドユーザーにより多くの価値を提供する方法に集中できます。

## バックオフィス

このプラットフォームは、フォームインターフェースの作成とデータベース構造の自動化を統合することで、開発の道のりを簡素化します。

このアプローチは学習曲線を大幅に短縮し、開発者がビジネスロジックに集中できる一方で、プラットフォームがインフラストラクチャを管理します。

これにより、手動で SQL スクリプトを書いたり、繰り返しの CRUD（Create、Read、Update、Delete）画面を作成したりする必要がなくなります。


フォームを設計するとき、同時にデータベースをモデリングし、完全な管理インターフェースを生成しています。

Netuno はすぐに使える管理エコシステムを提供します。これには以下が含まれます：

| 機能 | 説明 |
| :--- | :--- |
| **リレーションシップ** | ダイアグラム、外部キー、テーブル間の関連を自動管理します。 |
| **高度な検索** | レコードをすばやく見つけるための詳細なフィルター。 |
| **ファイル管理** | 画像やドキュメントのアップロード用のネイティブコンポーネント。 |
| **エクスポート** | レポート向けの互換形式でのデータ抽出。 |
| **セキュリティ** | アクセスプロファイルの制御と統合認証。 |

Netuno は **オープンソース** であり、複雑な作業を高い生産性で行うために、ツールの可能性を無料で協力的に探求できます。[今すぐ始める](/docs/get-started/installation)。

## データベース

Netuno はバックオフィスの作成とデータベース構造を統合することで、データ管理を簡素化します。この構築では、テーブル作成のために複雑な SQL スクリプトを手動で書く必要はありません。

ビジュアルインターフェースを通じてフィールドとリレーションシップを定義でき、プラットフォームがそれらの定義をデータベースと同期し、管理インターフェースとデータダイアグラムを自動的に生成します。

## データダイアグラム

Netuno はアプリケーションのデータモデルを表す動的なダイアグラムを自動的に生成します。この機能は、情報アーキテクチャとテーブル間の関連を可視化するために不可欠です。

## クエリ

Netuno は堅牢で直感的なデータベースコンソールを提供し、開発者がデータと迅速かつ整理された方法で直接やり取りできるようにします。

複雑なコマンドや頻繁に使用するコマンドを保存して、後ですばやくアクセスできます。
システムは実行されたコマンドの履歴を保持し、監査や以前のクエリロジックの復元を容易にします。

コンソールでは複数のコマンドを同時に実行できます。命令を区切り、Netuno がそれぞれを正しく解釈できるようにするには、二重セミコロン区切り文字 `;;` を使用してください。

## ローコードとポリグロット開発


Netuno は柔軟なアーキテクチャにより、各プロジェクトで複数のプログラミング言語を同時に使用できる点が際立っています。

独立した複数のアプリケーション（プロジェクト）を作成でき、それぞれの中で Netuno がサポートする市場で最も人気のある言語を使用してサービスを書くことができます。

プラットフォームは、サーバーのサービスフォルダーに作成されたファイルの拡張子に基づいて、使用する実行エンジンを自動的に識別します。例：

- `.js` - JavaScript
- `.py` - Python
- `.rb` - Ruby
- `.kts` - Kotlin Script
- `.groovy` - Groovy
