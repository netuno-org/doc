Netunoでさらに成長し続けるために必要なことを心に留めておいてください。

ドキュメント全体は常に改善されており、できるだけシンプルで入門しやすい内容を目指しています。

ただし、いくつかの知識の基礎と、次のような分野での経験があることを前提としています:

* データベース。一般的なクエリ、insert、update、deleteなど。
* Webサービス。GETとPOST。
* <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>と<a href="https://reactjs.org/" target="_blank">ReactJS</a>。

これらのスキルのいずれかを持っていない場合は、それを身につけられるよう支援します。

常にGitHubやDiscordで助けを求め、サイトのフッターにある案内を参照してください。

## データベース

Netunoでは、さまざまな種類のデータベースを扱い、知識を深めることができます。

優れたデータベースの知識があって初めて、大量のデータを収集・管理する複雑な構造のアプリケーションを作成できます。

こうして、最も重要な部分であるデータベースを堅牢に作成するための自律性が得られます。

よく整理され最適化されたデータベースを構築することは、エンドユーザーの体験だけでなく、開発から実行までのパフォーマンスにも大きな違いをもたらします。

## サービス

すでに<a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>、<a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>、<a href="https://www.jython.org/" target="_blank">Python</a>、<a href="https://www.jruby.org/" target="_blank">Ruby</a>、<a href="https://kotlinlang.org/" target="_blank">Kotlin</a>、<a href="https://groovy-lang.org/" target="_blank">Groovy</a>のいずれかのプログラミング言語の知識があれば、Netunoが**ローコード**プログラミングのために提供する各種リソースを利用して、複雑で堅牢なWebサービスをすばやく作成できます。

アプリケーションのフォルダー内、特に **server** フォルダーでは、これらのさまざまな言語でプログラミングできます。

対応する拡張子を使用するだけです:

* **.js** &nbsp; <a href="https://developer.mozilla.org/pt-PT/docs/Web/JavaScript" target="_blank">JavaScript</a>
* **.ts** &nbsp; <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>
* **.py** &nbsp; <a href="https://www.jython.org/" target="_blank">Python</a>
* **.rb** &nbsp; <a href="https://www.jruby.org/" target="_blank">Ruby</a>
* **.kts** &nbsp; <a href="https://kotlinlang.org/" target="_blank">Kotlin</a>
* **.groovy** &nbsp; <a href="https://groovy-lang.org/" target="_blank">Groovy</a>

**demo** _アプリケーション_に含まれるWebサービスの例を確認してください:

- `/apps/demo/server/services/samples`

また、利用可能なリソースを詳しく知るために、**ライブラリ**のドキュメントも参照してください。


## ユーザーインターフェース

Webでのフロントエンド開発はここ数年で大きく変化し、<a href="https://vite.dev/" target="_blank">Vite</a>の利用が標準になりました。

私たちが選ぶ<a href="https://reactjs.org/" target="_blank">ReactJS</a>、<a href="https://bun.sh/" target="_blank">Bun</a>、<a href="https://ant.design/" target="_blank">Ant.Design</a>、<a href="http://lesscss.org/" target="_blank">Less</a>といった技術は、高い採用率を誇り、生産性を向上させる技術です。

これらの技術について知識を深めるには、インターネットで提供されているテキストや動画の各種ドキュメントを参照してください。

大きなコミュニティを持つ技術なので、学習を始めるための良質な教材を見つけるのは難しくありません。

Netunoでは、少しの知識でも大きな成果を得られることを再確認してください。これにより、フロントエンドの開発者がバックエンド全体を開発することも、その逆も可能になり、さらに<a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>のような単一のプログラミング言語だけですべてを開発することを選ぶこともできます。

## 結論

NetunoはWebアプリケーション開発を容易にし、データベース、Webサービス、フロントエンドに関する基礎知識が少ない一人でも、複雑なアプリケーションを自律的に開発できます。

また、各分野に高い専門性を持つ人がいる大規模なチームにとっても、一般的に生産性を大きく向上させます。

Netunoは、データベースのバックオフィスとして、または分離されたフロントエンドやモバイルアプリケーション向けのREST APIサーバーとしても利用できます。

時間を節約し、ビジネスルールのロジックに集中して開発してください。すでにお持ちの知識があれば、さらに遠くまで到達できます。
