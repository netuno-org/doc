## Netuno とは？

*ローコード*で*オープンソース*、そして完全無料のプラットフォームです。

私たちの主な目的は、*フルスタック*開発を習得することで、プログラミングにおけるあなたのキャリアを後押しし、完全な独立と自律性を提供することです。

このプラットフォームは、*バックエンド*をわかりやすくすることで*フルスタック*開発を促進します。次のような開発におけるさまざまなレイヤーを大幅に簡素化します：

* Web ソリューションとアプリケーション；
* *バックオフィス*システム；
* REST API。

*フルスタック*のエコシステムを理解することで、自分の自然な適性が*フロントエンド*寄りか*バックエンド*寄りかがわかります。また、さまざまな専門分野のチームと交流し、コミュニケーションを取り、協力するための能力を大幅に高めたプロフェッショナルになれます。

![Netuno は Web プロジェクトのローンチプラットフォームです](/docs/assets/academy/introduction.jpg "Netuno は Web プロジェクトのローンチプラットフォームです。")

## 始めるための前提条件

Netuno では、一般的な技術的障壁の多くが取り除かれるため学習曲線は緩やかになりますが、人間的な要素 — あなたの創造性と知性 — は依然として不可欠です。

学習を始める前に、期待を調整し、次のことを備えていることが重要です：

* **コンフォートゾーンから抜け出す意欲：** 継続的な学習はテクノロジーの旅の一部です。
* **関心と忍耐：** 新しい技術や概念を学ぶには、時間、実践、そして専念が必要です。
* **集中力と粘り強さ：** ソフトウェア開発には高い集中力が求められます。課題は必ず現れますが、成功の鍵は粘り強さです。
* **最適化への意欲：** より迅速かつ効率的に堅牢なソリューションを生み出したいという意欲。

:::tip ヒントとベストプラクティス
* **困難に直面しても諦めないでください：** 学習は間接的にあなたのレジリエンスを育むのが普通です。多くの人は障害に直面すると諦めてしまいますが、思い出してください。ソフトウェア開発が極端に簡単であれば、すでに完全に自動化されていたはずです。人間の思考力は不可欠です。
* **必要なときはいつでも助けを求めてください：** 自信を持って進みましょう。ただし、旅の途中で迷いを感じるのは自然なことです。そうなったときは、ためらわずにサポートを求めてください。
:::


このプラットフォームは、あなたが迅速かつスマートに構築できるように作られています。

Netuno が推進し、教える技術を学んだり使用したりするために**お金を使う必要はありません**。私たちのエコシステムと推奨ツールはすべて無料です。
