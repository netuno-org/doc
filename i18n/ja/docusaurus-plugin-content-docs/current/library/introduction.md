このセクションには、Netuno におけるバックエンドロジックの大部分が含まれています。Netuno を基に Web サイトを構築するための機能的なロジックを理解するのに役立つ定義、説明、コード例が記載されています。

> Netuno プラットフォームは無料です。[今すぐ始めましょう](/docs/get-started/installation)。

## チュートリアル

Netuno での開発方法を探ってみましょう:

[詳細を見る](/docs/get-started/tutorials)

## オブジェクト

このセクションには、Netuno のオブジェクト、特に Values に関する情報が含まれています。

* [Values](/docs/library/objects/Values)

## リソース

Netuno のリソースを活用すれば、より短時間でより多くのことができ、コードの行数や悩みの種を減らせます。
