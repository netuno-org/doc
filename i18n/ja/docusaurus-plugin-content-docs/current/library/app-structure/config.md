アプリケーションの一般的な設定。

## 設定フォルダ

アプリケーションの設定は `📂 config` フォルダで利用できます。ここでは、アプリケーションおよび外部連携の一般的なパラメータ設定を行います。

Netuno はさまざまな環境タイプをサポートしており、デフォルトでは `development`（開発）と `production`（本番）を使用します。

有効な環境は、Netuno のインストールルートにある `config.js` で定義されます:

```javascript title="netuno/config.js"
...
config.env = 'development'
...
```

環境の定義には任意の名前を使用できますが、アプリケーションは環境名と同じ名前のファイル（アプリケーションの `📂 config` フォルダ内の `.json` と `.js`）を持つ必要があります。

デフォルトでは、このフォルダに次のファイルがあります:

## _development.js

JavaScript コードを注入して、`_development.json` ファイルで定義されたパラメータ設定に対してプログラムロジックによる動的な設定を行うことができます。たとえば、データベースにある情報に基づいて設定を定義したり、コード実行の動作をパラメータ設定したりするなどです。

このファイルは環境の定義に応じて使用されます。`development`（開発）の場合です。

## _development.json

言語、リソースおよび連携の一般的な設定など、アプリケーションのパラメータ設定を定義します。たとえば、データベース設定、Cron Jobs、SMTP やリモート API との連携、認証など、多数の設定があります。

このファイルは環境の定義に応じて使用されます。`development`（開発）の場合です。

## _production.js

このファイルは環境の定義に応じて使用されます。`production`（本番）の場合です。
