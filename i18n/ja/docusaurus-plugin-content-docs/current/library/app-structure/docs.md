ドキュメントおよび各種文書について。

## ドキュメントフォルダ

`📂 docs` フォルダは、アプリケーションの一般的な文書を整理する場所です。

ドキュメント、設計、アーキテクチャ、連携など、役立つファイルを整理するために使用します。

アプリケーションの開発に携わる他の人々に役立つもの、またはメンテナンスや機能拡張の開発に役立つものを対象とします。

大きすぎるバイナリファイルは、コードリポジトリ、つまり GIT を決定的に汚し、肥大化させる可能性があることに注意してください。大きすぎるファイルを GIT に追加すると変更履歴が大幅に増えるため、動画ファイル、ZIP、その他非常に大きな文書は、GIT に負荷をかけ、将来の支障を生まないよう避けるべきです。
