## データベース用フォルダ

`📂 dbs` フォルダは、アプリケーションのデータベースファイルを保存するためのものです。

H2 Database タイプのデータベースの場合、すべてのファイルはこのフォルダ内に自動的に生成されます。

このフォルダは、データベースに関連するあらゆるものを保存するのに便利です。例えば、バックアップ、スクリプト、
ダンプ、ダイアグラムなどです。

データベースに関連し、アプリケーションのプロジェクトに含めるべきすべてのドキュメントは、
このフォルダ内で整理することをお勧めします。
