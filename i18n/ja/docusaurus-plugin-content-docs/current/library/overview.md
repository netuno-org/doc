Netunoは、Webサービスの迅速な作成を可能にするローコードプラットフォームであり、統合されたビジュアルインターフェースによるデータ管理を容易にし、高性能なWebベースアプリケーションの構築を保証します。

開発の労力と時間、および管理・運営・産業分野における本番コストを削減します。

![Netunoの構造](/docs/assets/introducao1.png)

Netunoが、開発から実行までパフォーマンスレベルを維持しながら、創造的で反復の少ないプログラミングを実現するために、どのようにプログラミング体験を支援するかをご覧ください：

> Netunoプラットフォームは無料です。[今すぐ始める](/docs/get-started/installation)。

## フォームとフィールド

データモデルの作成は、Web環境のフォームエンジンによって容易になります。フォームを定義するとデータベースにテーブルが作成され、そのフィールドが列を定義します。データ型、フィールドのプロパティ、およびそれらのリレーションをパラメータ化できます。Web構築の_スイート_は、データベースへのクエリやエンティティ関連モデルの表示など、さまざまな機能を提供します。

## アクセスと権限の管理

ユーザーとその権限の管理はWeb環境で設定可能で、Netunoのバックエンドサービスを通じてアクセスできます。また、フォームやレポートへのユーザーごとおよびグループごとのアクセスを制御することもできます。

## リソースライブラリ

リソースライブラリは、すぐに使える幅広い機能を提供します。これには、PDF、Excel、メール、Firebaseとの統合から、タスクのスケジューリングやJasperによるレポート生成まで含まれます。

## REST API

サーバーの通信レイヤーはREST APIによって提供されます。JSONによるサービスの提供により、Netunoは異なる性質の複数のアプリケーションと通信でき、たとえば同じインターフェース上でWebクライアントとモバイルアプリケーションに同時にサービスを提供できます。

## 多言語サービスレイヤー

<a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>、<a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>、<a href="https://groovy-lang.org/" target="_blank">Groovy</a>、<a href="https://www.jython.org/" target="_blank">Python</a>、<a href="https://www.jruby.org/" target="_blank">Ruby</a>、<a href="https://kotlinlang.org/" target="_blank">Kotlin</a>、または<a href="https://pt.wikipedia.org/wiki/Java_(linguagem_de_programa%C3%A7%C3%A3o)" target="_blank">Java</a>でサービスを記述できます。これらはすべて有効です。Netunoはプログラミング言語間の分離を取り除き、同じアプリケーションが複数の言語で同時に実行されるサービスを、処理負荷を増やすことなくサポートします。

## マルチデータベース

複数の異なるデータベースを設定し、同時に使用できます。Netunoはネイティブで、<a href="https://www.h2database.com/html/main.html" target="_blank">H2DataBase</a>、<a href="https://www.postgresql.org/" target="_blank">PostgreSQL</a>とCockroachDB、<a href="https://mariadb.org/" target="_blank">MariaDB（_MySQL_）</a>、Microsoft SQL Server、Oracleなど、さまざまなリレーショナルデータベースエンジンをサポートします。たとえば、メインデータベースとしてPostgreSQLを使用し、MariaDBの他のデータベースと統合するアプリケーションを作成でき、プロジェクトの途中でコードを一切変更せずにMicrosoft SQL ServerやOracleに切り替えることもできます。

> MongoDBとの統合をネイティブでサポートします。

## サーバーレス

Netunoはアプリケーションサーバーでもあります。1つのコマンドで、ライセンス、設定、追加開発に時間を費やすことなくアプリケーションを実行できます。

## 開発時と実行時のパフォーマンス

新しいドラッグ＆ドロップ開発ソフトウェアの操作方法を学ぶ必要も、新しいフレームワークのインターフェースを覚える必要もありません。6つの異なる言語でプログラミングでき、データレイヤーは自動生成され、ライブラリはオンザフライで利用できるため、Netunoのローコードは厳しい締め切りに対する最良のソリューションです。

高いパフォーマンス向けに最適化されたコードジェネレーターと最新の<a href="https://www.graalvm.org/" target="_blank">GraalVM</a>を使用することで、アプリケーションサーバーは使用する言語に関係なく驚くほど高速になります。
