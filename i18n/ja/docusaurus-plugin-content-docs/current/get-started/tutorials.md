# チュートリアル

Netuno プラットフォームのチュートリアルを探索し、リソースの設定、データのモデリング、インターフェースの作成、バックエンドでのビジネスロジックの開発方法を実践的に学びましょう。

このページでは、これから始める方から、プラットフォームの利用を深めたい方まで、主要なコンテンツをまとめています。

## 始める前に

チュートリアルを始める前に、環境が整っていることを確認してください：

- **Netuno がインストールされ**、ローカルまたは開発環境で実行されていること。
- 適切な権限で**管理パネルにアクセスできること**。
- 技術的な内容をよりよく理解するために、データモデリング、HTTP、REST API に関する**基礎知識を推奨**します。

進む前に[インストール](./installation)ガイドを参照してください。

## 推奨する順序

Netuno を初めて利用する場合は、次の順序で進めてください：

1. グラフィカルインターフェースを確認する。
2. フォームとフィールドの作成方法を学ぶ。
3. フォーム間のリレーションを設定する。
4. 権限とユーザーグループに進む。
5. プロジェクトの必要性に応じて、クエリとバックエンド機能を探索する。

## バックエンド

Netuno では、ローコードと、さまざまな言語やシナリオでのバックエンド開発を組み合わせることができます。以下のチュートリアルは、インテグレーションの作成、データの操作、ビジネスロジックの実装に役立ちます。

### 前提条件

このセクションに進む前に、次の事項に慣れていることを推奨します：

- クライアントサーバーアーキテクチャと HTTP プロトコル。
- JSON のデータ構造。
- JavaScript、Python、または開発フローに合ったその他の言語でのプログラミングロジック。

| [メール送信](/docs/academy/server/services/sending-emails) | SMTP 経由でトランザクションメールの送信を設定する。 | 中級 |

:::tip チュートリアルの選び方

**グラフィカルインターフェース**のチュートリアルは、アプリケーションを視覚的に設定し、データを構造化し、インターフェースからリソースを管理することを目的とする場合に使用します。  
**バックエンド**のチュートリアルは、ビジネスロジック、インテグレーション、認証、自動化、またはデータへのプログラムによるアクセスを作成する必要がある場合に使用します。
:::

## 次のステップ

最初のチュートリアルを完了したら、[Netuno アカデミー](/docs/academy/overview)にアクセスして、プラットフォームの特定分野に関する知識を深めてください。


エラー（バグ）を見つけた場合や、新機能の提案がある場合は、お気軽に[GitHub で issue を作成](https://github.com/netuno-org/doc)してください。私たちのチームとコミュニティが喜んでお手伝いします。
