# Installation Avancée

Si vous rencontrez un problème avec l'installation rapide via script, ou si vous souhaitez mieux comprendre comment fonctionne l'installation de Netuno, ou pour toute autre raison, vous pouvez effectuer l'installation manuelle.

Choisissez la version souhaitée. La sélection effectuée ici s'appliquera à tous les blocs de commande de cette page.

<Tabs groupId="version">
  <TabItem value="stable" label="Version Stable" default>

La **Version Stable** est l'édition homologuée de Netuno. Elle a passé des tests rigoureux et est totalement prête à être utilisée dans des environnements de production.

</TabItem>
  <TabItem value="testing" label="Version en Test">

:::danger NE PAS UTILISER EN PRODUCTION
La **Version en Test** contient les fonctionnalités les plus récentes et les implémentations en cours. Comme elle est expérimentale, elle peut présenter des instabilités. Nous recommandons son utilisation uniquement pour découvrir de nouvelles fonctionnalités, effectuer des tests ou contribuer à l'écosystème de la plateforme.
:::

  </TabItem>
</Tabs>

## Prérequis

Avant de commencer, vérifiez ce que vous devez avoir installé sur votre ordinateur :

- **Java** *(Uniquement pour l'installateur)*

Il est nécessaire d'avoir **Java** préalablement installé sur votre système d'exploitation. Il sera utilisé **exclusivement** pour exécuter le script d'installation initial de Netuno.

- **GraalVM** *(Installation Automatique)*

Pendant l'installation, le moteur **GraalVM** est téléchargé et configuré automatiquement dans le dossier de Netuno lui-même. À partir de ce moment, le Java de GraalVM isolé sera utilisé pour exécuter la plateforme, garantissant stabilité et haute performance sans interférer avec les configurations globales de votre machine.

Pour en savoir plus sur la technologie, consultez : [GraalVM](https://www.graalvm.org/).

:::info Les Prérequis Frontend sont Optionnels
L'installation d'outils frontend (comme Node.js, NPM ou Yarn) est totalement optionnelle. Vous n'aurez besoin de les configurer que si votre objectif est de développer des interfaces avancées en mode full-stack.
:::

### Backend - Java

Cette étape garantit que l'environnement est prêt à exécuter l'installateur de la plateforme. Il est nécessaire d'avoir **Java version 11 ou supérieure** installé.

Vérifiez si Java est déjà installé en exécutant la commande ci-dessous dans le terminal :

```bash
java -version
```

Si ce n'est pas installé, nous recommandons l'installation de **Java open source** :

- Windows et macOS : [Java OpenJDK Eclipse Temurin](https://adoptium.net/pt-BR)

- Linux (Ubuntu / Debian) :

```bash
apt install default-jdk-headless
```

### Frontend - Bun

Pour développer des interfaces utilisateur (UI / Frontend), nous recommandons l'utilisation de **Bun**, l'outil standard officiel de l'écosystème Netuno pour la compilation frontend.

#### Pourquoi utiliser Bun ?

**Bun** est une alternative moderne et hautement optimisée à Node.js. Il se démarque dans l'environnement Netuno en offrant :

- **Haute Performance :** Exécution et installation de dépendances visiblement plus rapides.
- **Productivité :** Meilleure performance dans le flux quotidien de développement d'interfaces.
- **Intégration Native :** Tous les projets d'exemple et templates de Netuno sont déjà préconfigurés pour fonctionner avec Bun.

Consultez le guide : [Installation de Bun](/docs/academy/website/bun)

Netuno ne fige pas vos choix technologiques. Si vous préférez, **il est possible d'utiliser Node.js avec NPM, PNPM, Yarn** ou tout autre gestionnaire de paquets. Le choix de la stack frontend est entièrement à votre discrétion.

:::tip MAINTENEZ LES OUTILS À JOUR
Indépendamment de la technologie choisie, utilisez toujours les versions les plus récentes pour garantir compatibilité, sécurité et performance.
:::

## Linux ou macOS

La plupart des distributions Linux et macOS incluent déjà **cURL** ou **Wget** par défaut. Vérifiez lequel est disponible :

```bash
curl --version
```
```bash
wget --version
```

Suivez les étapes ci-dessous :

**1. Créez le dossier et accédez-y :**

```bash
mkdir -p netuno && cd netuno
```

**2. Téléchargez l'installateur** (choisissez une seule méthode) :

<Tabs groupId="version">
  <TabItem value="stable" label="Version Stable" default>

**Avec cURL :**
```bash
curl -L https://github.com/netuno-org/platform/releases/download/stable/netuno-setup.jar -o netuno-setup.jar
```

**Avec Wget :**
```bash
wget https://github.com/netuno-org/platform/releases/download/stable/netuno-setup.jar -O netuno-setup.jar
```

  </TabItem>
  <TabItem value="testing" label="Version en Test">

**Avec cURL :**
```bash
curl -L https://github.com/netuno-org/platform/releases/download/testing/netuno-setup.jar -o netuno-setup.jar
```

**Avec Wget :**
```bash
wget https://github.com/netuno-org/platform/releases/download/testing/netuno-setup.jar -O netuno-setup.jar
```

  </TabItem>
</Tabs>

**3. Exécutez l'installation :**

<Tabs groupId="version">
  <TabItem value="stable" label="Version Stable" default>

```bash
java -jar netuno-setup.jar install
```

  </TabItem>
  <TabItem value="testing" label="Version en Test">

```bash
java -jar netuno-setup.jar install version=testing
```

  </TabItem>
</Tabs>

:::caution ATTENTION
macOS possède un mécanisme de sécurité natif (Gatekeeper) qui peut bloquer les applications téléchargées via le terminal.
:::

Sur **macOS**, pour garantir que Netuno fonctionne sans erreurs de permission, exécutez la commande ci-dessous immédiatement après l'étape 3, toujours dans le dossier `netuno`.

```bash
sudo xattr -r -d com.apple.quarantine .
```

Le système demandera le mot de passe administrateur de votre Mac pour confirmer.

## Windows

Nous utiliserons **PowerShell** pour effectuer le téléchargement et l'installation. Ouvrez PowerShell via le menu Démarrer en tapant `powershell`.

**1. Créez le dossier, accédez-y et téléchargez l'installateur**. Copiez le bloc complet et appuyez sur Entrée :

<Tabs groupId="version">
  <TabItem value="stable" label="Version Stable" default>

```powershell
md netuno; cd netuno
Invoke-WebRequest -Uri "https://github.com/netuno-org/platform/releases/download/stable/netuno-setup.jar" -OutFile "netuno-setup.jar"
```

  </TabItem>
  <TabItem value="testing" label="Version en Test">

```powershell
md netuno; cd netuno
Invoke-WebRequest -Uri "https://github.com/netuno-org/platform/releases/download/testing/netuno-setup.jar" -OutFile "netuno-setup.jar"
```

  </TabItem>
</Tabs>

**2. Exécutez l'installation :**

<Tabs groupId="version">
  <TabItem value="stable" label="Version Stable" default>

```powershell
java -jar netuno-setup.jar install
```

  </TabItem>
  <TabItem value="testing" label="Version en Test">

```powershell
java -jar netuno-setup.jar install version=testing
```

  </TabItem>
</Tabs>

:::caution ATTENTION
L'installation standard ne nécessite généralement pas de privilèges élevés. Cependant, si vous recevez un message "Accès Refusé", fermez PowerShell, rouvrez-le en tant qu'**Administrateur** et exécutez à nouveau la commande.
:::

## Recommencer à Zéro

Pour nettoyer l'environnement et recommencer à zéro :

**1. Revenez d'un niveau dans le terminal :**

```bash
cd ..
```

**2. Supprimez le dossier défaillant :**

<Tabs groupId="os">
  <TabItem value="linux-mac" label="Linux ou macOS" default>

```bash
rm -rf netuno
```

  </TabItem>
  <TabItem value="windows" label="Windows">

```powershell
rmdir /s /q netuno
```

  </TabItem>
</Tabs>

**3. Redémarrez l'installation**.
