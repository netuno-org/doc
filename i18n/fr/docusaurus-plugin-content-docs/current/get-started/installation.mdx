# Introduction

Bienvenue dans le guide d'installation de **Netuno**, la plateforme *low-code*, polyglotte et *open source* conçue pour accélérer la création de vos projets et faciliter la configuration de l'environnement de développement.

Ici, vous construisez des applications full-stack robustes de manière agile, en combinant la vitesse du low-code avec la puissance du codage traditionnel.

## Installation Rapide 

La façon la plus simple d'installer Netuno est via le script d'installation fourni par la plateforme. Exécutez simplement les commandes dans le terminal selon votre système d'exploitation.

<Tabs groupId="os">
    <TabItem value="linux-mac" label="Linux ou macOS" default>

```bash
bash <(curl -fsSL https://netu.no/install.sh)
```

    </TabItem>
    <TabItem value="windows" label="Windows">

```powershell
powershell -c "irm https://netu.no/install.ps1|iex"
```

    </TabItem>
</Tabs>

## Démarrer l'application DEMO

Une fois l'installation terminée, exécutez la commande ci-dessous dans le dossier `netuno` pour démarrer le serveur avec l'application de démonstration :

```bash
./netuno server
```

### Ouvrir l'application dans le navigateur

Après l'initialisation, le navigateur s'ouvrira automatiquement avec l'adresse du serveur local. Si cela ne se produit pas, accédez manuellement à l'une des adresses ci-dessous :

- [http://demo.local.netu.no:9000](http://demo.local.netu.no:9000)
- [http://localhost:9000](http://localhost:9000)

## Arrêter le serveur

Pour arrêter le serveur, appuyez dans le terminal sur les touches :

**CTRL + C**

Pour le redémarrer, utilisez la même commande `./netuno server`.
