Documentation et documents en général.

## Dossier des documents

C'est dans le dossier `📂 docs` que nous organisons les documents généraux de l'application.

Il sert à organiser les fichiers utiles tels que la documentation, le design, l'architecture, les intégrations, etc.

Tout ce qui peut être utile aux autres personnes qui travaillent également au développement de l'application, ou qui 
est utile au développement de la maintenance ou de l'évolution.

Il faut garder à l'esprit que des fichiers binaires trop volumineux peuvent polluer et encombrer définitivement le 
dépôt de code, c'est-à-dire GIT. Car tout fichier trop volumineux envoyé vers GIT augmente 
considérablement l'historique des modifications ; ainsi, les fichiers vidéo, les zips, ou tout autre document très 
volumineux doivent être évités pour ne pas surcharger GIT et créer des contraintes futures.
