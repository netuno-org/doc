Organisation des fichiers de base de données.

## Dossier pour la base de données

Le dossier `📂 dbs` est destiné à stocker les fichiers de base de données de votre application.

Dans le cas des bases de données de type H2 Database, tous les fichiers sont générés automatiquement dans ce dossier.

Ce dossier est utile pour stocker tout ce qui est lié à la base de données, par exemple des sauvegardes, des scripts,
des dumps, des diagrammes, etc.

Il est recommandé d'organiser dans ce dossier toute documentation liée à la base de données et qui doit accompagner
le projet de l'application.
