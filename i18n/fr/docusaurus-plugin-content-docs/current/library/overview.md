Netuno est une plateforme low-code de création rapide de services web qui facilite la gestion des données avec une interface visuelle intégrée, garantissant la création d'applications web à haute performance.

Réduit l'effort et le temps de développement, ainsi que les coûts de production dans les domaines de l'administration, de la gestion et de l'industrie.

![Structure Netuno](/docs/assets/introducao1.png)

Découvrez comment Netuno favorise votre expérience de programmation pour que vous ayez une programmation créative et non répétitive, en maintenant les niveaux de performance depuis le développement jusqu'à l'exécution :

> La plateforme Netuno est gratuite, [commencez dès maintenant](/docs/get-started/installation).

## Formulaires et champs

La création du modèle de données est facilitée par le moteur de formulaires en environnement WEB. La définition de formulaires donne naissance à des tables dans la base de données, et leurs champs définissent les colonnes. Il est possible de paramétrer le type de données, les propriétés des champs, ainsi que leurs relations. La _suite_ de construction WEB propose plusieurs fonctionnalités comme des requêtes à la base de données, la visualisation du Modèle Entité-Association, entre autres.

## Gestion des accès et des permissions

La gestion des utilisateurs et de leurs permissions est configurable en environnement WEB et accessible via des services backend dans Netuno. Il est également possible de contrôler l'accès par utilisateur et par groupe aux formulaires et aux rapports.

## Bibliothèque de ressources

La bibliothèque de ressources présente une vaste gamme de fonctionnalités prêtes à l'emploi. Parmi celles-ci, on trouve des intégrateurs avec PDF, Excel, E-mail, Firebase et même la planification de tâches ou le générateur de rapports avec Jasper.

## API REST

La couche de communication du serveur est mise à disposition via une API REST. La mise à disposition de services via JSON permet à Netuno de communiquer avec de multiples applications de nature différente, pouvant par exemple servir simultanément des clients WEB et des applications mobiles sur la même interface.

## Couche de services polyglotte

Écrivez des services en <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://groovy-lang.org/" target="_blank">Groovy</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a> ou en <a href="https://pt.wikipedia.org/wiki/Java_(linguagem_de_programa%C3%A7%C3%A3o)" target="_blank">Java</a>, toutes sont valides. Netuno supprime l'isolement entre les langages de programmation, la même application prend en charge des services exécutés simultanément dans plusieurs langages sans que cela n'augmente la charge de traitement.

## Multi-base de données

Configurez plusieurs bases de données différentes et utilisez-les simultanément. Nativement, Netuno prend en charge plusieurs moteurs de bases de données relationnelles tels que <a href="https://www.h2database.com/html/main.html" target="_blank">H2DataBase</a>, <a href="https://www.postgresql.org/" target="_blank">PostgreSQL</a> et CockroachDB, <a href="https://mariadb.org/" target="_blank">MariaDB (_MySQL_)</a>, Microsoft SQL Server et Oracle. Vous pourrez créer votre application en utilisant, par exemple, PostgreSQL avec une base de données principale et l'intégrer avec d'autres bases de données en MariaDB, et, au milieu d'un projet, passer à Microsoft SQL Server ou Oracle sans avoir à effectuer la moindre modification de code.

> Offre un support natif pour l'intégration avec MongoDB.

## Serverless

Netuno est aussi votre serveur applicatif. Avec une commande, exécutez votre application sans avoir à perdre de temps en licences, configurations et développements supplémentaires.

## Performance en développement et à l'exécution

Vous n'avez pas besoin d'apprendre à travailler avec un nouveau logiciel de développement par glisser-déposer, ni de mémoriser l'interface d'un nouveau framework. Avec la possibilité de programmer dans 6 langages différents, de disposer d'une couche de données auto-générée et de bibliothèques disponibles pour une utilisation à la volée, le low-code de Netuno est la meilleure solution pour vos délais serrés.

En utilisant des générateurs de code optimisés pour une grande performance et en utilisant la récente <a href="https://www.graalvm.org/" target="_blank">GraalVM</a>, le serveur applicatif devient incroyablement rapide, quel que soit le langage que vous utilisez.
