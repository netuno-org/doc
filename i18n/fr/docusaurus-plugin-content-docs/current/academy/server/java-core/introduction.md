Netuno est développé en Java, donc à partir de Java nous pouvons créer de nouvelles fonctionnalités.

Par exemple, nous pouvons créer de nouveaux services natifs, ou même de nouvelles fonctionnalités de programmation low-code qui sont disponibles dans tous les langages de programmation polyglottes, comme JavaScript, Python, Ruby, Groovy et Kotlin.

En Java, nous pouvons également créer des services web multi-applications qui sont disponibles dans toutes les applications Netuno.

N'importe quelle technique ou bibliothèque de l'écosystème Java peut être utilisée pour créer tout type de fonctionnalité.

> Nous vous conseillons, avant de commencer ce tutoriel, d'avoir quelques notions de base en _Java_.
