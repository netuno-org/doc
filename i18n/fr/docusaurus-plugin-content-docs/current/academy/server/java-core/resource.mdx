Dans ce tutoriel, nous allons créer une ressource native pour Netuno. Cela signifie que nous allons créer une classe en Java qui se trouvera dans le répertoire de base de Netuno et qui pourra être utilisée par n'importe quelle application dans le dossier `apps` en utilisant la syntaxe `_foo.nomMethode(arguments)`.

L'exemple que nous allons créer, en suivant les tutoriels précédents, est la ressource `_calcul`, qui est une ressource d'exemple pour exécuter des opérations arithmétiques simples.

Pour commencer, il faut d'abord créer la structure de dossiers du projet. Dans cet exemple, nous considérerons que le projet sera créé dans un dossier nommé `Calcul`. Il faut donc créer la structure de dossiers qui reflète le nom du package (dans notre exemple, `org.netuno.addon.calcul`). Notre structure de dossiers sera donc :

- `Calcul/src/main/java/org/netuno/addon/calcul/ressource/`

Dans cette structure, nous allons créer une classe Java nommée `CalculRessource`, qui définira notre ressource native personnalisée.

- ` Calcul/src/main/java/org/netuno/addon/calcul/ressource/CalculRessource.java`

Ainsi, le package défini dans la classe sera :

```java
package org.netuno.addon.calcul.ressource;
```

Pour que la classe définisse une ressource native personnalisée, elle doit être annotée avec l'annotation `org.netuno.tritao.ResourceBase`. Le paramètre `name` sera le nom de la ressource qui peut être accédé avec un underscore (`_`) avant le nom (dans notre cas, `_calcul`). La façon la plus simple de créer la ressource est d'étendre la classe `org.netuno.tritao.resource.ResourceBase` :

```java
package org.netuno.addon.calcul.ressource;

import org.netuno.tritao.resource.Resource;
import org.netuno.tritao.resource.ResourceBase;

@Resource(name = "calcul")
public class CalculRessource extends ResourceBase {
    // ...
}
```

Étendre la classe `ResourceBase` nous évite de devoir initialiser la ressource, il suffit d'appeler `super` avec les arguments corrects :

```java
package org.netuno.addon.calcul.ressource;

import org.netuno.proteu.Proteu;
import org.netuno.tritao.hili.Hili;
import org.netuno.tritao.resource.Resource;
import org.netuno.tritao.resource.ResourceBase;

@Resource(name = "calcul")
public class CalculRessource extends ResourceBase {
    // ...
    public CalculRessource(Proteu proteu, Hili hili) {
        super(proteu, hili);
    }
}
```

La fonction `init` est obligatoire, et à l'intérieur de celle-ci, nous allons initialiser la ressource en appelant le constructeur de notre classe avec les accesseurs de la classe parente :

```java
package org.netuno.addon.calcul.ressource;

import org.netuno.proteu.Proteu;
import org.netuno.tritao.hili.Hili;
import org.netuno.tritao.resource.Resource;
import org.netuno.tritao.resource.ResourceBase;

@Resource(name = "calcul")
public class CalculRessource extends ResourceBase {
    // ...
    public CalculRessource(Proteu proteu, Hili hili) {
        super(proteu, hili);
    }

    public CalculRessource init() {
        return new CalculRessource(getProteu(), getHili());
    }
}
```

Ensuite, nous allons définir nos propres champs et fonctions :

```java
package org.netuno.addon.calcul.ressource;

import org.netuno.proteu.Proteu;
import org.netuno.tritao.hili.Hili;
import org.netuno.tritao.resource.Resource;
import org.netuno.tritao.resource.ResourceBase;

@Resource(name = "calcul")
public class CalculRessource extends ResourceBase {
    public double valeur = 0;

    public CalculRessource(Proteu proteu, Hili hili) {
        super(proteu, hili);
    }

    public CalculRessource init() {
        return new CalculRessource(getProteu(), getHili());
    }

    public CalculRessource definir(double v) {
        valeur = v;
        return this;
    }

    public CalculRessource ajouter(double v) {
        valeur += v;
        return this;
    }

    public CalculRessource soustraire(double v) {
        valeur -= v;
        return this;
    }

    public double obtenir() {
        return valeur;
    }
}
```

Maintenant, il ne reste plus qu'à compiler la classe, en s'assurant que le fichier `CalculRessource.class` se trouve dans le dossier :

- `netuno/core/web/WEB-INF/classes/org/netuno/addon/calcul/ressource/`

Ou produire un fichier JAR, en s'assurant qu'il se trouve dans le dossier :

- `netuno/lib/`

Créons une application de test pour utiliser cette ressource :

```bash
./netuno app name=calcul
```

Créons également un service dans cette application pour utiliser la ressource.
Dans l'exemple, nous allons créer le fichier `netuno/apps/calcul/server/services/calcul-test.js` :

<PolyglotCode

Démarrons notre application :

```bash
./netuno server app=calcul
```

Et maintenant, lorsque nous appelons ce service :

- `http://localhost:9000/services/calcul-test`

Il renverra la valeur `130`.

Pour utiliser une ressource dans le code Java, certaines classes comme `org.netuno.tritao.Web`
et `org.netuno.tritao.event.EventBase` fournissent la fonction `resource`, qui initialise cette ressource.
Dans la classe où vous souhaitez utiliser la ressource `calcul`, faites :

```java
import org.netuno.addon.calcul.ressource.CalculRessource;

// ...
    CalculRessource calcul = resource(CalculRessource.class);
    calcul.definir(10);
    calcul.ajouter(120);
    System.out.println(calcul.obtenir());
// ...
```

Vous pouvez voir les fichiers complets du projet dans ce [lien](https://github.com/netuno-org/maven/tree/main/Calc/src/main/java/org/netuno/addon/calc/resource).
