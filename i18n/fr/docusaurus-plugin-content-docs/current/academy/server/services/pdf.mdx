Traiter des fichiers PDF personnalisés.

## Introduction

Netuno génère des fichiers PDF avec prise en charge des images, tableaux, polices et bien plus encore, grâce à la ressource [PDF](/docs/library/resources/pdf) qui permet une abstraction low-code d'[iTextPDF](https://itextpdf.com/) pour les différents langages de programmation pris en charge par Netuno.

L'application fournie avec Netuno nommée **demo** (application de démonstration) contient de nombreux exemples des implémentations de code possibles dans plusieurs langages, y compris la démonstration de l'exportation vers PDF via le service `export-pdf` situé dans :

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-pdf`
]} />

## Initialisation

Tout d'abord, il est nécessaire de créer l'objet qui contiendra le contexte du nouveau document en cours de création ; par défaut, la taille des pages est A4.

Lors de la création du document, l'emplacement où il sera généré est défini.

Si rien n'est défini, il sera généré dans la sortie de données du service, par exemple :

## En-tête HTTP

Pour créer un service dans l'API REST qui renvoie un fichier PDF comme sortie de données, il faut ajouter dans l'en-tête le paramètre `Content-Type` du protocole HTTP.

Exemple de définition du contenu en PDF :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("pdf")
            `
        },
    ]}
/>

Le code `pdf` est une abréviation pour :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("application/pdf")
            `
        },
    ]}
/>

## Paragraphe

Ajoute un nouveau paragraphe au document :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentPdf.add(
                    _pdf.paragraph("Mon texte ici...")
                        .setFontSize(15)
                )
            `
        },
    ]}
/>

Pour ajouter un paragraphe à une position fixe :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentPdf.add(
                    documentPdf.add(
                        _pdf.paragraph("Mon texte fixe...")
                            .setFixedPosition(100, 500, 200)
                            .setFontSize(15)
                    )
                )
            `
        },
    ]}
/>

Dans le code ci-dessus, dans la méthode `setFixedPosition`, le premier paramètre est la position X (`100`), le deuxième paramètre est la position Y (`500`), et le troisième paramètre est la largeur (`200`).

**Attention :** si Y est défini avec la valeur `0`, cela signifie qu'il se trouve en bas de la page ; pour le faire monter, il faut augmenter la valeur de Y. Plus la valeur de Y est grande, plus il apparaîtra vers le haut, mais s'il est trop élevé au-delà de la longueur de la page, il ne sera pas visible.

> Documentation avec toutes les méthodes de l'objet [Paragraphe d'iText](https://api.itextpdf.com/iText/java/8.0.3/com/itextpdf/layout/element/Paragraph.html).

## Tableau

Il est possible de créer des tableaux, ce qui permet de présenter un ensemble de données de manière plus lisible.

Le nombre de colonnes du tableau est défini avec le paramètre : `_pdf.table(nombreColonnes)`

Dans l'exemple ci-dessous, `nombreColonnes` est le nombre `1`, soit une colonne.

Comme nous ajoutons deux cellules au tableau, la deuxième cellule passe à la ligne suivante.

Remarquez :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentPdf.add(
                    _pdf.table(1)
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Personne")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBorder(_pdf.border("solid", 2))
                                .setBackgroundColor(_pdf.colorRGB(1, 0, 0))
                        )
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Nicole")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBackgroundColor(_pdf.colorGray(0.5))
                        )
                )
            `
        },
    ]}
/>

La méthode `addCell` permet d'insérer la définition des cellules avec leur contenu respectif.

> Documentation avec toutes les méthodes de l'objet [Cell d'iText](https://api.itextpdf.com/iText/java//8.0.3/com/itextpdf/layout/element/Cell.html).

## Fermer et enregistrer le document

Le document n'est totalement enregistré ou généré que lorsque la méthode `close` est appelée, de la façon suivante :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                documentPdf.close()
            `
        },
    ]}
/>

L'emplacement où le document est généré est défini lors de l'initialisation ; c'est donc lors de l'initialisation du document que nous définissons où sera généré le document final, que ce soit dans la sortie de données du service (`output`) ou dans un fichier.

## Lire un fichier

Pour lire un document PDF, en extrayant les informations textuelles.

Nous utilisons la méthode `extract`, qui obtient toutes les données du fichier PDF dans un objet JSON.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const donneesPdf = _pdf.extract(_app.file("fichier-1.pdf"))

                _out.json(donneesPdf)
            `
        },
        {
            lang: 'python',
            code: `
                donneesPdf = _pdf.extract(_app.file("fichier-1.pdf"))

                _out.json(donneesPdf)
            `
        },
        {
            lang: 'ruby',
            code: `
                donneesPdf = _pdf.extract(_app.file("fichier-1.pdf"))

                _out.json(donneesPdf)
            `
        },
        {
            lang: 'kotlin',
            code: `
                val donneesPdf = _pdf.extract(_app.file("fichier-1.pdf"))

                _out.json(donneesPdf)
            `
        },
        {
            lang: 'groovy',
            code: `
                def donneesPdf = _pdf.extract(_app.file("fichier-1.pdf"))

                _out.json(donneesPdf)
            `
        },
    ]}
/>

Le JSON retourné a la clé `content` avec tout le contenu textuel du fichier PDF, et la clé `metadata` avec les différentes propriétés du fichier PDF.

Voici un exemple du JSON retourné par `extract` :

```json
{
  "content": "Tout le contenu textuel du fichier PDF apparaît ici...",
  "metadata":{
    "Content-Type":"application/pdf",
    "dc:format":"application/pdf; version=1.4",
    "dc:title":"Linux 1",
    "pdf:PDFVersion":"1.4",
    "pdf:charsPerPage":"580",
    "pdf:containsDamagedFont":"false",
    "pdf:containsNonEmbeddedFont":"false",
    "pdf:docinfo:producer":"Skia/PDF m125 Google Docs Renderer",
    "pdf:docinfo:title":"Fichier 1",
    "pdf:encrypted":"false",
    "xmpTPg:NPages":"3",
    ...
  }
}
```

Il existe de nombreuses autres données obtenues dans `metadata` mais qui ont été omises dans les `...` pour que l'exemple ne soit pas trop long.

## Convertir

Il est possible de convertir programmatiquement le PDF en texte ou même en HTML.

### PDF en texte

Nous pouvons extraire tout le contenu du fichier PDF en texte brut en utilisant la méthode :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `

            `
        },
    ]}
/>

Exemple d'utilisation pour lire un fichier à la racine de l'application :

    codes={[
