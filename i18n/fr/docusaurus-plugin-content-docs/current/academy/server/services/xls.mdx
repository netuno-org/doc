Traiter des fichiers Excel personnalisés.

## Introduction

Netuno génère des fichiers EXCEL compatibles avec LibreOffice, OpenOffice, Microsoft Office, Google Drive, etc., grâce à la ressource [XLS](/docs/library/resources/xls) qui permet une abstraction low-code d'[Apache POI](https://poi.apache.org/) pour les différents langages de programmation pris en charge par Netuno.

Nous pouvons générer des fichiers XLSX, XLS ou ODS.

L'application fournie avec Netuno nommée **demo** (application de démonstration) contient de nombreux exemples des implémentations de code possibles dans plusieurs langages, y compris la démonstration de l'export de feuilles de calcul via le service `export-excel` qui se trouve dans :

<PolyglotPath files={[
    `netuno/apps/demo/server/services/exemples/%lang%/export-excel`
]} />

## Initialisation

Pour initialiser la ressource XLS :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const classeur = _xls.create()
            `
        },
    ]}
/>

Crée l'objet qui contient le contexte du nouveau fichier qui sera construit, avec une feuille de calcul vide.

## Formatage

La définition des styles de formatage visuel, c'est-à-dire le format des dates, heures, monnaie, entre autres, doit être effectuée avant la définition des valeurs des cellules, car en définissant les valeurs des cellules, il est possible d'y associer leur style de formatage.

Ainsi, comme le montre l'exemple fourni avec l'application `demo`, les formats sont définis au début du code.

Pour formater les dates :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const styleDate = classeur.cellStyleFormat("dd/mm/yy")
            `
        },
    ]}
/>

Pour formater les heures :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const styleHeure = classeur.cellStyleFormat("hh:mm:ss")
            `
        },
    ]}
/>

Pour formater les dates avec les heures :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const styleDateHeure = classeur.cellStyleFormat("dd/mm/yyyy hh:mm:ss")
            `
        },
    ]}
/>

Pour formater les valeurs monétaires en **euro** :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const styleMonnaieEuro = classeur.cellStyleFormat("€#,##0.00;\\-€#,##0.00")
            `
        },
    ]}
/>

Pour formater les valeurs monétaires en **réaux** :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const styleMonnaieReal = classeur.cellStyleFormat("R$#,##0.00;\\-R$#,##0.00")

<PolyglotCode
    codes={[
        {

        },

## Apparence

La définition des styles d'apparence visuelle, c'est-à-dire l'apparence des cellules comme les couleurs, la police, les bordures, l'alignement, entre autres, doit être effectuée avant la définition des valeurs des cellules, car en définissant les valeurs des cellules, il est possible d'y associer leur style d'apparence.

Ainsi, comme le montre l'exemple fourni avec l'application `demo`, les apparences sont définies au début du code.

Exemple de définition des couleurs et de l'alignement :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const styleEnTete = classeur.cellStyle()
                styleEnTete.setFillPattern(_xls.fillPattern("solid-foreground"))
                styleEnTete.setFillBackgroundColor(classeur.color("black"))
                styleEnTete.setAlignment(_xls.horizontalAlignment("center"))
            `
        },
    ]}
/>

> Documentation avec toutes les méthodes de l'objet <a href="https://poi.apache.org/apidocs/dev/org/apache/poi/hssf/usermodel/HSSFCellStyle.html" target="_blank">Styles dans Apache POI</a>.

Définition du style des bordures :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const styleDonnees = classeur.cellStyle()
                styleDonnees.setBorderBottom(_xls.borderStyle("thin"))
                styleDonnees.setBorderTop(_xls.borderStyle("thin"))
                styleDonnees.setBorderLeft(_xls.borderStyle("thin"))
                styleDonnees.setBorderRight(_xls.borderStyle("thin"))
            `
        },
    ]}
/>

> Documentation avec toutes les méthodes de l'objet <a href="https://poi.apache.org/apidocs/dev/org/apache/poi/hssf/usermodel/HSSFCellStyle.html" target="_blank">Styles dans Apache POI</a>.

Crée un nouveau style de police pour le texte, associe les définitions de la police à un style de cellule existant donné :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const policeTitre = classeur.font()

                policeTitre.setFontHeightInPoints(14)
                policeTitre.setColor(classeur.color("yellow"))
                // Définit la police du styleEnTete
                styleEnTete.setFont(policeTitre)

/>

## Fusionner des cellules

Pour fusionner des cellules dans une région, nous utilisons la méthode `mergedRegion`.

L'ordre des paramètres est le suivant :

1. Ligne de début
2. Colonne de début
3. Ligne de fin
4. Colonne de fin

> Les références numériques de positionnement commencent toujours à **zéro**.

Dans cet exemple ci-dessous, toutes les cellules de la colonne 10 à la colonne 15 qui se trouvent sur la ligne 3 seront fusionnées :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                classeur.mergedRegion(2, 9, 2, 14)
            `
        },
    ]}
/>

## Insérer des données tabulaires

Nous pouvons insérer un tableau de données en utilisant la méthode `addDataTable`.

Comme les deux premiers paramètres définissent la position où le tableau de données doit être inséré, ils correspondent aux numéros des lignes et des colonnes.

> Attention, le positionnement des lignes et des colonnes dans le code commence toujours à partir de **zéro**.
>
> C'est-à-dire que la Ligne 1 est la position `0` et la Colonne A est également la position `0`.

Ensuite, nous passons une liste de lignes, où chaque ligne contient une autre liste pour les colonnes, puis nous ajoutons une map avec la valeur de la cellule.

Exemple complet :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                classeur.addDataTable(
                    6, 1,
                    _val.list() // Lignes
                        .add(
                            _val.list() // Colonne
                                .add(
                                    _val.map() // Cellule
                                        .set("value", "Nom")
                                )
                                .add(
                                    _val.map()
                                        .set("value", "Âge")
                                )
                        )
                        .add( // Autre ligne
                            _val.list()
                                .add( // Première colonne
                                    _val.map()
                                        .set("value", "Marie")
                                )
                                .add( // Deuxième colonne
                                    _val.map()
                                        .set("value", 26)
                                )
                        )
                )
            `
        },
    ]}
/>

### Apparence

Dans la map des cellules, nous pouvons associer les styles déjà créés, en utilisant par exemple les styles définis dans la section apparence et formatage que nous avons vue précédemment.

<PolyglotCode

/>

### Formules

Pour insérer des formules, nous utilisons la clé `formula` dans la map de définitions de la cellule.

Dans cet exemple, la somme de toutes les valeurs des autres cellules sera effectuée dans la dernière cellule :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                classeur.addDataTable(
                    6, 1,
                    _val.list()
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 45))
                                .add(_val.map().set("value", 26))
                        )
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 51))
                                .add(_val.map().set("value", 30))
                        )
                        .add(
                            _val.list()
                                .add(
                                    _val.map().set("value", "Total")
                                )
                                .add(
                                    _val.map().set("formula", "SUM(B7:C8)")
                                )
                        )
                )
            `
        },
    ]}
/>

Pour obtenir la lettre de la colonne à partir du numéro de la colonne, la méthode `columnReference` peut être utilisée, ce qui peut aider dans la définition des formules. La même méthode peut également être utilisée pour obtenir le numéro de la colonne à partir de la lettre de référence, par exemple :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                classeur.addDataTable(
                    6, _xls.columnReference('B'),
                    _val.list()
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 45))
                                .add(_val.map().set("value", 26))
                        )
                        .add(
                            _val.list()
                                .add(_val.map().set("value", 51))
                                .add(_val.map().set("value", 30))
                        )
                        .add(
                            _val.list()
                                .add(
                                    _val.map().set("value", "Total")
                                )
                                .add(
                                    _val.map().set(
                                        "formula",
                                        "SUM("+ _xls.columnReference(1) +"7:"+ _xls.columnReference(2) +"8)"
                                )
                            )
                        )
                )
            `
        },
    ]}
/>

### Activer

Ainsi, pour éviter de devoir constamment indiquer dans les méthodes quelle feuille doit être traitée, comme dans les exemples ci-dessus, il est possible en alternative d'indiquer quelle est la feuille active.

> Toutes les méthodes de manipulation de cellules, d'images et de données utilisent la feuille qui est activée lorsqu'aucune feuille spécifique **n'est** indiquée.

Voyez deux façons d'activer une feuille spécifique, d'abord avec la référence de l'objet, puis avec l'index de la feuille :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                classeur.activeSheet(maFeuille) // Objet de référence de la feuille.
                classeur.activeSheet(1) // Index de la feuille qui sera activée.
            `
        },
    ]}
/>

## Modifier le fichier

Nous pouvons modifier des fichiers en les ouvrant, en effectuant les modifications nécessaires, puis en enregistrant le nouveau fichier modifié.

Voici ci-dessous quelques exemples de comment il est possible d'ouvrir des fichiers.

Ouvrir un fichier à la racine de l'application :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const classeur = _xls.open(_app.file("fichier.xlsx"))
            `
        },
    ]}
/>

Pour ouvrir le fichier généré dans le dossier `storage/filesystem` de l'application :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const classeur = _xls.open(_storage.filesystem("server", "fichier.xlsx"))
            `
        },
    ]}
/>

Et aussi pour ouvrir le fichier dans le dossier `/tmp` à partir du système de fichiers du disque dur :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const classeur = _xls.open(_os.file("/tmp/fichier.xlsx"))
            `
        },
    ]}
/>

Dans les exemples ci-dessus, la constante `classeur` contiendra l'objet d'édition avec le contexte du fichier respectif, ainsi il est possible de faire tout type de manipulation.

Lorsque vous avez terminé les modifications, générez le nouveau fichier.

> Il n'est pas possible de modifier directement le même fichier ouvert, il est nécessaire de générer un nouveau fichier avec un chemin différent.

Pour modifier directement le même fichier, cela peut être fait en utilisant le `inputStream`.

Voici un exemple de comment modifier la valeur d'une cellule :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const fichierEntree = _app.file("fichier.xlsx").inputStream()
                const classeur = _xls.open(fichierEntree)

                classeur.setCellData(
                    10, 1,
                    _val.map()
                        .set(
                            "value",
                            classeur.getCellData(10, 1).getInt("value") + 10
                        )
                )

                fichierEntree.close() // Ferme le fichier ouvert.
                classeur.save(_app.file("fichier.xlsx")) // Enregistre la nouvelle version.
                `
        },
    ]}
/>

## Lire le fichier

L'extraction de données à partir de fichiers Excel se fait avec la méthode `read`.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const donnees = _xls.read(_app.file("fichier.xlsx"))
            `
        },
    ]}
/>

Les données sont obtenues dans une structure d'objets de type Values qui contient des Listes, pour les feuilles, lignes et colonnes, et des Maps (clé et valeur) pour les cellules.

Pour visualiser toutes les données, nous pouvons les placer comme sortie de données du service :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _out.json(donnees)
            `
        },
    ]}
/>

Pour réaliser l'itération, nous devons garder à l'esprit que la structure des données est organisée dans l'ordre suivant :

1. `sheets` - Feuilles
2. `rows` - Lignes
3. `columns` - Colonnes

Exemple d'une itération complète :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                for (const feuille of donnees.getValues("sheets")) {
                    _out.println(\`<h4>Feuille : \${feuille.getInt("index")} - \${feuille.getString("name")}</h4>\`)
                    for (const ligne of feuille.getValues("rows")) {
                        _out.println(\`<h4>Ligne : \${ligne.getInt("row")}</h4>\`)
                        _out.println("<p>")
                        for (const colonne of ligne.getValues("columns")) {
                            _out.print(\`\${colonne.getInt("row")}:\${colonne.getInt("column")}\`)
                            _out.print(\` # \${colonne.getString("address")}\`)
                            _out.print(\` # \${colonne.getString("type")}\`)
                            _out.print(\` # \${colonne.getString("value")}\`)
                            _out.println("<br>")
                        }
                        _out.println("</p>")
                    }
                }
            `
        },
        {
            lang: 'python',

Le type de la cellule est obtenu via le code :

- `colonne.getString("type")`

Et les types supportés sont :

- `string` - Contenu texte.
- `numeric` - Contenu numérique ou de date et/ou heure.
- `boolean` - Vrai ou faux.
- `blank` - Cellule vide.
- `formula` - Cellule qui contient une formule.
- `error` - Erreur lors du traitement de la cellule.

### Paramètres supplémentaires

Pour chaque type de cellule, nous avons quelques paramètres supplémentaires.

`string` - Type de cellule avec contenu textuel.

- `value` - Texte de la cellule.
- `richValue` - Formatages de la cellule.

`numeric` - Type de cellule avec contenu numérique, ou dates et aussi heures.

- `value` - Valeur du contenu numérique de la cellule.
  
Dans le cas des dates et heures, nous avons ces paramètres supplémentaires :

- `localDateTime` - Objet Java Time LocalDateTime qui représente la valeur de date et heure de la cellule.
- `localDate` - Objet Java Time LocalDate qui représente la valeur de date de la cellule.
- `localTime` - Objet Java Time LocalTime qui représente la valeur d'heure de la cellule.
- `instant` - Objet Java Time Instant qui représente la valeur de date et/ou heure de la cellule.
- `date` - Objet Date de Java qui représente la valeur de date et/ou heure de la cellule.

`boolean` - Type de cellule avec contenu booléen, c'est-à-dire vrai ou faux.

- `value` - Valeur de type _boolean_, `true` ou `false`.

`blank` - Type de cellule sans contenu, donc ne contient pas de paramètres supplémentaires.

`formula` - Type de cellule qui contient des formules de calcul.

- `value` - Valeur finale résultant du calcul.
- `formula` - Contient l'expression de la formule utilisée pour le calcul.

`error` - Type de cellule qui contient une erreur.

- `value` - Valeur en octet de l'erreur générée.
- `code` - En cas d'erreurs dans le calcul de la formule, fournit ici le code de l'erreur survenue.
