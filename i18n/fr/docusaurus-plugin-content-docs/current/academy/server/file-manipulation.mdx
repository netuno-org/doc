## Introduction

Dans le code backend polyglotte de la plateforme Netuno, nous pouvons manipuler n'importe quel fichier ou dossier.

La manipulation consiste à pouvoir créer, renommer et supprimer des fichiers et dossiers, modifier le contenu de fichiers et lister le contenu de dossiers. De manière générale, ce sont les opérations que nous devons habituellement effectuer par programmation.

Dans la plateforme Netuno, il existe des ressources de programmation low-code qui permettent de manipuler les dossiers et les fichiers internes de l'application, mais aussi n'importe quels fichiers et dossiers du système en général, c'est-à-dire en dehors de l'application.

C'est utile lorsque nous devons automatiser un processus qui doit modifier un fichier quelconque, voyons comment.

Les ressources de programmation polyglotte low-code qui permettent de manipuler des fichiers sont :

- `_app` - [Application](/docs/library/resources/app)
- `_storage` - [Stockage](/docs/library/resources/storage)
- `_os` - [Système d'exploitation](/docs/library/resources/os)

À travers ces ressources, nous avons les méthodes pour :

- `.file` - Fichier existant.
- `.folder` - Dossier existant.
- `.path` - Chemin générique, pouvant être un fichier ou un dossier, existant ou non.

Avec ces méthodes, nous obtenons un objet de type [File](/docs/library/objects/File), qui fournit tous les moyens pour manipuler des fichiers, dossiers et chemins en général, ce qui permet d'effectuer des opérations telles que :

- Créer des fichiers et dossiers.
- Supprimer des fichiers et dossiers.
- Lister le contenu des dossiers.
- Renommer des fichiers et dossiers.
- Lire et écrire des données dans des fichiers.
- Supprimer des dossiers et leurs sous-dossiers et fichiers respectifs de manière récursive.

## Application

Pour effectuer les principales opérations de manipulation de fichiers et dossiers dans la structure de l'application, nous utilisons la ressource `_app` :

#### Dossiers dans l'Application

Garantit l'obtention d'un dossier qui existe, par exemple :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const monDossier = _app.folder("mon/dossier")
            `
        },
    ]}
/>

#### Fichiers dans l'Application

Garantit l'obtention d'un fichier qui existe, par exemple :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const monFichier = _app.file("mon/dossier/fichier.txt")
            `
        },
    ]}
/>

#### Chemins dans l'Application

Obtient un chemin de fichier ou de dossier, qu'il existe ou non, par exemple :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const nouveauFichier = _app.path("mon/dossier/nouveau-fichier.txt")
            `
        },
    ]}
/>

## Créer des Dossiers

La méthode `mkdir` crée un dossier.

Dans l'exemple suivant, crée le dossier spécifique à la racine de l'application :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const dossier = _app.path("temp")
                dossier.mkdir()
            `
        },
    ]}
/>

Pour créer un sous-dossier dans le dossier existant, indiquez le chemin complet en séparant la hiérarchie des dossiers avec `/` :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const sousDossier = _app.path("temp/autre")
                sousDossier.mkdir()
            `
        },
    ]}
/>

Le `mkdirs`, quant à lui, crée les dossiers précédents et/ou les sous-dossiers s'ils n'existent pas, il permet donc de créer une structure de dossiers dans l'application, par exemple :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const cheminDossiers = _app.path("temp/a/b/c")
                cheminDossiers.mkdirs()
            `
        },
    ]}
/>

La ressource `_storage` possède la méthode [ensurePath](/docs/library/resources/storage#ensurepath) qui vérifie si le chemin existe, et le crée s'il n'existe pas :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const fichier = _storage.filesystem(
                    "public",
                    "temp/sous-dossier",
                    "fichier.txt"
                )
                // Crée la structure de dossiers si elle n'existe pas :
                fichier.ensurePath()
            `
        },
    ]}
/>

Donc `ensurePath` garantit que la structure de dossiers existe.

## Supprimer des Fichiers et Dossiers

Avec la méthode `delete`, nous pouvons supprimer aussi bien des dossiers que des fichiers, étant entendu que les dossiers doivent être vides, voyez l'exemple :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                // Supprime un dossier vide :
                const dossierVide = _app.folder("dossier/vide")
                dossierVide.delete()

                // Supprime un fichier :
                const fichier = _app.file("dossier/fichier.txt")
                fichier.delete()

                // Supprime un chemin, un dossier vide ou un fichier :
                const chemin = _app.path("dossier1/fichier-ou-dossier-vide")
                chemin.delete()
            `
        },
    ]}
/>

Avec `deleteAll`, il est possible de tout supprimer, c'est-à-dire tous les fichiers, dossiers et sous-dossiers de manière récursive :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                // Supprime le dossier et tout son contenu de manière récursive :
                const dossierVide = _app.folder("dossier/exemple")
                dossierVide.deleteAll()

                // Supprime le chemin d'un dossier et tout son contenu interne,
                // y compris les sous-dossiers et les fichiers :
                const chemin = _app.path("chemin/dossier")
                chemin.deleteAll()
            `
        },
    ]}
/>

Pour supprimer uniquement les fichiers dans le dossier sans rien supprimer dans les sous-dossiers, nous avons `deleteFiles`, qui permet de recevoir une extension si vous souhaitez supprimer uniquement les fichiers ayant une extension spécifique :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                // Supprime les fichiers uniquement dans le dossier :
                const dossier = _app.folder("dossier/exemple")
                dossier.deleteFiles()

                // Supprime les fichiers avec l'extension JPG uniquement dans le dossier :
                const chemin = _app.path("chemin/dossier")
                chemin.deleteFiles("jpg")
`
        },
    ]}
/>

Pour supprimer uniquement les fichiers de manière récursive et conserver la structure des dossiers, nous avons `deleteAllFiles`, qui permet également de recevoir une extension si vous souhaitez supprimer uniquement un type de fichier spécifique, voyez ces deux exemples :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                // Supprime tous les fichiers dans le dossier et les sous-dossiers :
                const dossier = _app.folder("dossier/exemple")
                dossier.deleteAllFiles()

                // Supprime tous les fichiers avec l'extension JPG dans le dossier et les sous-dossiers :
                const chemin = _app.path("chemin/dossier")
                chemin.deleteAllFiles("jpg")
            `
        },
    ]}
/>

## Renommer ou Déplacer

Pour déplacer un dossier, cela revient à le renommer :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const dossier = _app.folder("temp")
                dossier.renameTo("test")
            `
        },
    ]}
/>

Pour renommer un dossier et le changer de niveau dans la hiérarchie des dossiers, cela revient à déplacer le dossier :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const dossier = _app.folder("temp/a/b")
                dossier.renameTo("test/z")
            `
        },
    ]}
/>

Et pour déplacer un sous-dossier sans changer son nom, il suffit d'indiquer le nouveau chemin dans la méthode `renameTo` :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const dossier = _app.folder("test/autre")
                dossier.renameTo("nouvelle")
            `
        },
    ]}
/>

## Enregistrer des Contenus dans des Fichiers

La génération de contenus dans des fichiers se fait via la méthode `output`, qui fournit un objet de type [OutputStream](/docs/library/objects/OutputStream).

Pour écrire les données dans l'`output`, nous utilisons la méthode [printAndClose](/docs/library/objects/OutputStream#printandclose), qui imprime le contenu dans le fichier et ferme le fichier en enregistrant le contenu.

#### Écrire un Fichier Texte

Voyez l'exemple de création d'un fichier avec un contenu texte :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _app.path("temp").mkdir()
                const ecriture = _app.path("temp/fichier.txt").output()
                ecriture.printAndClose("Mon texte ici...")
            `
        },
    ]}
/>

> Chaque fois que nous utilisons `output`, un nouveau fichier est généré, donc si vous exécutez à nouveau le code, le fichier sera recréé.

#### Écrire un fichier JSON

Voyez comment nous pouvons enregistrer des données JSON dans des fichiers :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _app.path("temp").mkdir()
                const ecriture = _app.path("temp/client.json").output()
                ecriture.printAndClose(
                    _val.map()
                        .set("nom", "Marie Jeanne")
                        .set(
                            "enregistrements",
                            _val.list()
                                .add(1).add(2).add(3)
                        )
                        .toJSON()
                )
            `
        },
    ]}
/>

Pour générer le JSON indenté, c'est-à-dire formaté sur plusieurs lignes et tabulé, nous pouvons passer le nombre d'espaces qui sera utilisé pour la tabulation, par exemple `.toJSON(4)`.

> Plus de détails sur la méthode [toJSON dans Values](/docs/library/objects/Values#tojsonindentfactor-int--string).

## Lire des Contenus dans des Fichiers

L'obtention de contenus dans des fichiers se fait via la méthode `input`, qui fournit un objet de type [InputStream](/docs/library/objects/InputStream).

Pour lire les données dans l'`input`, nous utilisons la méthode [readAllAndClose](/docs/library/objects/InputStream#readallandclose), qui traite la lecture du contenu dans le fichier et ferme le fichier.

#### Lire un Fichier Texte

Voyez l'exemple de lecture d'un fichier et d'obtention du contenu texte :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const fichier = _app.file("temp/fichier.txt")
                const lecture = fichier.input()
                _log.info(lecture.readAllAndClose())
            `
        },
    ]}
/>

#### Lire un fichier JSON

Voyez comment nous pouvons traiter des données JSON obtenues dans des fichiers :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const fichier = _app.file("temp/fichier.txt")
                const lecture = fichier.input()
                const donnees = _val.fromJSON(lecture.readAllAndClose())
                _log.info("Données du fichier :", donnees)
            `
        },
    ]}
/>

> Plus de détails sur la méthode [fromJSON de la ressource Val](/docs/library/resources/val#fromjson).

## Particularités du Stockage

La ressource storage possède quelques méthodes à utiliser directement.

Par exemple, nous pouvons y accéder via le stockage :

- [Storage Output](/docs/library/resources/storage#output)
- [Storage Input](/docs/library/resources/storage#input)

Cela signifie que nous n'avons pas besoin d'obtenir le `file` ou le `path` pour travailler avec l'`input` ou l'`output`.

#### Écrire un Fichier Texte dans le Stockage

Lors de l'initialisation d'un stockage pour un fichier, nous pouvons effectuer l'écriture en utilisant la méthode [output](/docs/library/resources/storage#output), qui obtient une instance de l'objet [OutputStream](/docs/library/objects/OutputStream) permettant de traiter et de lire les données.

Ainsi, avec l'`OutputStream`, la méthode [printAndClose](/docs/library/objects/OutputStream#printandclose) effectue l'écriture de texte (`string`) dans le fichier et le ferme.

Voyez cet exemple :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const txt = _storage.filesystem("server", "temp", "fichier.txt")
                txt.ensurePath()
                txt.output().printAndClose("Mon texte ici...")
            `
        },
    ]}
/>

#### Lire un Fichier Texte dans le Stockage

Lors de l'initialisation d'un stockage pour un fichier, nous pouvons effectuer la lecture en utilisant la méthode [input](/docs/library/resources/storage#input), qui obtient une instance de l'objet [InputStream](/docs/library/objects/InputStream) permettant de traiter et de lire les données.

Ainsi, avec l'`InputStream`, la méthode [readAllAndClose](/docs/library/objects/InputStream#readallandclose) lit tout le fichier et le ferme, en retournant les données sous forme de texte (`string`).

Voyez cet exemple :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const txt = _storage.filesystem("server", "temp", "fichier.txt")
                _log.info(txt.input().readAllAndClose())
            `
        },
    ]}
/>

#### Créer un fichier aléatoire dans le Stockage

La ressource `_storage` permet de générer des noms de fichiers aléatoires, avec la méthode [newRandomFile](/docs/library/resources/storage#newrandomfile).

Vous devez initialiser un stockage pour le chemin d'un dossier, et lors de l'exécution de la méthode `newRandomFile`, vous passez l'extension du fichier souhaité.

La méthode retourne une nouvelle instance du stockage pour le fichier aléatoire généré automatiquement, à utiliser dans le dossier initial.

Voyez comment générer un fichier avec l'extension `TXT` et un nom aléatoire :

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const dossier = _storage.filesystem("server", "temp")
                const fichier = dossier.newRandomFile("txt")
                fichier.output().printAndClose("Mon texte ici...")
            `
        },
    ]}
/>

## Conclusion

Avec le framework low-code polyglotte de Netuno, nous pouvons effectuer toutes les principales opérations sur les dossiers et fichiers directement.

En utilisant les ressources spécifiques pour manipuler des fichiers et dossiers dans :

- `_app` - Application
- `_storage` - Stockage de l'Application
- `_os` - Système d'exploitation

> Pour des questions de bonnes pratiques et d'organisation, nous devons privilégier l'utilisation du **stockage** ; les exceptions ne doivent être que des cas ponctuels et strictement nécessaires.

Netuno gère la fermeture automatique des inputs et outputs à la fin du traitement des services, mais par bonnes pratiques, nous devons toujours essayer de les fermer.
