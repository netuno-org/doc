Netuno est polyglotte tant au niveau des bases de données qu'au niveau du code de programmation, mais aussi au niveau du système d'exploitation.

Avec toute cette diversité, les options d'utilisation augmentent.

En prenant en charge diverses bases de données, langages de programmation et systèmes d'exploitation, il facilite le développement en s'adaptant à chaque situation tout en garantissant un environnement cohérent pour les développements.

## Bases de données

Il peut être utilisé pour intégrer plusieurs types de bases de données différentes et même être développé avec différents langages de programmation dans le même projet.

Intégrer différentes bases de données est assez courant pour réaliser l'intégration de données lors de la consultation ou de la modification de données dans la base de données d'un autre système.

![Logos des bases de données](/docs/assets/business/databases.jpg "Bases de données multiples")

Netuno prend en charge les bases de données suivantes :

- H2 Database
- PostgreSQL
- MariaDB
- MySQL
- Microsoft SQL Server
- Oracle

## Langages de programmation

Prendre en charge différents langages de programmation peut ne pas sembler très intéressant dans le sens de mélanger les langages de programmation, mais c'est possible et cela ne signifie pas qu'il faut le faire ainsi.

En pratique, il est souvent compliqué de réaliser des projets où une technologie dominante est limitée à un langage de programmation ; il faut donc trouver des personnes exclusivement compétentes pour ce langage de programmation.

Avec Netuno, on finit par avoir une offre plus large, où tout le travail n'est pas gaspillé s'il est nécessaire d'utiliser un nouveau langage de programmation suite à un changement de stratégie, un manque de techniciens compétents, ou pour gagner en agilité lors du développement de quelque chose de spécifique, entre autres situations qui peuvent avoir du sens.

En règle générale, cela serait impensable car la maintenance d'un système avec plusieurs langages de programmation commence à être préoccupante, mais comme il s'agit de low-code, cette préoccupation devient beaucoup moins pertinente, car :

* Les langages de programmation finissent par se ressembler au niveau de la logique et de l'algorithme.
* Le langage de programmation peut être différent, mais les ressources de Netuno sont les mêmes et utilisées de la même manière indépendamment du langage.

Ainsi, même si un technicien est très habitué à travailler avec un langage de programmation, rien ne l'empêchera d'effectuer la maintenance dans un autre ; s'il a besoin d'étendre beaucoup plus son intervention ou même de refaire, il pourra choisir de développer dans son langage préféré et intégrer son développement au langage déjà utilisé.

![Logos des langages de programmation](/docs/assets/business/languages.jpg "Langages de programmation")

Netuno prend en charge le développement dans les langages de programmation suivants :

- Groovy
- Java
- JavaScript
- Kotlin
- Python
- Ruby

## Systèmes d'exploitation

En travaillant avec plusieurs systèmes d'exploitation et en prenant en charge les configurations d'environnement, Netuno permet de garantir le bon fonctionnement des développements de manière transversale et d'organiser en environnements de développement, test, qualité, production, entre autres.

Le changement de système d'exploitation ou d'environnement est indifférent pour le bon fonctionnement de Netuno et des applications.

![Logos des systèmes d'exploitation](/docs/assets/business/operationsystems.jpg "Systèmes d'exploitation multiples")

Les systèmes d'exploitation pris en charge par Netuno sont :

* Linux
* Mac OS X
* Windows
