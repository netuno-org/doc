# Vue d'ensemble de Netuno

## Introduction

Bienvenue sur **Netuno** !

Nous savons qu'adopter de nouvelles technologies peut être un défi en raison du grand nombre d'options disponibles sur le marché. Netuno a été créé pour résoudre ce problème, en simplifiant le développement en regroupant les meilleurs outils et solutions en un seul endroit.

Nous sommes une plateforme axée sur la productivité. L'un des plus grands accélérateurs de Netuno est l'absence de processus de compilation ou de build longs.

Nous offrons une expérience de développement fluide et flexible pour utiliser divers langages de programmation intégrés aux principales bases de données.

L'environnement **low-code** de Netuno est polyglotte, vous permettant de choisir le langage qui s'adapte le mieux aux besoins spécifiques de chaque service.

> Notre devise est simple : **avec moins de lignes de code, vous en faites plus.**

## Langages pris en charge

Dans toutes les options de développement, vous bénéficiez d'un support natif pour les langages :

* <a href="https://developer.mozilla.org/en-US/docs/Web/JavaScript" target="_blank">JavaScript</a>
* <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>

* <a href="https://www.jruby.org/" target="_blank">Ruby</a>
* <a href="https://kotlinlang.org/" target="_blank">Kotlin</a>
* <a href="https://groovy-lang.org/" target="_blank">Groovy</a>

## Productivité au travail

Netuno élimine les goulots d'étranglement du développement grâce aux piliers suivants :

-  **Choix sûr des outils :** Nous réduisons votre temps de recherche et de configuration initiale. Netuno est déjà structuré avec les solutions les plus efficaces du moment.

- **Flexibilité polyglotte :** Travaillez avec le langage de programmation de votre choix au sein du même écosystème, en utilisant une large variété de ressources prêtes à l'emploi pour chaque service web spécifique.

- **Création rapide de services web :** L'approche low-code permet de développer rapidement des API REST complexes.

- **Intégration sans complication :** Développez le backend rapidement et connectez-le facilement à n'importe quel frontend, application mobile, portail d'entreprise ou boutique en ligne.

- **Mise à jour en temps réel (Hot Reload) :** La rapidité de développement est également due au fait de ne pas avoir à redémarrer le serveur. Dans l'écosystème Netuno, il n'y a ni compilations ni redémarrages. La modification du code est immédiate et en temps réel.

* **Agilité de développement :** Testez vos API simultanément pendant que vous développez. Enregistrez le code dans Netuno et faites la requête depuis votre frontend immédiatement.

* **Concentration sur la logique métier :** Laissez Netuno s'occuper de l'infrastructure de base et des connexions. Concentrez-vous sur la façon dont votre système peut apporter plus de valeur à l'utilisateur final.

## Backoffice

La plateforme simplifie le parcours de développement en unifiant la création d'interfaces de formulaire avec la structuration automatique de la base de données.

Cette approche réduit considérablement la courbe d'apprentissage, permettant aux développeurs de se concentrer sur la logique métier pendant que la plateforme gère l'infrastructure.

Cela élimine le besoin d'écrire des scripts SQL manuels ou de créer des écrans CRUD (Create, Read, Update, Delete) répétitifs.


En concevant un formulaire, vous modélisez simultanément votre base de données et générez une interface administrative complète.

Netuno fournit un écosystème administratif prêt à l'emploi, qui comprend :

| Fonctionnalité | Description |
| :--- | :--- |
| **Relations** | Gestion automatique des diagrammes, clés étrangères et liens entre tables. |
| **Recherche avancée** | Filtres affinés pour une localisation rapide des enregistrements. |
| **Gestion de fichiers** | Composants natifs pour le téléchargement d'images et de documents. |
| **Exportation** | Extraction de données dans des formats compatibles pour les rapports. |
| **Sécurité** | Contrôle des profils d'accès et authentification intégrée. |

Netuno est **open-source** et vous permet d'explorer tout le potentiel de l'outil de manière gratuite et collaborative pour réaliser des travaux complexes avec une haute productivité. [Commencez maintenant](/docs/get-started/installation).

## Base de données

Netuno simplifie la gestion des données en unifiant la création du Backoffice avec la structure de la base de données. Cette construction ne nécessite pas l'écriture manuelle de scripts SQL complexes pour la création de tables.

Grâce à l'interface visuelle, il est possible de définir les champs et les relations, et la plateforme synchronise ces définitions avec la base de données, générant automatiquement l'interface d'administration et le diagramme de données.

## Diagramme de données

Netuno génère automatiquement un diagramme dynamique qui représente le modèle de données de votre application. Cette fonctionnalité est essentielle pour visualiser l'architecture de l'information et les liens entre les tables.

## Requête

Netuno fournit une console de base de données robuste et intuitive, permettant aux développeurs d'interagir directement avec les données de manière agile et organisée.

Il est possible d'enregistrer des commandes complexes ou récurrentes pour un accès rapide à l'avenir. 
Le système conserve un historique des commandes exécutées, facilitant l'audit et la récupération de logiques de requête antérieures.

La console permet l'exécution de plusieurs commandes simultanément. Pour séparer les instructions et garantir que Netuno interprète chacune correctement, utilisez le délimiteur point-virgule double `;;`.

## Développement Low-code et Polyglotte


Netuno se distingue par son architecture flexible, permettant à chaque projet d'utiliser plusieurs langages de programmation simultanément.

Il est possible de créer plusieurs applications (projets) indépendantes et, au sein de chacune, d'écrire des services en utilisant les langages du marché les plus populaires et pris en charge par Netuno.

La plateforme identifie automatiquement quel moteur d'exécution utiliser en fonction de l'extension du fichier créé dans le dossier des services du serveur, par exemple :

- `.js` - JavaScript
- `.py` - Python
- `.rb` - Ruby
- `.kts` - Kotlin Script
- `.groovy` - Groovy
