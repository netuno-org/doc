L'interface de Netuno est divisée en deux espaces de travail, aux finalités spécifiques et différentes. Le mode de *visualisation* pour interagir et afficher le résultat de l'application finale (Frontend), et le mode de *construction* pour développer votre application.

### Visualiser

C'est l'environnement frontend où les utilisateurs interagissent avec la partie visuelle de l'application.

#### 1 - Construire

Ce bouton vous permet d'accéder au mode de développement de l'application.

#### 2 - Menu déroulant

 Permet de sélectionner des options pour gérer votre session, telles que vous déconnecter, modifier le mot de passe de votre compte et consulter les données de votre utilisateur et de vos groupes.

#### 3 - Mon espace de travail

C'est la zone centrale, où votre application web frontend, programmée dans le dossier `public`, est affichée.

#### 4 - Tables et formulaires

Dans cette zone, vous trouvez l'accès à toutes les tables de données. Cliquez pour visualiser, ajouter, modifier ou supprimer des données directement via des formulaires.

### Construire

C'est l'environnement low-code où vous configurez et gérez tous les aspects de votre application sans avoir besoin d'écrire un code extensif.

#### 1 - Visualiser

Permet le retour immédiat au mode « Visualiser », pour vérifier l'impact de vos modifications en temps réel.

#### 2 - Menu déroulant

Permet de quitter l'application.

#### 3 -  Mon espace de travail

C'est la zone centrale, où votre application web frontend, programmée dans le dossier `public`, est affichée. 

#### 4 - Gestion

Cette section permet de gérer les formulaires, les rapports, les query et les diagrammes.

#### 5 - Déboguer

Cette section permet la surveillance et l'inspection du comportement des scripts en cours d'exécution. Ainsi, il est possible d'identifier des problèmes, de suivre les valeurs des variables et de comprendre le flux d'exécution du code.

#### 6 - Gestion des champs

Cette section permet la gestion de la structure de vos tables de données. Vous pouvez ajouter, modifier ou supprimer des champs et définir le type de données (texte, nombre, date, etc.) pour chacun d'eux.
