Avec Netuno, il est possible de créer des **_Web Services_** et de construire tout type d'**APIs <a href="https://pt.wikipedia.org/wiki/REST" target="_blank">REST</a>** complexes pour l'intégration de données entre systèmes.

:::info Qu'est-ce qu'un Web Service ?
Un Web Service permet à des systèmes d'échanger des informations en ligne de manière standardisée. Dans Netuno, chaque fichier dans `server/services/` devient automatiquement un endpoint accessible via HTTP.
:::

## Pourquoi utiliser des Web Services ?

L'utilisation de services asynchrones apporte des bénéfices clairs pour l'expérience utilisateur :

- **Chargement plus rapide :** le serveur livre la structure visuelle de la page immédiatement, sans attendre le traitement de toutes les données.
- **Données dynamiques à la demande :** le frontend ne demande que les données nécessaires, quand c'est nécessaire.
- **Intégration entre systèmes :** un service créé dans Netuno peut être consommé par n'importe quelle application externe (mobile, autre système web, etc.).
- **Meilleure expérience utilisateur :** l'utilisateur n'a pas besoin d'attendre le traitement complet de la page avant de voir quelque chose à l'écran.

## Prérequis

Avant de commencer, assurez-vous que :

- Netuno est installé et en cours d'exécution localement.
- L'application `démo` a été créée comme décrit dans [Créer une Application](../app-create).
- Il y a des données enregistrées dans **Tâches** et liées à **Enregistrements** (nécessaire pour que le retour ne soit pas vide).

## Configurer l'Éditeur de Code

Pour créer et modifier des services dans Netuno, utilisez un éditeur de code de votre choix. Nous recommandons **[Visual Studio Code](https://code.visualstudio.com/download)** car il est gratuit, léger et très intuitif, mais n'importe quel éditeur compatible avec JavaScript/Python/Groovy fonctionnera normalement.

## Ouvrir l'Application Démo {#abrir-a-aplicacao-demo}

1. Ouvrez **Visual Studio Code**.
2. Cliquez sur l'icône **Fichiers** dans le panneau latéral gauche.
3. Sélectionnez **Ouvrir le dossier** (File > Open Folder).
4. Naviguez jusqu'au dossier d'installation de Netuno.
5. Sélectionnez le répertoire : **`apps/démo`**
6. Cliquez sur **Ouvrir**.

La structure de dossiers de l'application `démo` sera chargée dans le panneau gauche.

## Créer le Service

Les services sont traités côté **serveur**. Pour créer un nouveau service :

1. Dans le panneau de fichiers, développez la structure jusqu'à trouver le dossier `server/services/`.
2. Cliquez avec le **bouton droit** sur le dossier `services`.
3. Sélectionnez **Nouveau Fichier** `New File`.
4. Nommez le fichier en fonction du langage que vous souhaitez utiliser :

Implémentez le service en ajoutant le code ci-dessous au fichier créé. Ce service interroge la base de données et renvoie une liste de travailleurs avec le total des heures enregistrées, au format **JSON**.

### Comprendre le Code

| Objet/Méthode | Description |
|---|---|
| `_db.query()` | Exécute une requête SQL et renvoie une liste d'objets au format clé-valeur (colonne → donnée). |
| `_val.list()` | Crée une liste mutable pour accumuler les résultats. |
| `_val.map()` | Crée un objet de mappage (clé-valeur) pour chaque ligne de résultat. |
| `_out.json()` | Sérialise l'objet en JSON et envoie la réponse aux requêtes HTTP. |

:::warning Données nécessaires
Assurez-vous qu'il y a des données enregistrées dans **Tâches** et liées à **Enregistrements**. Sinon, l'endpoint renverra une liste vide `[]`.
:::

## Exécuter et Tester le Service

Avec Netuno en cours d'exécution, accédez à l'endpoint dans le navigateur :

:::tip Astuce pour visualiser le JSON
Nous recommandons **[Firefox](https://www.mozilla.org/)** pour tester les endpoints directement dans le navigateur, car il formate et affiche la réponse JSON de manière lisible avec coloration syntaxique. Alternativement, utilisez des extensions comme **JSON Viewer** dans Chrome ou des outils comme **[Postman](https://www.postman.com/)** pour des tests plus avancés.
:::

Le retour attendu sera un JSON similaire à :

```json
[
  { "nom": "Anne Dupont", "total": 12 },
  { "nom": "Charles Martin", "total": 28 },
  { "nom": "Jean Durand", "total": 45 }
]
```
