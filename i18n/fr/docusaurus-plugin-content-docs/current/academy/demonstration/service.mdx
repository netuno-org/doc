Avec Netuno, il est possible de créer des **_Web Services_** et de construire tout type d'**API <a href="https://pt.wikipedia.org/wiki/REST" target="_blank">REST</a>** complexes pour l'intégration de données entre systèmes.

:::info Qu'est-ce qu'un Web Service ?
Un Web Service permet aux systèmes d'échanger des informations en ligne de manière standardisée. Dans Netuno, chaque fichier dans `server/services/` devient automatiquement un endpoint accessible via HTTP.
:::

## Pourquoi utiliser des Web Services ?

L'utilisation de services asynchrones apporte des bénéfices clairs pour l'expérience utilisateur :

- **Chargement plus rapide :** le serveur livre la structure visuelle de la page immédiatement, sans attendre le traitement de toutes les données.
- **Données dynamiques à la demande :** le frontend ne demande que les données nécessaires, quand elles sont nécessaires.
- **Intégration entre systèmes :** un service créé dans Netuno peut être consommé par n'importe quelle application externe (mobile, autre système web, etc.).
- **Meilleure expérience utilisateur :** l'utilisateur n'a pas besoin d'attendre le traitement complet de la page avant de voir quelque chose à l'écran.

## Prérequis

Avant de commencer, assurez-vous que :

- Netuno est installé et en cours d'exécution en local.
- L'application `demo` a été créée comme décrit dans [Créer une application](../app-create).
- Des données sont enregistrées dans **Tâches** et liées à **Enregistrements** (nécessaire pour que le retour ne soit pas vide).

## Configurer l'éditeur de code

Pour créer et modifier des services dans Netuno, utilisez un éditeur de code de votre choix. Nous recommandons **[Visual Studio Code](https://code.visualstudio.com/download)** car il est gratuit, léger et très intuitif, mais tout éditeur compatible avec JavaScript/Python/Groovy fonctionnera normalement.

## Ouvrir l'application démo {#abrir-a-aplicacao-demo}

1. Ouvrez **Visual Studio Code**.
2. Cliquez sur l'icône **Fichiers** dans le panneau latéral gauche.
3. Sélectionnez **Ouvrir le dossier** (Fichier > Ouvrir le dossier).
4. Naviguez jusqu'au dossier d'installation de Netuno.
5. Sélectionnez le répertoire : **`apps/demo`**
6. Cliquez sur **Ouvrir**.

La structure de dossiers de l'application `demo` sera chargée dans le panneau de gauche.

## Créer le service

Les services sont traités côté **serveur**. Pour créer un nouveau service :

1. Dans le panneau des fichiers, développez l'arborescence jusqu'à trouver le dossier `server/services/`.
2. Faites un clic droit sur le dossier `services`.
3. Sélectionnez **Nouveau fichier** `Nouveau fichier`.
4. Nommez le fichier en fonction du langage que vous souhaitez utiliser :

Implémentez le service en ajoutant le code ci-dessous au fichier créé. Ce service interroge la base de données et renvoie une liste de travailleurs avec le total d'heures enregistrées, au format **JSON**.

### Comprendre le code

| Objet/Méthode | Description |
|---|---|
| `_db.query()` | Exécute une requête SQL et renvoie une liste d'objets au format clé-valeur (colonne → donnée). |
| `_val.list()` | Crée une liste mutable pour accumuler les résultats. |
| `_val.map()` | Crée un objet de mappage (clé-valeur) pour chaque ligne de résultat. |
| `_out.json()` | Sérialise l'objet en JSON et envoie la réponse aux requêtes HTTP. |

:::warning Données nécessaires
Assurez-vous que des données sont enregistrées dans **Tâches** et liées à **Enregistrements**. Sinon, l'endpoint renverra une liste vide `[]`.
:::

## Exécuter et tester le service

Avec Netuno en cours d'exécution, accédez à l'endpoint dans le navigateur :

:::tip Astuce pour visualiser le JSON
Nous recommandons **[Firefox](https://www.mozilla.org/)** pour tester les endpoints directement dans le navigateur, car il formate et affiche la réponse JSON de manière lisible avec coloration syntaxique. Vous pouvez également utiliser des extensions comme **JSON Viewer** dans Chrome ou des outils comme **[Postman](https://www.postman.com/)** pour des tests plus avancés.
:::

Le retour attendu sera un JSON similaire à :

```json
[
  { "nom": "Anne Dupont", "total": 12 },
  { "nom": "Charles Martin", "total": 28 },
  { "nom": "Jean Dubois", "total": 45 }
]
```
