## Qu’est-ce que c’est

À partir d’une page existante, il est possible d’en créer une nouvelle via l’option **Cloner**. Dans le formulaire de clonage, il faut indiquer :

- Le **Titre** et le **Lien** de la nouvelle page.
- La **Version source** — de quelle version de la page d’origine le contenu sera copié.
- La **Langue** — éventuellement différente de la langue de la page d’origine.
- Si la nouvelle page doit être **publiée** immédiatement.

En confirmant, CLUAR duplique toute la structure de composants (Bannière, Contenu, Liste, Slider, Fonctionnalité, avec les actions correspondantes) de cette version vers la nouvelle page.

## À quoi ça sert

C’est ainsi qu’en pratique, on crée la « traduction » d’une page : au lieu de monter une nouvelle page à partir de zéro, on choisit la page déjà existante dans une autre langue, on la clone vers la nouvelle langue, puis on ajuste les textes. Cela sert aussi à créer rapidement des pages similaires dans la même langue (ex. : plusieurs pages de campagne avec la même structure).

:::info Traduction des contenus
Le clonage duplique la **structure** de la page (les mêmes composants, dans le même ordre), mais **ne traduit pas le texte** — les champs de chaque composant (Bannière, Contenu, Liste, Slider, Fonctionnalité) conservent le contenu d’origine, et il faut entrer dans chacun et traduire manuellement. La traduction automatique des contenus lors du clonage est déjà prévue, mais n’a pas encore été développée.
:::
