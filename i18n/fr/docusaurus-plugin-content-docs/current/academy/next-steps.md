Gardez à l'esprit ce qu'il faut pour continuer à évoluer dans Netuno.

La documentation en général bénéficie d'améliorations constantes et s'efforce d'être aussi simple et introductive que possible.

Mais il est supposé que vous ayez certaines bases de connaissance et une certaine expérience dans certains domaines, tels que :

* Bases de données, comme les requêtes en général, insert, update et delete ;
* Services web, avec GET et POST ;
* <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a> et <a href="https://reactjs.org/" target="_blank">ReactJS</a> ;

Si vous ne possédez pas l'une de ces compétences, nous essaierons de vous aider à les développer.

Recherchez toujours de l'aide sur GitHub ou Discord, consultez les indications dans le pied de page du site.

## Base de données

Avec Netuno, vous pourrez travailler avec différents types de bases de données et approfondir vos connaissances.

Avec une bonne connaissance des bases de données, il est possible de créer des applications avec des structures complexes pour collecter et gérer un grand volume de données.

Ainsi, vous aurez l'autonomie nécessaire pour créer de manière robuste la partie la plus importante, à savoir la base de données.

La construction d'une base de données bien organisée et optimisée fait toute la différence dans l'expérience des utilisateurs finaux ainsi que dans les performances, du développement à l'exécution.

## Services

Si vous avez déjà des connaissances dans l'un des langages de programmation suivants, comme <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a> ou <a href="https://groovy-lang.org/" target="_blank">Groovy</a>, vous pourrez créer rapidement des services web complexes et robustes en utilisant les diverses ressources que Netuno met à disposition pour la programmation **low code**.

Dans le dossier des applications, en particulier dans le dossier **server**, vous pourrez programmer dans ces différents langages.

Il suffit d'utiliser l'extension correspondante :

* **.js** &nbsp; <a href="https://developer.mozilla.org/pt-PT/docs/Web/JavaScript" target="_blank">JavaScript</a>
* **.ts** &nbsp; <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>
* **.py** &nbsp; <a href="https://www.jython.org/" target="_blank">Python</a>
* **.rb** &nbsp; <a href="https://www.jruby.org/" target="_blank">Ruby</a>
* **.kts** &nbsp; <a href="https://kotlinlang.org/" target="_blank">Kotlin</a>
* **.groovy** &nbsp; <a href="https://groovy-lang.org/" target="_blank">Groovy</a>

Explorez les exemples de services web inclus dans l'application **démo**_nstration_, dans :

- `/apps/demo/server/services/samples`

Et explorez également la documentation de notre **bibliothèque** pour découvrir en détail les ressources disponibles.


## Interface utilisateur

Le développement du frontend web a subi de nombreux changements ces dernières années et l'utilisation de <a href="https://vite.dev/" target="_blank">Vite</a> est devenue une norme.

Nos choix technologiques, tels que <a href="https://reactjs.org/" target="_blank">ReactJS</a>, <a href="https://bun.sh/" target="_blank">Bun</a>, <a href="https://ant.design/" target="_blank">Ant.Design</a> et <a href="http://lesscss.org/" target="_blank">Less</a>, sont des technologies qui apportent un gain de productivité avec une large adoption.

Pour approfondir vos connaissances sur ces technologies, explorez les diverses documentations au format texte et vidéo disponibles sur Internet.

Comme ce sont des technologies avec de grandes communautés, il n'est pas difficile de trouver de bons supports pour commencer à apprendre.

Rappelons qu'avec Netuno, même avec peu de connaissances, il est déjà possible d'obtenir de grands résultats, ce qui donne au développeur frontend le pouvoir de développer tout le backend et vice-versa, et il est même possible de choisir de tout développer avec un seul langage de programmation comme <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>.

## Conclusion

Netuno facilite le développement des applications web où une seule personne avec peu de connaissances en bases de données, services web et frontend peut développer des applications complexes de manière autonome.

Pour les grandes équipes également, où il y a des personnes plus compétentes dans chacun des domaines, il apporte, de manière générale, une grande augmentation de productivité.

Netuno peut également être utilisé comme backoffice pour des bases de données ou comme serveur d'API REST pour des frontends découplés et des applications mobiles.

Gagnez du temps et développez en vous concentrant davantage sur la logique des règles métier et, avec les connaissances que vous avez déjà, vous irez plus loin.
