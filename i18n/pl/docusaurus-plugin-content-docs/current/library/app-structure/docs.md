Dokumentacja i dokumenty ogólnie.

## Folder dokumentów

W folderze `📂 docs` organizujemy ogólne dokumenty aplikacji.

Służy do organizowania przydatnych plików, takich jak dokumentacja, design, architektura, integracje itp.

Wszystko, co jest przydatne dla innych osób również pracujących nad rozwojem aplikacji albo przydaje się przy pracach konserwacyjnych lub rozwojowych.

Należy pamiętać, że zbyt duże pliki binarne mogą bezpowrotnie zanieczyścić i zaśmiecić repozytorium kodu, czyli GIT. Ponieważ każdy zbyt duży plik trafiający do GIT znacząco zwiększa historię zmian, plików wideo, archiwów ZIP oraz wszelkich innych bardzo obszernych dokumentów należy unikać, aby nie obciążać GIT-a i nie powodować problemów w przyszłości.
