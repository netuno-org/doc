## Folder bazy danych

Folder `📂 dbs` służy do przechowywania plików bazy danych Twojej aplikacji.

W przypadku baz danych typu H2 Database wszystkie pliki są generowane automatycznie w tym folderze.

Ten folder jest przydatny do przechowywania wszelkich materiałów związanych z bazą danych, na przykład kopii zapasowych, skryptów,
dumpów, diagramów itp.

Całą dokumentację związaną z bazą danych, która powinna towarzyszyć projektowi aplikacji, zaleca się
organizować w tym folderze.
