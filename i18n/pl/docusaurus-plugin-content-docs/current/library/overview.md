Netuno to platforma low-code do szybkiego tworzenia usług webowych, która ułatwia zarządzanie danymi dzięki zintegrowanemu interfejsowi wizualnemu, zapewniając tworzenie aplikacji webowych o wysokiej wydajności.

Zmniejsza nakład pracy i czas developmentu, a także koszty produkcji w obszarze administracji, zarządzania i przemysłu.

![Struktura Netuno](/docs/assets/introducao1.png)

Dowiedz się, jak Netuno usprawnia Twoje doświadczenie programistyczne, aby programowanie było kreatywne, a nie powtarzalne, zachowując poziom wydajności od developmentu aż po wykonanie:

> Platforma Netuno jest darmowa, [zacznij już teraz](/docs/get-started/installation).

## Formularze i pola

Tworzenie modelu danych jest ułatwione dzięki silnikowi formularzy w środowisku WEB. Definicja formularzy tworzy tabele w bazie danych, a ich pola definiują kolumny. Można sparametryzować typ danych, właściwości pól oraz ich relacje. _Suite_ do budowy w WEB udostępnia wiele funkcjonalności, takich jak zapytania do bazy danych, podgląd modelu encja-asocjacja i inne.

## Zarządzanie dostępem i uprawnieniami

Zarządzanie użytkownikami i ich uprawnieniami jest konfigurowalne w środowisku WEB i dostępne poprzez usługi backendowe w Netuno. Można również kontrolować dostęp per użytkownik i per grupa do formularzy i raportów.

## Biblioteka zasobów

Biblioteka zasobów oferuje szeroki wachlarz gotowych do użycia funkcjonalności. Znaleźć w niej można m.in. integracje z PDF, Excel, Email, Firebase, a także planowanie zadań czy generator raportów z Jasper.

## API Rest

Warstwa komunikacji serwera jest udostępniana przez API REST. Udostępnianie usług przez JSON pozwala Netuno komunikować się z wieloma aplikacjami różnej natury, mogąc na przykład jednocześnie obsługiwać klientów WEB i aplikacje mobilne za pośrednictwem tego samego interfejsu.

## Wielojęzyczna warstwa usług

Pisz usługi w <a href="https://developer.mozilla.org/pt-BR/docs/Web/JavaScript" target="_blank">JavaScript</a>, <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a>, <a href="https://groovy-lang.org/" target="_blank">Groovy</a>, <a href="https://www.jython.org/" target="_blank">Python</a>, <a href="https://www.jruby.org/" target="_blank">Ruby</a>, <a href="https://kotlinlang.org/" target="_blank">Kotlin</a> lub <a href="https://pt.wikipedia.org/wiki/Java_(linguagem_de_programa%C3%A7%C3%A3o)" target="_blank">Java</a> — wszystkie są równie dobre. Netuno usuwa izolację między językami programowania; ta sama aplikacja obsługuje usługi działające jednocześnie w wielu językach, bez zwiększania obciążenia procesora.

## Wiele baz danych

Konfiguruj kilka różnych baz danych i używaj ich jednocześnie. Netuno natywnie obsługuje wiele silników relacyjnych baz danych, takich jak <a href="https://www.h2database.com/html/main.html" target="_blank">H2DataBase</a>, <a href="https://www.postgresql.org/" target="_blank">PostgreSQL</a> i CockroachDB, <a href="https://mariadb.org/" target="_blank">MariaDB (_MySQL_)</a>, Microsoft SQL Server i Oracle. Będziesz mógł stworzyć swoją aplikację, używając na przykład PostgreSQL jako głównej bazy danych i integrując się z innymi bazami danych w MariaDB, a w trakcie projektu przełączyć się na Microsoft SQL Server lub Oracle bez konieczności wprowadzania jakichkolwiek zmian w kodzie.

> Oferuje natywne wsparcie integracji z MongoDB.

## Serverless

Netuno jest także Twoim serwerem aplikacyjnym. Jednym poleceniem uruchom swoją aplikację, bez tracenia czasu na licencje, konfiguracje i dodatkowy development.

## Wydajność w developmentcie i w wykonaniu

Nie musisz uczyć się pracy z nowym oprogramowaniem do tworzenia aplikacji metodą drag and drop ani zapamiętywać interfejsu nowego frameworka. Dzięki możliwości programowania w 6 różnych językach, autogenerowanej warstwie danych i bibliotekom dostępnym do użycia on-the-fly, low-code Netuno jest najlepszym rozwiązaniem na Twoje napięte terminy.

Wykorzystując generatory kodu zoptymalizowane pod wysoką wydajność oraz najnowszą <a href="https://www.graalvm.org/" target="_blank">GraalVM</a>, serwer aplikacyjny staje się niesamowicie szybki, niezależnie od używanego języka.
