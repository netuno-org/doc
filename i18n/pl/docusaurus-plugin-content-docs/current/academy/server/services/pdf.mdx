Przetwarzanie niestandardowych plików PDF.

## Wprowadzenie

Netuno generuje pliki PDF z obsługą obrazów, tabel, czcionek i wielu innych elementów poprzez zasób [PDF](/docs/library/resources/pdf), który zapewnia abstrakcję low-code dla [iTextPDF](https://itextpdf.com/) w różnych językach programowania obsługiwanych przez Netuno.

Aplikacja dostarczana z Netuno o nazwie **demo** (aplikacja demonstracyjna) zawiera wiele przykładów możliwych implementacji kodu w różnych językach, w tym demonstrację eksportu do PDF poprzez usługę `export-pdf`, która znajduje się w:

<PolyglotPath files={[
    `netuno/apps/demo/server/services/samples/%lang%/export-pdf`
]} />

## Inicjalizacja

Najpierw należy utworzyć obiekt, który będzie zawierał kontekst tworzonego nowego dokumentu; domyślnie rozmiar stron to A4.

Podczas tworzenia dokumentu określa się, gdzie zostanie wygenerowany.

Jeśli nic nie zostanie określone, zostanie wygenerowany na wyjściu danych usługi, na przykład:

## Nagłówek HTTP

Aby utworzyć usługę w API REST, która zwraca plik PDF jako wyjście danych, należy dodać w nagłówku parametr `Content-Type` protokołu HTTP.

Przykład określenia zawartości jako PDF:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("pdf")
            `
        },
    ]}
/>

Kod `pdf` jest skrótem dla:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _header.contentType("application/pdf")
            `
        },
    ]}
/>

## Akapit

Dodaje nowy akapit do dokumentu:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                dokumentPdf.add(
                    _pdf.paragraph("Mój tekst tutaj...")
                        .setFontSize(15)
                )
            `
        },
    ]}
/>

Aby dodać akapit w stałej pozycji:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                dokumentPdf.add(
                    dokumentPdf.add(
                        _pdf.paragraph("Mój stały tekst...")
                            .setFixedPosition(100, 500, 200)
                            .setFontSize(15)
                    )
                )
            `
        },
    ]}
/>

W powyższym kodzie, w metodzie `setFixedPosition`, pierwszy parametr to pozycja X (`100`), drugi parametr to pozycja Y (`500`), a trzeci parametr to szerokość (`200`).

**Uwaga:** jeśli Y zostanie ustawione na wartość `0`, oznacza to, że znajduje się na dole strony; aby przejść wyżej, należy zwiększyć wartość Y. Im większa wartość Y, tym wyżej element się pojawi, ale jeśli będzie zbyt wysoka względem długości strony, nie będzie widoczny.

> Dokumentacja ze wszystkimi metodami obiektu [akapitu iText](https://api.itextpdf.com/iText/java/8.0.3/com/itextpdf/layout/element/Paragraph.html).

## Tabela

Można tworzyć tabele, co pozwala przedstawić zestaw danych w bardziej czytelny sposób.

Liczbę kolumn tabeli definiuje się parametrem: `_pdf.table(liczbaKolumn)`

W poniższym przykładzie `liczbaKolumn` to liczba `1`, czyli jedna kolumna.

Ponieważ dodajemy dwie komórki do tabeli, druga komórka przejdzie do następnego wiersza.

Zauważ:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                dokumentPdf.add(
                    _pdf.table(1)
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Osoba")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBorder(_pdf.border("solid", 2))
                                .setBackgroundColor(_pdf.colorRGB(1, 0, 0))
                        )
                        .addCell(
                            _pdf.cell()
                                .add(
                                    _pdf.paragraph("Nikola")
                                        .setFont(helvetica)
                                        .setFontSize(10)
                                )
                                .setBackgroundColor(_pdf.colorGray(0.5))
                        )
                )
            `
        },
    ]}
/>

Metoda `addCell` pozwala wstawić definicję komórek wraz z ich odpowiednią zawartością.

> Dokumentacja ze wszystkimi metodami obiektu [komórki iText](https://api.itextpdf.com/iText/java//8.0.3/com/itextpdf/layout/element/Cell.html).

## Zamykanie i zapisywanie dokumentu

Dokument jest w pełni zapisywany lub generowany dopiero po wywołaniu metody `close`, w następujący sposób:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                dokumentPdf.close()
            `
        },
    ]}
/>

Miejsce generowania dokumentu jest określane podczas inicjalizacji; to właśnie przy inicjalizacji dokumentu definiujemy, gdzie zostanie wygenerowany dokument końcowy — na wyjściu danych usługi (`output`) czy w pliku.

## Odczyt pliku

Aby odczytać dokument PDF, wyodrębniając informacje tekstowe.

Używamy metody `extract`, która pobiera wszystkie dane pliku PDF do obiektu JSON.

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                const danePdf = _pdf.extract(_app.file("plik-1.pdf"))

                _out.json(danePdf)
            `
        },
        {
            lang: 'python',
            code: `
                danePdf = _pdf.extract(_app.file("plik-1.pdf"))

                _out.json(danePdf)
            `
        },
        {
            lang: 'ruby',
            code: `
                danePdf = _pdf.extract(_app.file("plik-1.pdf"))

                _out.json(danePdf)
            `
        },
        {
            lang: 'kotlin',
            code: `
                val danePdf = _pdf.extract(_app.file("plik-1.pdf"))

                _out.json(danePdf)
            `
        },
        {
            lang: 'groovy',
            code: `
                def danePdf = _pdf.extract(_app.file("plik-1.pdf"))

                _out.json(danePdf)
            `
        },
    ]}
/>

Zwrócony JSON ma klucz `content` zawierający całą treść tekstową pliku PDF oraz klucz `metadata` z różnymi właściwościami pliku PDF.

Oto przykład JSON zwróconego przez `extract`:

```json
{
  "content": "Cała treść tekstowa pliku PDF znajduje się tutaj...",
  "metadata":{
    "Content-Type":"application/pdf",
    "dc:format":"application/pdf; version=1.4",
    "dc:title":"Linux 1",
    "pdf:PDFVersion":"1.4",
    "pdf:charsPerPage":"580",
    "pdf:containsDamagedFont":"false",
    "pdf:containsNonEmbeddedFont":"false",
    "pdf:docinfo:producer":"Skia/PDF m125 Google Docs Renderer",
    "pdf:docinfo:title":"Plik 1",
    "pdf:encrypted":"false",
    "xmpTPg:NPages":"3",
    ...
  }
}
```

Istnieje wiele innych danych uzyskiwanych w `metadata`, ale zostały pominięte w `...`, aby przykład nie był zbyt długi.

## Konwersja

Można programowo konwertować PDF na tekst, a nawet na HTML.

### PDF na tekst

Możemy wyodrębnić całą zawartość pliku PDF jako ciągły tekst za pomocą metody:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _pdf.toText(...)
            `
        },
    ]}
/>

Przykład użycia do odczytania pliku w katalogu głównym aplikacji:

<PolyglotCode
    codes={[
        {
            lang: 'javascript',
            code: `
                _out.print(_pdf.toText(_app.file("moj-dokument.pdf")))
            `
        },
    ]}
/>

Lub jeszcze przy użyciu pliku w `storage` aplikacji:

<PolyglotCode
