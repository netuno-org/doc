Netuno jest rozwijany w Javie, dzięki czemu za pomocą Javy możemy tworzyć nowe funkcjonalności.

Możemy na przykład tworzyć nowe usługi natywne lub nawet nowe możliwości programowania low-code, które są
dostępne we wszystkich językach programowania poliglotycznego, takich jak JavaScript, Python, Ruby, Groovy i Kotlin.

W Javie możemy również tworzyć wieloaplikacyjne usługi webowe, które są dostępne we wszystkich aplikacjach Netuno.

Do tworzenia dowolnego rodzaju funkcjonalności można wykorzystać dowolną technikę lub bibliotekę z ekosystemu Javy.

> Zalecamy, aby przed rozpoczęciem tego samouczka mieć podstawową znajomość _Javy_.
