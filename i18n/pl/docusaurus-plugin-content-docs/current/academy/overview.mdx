# Przegląd platformy Netuno

## Wprowadzenie

Witamy w **Netuno**!

Wiemy, że wdrażanie nowych technologii może być wyzwaniem ze względu na dużą liczbę opcji dostępnych na rynku. Netuno powstał, aby rozwiązać ten problem, upraszczając rozwój poprzez połączenie najlepszych narzędzi i rozwiązań w jednym miejscu.

Jesteśmy platformą skoncentrowaną na produktywności. Jednym z największych akceleratorów w Netuno jest brak czasochłonnych procesów kompilacji lub budowania.

Oferujemy płynne i elastyczne doświadczenie programistyczne, umożliwiające korzystanie z różnych języków programowania zintegrowanych z głównymi bazami danych.

Środowisko **low-code** Netuno jest wielojęzyczne, pozwalając wybrać język najlepiej dopasowany do konkretnych potrzeb każdej usługi.

> Nasze motto jest proste: **mniej linii kodu — więcej efektów.**

## Produktywność w pracy

Netuno eliminuje wąskie gardła w rozwoju dzięki następującym filarom:

-  **Bezpieczny wybór narzędzi:** Skracamy czas wyszukiwania i wstępnej konfiguracji. Netuno jest już ustrukturyzowany z najwydajniejszymi dostępnymi obecnie rozwiązaniami.

- **Wielojęzyczna elastyczność:** Pracuj z preferowanym językiem programowania w tym samym ekosystemie, korzystając z szerokiej gamy gotowych zasobów dla każdej konkretnej usługi internetowej.

- **Szybkie tworzenie usług internetowych:** Podejście low-code pozwala sprawnie tworzyć złożone API REST.

- **Bezproblemowa integracja:** Szybko rozwijaj backend i łatwo łącz go z dowolnym frontendem, aplikacjami mobilnymi, portalami korporacyjnymi lub sklepami internetowymi.

- **Aktualizacja w czasie rzeczywistym (Hot Reload):** Szybkość rozwoju wynika również z braku konieczności restartowania serwera. W ekosystemie Netuno nie ma kompilacji ani restartów. Zmiany w kodzie są natychmiastowe i widoczne w czasie rzeczywistym.

* **Sprawność w rozwoju:** Testuj swoje API równocześnie podczas programowania. Zapisz kod w Netuno i od razu wykonaj żądanie w swoim frontendzie.

* **Koncentracja na logice biznesowej:** Pozwól, aby Netuno zadbał o podstawową infrastrukturę i połączenia. Skup się na tym, jak Twój system może dostarczyć więcej wartości użytkownikowi końcowemu.

## Backoffice

Platforma upraszcza proces rozwoju, łącząc tworzenie interfejsów formularzy z automatycznym strukturyzowaniem bazy danych.

To podejście drastycznie skraca krzywą uczenia się, pozwalając programistom skupić się na logice biznesowej, podczas gdy platforma zarządza infrastrukturą.

Eliminuje to konieczność pisania ręcznych skryptów SQL lub tworzenia powtarzalnych ekranów CRUD (tworzenie, odczyt, aktualizacja, usuwanie).


Projektując formularz, jednocześnie modelujesz swoją bazę danych i generujesz kompleksowy interfejs administracyjny.

Netuno dostarcza gotowy do użycia ekosystem administracyjny, który obejmuje:

| Funkcjonalność | Opis |
| :--- | :--- |
| **Relacje** | Automatyczne zarządzanie diagramami, kluczami obcymi i powiązaniami między tabelami. |
| **Wyszukiwanie zaawansowane** | Dopracowane filtry do szybkiego odnajdowania rekordów. |
| **Zarządzanie plikami** | Wbudowane komponenty do przesyłania obrazów i dokumentów. |
| **Eksport** | Ekstrakcja danych w formatach odpowiednich do raportów. |
| **Bezpieczeństwo** | Kontrola profili dostępu i zintegrowane uwierzytelnianie. |

Netuno jest **open source** i pozwala odkrywać cały potencjał narzędzia bezpłatnie i we współpracy, aby realizować złożone zadania z wysoką produktywnością. [Zacznij teraz](/docs/get-started/installation).

## Baza danych

Netuno upraszcza zarządzanie danymi, łącząc tworzenie Backoffice ze strukturą bazy danych. Ta konstrukcja nie wymaga ręcznego pisania złożonych skryptów SQL do tworzenia tabel.

Za pomocą interfejsu wizualnego można zdefiniować pola i relacje, a platforma synchronizuje te definicje z bazą danych, automatycznie generując interfejs administracyjny i diagram danych.

## Diagram danych

Netuno automatycznie generuje dynamiczny diagram przedstawiający model danych Twojej aplikacji. Ta funkcja jest niezbędna do wizualizacji architektury informacji i powiązań między tabelami.

## Zapytania

Netuno udostępnia solidną i intuicyjną konsolę bazy danych, pozwalającą programistom na bezpośrednią, sprawną i uporządkowaną interakcję z danymi.

Można zapisywać złożone lub często używane polecenia, aby mieć do nich szybki dostęp w przyszłości. 
System przechowuje historię wykonanych poleceń, ułatwiając audyt i odzyskiwanie wcześniejszych logik zapytań.

Konsola umożliwia jednoczesne wykonywanie wielu poleceń. Aby oddzielić instrukcje i zapewnić, że Netuno zinterpretuje każdą z nich poprawnie, użyj podwójnego średnika `;;` jako separatora.

## Programowanie low-code i wielojęzyczne


Netuno wyróżnia się elastyczną architekturą, pozwalającą każdemu projektowi na jednoczesne korzystanie z wielu języków programowania.

Można tworzyć wiele niezależnych aplikacji (projektów), a w każdej z nich pisać usługi przy użyciu najpopularniejszych języków rynkowych obsługiwanych przez Netuno.

Platforma automatycznie identyfikuje, którego silnika wykonawczego użyć, na podstawie rozszerzenia pliku utworzonego w folderze usług serwera, na przykład:

- `.js` - JavaScript
- `.py` - Python
- `.rb` - Ruby
- `.kts` - Kotlin Script
- `.groovy` - Groovy
