# Inicjalizacja 

Inicjalizacja aplikacji Demo

Aby rozpocząć ten samouczek, pierwszym krokiem jest uruchomienie serwera aplikacji **Demo** i przygotowanie środowiska programistycznego.


### Uruchom serwer 

Otwórz terminal swojego systemu operacyjnego i przejdź do folderu głównego, w którym zainstalowana jest platforma Netuno (na przykład `📁 /netuno`).

Wykonaj poniższe polecenie, aby uruchomić serwer:

```bash
./netuno server
```

:::info Alternatywny sposób uruchomienia
Jeśli główne polecenie nie działa lub aplikacja Demo nie jest domyślnie ładowana, wymuś uruchomienie, określając parametr aplikacji:
:::

```bash
./netuno server app=demo
```

### Wybierz edytor kodu
Możesz użyć preferowanego edytora kodu do tworzenia zarówno backendu, jak i frontendu swojej aplikacji.

Jeśli jeszcze go nie masz, polecamy następujące darmowe i open source opcje:

- VS Code: <a href="https://code.visualstudio.com/" target="_blank">code.visualstudio.com</a>
- VS Codium: <a href="https://vscodium.com/" target="_blank">vscodium.com</a>
- WebStorm: <a href="https://www.jetbrains.com/webstorm/" target="_blank">jetbrains.com/webstorm</a>


#### Otwórz folder projektu
Po otwarciu edytora kodu znajdź i otwórz katalog aplikacji Demo: `📁 apps/demo`.

Ten folder zawiera wszystkie pliki i konfiguracje nowej aplikacji. Cały rozwój będzie prowadzony wyłącznie w tym katalogu.

### Następne kroki

Gdy serwer działa i pliki są otwarte w edytorze kodu, środowisko jest gotowe. Przejdź do następnego etapu samouczka, aby zacząć poznawać i modyfikować aplikację.
