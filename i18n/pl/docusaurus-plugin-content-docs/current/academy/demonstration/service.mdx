Za pomocą Netuno można tworzyć **_usługi sieciowe_** i budować dowolnego rodzaju złożone **API <a href="https://pt.wikipedia.org/wiki/REST" target="_blank">REST</a>** do integracji danych między systemami.

:::info Czym jest usługa sieciowa?
Usługa sieciowa pozwala systemom wymieniać informacje online w ustandaryzowany sposób. W Netuno każdy plik w `server/services/` automatycznie staje się punktem końcowym dostępnym przez HTTP.
:::

## Dlaczego warto używać usług sieciowych?

Korzystanie z asynchronicznych usług przynosi wyraźne korzyści dla doświadczenia użytkownika:

- **Szybsze ładowanie:** serwer natychmiast dostarcza strukturę wizualną strony, nie czekając na przetworzenie wszystkich danych.
- **Dane dynamiczne na żądanie:** frontend żąda tylko potrzebnych danych, gdy są potrzebne.
- **Integracja między systemami:** usługa utworzona w Netuno może być używana przez dowolną aplikację zewnętrzną (mobilną, inny system webowy itp.).
- **Lepsze doświadczenie użytkownika:** użytkownik nie musi czekać na pełne przetworzenie strony, zanim zobaczy cokolwiek na ekranie.

## Wymagania wstępne

Przed rozpoczęciem upewnij się, że:

- Netuno jest zainstalowane i uruchomione lokalnie.
- Aplikacja `demo` została utworzona zgodnie z opisem w [Tworzenie aplikacji](../app-create).
- W **Zadaniach** i powiązanych **Rejestrach** są zapisane dane (potrzebne, aby odpowiedź nie była pusta).

## Konfiguracja edytora kodu

Aby tworzyć i edytować usługi w Netuno, użyj edytora kodu według własnych preferencji. Polecamy **[Visual Studio Code](https://code.visualstudio.com/download)**, ponieważ jest darmowy, lekki i bardzo intuicyjny, ale każdy edytor zgodny z JavaScript/Python/Groovy będzie działał normalnie.

## Otwieranie aplikacji demo {#abrir-a-aplicacao-demo}

1. Otwórz **Visual Studio Code**.
2. Kliknij ikonę **Pliki** w lewym panelu bocznym.
3. Wybierz **Otwórz folder** (menu Plik > Otwórz folder).
4. Przejdź do folderu instalacyjnego Netuno.
5. Wybierz katalog: **`apps/demo`**
6. Kliknij **Otwórz**.

Struktura folderów aplikacji `demo` zostanie wczytana w lewym panelu.

## Tworzenie usługi

Usługi są przetwarzane po stronie **serwera**. Aby utworzyć nową usługę:

1. W panelu plików rozwiń strukturę, aż znajdziesz folder `server/services/`.
2. Kliknij **prawym przyciskiem myszy** na folderze `services`.
3. Wybierz **Nowy plik** `New File`.
4. Nazwij plik zgodnie z językiem, którego chcesz użyć:

Zaimplementuj usługę, dodając poniższy kod do utworzonego pliku. Ta usługa odpytuje bazę danych i zwraca listę pracowników z łączną liczbą zarejestrowanych godzin w formacie **JSON**.

### Zrozumienie kodu

| Obiekt/Metoda | Opis |
|---|---|
| `_db.query()` | Wykonuje zapytanie SQL i zwraca listę obiektów w formacie klucz-wartość (kolumna → dana). |
| `_val.list()` | Tworzy mutowalną listę do gromadzenia wyników. |
| `_val.map()` | Tworzy obiekt mapowania (klucz-wartość) dla każdego wiersza wyniku. |
| `_out.json()` | Serializuje obiekt do JSON i wysyła odpowiedź na żądania HTTP. |

:::warning Wymagane dane
Upewnij się, że w **Zadaniach** i powiązanych **Rejestrach** są zapisane dane. W przeciwnym razie punkt końcowy zwróci pustą listę `[]`.
:::

## Uruchamianie i testowanie usługi

Gdy Netuno jest uruchomione, otwórz punkt końcowy w przeglądarce:

:::tip Wskazówka dotycząca wyświetlania JSON
Polecamy **[Firefox](https://www.mozilla.org/)** do testowania punktów końcowych bezpośrednio w przeglądarce, ponieważ formatuje i wyświetla odpowiedź JSON w czytelny sposób z podświetlaniem składni. Alternatywnie użyj rozszerzeń takich jak **JSON Viewer** w Chrome lub narzędzi takich jak **[Postman](https://www.postman.com/)** do bardziej zaawansowanych testów.
:::

Oczekiwany wynik będzie podobny do poniższego JSON:

```json
[
  { "imie": "Anna Kowalska", "suma": 12 },
  { "imie": "Karol Nowak", "suma": 28 },
  { "imie": "Jan Kowalski", "suma": 45 }
]
```
