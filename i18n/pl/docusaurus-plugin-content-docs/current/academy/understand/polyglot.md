Netuno jest poliglotą zarówno na poziomie baz danych, jak i kodu programowania, a także na poziomie systemu operacyjnego.

Ta różnorodność zwiększa liczbę opcji jego wykorzystania.

Obsługując różne bazy danych, języki programowania i systemy operacyjne, ułatwia tworzenie oprogramowania, potrafiąc dostosować się do każdej sytuacji, a jednocześnie zapewniając spójne środowisko dla prac rozwojowych.

## Baza danych

Można go wykorzystać do integracji różnych typów baz danych, a nawet do tworzenia oprogramowania w różnych językach programowania w tym samym projekcie.

Integracja różnych baz danych jest dość powszechna przy integracji danych podczas odczytu lub modyfikacji danych w bazie danych innego systemu.

![Logotypy baz danych](/docs/assets/business/databases.jpg "Wiele baz danych")

Netuno obsługuje następujące bazy danych:

- H2 Database
- PostgreSQL
- MariaDB
- MySQL
- Microsoft SQL Server
- Oracle

## Języki programowania

Obsługa różnych języków programowania może nie wydawać się zbyt interesująca w kontekście mieszania języków programowania, ale jest możliwa i nie oznacza, że należy tak robić.

W praktyce często trudno realizować projekty, w których dominująca technologia jest ograniczona do jednego języka programowania, więc trzeba pozyskać osoby wyłącznie kompetentne w tym konkretnym języku programowania.

Dzięki Netuno mamy ostatecznie większą ofertę, w której cała praca nie jest marnowana, jeśli zajdzie potrzeba użycia nowego języka programowania wynikającego ze zmiany strategii, braku kompetentnych techników, chęci zwiększenia zwinności przy tworzeniu czegoś konkretnego lub innych sytuacji, które mogą mieć sens.

Z reguły byłoby to nie do pomyślenia, ponieważ utrzymanie systemu z wieloma językami programowania zaczyna budzić obawy, ale ponieważ jest to low-code, ta obawa przestaje być bardzo istotna, ponieważ:

* Języki programowania są ostatecznie podobne pod względem logiki i algorytmów.
* Język programowania może być inny, ale zasoby Netuno są takie same i są wykorzystywane w ten sam sposób niezależnie od języka.

Tak więc, nawet jeśli technik jest bardzo przyzwyczajony do pracy z jednym językiem programowania, nic nie stoi na przeszkodzie, aby wykonywał prace utrzymaniowe w innym; jeśli będzie musiał znacznie rozszerzyć swoją ingerencję lub nawet coś przerobić, może zdecydować się na tworzenie w swoim preferowanym języku i zintegrować swoje rozwiązanie z językiem już używanym.

![Logotypy języków programowania](/docs/assets/business/languages.jpg "Języki programowania")

Netuno obsługuje tworzenie oprogramowania w następujących językach programowania:

- Groovy
- Java
- JavaScript
- Kotlin
- Python
- Ruby

## Systemy operacyjne

Netuno, pracując z wieloma systemami operacyjnymi i obsługując konfiguracje środowisk, pozwala zapewnić prawidłowe działanie rozwiązań w sposób przekrojowy oraz organizować je w środowiskach deweloperskich, testowych, jakościowych, produkcyjnych i innych.

Zmiana systemu operacyjnego lub środowiska nie ma wpływu na prawidłowe działanie Netuno i aplikacji.

![Logotypy systemów operacyjnych](/docs/assets/business/operationsystems.jpg "Wiele systemów operacyjnych")

Systemy operacyjne obsługiwane przez Netuno to:

* Linux
* Mac OS X
* Windows
