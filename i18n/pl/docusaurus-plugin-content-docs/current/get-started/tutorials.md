# Tutoriale

Poznaj tutoriale platformy Netuno i naucz się w praktyce, jak konfigurować zasoby, modelować dane, tworzyć interfejsy i rozwijać logikę biznesową w backendzie.

Ta strona gromadzi najważniejsze treści dla osób zaczynających przygodę z platformą, a także dla tych, które chcą pogłębić jej wykorzystanie.

## Zanim zaczniesz

Przed rozpoczęciem dowolnego tutorialu sprawdź, czy Twoje środowisko jest gotowe:

- **Netuno zainstalowany** i uruchomiony w środowisku lokalnym lub deweloperskim.
- **Dostęp do panelu administracyjnego** z odpowiednimi uprawnieniami.
- **Zalecana podstawowa wiedza** z zakresu modelowania danych, HTTP i API REST, aby lepiej wykorzystać treści techniczne.

Zapoznaj się z przewodnikiem [Instalacja](./installation) przed kontynuowaniem.

## Zalecana kolejność

Jeśli to Twoje pierwsze doświadczenie z Netuno, postępuj według tej kolejności:

1. Poznaj interfejs graficzny.
2. Naucz się tworzyć formularze i pola.
3. Skonfiguruj relacje między formularzami.
4. Przejdź do uprawnień i grup użytkowników.
5. Odkrywaj zapytania i zasoby backendu zgodnie z potrzebami projektu.

## Backend

Netuno pozwala łączyć low-code z rozwojem backendu w różnych językach i scenariuszach. Poniższe tutoriale pomogą Ci tworzyć integracje, manipulować danymi i wdrażać reguły biznesowe.

### Wymagania wstępne

Przed przejściem do tej sekcji zaleca się znajomość:

- Architektury klient-serwer i protokołu HTTP.
- Struktur danych w JSON.
- Logiki programowania w JavaScript, Python lub innym języku zgodnym z Twoim procesem rozwoju.

:::tip Jak wybrać tutorial

Używaj tutoriali dotyczących **interfejsu graficznego**, gdy celem jest konfigurowanie aplikacji wizualnie, porządkowanie danych i administrowanie zasobami przez interfejs.  
Używaj tutoriali dotyczących **backendu**, gdy konieczne jest tworzenie logiki biznesowej, integracji, uwierzytelniania, automatyzacji lub programowego dostępu do danych.
:::
